id: watcher
title: テストファイルの監視
description: "WDIOテストランナーを--watchフラグとfilesToWatchを使用して実行することで、specファイルやアプリケーションファイルが変更されたときにテストを自動的に再実行します。"
---

WDIOテストランナーを使用すると、作業中のファイルを監視することができます。アプリまたはテストファイルのいずれかを変更すると、テストが自動的に再実行されます。`wdio`コマンドを呼び出す際に`--watch`フラグを追加すると、テストランナーはすべてのテストを実行した後、ファイルの変更を待機します。例：

```sh
wdio wdio.conf.js --watch
```

デフォルトでは、`specs`ファイルの変更のみを監視します。ただし、`wdio.conf.js`にファイルパスのリスト（グロブパターン対応）を含む`filesToWatch`プロパティを設定すると、それらのファイルの変更も監視し、スイート全体を再実行します。これは、アプリケーションコードを変更した際にすべてのテストを自動的に再実行したい場合に便利です。例：

```js
// wdio.conf.js
export const config = {
    // ...
    filesToWatch: [
        // アプリ内のすべてのJSファイルを監視
        './src/app/**/*.js'
    ],
    // ...
}
```

:::info
できる限りテストを並列で実行するようにしてください。E2Eテストは本質的に遅いものです。テストの再実行は、個々のテストの実行時間を短く保てる場合にのみ有用です。時間を節約するため、テストランナーはファイルの変更を待機している間、WebDriverセッションを維持します。一定時間コマンドが実行されなかった場合にセッションが自動的に閉じられないよう、WebDriverバックエンドを変更できることを確認してください。
:::
