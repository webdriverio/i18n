`show-trace` プレーヤーは、[トレースモード](/docs/devtools/wdio/trace-mode)で生成された任意のトレースを WebdriverIO DevTools UI 自体で開きます。これは、オフラインでの再生、レビュー、AI エージェントによる差分比較のための専用の読み取り専用**プレーヤー**モードです。

## `show-trace` — ファーストパーティのプレーヤー

DevTools UI でトレースを開きます：

```sh
show-trace trace-<sessionId>.zip          # インストール後、PATH 上の bin から
npx show-trace trace-<sessionId>.zip      # または npx 経由で
pnpm show-trace trace-<sessionId>.zip     # devtools モノレポから
```

`show-trace` bin は各アダプター（`@wdio/devtools-service`、`@wdio/nightwatch-devtools`、`@wdio/selenium-devtools`）に同梱されているため、いずれかをインストールしたプロジェクトであれば追加の依存関係なしで利用できます。同じ DevTools UI を専用の**プレーヤー**モードで起動し、ブラウザで開きます：

- **アクションリスト**（左）— キャプチャされたコマンドと、その横にある **Metadata** タブ。
- **ブラウザペイン**（中央）— 選択したアクションの時点で再構築されたページ（下記の [DOM タイムトラベル](#trace-player-features)を参照）。トレースにフィルムストリップ/動画が含まれている場合は、**Snapshot / Screencast** トグルで録画された動画に切り替えられます。
- **タイムラインストリップ**（上部）— 実時間の位置に配置されたサムネイルのフィルムストリップと、ドラッグ可能な再生ヘッド付きのスクラブバー。サムネイルをクリックするか、任意の場所をドラッグしてシークします。
- **コントロールバー** — 再生/一時停止、ステップ、速度。
- **ドックタブ**（下部）— **Source**、**Log**、**Console**、**Network**、**Errors**（それぞれ件数のバッジ付き）に加え、プレーヤー専用の **A11y** タブと **Transcript** タブ。**Network** の行をクリックすると、リクエストの詳細（ヘッダー、タイミング、ステータス）が表示されます。
- **キーボードショートカット** — `Space` で再生/一時停止、`←`/`→` でアクション間を移動、`Home`/`End` で最初/最後へジャンプ、`,`/`.` で速度変更、`/` でフィルターにフォーカス、`?` ですべてのショートカットを表示。

> `.zip` のみ受け付けます。同じショートカットはライブダッシュボードでも機能します（`←`/`→` でコマンドリストを移動、`?` でヘルプを表示）。

### トレースプレーヤーの機能

静的なフレーム単位のステップ送りに加えて、プレーヤーは実行内容を再構築し、相互に関連付けます：

- **DOM タイムトラベル** — ブラウザペインは、キャプチャされた DOM ミューテーションストリーム（およびフォームフィールドの状態 — input の `value`、checkbox の `checked`、空に戻されたフィールドを含む）を再生し、スクリーンショットだけでなく、選択したアクションの時点における*実際の* DOM を再構築します。キャプチャされたフレームを持たない時点（アサーション、静的な待機）でも、本当のページ状態が表示されます。
- **A11y タブ + 要素オーバーレイ（「ロケーターを選択」）** — **A11y** タブには、選択したコマンドに対してキャプチャされたアクセシビリティツリー（ロール + アクセシブルネーム）が表示されます。ブラウザクロームで要素オーバーレイを切り替えると、テストが操作したすべての要素が枠で囲まれます。ボックスに**ホバー**すると A11y ツリー内の対応する行がハイライトされ、**クリック**すると堅牢なロケーターがコピーされます。この連携は双方向で、ツリーの行にホバーするとスナップショット内の要素がハイライトされます。
- **Transcript タブ + Copy-for-LLM** — **Transcript** タブには、実行の `transcript.md`（実行順に並んだ、人間/LLM が読める形式の要約）が表示されます。ワンクリックの **Copy** で、トランスクリプトと失敗したコマンドのエラーをまとめ、LLM にそのまま貼り付けられるコンテキストとしてコピーします。
- **タイムラインの入力マーカー** — 各アクションは種類ごとにスクラブバー上にマークされます。キーボード操作は緑のバー、ポインター操作（ヒットポイントを持つ）は青い点、その他は通常の目盛りで表示されるため、操作のリズムを一目で把握できます。
- **Cucumber のネスト** — Cucumber の実行はアクションツリー内で Feature → Scenario → Step としてネストされるため、ステップはそれぞれのシナリオとフィーチャーの下に配置されます。
- **高密度フィルムストリップのスクラブ** — [`filmstrip`](/docs/devtools/wdio/trace-mode#dense-filmstrip--filmstrip) を有効にすると、タイムラインに高密度のフレームが詰め込まれ、アクションごとに 1 フレームずつジャンプするのではなく、滑らかにスクラブできます。

## 他のトレースビューアー

成果物はポータブルで標準的なトレースビューアーのディスク上フォーマットを使用しているため、同じ `.zip`（またはディレクトリ）は互換性のある**スタンドアロンのトレースビューアー**でも開くことができ、同じフォーマットを共有する **Allure レポートの組み込みトレースビューアー**（Allure ≥ 2.35）内でも開けます。以下が表示されます：
- タイミング付きのアクションのタイムライン
- アクションごとのスクリーンショット
- 要素のスナップショット
- ネットワークウォーターフォール
- コンソールイベント

LLM / エージェントで利用する場合は、`transcript.md` を直接読み込んでください。セレクターや値を含むアクションを簡潔な Markdown で表現したものです。

トレースパイプライン（アクションマッピング、スナップショットシリアライザー、NDJSON ライター、zip / ディレクトリライター）は [`@wdio/devtools-core`](https://github.com/webdriverio/devtools/tree/main/packages/core) を介してアダプター間で共有されているため、どのアダプターで生成されたかに関係なく成果物の構造は同一です。詳しくは[クロスフレームワークサポート](/docs/devtools/cross-framework)を参照してください。
