テストが開くすべてのブラウザセッションの完全なコンテキストを確認できます。Metadata タブには各実行の背後にある capabilities、環境、タイミングが表示されるため、ログを掘り下げることなく、何がテストされていたのかを正確に確認できます。

**取得される情報:**
- **セッションの capabilities** - ブラウザ名とバージョン、プラットフォーム、およびネゴシエートされた WebDriver capabilities
- **セッションの詳細** - セッション ID、ベース URL、ビューポートサイズ
- **実行タイミング** - テストの所要時間、ステータス、開始/終了のタイムスタンプ
- **セッションごとのビュー** - 各ブラウザセッション（`browser.reloadSession()` によって作成されたセッションを含む）は個別に保持され、ドロップダウンから選択できます

これは、環境固有の失敗の診断、正しい capabilities が適用されたかの検証、そしてマルチセッションテストがどのように動作したかの把握に非常に役立ちます。
