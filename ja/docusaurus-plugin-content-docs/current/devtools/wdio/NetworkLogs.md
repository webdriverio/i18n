テスト中のすべてのネットワークアクティビティを監視・検査できます。DevTools はすべての HTTP リクエストとレスポンスをキャプチャし、ブラウザの DevTools と同様に、API 呼び出し、リソースの読み込み、ネットワークタイミングを完全に可視化します。

**キャプチャされる内容:**
- **リクエストの詳細** - URL、メソッド、ヘッダー、クエリパラメータ、リクエストボディ
- **レスポンスデータ** - ステータスコード、レスポンスヘッダー、レスポンスボディ、タイミング
- **リソースタイプ** - XHR/Fetch リクエスト、スクリプト、スタイルシート、画像など
- **パフォーマンスメトリクス** - リクエストのタイミング、所要時間、ネットワークウォーターフォール

これは、API の問題のデバッグ、遅いリクエストの特定、データペイロードの検証、そしてテスト中のアプリケーションのネットワーク動作を理解する上で非常に役立ちます。
