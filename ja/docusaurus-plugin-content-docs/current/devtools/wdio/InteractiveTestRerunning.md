description: "ライブブラウザプレビューとコマンドごとのスクリーンショットでテストの実行を確認し、DevTools UIから単一のテストやスイートを再実行します。"
---

ライブブラウザプレビューと、各WebDriverコマンドの実行後に自動的にキャプチャされるスクリーンショットにより、テストの実行をリアルタイムで確認できます。UIにはテスト実行の完全なビジュアルタイムラインが表示され、各ステップにおけるブラウザの正確な状態を確認できます。

最初のテスト実行が完了した後、DevTools UIで任意のテストケースまたはスイートをクリックすると、即座に再実行できます。これにより、テストランナー全体を再起動したりコードを変更したりする必要がなくなり、デバッグサイクルが大幅に高速化されます。

**主な機能:**
- **リアルタイム可視化** - すべてのコマンド（click、toBeExistingなど）の実行後にスクリーンショットを自動キャプチャ
- **ライブブラウザプレビュー** - テスト実行中にアプリケーションの現在の状態を確認
- **コマンドタイムライン** - 各アクションのタイムスタンプ付きの詳細なログを表示
- **インタラクティブな再実行** - 任意のテストまたはスイートをクリックして即座に再実行
- **同一セッションでの実行** - テストは同じブラウザセッションで再実行されるため、より迅速なフィードバックが得られます
- **スクロール可能な履歴** - テスト実行の任意の時点を確認
