## はじめに

[Argos](https://argos-ci.com/?utm_source=webdriverio&utm_medium=partnered&utm_campaign=documentation)は、WebdriverIOとシームレスに統合できる強力なオープンソースのビジュアルテストプラットフォームであり、アップデートを重ねても完璧なユーザーインターフェースを維持する力を高めます。ArgosをWebdriverIOプロジェクトに統合することで、プルリクエストによって導入されたビジュアルの変更を簡単に特定し、意図的な変更を確認し、アプリケーションにおける予期しないリグレッションを防ぐことができます。

### 標準的なビジュアルテストではなくArgosを選ぶ理由

WebdriverIOに組み込まれたビジュアルテストは優れた出発点ですが、Argosは以下の機能を提供することで、さらに一段上のレベルへと引き上げます：

-   **強化されたコラボレーション**: 統合されたレビューワークフローや、GitHubやSlackなどのプラットフォームでの通知といった機能により、Argosは開発者、デザイナー、QAチーム間のコラボレーションをシームレスかつ効率的にします。
-   **スケーラビリティ**: 小規模なプロジェクトでも大規模なアプリケーションでも、Argosは容易にスケールし、さまざまな環境にわたる幅広いビジュアルテストに対応します。
-   **簡素化されたレビュープロセス**: Argosの直感的なインターフェースはビジュアルの変更をグループ化するため、差分のレビューと承認が容易になり、ノイズを減らして重要な変更に集中できます。
-   **包括的なレポート**: 理解しやすくチームと共有しやすい詳細なレポートにより深い洞察が得られ、全員が同じ認識を持てるようになります。

## Argosはどのようにワークフローを強化するのか？

ArgosはWebdriverIOのテストプロセスに直接統合され、複雑さを増すことなくビジュアルテストの機能を強化します。WebdriverIOのテストを実行するたびに、Argosは自動的にスクリーンショットを取得してベースラインと比較し、関連するビジュアルの変更のみをハイライトします。

Argosを使えば、単なるビジュアル差分ツール以上のものが得られます：

-   **インテリジェントなグループ化**: 関連するビジュアルの変更を自動的にグループ化し、問題をすばやく特定して対処できるようにします。
-   **継続的なモニタリング**: Argosはコミットごとに UI を監視するため、ビジュアルのバグが問題になる前に検出して修正できます。
-   **カスタマイズ可能なしきい値**: プロジェクトのニーズに合わせてビジュアルテストの感度を微調整でき、重要な変更についてのみアラートを受け取れます。
