# 最適な使用のための重要な考慮事項

`@wdio/visual-service` の強力な機能を使い始める前に、このツールを最大限に活用するための重要な考慮事項を理解しておくことが不可欠です。以下のポイントは、ベストプラクティスとよくある落とし穴を案内し、正確で効率的なビジュアルテスト結果を得られるよう設計されています。これらの考慮事項は単なる推奨事項ではなく、実際のシナリオでサービスを効果的に活用するために念頭に置いておくべき重要な要素です。

## 比較の性質

-   **知覚的比較：** このモジュールは、人間が色の違いを知覚する方法により近い YIQ 色空間を使用して、画像の知覚的なピクセル比較を行います。一部の項目は [比較オプション](./compare-options) で調整できます。
-   **ブラウザ更新の影響：** Chrome などのブラウザの更新によってフォントのレンダリングが変わる可能性があり、ベースライン画像の更新が必要になる場合があることに注意してください。

## プラットフォームの一貫性

-   **同一プラットフォームでの比較：** スクリーンショットは必ず同じプラットフォーム内で比較してください。例えば、Mac 上の Chrome で撮影したスクリーンショットを、Ubuntu や Windows 上の Chrome で撮影したものと比較してはいけません。
-   **例え：** 簡単に言えば、_「リンゴはリンゴと比較し、リンゴ（Apple）をアンドロイド（Android）と比較しない」_ ということです。

## 不一致率に関する注意

-   **不一致を許容するリスク：** 不一致率を許容する際は注意してください。特に大きなスクリーンショットの場合、不一致を許容することで、ボタンや要素の欠落といった重大な差異を意図せず見逃してしまう可能性があります。

## モバイル画面のシミュレーション

-   **モバイルのシミュレーションにブラウザのリサイズを使用しない：** デスクトップブラウザをリサイズしてモバイルブラウザとして扱い、モバイルの画面サイズをシミュレートしようとしないでください。デスクトップブラウザはリサイズしても、実際のモバイルブラウザのレンダリングを正確に再現することはできません。
-   **比較の真正性：** このツールは、エンドユーザーに実際に表示されるとおりのビジュアルを比較することを目的としています。リサイズしたデスクトップブラウザは、モバイルデバイスでの実際の体験を反映しません。

## ヘッドレスブラウザに対する方針

-   **ヘッドレスブラウザでの使用は非推奨：** このモジュールをヘッドレスブラウザで使用することは推奨されません。その理由は、エンドユーザーはヘッドレスブラウザを操作しないためであり、そのような使用によって発生した問題はサポート対象外となります。
