این آموزش برای افرادی است که از Protractor استفاده می‌کنند و می‌خواهند فریم‌ورک خود را به WebdriverIO منتقل کنند. این آموزش پس از آن آغاز شد که تیم Angular [اعلام کرد](https://github.com/angular/protractor/issues/5502) که Protractor دیگر پشتیبانی نخواهد شد. WebdriverIO تحت تأثیر بسیاری از تصمیمات طراحی Protractor بوده است و به همین دلیل احتمالاً نزدیک‌ترین فریم‌ورک برای مهاجرت است. تیم WebdriverIO از کار تک‌تک مشارکت‌کنندگان Protractor قدردانی می‌کند و امیدوار است که این آموزش انتقال به WebdriverIO را آسان و سرراست کند.

اگرچه دوست داشتیم یک فرآیند کاملاً خودکار برای این کار داشته باشیم، واقعیت متفاوت است. هر کسی تنظیمات متفاوتی دارد و از Protractor به روش‌های مختلفی استفاده می‌کند. هر مرحله را باید بیشتر به عنوان راهنما در نظر گرفت تا یک دستورالعمل گام به گام. اگر در مهاجرت با مشکلی مواجه شدید، در [تماس با ما](https://github.com/webdriverio/codemod/discussions/new) تردید نکنید.

## راه‌اندازی

API های Protractor و WebdriverIO در واقع بسیار شبیه به هم هستند، تا جایی که اکثر دستورات را می‌توان به صورت خودکار از طریق یک [codemod](https://github.com/webdriverio/codemod) بازنویسی کرد.

برای نصب codemod، دستور زیر را اجرا کنید:

```sh
npm install jscodeshift @wdio/codemod
```

## استراتژی

استراتژی‌های مهاجرت زیادی وجود دارد. بسته به اندازه تیم شما، تعداد فایل‌های تست و فوریت مهاجرت، می‌توانید تلاش کنید همه تست‌ها را یکجا یا فایل به فایل تبدیل کنید. با توجه به اینکه Protractor تا نسخه 15 Angular (پایان سال 2022) همچنان نگهداری خواهد شد، هنوز زمان کافی دارید. می‌توانید تست‌های Protractor و WebdriverIO را همزمان اجرا کنید و نوشتن تست‌های جدید را در WebdriverIO آغاز کنید. بسته به بودجه زمانی خود، می‌توانید ابتدا مهاجرت موارد تست مهم را شروع کنید و به تدریج به سراغ تست‌هایی بروید که شاید حتی بتوانید آن‌ها را حذف کنید.

## ابتدا فایل پیکربندی

پس از نصب codemod می‌توانیم تبدیل اولین فایل را آغاز کنیم. ابتدا نگاهی به [گزینه‌های پیکربندی WebdriverIO](configuration) بیندازید. فایل‌های پیکربندی می‌توانند بسیار پیچیده شوند و ممکن است منطقی باشد که فقط بخش‌های ضروری را منتقل کنید و ببینید بقیه چگونه می‌توانند اضافه شوند، زمانی که تست‌های مربوطه‌ای که به گزینه‌های خاصی نیاز دارند در حال مهاجرت هستند.

برای اولین مهاجرت، فقط فایل پیکربندی را تبدیل می‌کنیم و دستور زیر را اجرا می‌کنیم:

```sh
npx jscodeshift -t ./node_modules/@wdio/codemod/protractor ./conf.ts
```

:::info

 ممکن است فایل پیکربندی شما نام متفاوتی داشته باشد، اما اصل کار باید یکسان باشد: مهاجرت را ابتدا با فایل پیکربندی آغاز کنید.

:::

## نصب وابستگی‌های WebdriverIO

مرحله بعدی پیکربندی یک راه‌اندازی حداقلی WebdriverIO است که با مهاجرت از یک فریم‌ورک به فریم‌ورک دیگر، آن را به تدریج گسترش می‌دهیم. ابتدا WebdriverIO CLI را از طریق دستور زیر نصب می‌کنیم:

```sh
npm install --save-dev @wdio/cli
```

سپس ویزارد پیکربندی را اجرا می‌کنیم:

```sh
npx wdio config
```

این ویزارد شما را از طریق چند سؤال راهنمایی می‌کند. برای این سناریوی مهاجرت شما:
- گزینه‌های پیش‌فرض را انتخاب کنید
- توصیه می‌کنیم فایل‌های نمونه را به صورت خودکار تولید نکنید
- یک پوشه متفاوت برای فایل‌های WebdriverIO انتخاب کنید
- و Mocha را به جای Jasmine انتخاب کنید.

:::info چرا Mocha؟
اگرچه ممکن است قبلاً از Protractor همراه با Jasmine استفاده کرده باشید، اما Mocha مکانیزم‌های تلاش مجدد بهتری ارائه می‌دهد. انتخاب با شماست!
:::

پس از این پرسشنامه کوتاه، ویزارد تمام بسته‌های لازم را نصب کرده و آن‌ها را در `package.json` شما ذخیره می‌کند.

## مهاجرت فایل پیکربندی

پس از اینکه یک `conf.ts` تبدیل‌شده و یک `wdio.conf.ts` جدید داریم، اکنون زمان آن رسیده است که پیکربندی را از یک فایل به فایل دیگر منتقل کنیم. مطمئن شوید که فقط کدی را منتقل می‌کنید که برای اجرای همه تست‌ها ضروری است. در مورد ما، تابع hook و timeout فریم‌ورک را منتقل می‌کنیم.

اکنون فقط با فایل `wdio.conf.ts` خود ادامه می‌دهیم و بنابراین دیگر نیازی به هیچ تغییری در پیکربندی اصلی Protractor نخواهیم داشت. می‌توانیم آن تغییرات را برگردانیم تا هر دو فریم‌ورک بتوانند در کنار هم اجرا شوند و بتوانیم هر بار یک فایل را منتقل کنیم.

## مهاجرت فایل تست

اکنون آماده‌ایم تا اولین فایل تست را منتقل کنیم. برای شروع ساده، بیایید با فایلی شروع کنیم که وابستگی زیادی به بسته‌های شخص ثالث یا فایل‌های دیگری مانند PageObjectها ندارد. در مثال ما، اولین فایلی که باید مهاجرت داده شود `first-test.spec.ts` است. ابتدا دایرکتوری‌ای را ایجاد کنید که پیکربندی جدید WebdriverIO فایل‌هایش را در آن انتظار دارد و سپس فایل را به آنجا منتقل کنید:

```sh
mv mkdir -p ./test/specs/
mv test-suites/first-test.spec.ts ./test/specs
```

حالا بیایید این فایل را تبدیل کنیم:

```sh
npx jscodeshift -t ./node_modules/@wdio/codemod/protractor ./test/specs/first-test.spec.ts
```

همین! این فایل آنقدر ساده است که دیگر نیازی به هیچ تغییر اضافی نداریم و می‌توانیم مستقیماً اجرای WebdriverIO را از طریق دستور زیر امتحان کنیم:

```sh
npx wdio run wdio.conf.ts
```

تبریک 🥳 شما همین الان اولین فایل را مهاجرت دادید!

## مراحل بعدی

از این نقطه به بعد، به تبدیل تست به تست و page object به page object ادامه می‌دهید. این احتمال وجود دارد که codemod برای برخی فایل‌ها با خطایی مانند زیر ناموفق شود:

```
ERR /path/to/project/test/testdata/failing_submit.js Transformation error (Error transforming /test/testdata/failing_submit.js:2)
Error transforming /test/testdata/failing_submit.js:2

> login_form.submit()
  ^

The command "submit" is not supported in WebdriverIO. We advise to use the click command to click on the submit button instead. For more information on this configuration, see https://webdriver.io/docs/api/element/click.
  at /path/to/project/test/testdata/failing_submit.js:132:0
```

برای برخی از دستورات Protractor هیچ جایگزینی در WebdriverIO وجود ندارد. در این صورت، codemod به شما توصیه‌هایی برای بازنویسی (refactor) آن ارائه می‌دهد. اگر بیش از حد با چنین پیام‌های خطایی مواجه می‌شوید، با خیال راحت [یک issue ثبت کنید](https://github.com/webdriverio/codemod/issues/new) و درخواست افزودن یک تبدیل خاص را مطرح کنید. اگرچه codemod در حال حاضر اکثر API های Protractor را تبدیل می‌کند، هنوز جای زیادی برای بهبود وجود دارد.

## نتیجه‌گیری

امیدواریم این آموزش شما را کمی در فرآیند مهاجرت به WebdriverIO راهنمایی کند. جامعه کاربری همچنان به بهبود codemod ادامه می‌دهد و در عین حال آن را با تیم‌های مختلف در سازمان‌های گوناگون آزمایش می‌کند. اگر بازخوردی دارید در [ثبت یک issue](https://github.com/webdriverio/codemod/issues/new) تردید نکنید، یا اگر در طول فرآیند مهاجرت با مشکل مواجه شدید، [یک بحث را آغاز کنید](https://github.com/webdriverio/codemod/discussions/new).
