این آموزش برای کسانی است که از Protractor استفاده می‌کنند و می‌خواهند فریمورک خود را به WebdriverIO منتقل کنند. این آموزش پس از آن آغاز شد که تیم Angular [اعلام کرد](https://github.com/angular/protractor/issues/5502) که Protractor دیگر پشتیبانی نخواهد شد. WebdriverIO از بسیاری از تصمیمات طراحی Protractor تأثیر پذیرفته است و به همین دلیل احتمالاً نزدیک‌ترین فریمورک برای مهاجرت به آن است. تیم WebdriverIO از کار تک‌تک مشارکت‌کنندگان Protractor قدردانی می‌کند و امیدوار است این آموزش انتقال به WebdriverIO را آسان و سرراست کند.

اگرچه دوست داشتیم یک فرایند کاملاً خودکار برای این کار داشته باشیم، اما واقعیت چیز دیگری است. هر کسی تنظیمات متفاوتی دارد و از Protractor به روش‌های متفاوتی استفاده می‌کند. هر گام را باید بیشتر به‌عنوان راهنمایی در نظر گرفت تا یک دستورالعمل گام‌به‌گام. اگر در مهاجرت با مشکلی مواجه شدید، در [تماس با ما](https://github.com/webdriverio/codemod/discussions/new) تردید نکنید.

## راه‌اندازی

API‌های Protractor و WebdriverIO در واقع بسیار شبیه به هم هستند، تا جایی که اکثر دستورات را می‌توان به‌صورت خودکار از طریق یک [codemod](https://github.com/webdriverio/codemod) بازنویسی کرد.

برای نصب codemod، دستور زیر را اجرا کنید:

```sh
npm install jscodeshift @wdio/codemod
```

## استراتژی

استراتژی‌های مهاجرت زیادی وجود دارد. بسته به اندازه تیم شما، تعداد فایل‌های تست و فوریت مهاجرت، می‌توانید تلاش کنید همه تست‌ها را یک‌جا یا فایل به فایل تبدیل کنید. با توجه به اینکه Protractor تا نسخه ۱۵ Angular (پایان سال ۲۰۲۲) همچنان نگهداری خواهد شد، هنوز زمان کافی دارید. می‌توانید تست‌های Protractor و WebdriverIO را هم‌زمان اجرا کنید و نوشتن تست‌های جدید را در WebdriverIO آغاز کنید. با توجه به بودجه زمانی خود، سپس می‌توانید ابتدا مهاجرت موارد تست مهم را شروع کنید و به‌تدریج به سراغ تست‌هایی بروید که شاید حتی بتوانید حذفشان کنید.

## ابتدا فایل پیکربندی

پس از نصب codemod، می‌توانیم تبدیل اولین فایل را آغاز کنیم. ابتدا نگاهی به [گزینه‌های پیکربندی WebdriverIO](configuration) بیندازید. فایل‌های پیکربندی می‌توانند بسیار پیچیده شوند و شاید منطقی باشد که فقط بخش‌های ضروری را منتقل کنید و ببینید بقیه را چگونه می‌توان زمانی اضافه کرد که تست‌های مربوطه‌ای که به گزینه‌های خاصی نیاز دارند در حال مهاجرت هستند.

برای اولین مهاجرت، فقط فایل پیکربندی را تبدیل می‌کنیم و دستور زیر را اجرا می‌کنیم:

```sh
npx jscodeshift -t ./node_modules/@wdio/codemod/protractor ./conf.ts
```

:::info

 ممکن است نام فایل پیکربندی شما متفاوت باشد، اما اصل کار باید یکسان باشد: مهاجرت را ابتدا با فایل پیکربندی شروع کنید.

:::

## نصب وابستگی‌های WebdriverIO

گام بعدی، پیکربندی یک راه‌اندازی حداقلی از WebdriverIO است که در حین مهاجرت از یک فریمورک به فریمورک دیگر آن را گسترش می‌دهیم. ابتدا WebdriverIO CLI را از طریق دستور زیر نصب می‌کنیم:

```sh
npm install --save-dev @wdio/cli
```

سپس ویزارد پیکربندی را اجرا می‌کنیم:

```sh
npx wdio config
```

این ویزارد شما را از طریق چند سؤال راهنمایی می‌کند. برای این سناریوی مهاجرت شما:
- گزینه‌های پیش‌فرض را انتخاب کنید
- توصیه می‌کنیم فایل‌های نمونه را به‌صورت خودکار تولید نکنید
- یک پوشه متفاوت برای فایل‌های WebdriverIO انتخاب کنید
- و Mocha را به Jasmine ترجیح دهید.

:::info چرا Mocha؟
اگرچه ممکن است پیش‌تر از Protractor همراه با Jasmine استفاده کرده باشید، اما Mocha مکانیزم‌های تلاش مجدد (retry) بهتری فراهم می‌کند. انتخاب با شماست!
:::

پس از این پرسش‌نامه کوتاه، ویزارد تمام بسته‌های لازم را نصب کرده و آن‌ها را در `package.json` شما ذخیره می‌کند.

## مهاجرت فایل پیکربندی

پس از اینکه یک `conf.ts` تبدیل‌شده و یک `wdio.conf.ts` جدید داریم، اکنون زمان آن رسیده که پیکربندی را از یکی به دیگری منتقل کنیم. مطمئن شوید که فقط کدی را منتقل می‌کنید که برای اجرای همه تست‌ها ضروری است. در مورد ما، تابع hook و timeout فریمورک را منتقل می‌کنیم.

اکنون فقط با فایل `wdio.conf.ts` ادامه می‌دهیم و بنابراین دیگر به هیچ تغییری در پیکربندی اصلی Protractor نیاز نخواهیم داشت. می‌توانیم آن تغییرات را برگردانیم تا هر دو فریمورک بتوانند در کنار هم اجرا شوند و بتوانیم هر بار یک فایل را منتقل کنیم.

## مهاجرت فایل تست

اکنون آماده‌ایم تا اولین فایل تست را منتقل کنیم. برای اینکه ساده شروع کنیم، بیایید با فایلی شروع کنیم که وابستگی زیادی به بسته‌های شخص ثالث یا فایل‌های دیگر مانند PageObjectها ندارد. در مثال ما، اولین فایل برای مهاجرت `first-test.spec.ts` است. ابتدا پوشه‌ای را که پیکربندی جدید WebdriverIO انتظار دارد فایل‌هایش در آن باشند ایجاد کنید و سپس فایل را به آنجا منتقل کنید:

```sh
mv mkdir -p ./test/specs/
mv test-suites/first-test.spec.ts ./test/specs
```

حالا بیایید این فایل را تبدیل کنیم:

```sh
npx jscodeshift -t ./node_modules/@wdio/codemod/protractor ./test/specs/first-test.spec.ts
```

همین! این فایل آن‌قدر ساده است که دیگر به هیچ تغییر اضافه‌ای نیاز نداریم و می‌توانیم مستقیماً WebdriverIO را از طریق دستور زیر اجرا کنیم:

```sh
npx wdio run wdio.conf.ts
```

تبریک می‌گوییم 🥳 شما همین الان اولین فایل را مهاجرت دادید!

## گام‌های بعدی

از این نقطه به بعد، تبدیل را تست به تست و page object به page object ادامه می‌دهید. ممکن است codemod برای برخی فایل‌ها با خطایی مانند زیر شکست بخورد:

```
ERR /path/to/project/test/testdata/failing_submit.js Transformation error (Error transforming /test/testdata/failing_submit.js:2)
Error transforming /test/testdata/failing_submit.js:2

> login_form.submit()
  ^

The command "submit" is not supported in WebdriverIO. We advise to use the click command to click on the submit button instead. For more information on this configuration, see https://webdriver.io/docs/api/element/click.
  at /path/to/project/test/testdata/failing_submit.js:132:0
```

برای برخی دستورات Protractor هیچ جایگزینی در WebdriverIO وجود ندارد. در این حالت، codemod به شما توصیه‌هایی درباره نحوه بازنویسی (refactor) آن ارائه می‌دهد. اگر بیش از حد با چنین پیام‌های خطایی مواجه می‌شوید، با خیال راحت [یک issue ثبت کنید](https://github.com/webdriverio/codemod/issues/new) و درخواست افزودن یک تبدیل خاص را بدهید. اگرچه codemod هم‌اکنون اکثر API‌های Protractor را تبدیل می‌کند، هنوز جای زیادی برای بهبود وجود دارد.

## جمع‌بندی

امیدواریم این آموزش کمی شما را در فرایند مهاجرت به WebdriverIO راهنمایی کند. جامعه کاربری همچنان در حال بهبود codemod است و آن را با تیم‌های مختلف در سازمان‌های مختلف آزمایش می‌کند. اگر بازخوردی دارید، در [ثبت یک issue](https://github.com/webdriverio/codemod/issues/new) تردید نکنید، یا اگر در طول فرایند مهاجرت با مشکل مواجه شدید، [یک بحث را آغاز کنید](https://github.com/webdriverio/codemod/discussions/new).
