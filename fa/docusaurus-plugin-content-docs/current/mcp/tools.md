سرور MCP وب‌درایور‌آی‌او ۲۹ ابزار ارائه می‌دهد که بر اساس عملکرد دسته‌بندی شده‌اند. ابزارهایی که با **فقط مرورگر** مشخص شده‌اند به یک نشست با `platform: "browser"` نیاز دارند. ابزارهایی که با **فقط موبایل** مشخص شده‌اند به `platform: "ios"` یا `platform: "android"` نیاز دارند.

## مدیریت نشست

### `start_session`

یک نشست جدید اتوماسیون مرورگر یا موبایل را آغاز می‌کند. در هر لحظه فقط یک نشست فعال وجود دارد؛ آغاز یک نشست جدید، نشست موجود را می‌بندد.

| پارامتر              | نوع                                                                   | الزامی     | پیش‌فرض          | توضیحات                                                                                                                       |
| ---------------------- | ---------------------------------------------------------------------- | ------------ | ---------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `platform`             | `"browser" \| "ios" \| "android"`                                      | ✓            | —                | پلتفرم نشست                                                                                                                  |
| `provider`             | `"local" \| "browserstack" \| "saucelabs" \| "testmu" \| "testingbot"` | —            | `"local"`        | ارائه‌دهنده نشست                                                                                                                  |
| `browser`              | `"chrome" \| "firefox" \| "edge" \| "safari"`                          | فقط مرورگر | —                | مرورگری که باید اجرا شود                                                                                                                 |
| `browserVersion`       | string                                                                 | —            | آخرین نسخه           | نسخه مرورگر (فقط ارائه‌دهندگان ابری، پیش‌فرض: آخرین نسخه)                                                                           |
| `os`                   | string                                                                 | —            | —                | سیستم‌عامل (فقط ارائه‌دهندگان ابری، مثلاً `"Windows"`، `"OS X"`)                                                               |
| `osVersion`            | string                                                                 | —            | —                | نسخه سیستم‌عامل (فقط ارائه‌دهندگان ابری، مثلاً `"11"`، `"Sequoia"`)                                                                       |
| `headless`             | boolean                                                                | —            | `true`           | اجرای مرورگر به‌صورت headless                                                                                                            |
| `windowWidth`          | number                                                                 | —            | `1920`           | عرض پنجره مرورگر (400–3840)                                                                                                   |
| `windowHeight`         | number                                                                 | —            | `1080`           | ارتفاع پنجره مرورگر (400–2160)                                                                                                  |
| `navigationUrl`        | string                                                                 | —            | —                | URL برای پیمایش پس از شروع                                                                                                 |
| `deviceName`           | string                                                                 | فقط موبایل  | —                | نام دستگاه/امولاتور/شبیه‌ساز                                                                                                    |
| `platformVersion`      | string                                                                 | —            | —                | نسخه سیستم‌عامل (مثلاً `"17.0"`، `"14"`)                                                                                                |
| `appPath`              | string                                                                 | —            | —                | مسیر فایل `.app` / `.apk` / `.ipa`                                                                                                  |
| `app`                  | string                                                                 | —            | —                | URL اپلیکیشن (`bs://...` برای BrowserStack، `storage:filename=` برای Sauce Labs، `lt://...` برای TestMu، app_url برای TestingBot) یا custom_id |
| `automationName`       | `"XCUITest" \| "UiAutomator2"`                                         | —            | خودکار             | درایور اتوماسیون                                                                                                                 |
| `autoGrantPermissions` | boolean                                                                | —            | `true`           | اعطای خودکار مجوزهای اپلیکیشن                                                                                                        |
| `autoAcceptAlerts`     | boolean                                                                | —            | `true`           | پذیرش خودکار هشدارها                                                                                                                |
| `autoDismissAlerts`    | boolean                                                                | —            | `false`          | رد خودکار هشدارها                                                                                                               |
| `appWaitActivity`      | string                                                                 | —            | —                | اکتیویتی اندروید که هنگام اجرا باید منتظر آن ماند                                                                                            |
| `udid`                 | string                                                                 | —            | —                | UDID دستگاه واقعی iOS                                                                                                              |
| `noReset`              | boolean                                                                | —            | —                | حفظ داده‌های اپلیکیشن بین نشست‌ها                                                                                                |
| `fullReset`            | boolean                                                                | —            | —                | حذف نصب اپلیکیشن قبل/بعد از نشست                                                                                                |
| `newCommandTimeout`    | number                                                                 | —            | `300`            | مهلت زمانی دستورات Appium (ثانیه)                                                                                                  |
| `attach`               | boolean                                                                | —            | `false`          | اتصال به Chrome موجود از طریق CDP                                                                                                 |
| `attachConfig`         | object                                                                 | —            | —                | اتصال CDP: `{ port: 9222, host: "localhost" }`                                                                               |
| `appiumConfig`         | object                                                                 | —            | —                | سرور Appium: `{ host, port, path }`                                                                                             |
| `tunnel`               | `boolean \| "external"`                                                | —            | `false`          | مسیریابی تونل محلی (ارائه‌دهندگان ابری). `true` = شروع خودکار، `"external"` = تونل از قبل به‌صورت خارجی در حال اجراست                     |
| `reporting`            | object                                                                 | —            | —                | برچسب‌های گزارش‌دهی ارائه‌دهنده ابری: `{ project, build, session }`                                                                    |
| `trace`                | boolean                                                                | —            | `false`          | فعال‌سازی ضبط trace — یک فایل zip با پسوند `.trace` سازگار با Playwright تولید می‌کند                                                            |
| `region`               | `"us-west-1" \| "eu-central-1" \| "apac-southeast-1"`                  | —            | `"eu-central-1"` | منطقه مرکز داده Sauce Labs                                                                                                     |
| `tunnelName`           | string                                                                 | —            | —                | نام شناسه تونل (برای `tunnel: "external"` الزامی است)                                                                        |
| `capabilities`         | object                                                                 | —            | —                | قابلیت‌های (capabilities) خام اضافی برای ادغام                                                                                              |

```js
// مرورگر Chrome محلی
start_session({ platform: "browser", browser: "chrome" })

// شبیه‌ساز iOS
start_session({ platform: "ios", deviceName: "iPhone 16", platformVersion: "18.0", appPath: "/path/to/app.app" })

// اندروید روی BrowserStack
start_session({ platform: "android", provider: "browserstack", deviceName: "Samsung Galaxy S24", app: "bs://abc123" })

// iOS روی Sauce Labs
start_session({ platform: "ios", provider: "saucelabs", deviceName: "iPhone 15", platformVersion: "17.0", app: "storage:filename=MyApp.ipa" })

// مرورگر روی TestMu
start_session({ platform: "browser", provider: "testmu", browser: "chrome", os: "Windows", osVersion: "11" })

// مرورگر روی TestingBot
start_session({ platform: "browser", provider: "testingbot", browser: "chrome", os: "Windows", osVersion: "11" })

// ارائه‌دهنده ابری با تونل
start_session({ platform: "browser", provider: "browserstack", browser: "chrome", tunnel: true })

// اتصال به Chrome موجود (پس از launch_chrome)
start_session({ platform: "browser", browser: "chrome", attach: true })
```

---

### `close_session`

نشست فعلی را می‌بندد یا از آن جدا می‌شود.

| پارامتر | نوع    | الزامی | پیش‌فرض | توضیحات                                                    |
| --------- | ------- | -------- | ------- | -------------------------------------------------------------- |
| `detach`  | boolean | —        | `false` | قطع اتصال بدون خاتمه دادن (وضعیت اپلیکیشن را در Appium حفظ می‌کند) |

نشست‌هایی که با `noReset: true` آغاز شده‌اند به‌طور پیش‌فرض به‌صورت خودکار جدا می‌شوند.

---

### `launch_chrome`

یک نمونه Chrome با اشکال‌زدایی از راه دور (remote debugging) فعال آماده می‌کند تا `start_session({ attach: true })` بتواند به آن متصل شود. دو حالت دارد:

- `newInstance` (پیش‌فرض): Chrome را در کنار نمونه موجود شما با استفاده از یک پوشه پروفایل جداگانه باز می‌کند؛ نشست فعلی شما دست‌نخورده باقی می‌ماند.
- `freshSession`: Chrome را با یک پروفایل خالی (بدون کوکی، بدون ورود) اجرا می‌کند. از `copyProfileFiles: true` برای انتقال کوکی‌ها و اطلاعات ورود استفاده کنید.

| پارامتر          | نوع                              | الزامی | پیش‌فرض         | توضیحات                                                      |
| ------------------ | --------------------------------- | -------- | --------------- | ---------------------------------------------------------------- |
| `port`             | number                            | —        | `9222`          | پورت اشکال‌زدایی از راه دور                                            |
| `mode`             | `"newInstance" \| "freshSession"` | —        | `"newInstance"` | حالت اجرا                                                      |
| `copyProfileFiles` | boolean                           | —        | `false`         | کپی پروفایل Default کروم (کوکی‌ها، اطلاعات ورود) به نشست اشکال‌زدایی |

پس از موفقیت این ابزار، `start_session({ platform: "browser", browser: "chrome", attach: true })` را فراخوانی کنید.

## پیمایش و تب‌ها

### `navigate`

یک URL را در تب فعلی بارگذاری کرده و منتظر رویداد بارگذاری صفحه می‌ماند. وضعیت صفحه (DOM، محیط اجرای JS) را بازنشانی می‌کند. **فقط مرورگر.**

| پارامتر | نوع   | الزامی | توضیحات        |
| --------- | ------ | -------- | ------------------ |
| `url`     | string | ✓        | URL مقصد پیمایش |

---

### `get_tabs`

همه تب‌های مرورگر را همراه با handle، عنوان، URL و تب فعال فهرست می‌کند. قبل از `switch_tab` برای یافتن handle مقصد از آن استفاده کنید. **فقط مرورگر.**

بدون پارامتر.

---

### `switch_tab`

یک تب مرورگر را بر اساس window handle یا اندیس مبتنی بر صفر فعال می‌کند. همه فراخوانی‌های بعدی ابزارها روی تب تازه فعال‌شده عمل می‌کنند. **فقط مرورگر.**

| پارامتر | نوع   | الزامی | توضیحات                |
| --------- | ------ | -------- | -------------------------- |
| `handle`  | string | —        | window handle مقصد |
| `index`   | number | —        | اندیس تب مبتنی بر صفر (≥ 0)    |

یا `handle` یا `index` را ارائه دهید. handleها را از `get_tabs` یا `wdio://session/current/tabs` دریافت کنید.

---

### `switch_frame`

زمینه فریم WebDriver را با استفاده از انتخابگر CSS/XPath به یک iframe منتقل می‌کند، یا در صورت حذف انتخابگر، به سطح بالا بازمی‌گرداند. تغییرات پایدار هستند؛ همه فراخوانی‌های بعدی `click_element`، `set_value` و `get_elements` تا زمانی که دوباره بازنگردید، درون فریم انتخاب‌شده عمل می‌کنند. تا ۵ ثانیه منتظر iframe می‌ماند. **فقط مرورگر.**

| پارامتر  | نوع   | الزامی | توضیحات                                                                            |
| ---------- | ------ | -------- | -------------------------------------------------------------------------------------- |
| `selector` | string | —        | انتخابگر CSS/XPath برای عنصر iframe. برای بازگشت به فریم سطح بالا آن را حذف کنید. |

```js
// ورود به یک iframe
switch_frame({ selector: "#my-iframe" })

// تعامل با عناصر داخل iframe
click_element({ selector: "button.submit" })

// بازگشت به سطح بالا
switch_frame()
```

## تعامل با عناصر

### `click_element`

منتظر وجود یک عنصر می‌ماند، آن را به محدوده دید اسکرول می‌کند و روی آن کلیک می‌کند. روی مرورگر و موبایل کار می‌کند. در iOS، `tap_element` را ترجیح دهید؛ `click_element` گاهی توسط لایه بومی نادیده گرفته می‌شود.

| پارامتر      | نوع    | الزامی | پیش‌فرض | توضیحات                              |
| -------------- | ------- | -------- | ------- | ---------------------------------------- |
| `selector`     | string  | ✓        | —       | انتخابگر CSS، XPath یا متنی             |
| `scrollToView` | boolean | —        | `true`  | اسکرول عنصر به محدوده دید قبل از کلیک |
| `timeout`      | number  | —        | —       | حداکثر زمان انتظار (میلی‌ثانیه)                       |

---

### `set_value`

یک input یا textarea را پاک کرده و متن داده‌شده را تایپ می‌کند. همیشه محتوای موجود را جایگزین می‌کند.

| پارامتر      | نوع    | الزامی | پیش‌فرض | توضیحات                            |
| -------------- | ------- | -------- | ------- | -------------------------------------- |
| `selector`     | string  | ✓        | —       | انتخابگر CSS، XPath یا متنی           |
| `value`        | string  | ✓        | —       | متنی که باید تایپ شود                           |
| `scrollToView` | boolean | —        | `true`  | اسکرول عنصر به محدوده دید قبل از تایپ |
| `timeout`      | number  | —        | —       | حداکثر زمان انتظار (میلی‌ثانیه)                     |

---

### `scroll`

صفحه را به اندازه تعدادی پیکسل اسکرول می‌کند. **فقط مرورگر.** برای موبایل از `swipe` استفاده کنید.

| پارامتر   | نوع             | الزامی | پیش‌فرض | توضیحات      |
| ----------- | ---------------- | -------- | ------- | ---------------- |
| `direction` | `"up" \| "down"` | ✓        | —       | جهت اسکرول |
| `pixels`    | number           | —        | `500`   | تعداد پیکسل برای اسکرول |

## تحلیل عناصر

### `get_elements`

عناصر قابل تعامل در صفحه فعلی را همراه با انتخابگرهای آماده استفاده برمی‌گرداند. برای آگاهی محیطی، منبع `wdio://session/current/elements` را ترجیح دهید؛ زمانی از این ابزار استفاده کنید که به فیلتر یا صفحه‌بندی نیاز دارید.

| پارامتر           | نوع    | الزامی | پیش‌فرض | توضیحات                                 |
| ------------------- | ------- | -------- | ------- | ------------------------------------------- |
| `inViewportOnly`    | boolean | —        | `false` | فقط عناصر قابل مشاهده در viewport برگردانده شوند       |
| `includeContainers` | boolean | —        | `false` | شامل عناصر نگهدارنده (divها، sectionها) |
| `includeBounds`     | boolean | —        | `false` | شامل مختصات کادر محدودکننده            |
| `limit`             | number  | —        | `0`     | حداکثر تعداد عناصر بازگشتی (0 = نامحدود)      |
| `offset`            | number  | —        | `0`     | تعداد عناصری که رد می‌شوند (صفحه‌بندی)               |

---

### `get_accessibility_tree`

درخت دسترس‌پذیری صفحه را همراه با نقش‌ها، نام‌ها و انتخابگرها برمی‌گرداند. از فیلتر و صفحه‌بندی پشتیبانی می‌کند. **فقط مرورگر.**

| پارامتر | نوع     | الزامی | پیش‌فرض | توضیحات                                                |
| --------- | -------- | -------- | ------- | ---------------------------------------------------------- |
| `limit`   | number   | —        | `0`     | حداکثر تعداد گره‌های بازگشتی (0 = نامحدود)                        |
| `offset`  | number   | —        | `0`     | تعداد گره‌هایی که رد می‌شوند (صفحه‌بندی)                                 |
| `roles`   | string[] | —        | —       | فیلتر بر اساس نقش‌های ARIA، مثلاً `["button", "link", "heading"]` |

## اسکرین‌شات‌ها

### `get_screenshot`

از صفحه یا صفحه‌نمایش فعلی اسکرین‌شات می‌گیرد. یک تصویر کدگذاری‌شده با base64 برمی‌گرداند که به‌طور خودکار تغییر اندازه داده و فشرده می‌شود تا در محدوده context مدل باقی بماند (حداکثر ۱ مگابایت، حداکثر ۲۰۰۰ پیکسل).

بدون پارامتر. برای کشف عناصر، `wdio://session/current/elements` را به اسکرین‌شات ترجیح دهید؛ سریع‌تر است و توکن‌های بسیار کمتری مصرف می‌کند. از اسکرین‌شات‌ها برای تأیید بصری یا اشکال‌زدایی چیدمان استفاده کنید.

## مدیریت کوکی‌ها

### `get_cookies`

همه کوکی‌های نشست فعلی یا یک کوکی خاص را بر اساس نام برمی‌گرداند. **فقط مرورگر.**

| پارامتر | نوع   | الزامی | توضیحات                              |
| --------- | ------ | -------- | ---------------------------------------- |
| `name`    | string | —        | نام کوکی. برای بازگرداندن همه کوکی‌ها آن را حذف کنید. |

---

### `set_cookie`

یک کوکی مرورگر تنظیم می‌کند. مرورگر باید از قبل روی دامنه مقصد باشد — کوکی‌ها را نمی‌توان به‌صورت بین‌دامنه‌ای تنظیم کرد. از آن برای تزریق توکن‌های نشست یا feature flagها بدون گذر از فرایند ورود استفاده کنید. **فقط مرورگر.**

| پارامتر  | نوع                          | الزامی | توضیحات                                |
| ---------- | ----------------------------- | -------- | ------------------------------------------ |
| `name`     | string                        | ✓        | نام کوکی                                |
| `value`    | string                        | ✓        | مقدار کوکی                               |
| `domain`   | string                        | —        | دامنه کوکی (پیش‌فرض: دامنه فعلی) |
| `path`     | string                        | —        | مسیر کوکی (پیش‌فرض: `/`)              |
| `expiry`   | number                        | —        | زمان انقضا به‌صورت Unix timestamp (ثانیه)         |
| `httpOnly` | boolean                       | —        | پرچم HttpOnly                              |
| `secure`   | boolean                       | —        | پرچم Secure                                |
| `sameSite` | `"strict" \| "lax" \| "none"` | —        | ویژگی SameSite                         |

---

### `delete_cookies`

همه کوکی‌ها یا یک کوکی خاص را بر اساس نام حذف می‌کند. **فقط مرورگر.**

| پارامتر | نوع   | الزامی | توضیحات                                        |
| --------- | ------ | -------- | -------------------------------------------------- |
| `name`    | string | —        | نام کوکی برای حذف. برای حذف همه کوکی‌ها آن را حذف کنید. |

## حرکات لمسی (موبایل)

### `tap_element`

`element.tap()` را روی عنصر منطبق فراخوانی می‌کند یا روی مختصات مطلق صفحه ضربه می‌زند. در iOS زمانی که `click_element` نادیده گرفته می‌شود از آن استفاده کنید؛ tap حرکت بومی است که iOS به آن پاسخ می‌دهد. **فقط موبایل.**

| پارامتر  | نوع   | الزامی | توضیحات                                  |
| ---------- | ------ | -------- | -------------------------------------------- |
| `selector` | string | —        | انتخابگر عنصر                             |
| `x`        | number | —        | مختصات X برای ضربه روی صفحه (در صورت نبود انتخابگر) |
| `y`        | number | —        | مختصات Y برای ضربه روی صفحه (در صورت نبود انتخابگر) |

یا `selector` یا مختصات `x`/`y` را ارائه دهید.

---

### `swipe`

یک حرکت swipe تمام‌صفحه انجام می‌دهد. جهت، جهت حرکت محتواست (مثلاً `"up"` یک فهرست را به سمت بالا اسکرول می‌کند). برای اسکرول فراتر از محدوده قابل مشاهده از آن استفاده کنید. برای جابه‌جایی یک عنصر خاص، از `drag_and_drop` استفاده کنید. **فقط موبایل.** برای مرورگرها از `scroll` استفاده کنید.

| پارامتر   | نوع                                  | الزامی | پیش‌فرض        | توضیحات                       |
| ----------- | ------------------------------------- | -------- | -------------- | --------------------------------- |
| `direction` | `"up" \| "down" \| "left" \| "right"` | ✓        | —              | جهت swipe                   |
| `duration`  | number                                | —        | `500`          | مدت زمان swipe (میلی‌ثانیه، 100–5000)     |
| `percent`   | number                                | —        | `0.5` / `0.95` | کسری از صفحه برای swipe (0–1) |

---

### `drag_and_drop`

یک عنصر را به عنصر دیگر یا به مختصات مشخص می‌کشد. **فقط موبایل.**

## تغییر Context (موبایل)

بدون پارامتر.

---

### `switch_context`

در یک اپلیکیشن موبایل هیبریدی، بین contextهای اتوماسیون بومی و webview جابه‌جا می‌شود. پیش از استفاده از انتخابگرهای CSS/XPath درون یک webview جاسازی‌شده الزامی است. **فقط موبایل.**

| پارامتر | نوع   | الزامی | توضیحات                                                    |
| --------- | ------ | -------- | -------------------------------------------------------------- |
| `context` | string | ✓        | نام context، مثلاً `"NATIVE_APP"`، `"WEBVIEW_com.example.app"` |

نام contextهای موجود را از `get_contexts` یا `wdio://session/current/contexts` دریافت کنید.

```js
// ۱. بررسی موارد موجود
get_contexts()
// → { contexts: ["NATIVE_APP", "WEBVIEW_com.example.app"], currentContext: "NATIVE_APP" }

// ۲. ورود به webview برای CSS/XPath
switch_context({ context: "WEBVIEW_com.example.app" })

// ۳. تعامل با عناصر webview با استفاده از انتخابگرهای CSS
click_element({ selector: "#login-button" })

// ۴. بازگشت به حالت بومی برای رابط کاربری بومی
switch_context({ context: "NATIVE_APP" })
```

## ابزارهای کمکی مرورگر

### `emulate_device`

یک دستگاه موبایل یا تبلت را در نشست مرورگر فعلی شبیه‌سازی می‌کند (viewport، DPR، user-agent و رویدادهای لمسی را تنظیم می‌کند). به یک نشست با BiDi فعال نیاز دارد: `start_session({ capabilities: { webSocketUrl: true } })`. **فقط مرورگر.**

| پارامتر | نوع   | الزامی | توضیحات                                                                                                             |
| --------- | ------ | -------- | ----------------------------------------------------------------------------------------------------------------------- |
| `device`  | string | —        | نام پیش‌تنظیم دستگاه (مثلاً `"iPhone 15"`، `"Pixel 7"`). برای فهرست کردن پیش‌تنظیم‌ها آن را حذف کنید. برای بازگرداندن تنظیمات پیش‌فرض دسکتاپ، `"reset"` را ارسال کنید. |

---

### `execute_script`

کد JavaScript را در مرورگر یا دستورات موبایل را از طریق Appium اجرا می‌کند.

| پارامتر | نوع   | الزامی | توضیحات                                                   |
| --------- | ------ | -------- | ------------------------------------------------------------- |
| `script`  | string | ✓        | کد JS (مرورگر) یا دستور Appium مانند `"mobile: pressKey"` |
| `args`    | any[]  | —        | آرگومان‌های ارسالی به اسکریپت یا دستور                     |

**مرورگر:** برای دریافت مقادیر از `return` استفاده کنید.

```javascript
// دریافت عنوان صفحه
execute_script({ script: "return document.title" })

// اسکرول عنصر به محدوده دید
execute_script({ script: "arguments[0].scrollIntoView()", args: ["#my-element"] })
```

**موبایل (Appium):** از نحو `mobile: <command>` استفاده می‌کند.

```javascript
// فشردن کلید بازگشت اندروید
execute_script({ script: "mobile: pressKey", args: [{ keycode: 4 }] })

// فعال‌سازی اپلیکیشن (iOS/اندروید)
execute_script({ script: "mobile: activateApp", args: [{ bundleId: "com.example.app" }] })

// دیپ‌لینک (iOS)
execute_script({ script: "mobile: deepLink", args: [{ url: "myapp://route", bundleId: "com.example.app" }] })
```

## ارائه‌دهندگان ابری

### `list_apps`

اپلیکیشن‌های بارگذاری‌شده در یک ارائه‌دهنده ابری (BrowserStack App Automate، Sauce Labs App Storage، TestMu یا TestingBot Storage) را فهرست می‌کند. اطلاعات احراز هویت مخصوص هر ارائه‌دهنده را از متغیرهای محیطی می‌خواند.

| پارامتر          | نوع                                                        | الزامی | پیش‌فرض          | توضیحات                              |
| ------------------ | ----------------------------------------------------------- | -------- | ---------------- | ---------------------------------------- |
| `provider`         | `"browserstack" \| "saucelabs" \| "testmu" \| "testingbot"` | ✓        | —                | ارائه‌دهنده ابری                           |
| `sortBy`           | `"app_name" \| "uploaded_at"`                               | —        | `"uploaded_at"`  | ترتیب مرتب‌سازی                               |
| `organizationWide` | boolean                                                     | —        | `false`          | (فقط BrowserStack) فهرست همه بارگذاری‌های سازمان |
| `limit`            | number                                                      | —        | `20`             | حداکثر تعداد نتایج                              |
| `region`           | `"us-west-1" \| "eu-central-1" \| "apac-southeast-1"`       | —        | `"eu-central-1"` | منطقه Sauce Labs                        |

```js
// فهرست برای هر چهار ارائه‌دهنده
list_apps({ provider: "browserstack" })
list_apps({ provider: "saucelabs", region: "us-west-1" })
list_apps({ provider: "testmu" })
list_apps({ provider: "testingbot" })
```

### `upload_app`

یک فایل محلی `.apk` یا `.ipa` را در یک ارائه‌دهنده ابری (BrowserStack، Sauce Labs، TestMu یا TestingBot) بارگذاری می‌کند. URL اپلیکیشن را برای استفاده در `start_session` برمی‌گرداند.

| پارامتر  | نوع                                                        | الزامی | پیش‌فرض          | توضیحات                                      |
| ---------- | ----------------------------------------------------------- | -------- | ---------------- | ------------------------------------------------ |
| `provider` | `"browserstack" \| "saucelabs" \| "testmu" \| "testingbot"` | ✓        | —                | ارائه‌دهنده ابری                                   |
| `path`     | string                                                      | ✓        | —                | مسیر مطلق فایل `.apk` یا `.ipa`       |
| `customId` | string                                                      | —        | —                | شناسه سفارشی اختیاری برای ارجاع به اپلیکیشن در آینده |
| `region`   | `"us-west-1" \| "eu-central-1" \| "apac-southeast-1"`       | —        | `"eu-central-1"` | منطقه Sauce Labs                                |

```js
// بارگذاری در هر ارائه‌دهنده
upload_app({ provider: "browserstack", path: "/path/to/app.apk" })
upload_app({ provider: "saucelabs", path: "/path/to/app.ipa", region: "us-west-1" })
upload_app({ provider: "testmu", path: "/path/to/app.apk" })
upload_app({ provider: "testingbot", path: "/path/to/app.apk" })
```
