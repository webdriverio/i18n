به مستندات API وب‌درایور‌آی‌او (WebdriverIO) خوش آمدید. این صفحات شامل مطالب مرجع برای تمام اتصال‌های پروتکل (protocol bindings) پیاده‌سازی‌شده و دستورات کمکی (convenience commands) هستند. دستورات پروتکل، از جمله [WebDriver](/docs/api/webdriver)، [WebDriver Bidi](/docs/api/webdriverBidi) یا دستورات موبایل مانند [Appium](http://appium.io)، دستوراتی هستند که مستقیماً به بک‌اند درایور زیرین ارسال می‌شوند. دستورات کمکی ارائه‌شده توسط شیء [`browser`](/docs/api/browser)، [`element`](/docs/api/element) یا [`mock`](/docs/api/mock) امکان تعامل در سطح بالاتر را فراهم می‌کنند.

:::info
این مستندات مربوط به WebdriverIO __v10__ است. هنوز از v9 استفاده می‌کنید؟ از [مستندات v9](https://v9.webdriver.io) استفاده کنید یا [راهنمای مهاجرت به v10](/docs/v10-migration) را دنبال کنید.
:::
