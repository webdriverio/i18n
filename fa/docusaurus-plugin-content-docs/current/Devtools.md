DevTools یک رابط اشکال‌زدایی قدرتمند مبتنی بر مرورگر برای مشاهده بصری، کنترل و بررسی اجرای تست‌های شما به‌صورت بلادرنگ است. این ابزار با **WebdriverIO**، **Nightwatch.js**، **Selenium WebDriver** (با هر اجراکننده‌ای) و **Python Selenium** کار می‌کند — با همان بک‌اند، همان رابط کاربری و همان زیرساخت ثبت داده‌ها.

## چه امکاناتی فراهم می‌کند

- **اجرای مجدد انتخابی تست‌ها** - روی هر مورد تست یا مجموعه تست کلیک کنید تا فوراً دوباره اجرا شود ([جزئیات](/docs/devtools/wdio/interactive-test-rerunning))
- **حفظ و اجرای مجدد (مقایسه)** - از یک تست ناموفق اسنپ‌شات بگیرید، آن را دوباره اجرا کنید و تفاوت دو اجرا را به‌صورت کنار هم و هم‌تراز بر اساس دستورها مقایسه کنید ([جزئیات](/docs/devtools/wdio/preserve-and-rerun))
- **اشکال‌زدایی بصری** - پیش‌نمایش زنده مرورگر را همراه با اسکرین‌شات‌های خودکار پس از هر دستور مشاهده کنید
- **ردیابی اجرا** - لاگ‌های دقیق دستورها را همراه با برچسب‌های زمانی و نتایج مشاهده کنید
- **نظارت بر شبکه و کنسول** - فراخوانی‌های API و لاگ‌های جاوااسکریپت را بررسی کنید ([شبکه](/docs/devtools/wdio/network-logs) · [کنسول](/docs/devtools/wdio/console-logs))
- **پیمایش به کد** - با TestLens مستقیماً به فایل‌های منبع تست بروید ([جزئیات](/docs/devtools/wdio/testlens))
- **ضبط نشست‌ها** - ویدیوی پیوسته `.webm` از مرورگر، برای هر نشست ([جزئیات](/docs/devtools/wdio/screencast))
- **موبایل** - نشست‌های Appium (مرورگر موبایل، اپلیکیشن‌های بومی و هیبریدی) در حالت زنده و حالت ردیابی ([جزئیات](/docs/devtools/mobile))
- **حالت ردیابی (Trace mode)** - مسیر ثبت بدون رابط گرافیکی (headless) که یک فایل قابل‌حمل `trace.zip` برای بازپخش آفلاین یا استفاده توسط عامل‌های هوشمند تولید می‌کند ([جزئیات](/docs/devtools/wdio/trace-mode))

## نحوه کار

1. تست‌های خود را طبق روال معمول اجرا کنید
2. DevTools به‌طور خودکار یک پنجره مرورگر در آدرس `http://localhost:3000` باز می‌کند
3. رابط کاربری، سلسله‌مراتب تست‌ها، پیش‌نمایش مرورگر، خط زمانی دستورها و لاگ‌ها را به‌صورت بلادرنگ نمایش می‌دهد
4. پس از اتمام تست‌ها، روی هر تست کلیک کنید تا دوباره اجرا شود؛ اجرای مجدد در یک فرایند تست جدید انجام می‌شود و در همان پنجره داشبورد نمایش داده می‌شود

## فریم‌ورک خود را انتخاب کنید

- **[WebDriverIO](/docs/devtools/wdio)** - از `@wdio/devtools-service` همراه با Mocha، Jasmine یا Cucumber استفاده کنید
- **[Nightwatch](/docs/devtools/nightwatch)** - از `@wdio/nightwatch-devtools` بدون هیچ تغییری در کد تست استفاده کنید
- **[Selenium](/docs/devtools/selenium)** - از `@wdio/selenium-devtools` همراه با Mocha، Jest، Cucumber یا اسکریپت‌های ساده Node استفاده کنید
- **[Python Selenium](/docs/devtools/selenium)** - از `selenium-devtools-py` تحت pytest یا یک اسکریپت ساده استفاده کنید (به تب‌های Python مراجعه کنید)
