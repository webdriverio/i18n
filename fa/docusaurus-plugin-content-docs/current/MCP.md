## چه کاری می‌تواند انجام دهد؟

WebdriverIO MCP یک **سرور Model Context Protocol (MCP)** است که به دستیارهای هوش مصنوعی امکان می‌دهد مرورگرهای وب و اپلیکیشن‌های موبایل را خودکارسازی کرده و با آن‌ها تعامل داشته باشند.

### چرا WebdriverIO MCP؟

-   **اولویت با موبایل**: برخلاف سرورهای MCP که فقط از مرورگر پشتیبانی می‌کنند، WebdriverIO MCP از خودکارسازی اپلیکیشن‌های بومی iOS و Android از طریق Appium پشتیبانی می‌کند
-   **انتخابگرهای چندسکویی**: تشخیص هوشمند عناصر به‌طور خودکار چندین استراتژی مکان‌یابی (accessibility ID، XPath، UiAutomator، iOS predicates) تولید می‌کند
-   **اکوسیستم WebdriverIO**: ساخته‌شده بر پایه فریم‌ورک آزموده‌شده WebdriverIO با اکوسیستم غنی از سرویس‌ها و گزارش‌دهنده‌ها

این ابزار یک رابط یکپارچه برای موارد زیر فراهم می‌کند:

-   🖥️ **مرورگرهای دسکتاپ** (Chrome، Firefox، Edge، Safari، با رابط گرافیکی یا headless)
-   📱 **اپلیکیشن‌های موبایل بومی** (شبیه‌سازهای iOS / امولاتورهای Android / دستگاه‌های واقعی از طریق Appium)
-   📳 **اپلیکیشن‌های موبایل هیبریدی** (جابه‌جایی بین زمینه Native و WebView از طریق Appium)
-   ☁️ **دستگاه‌های ابری** (BrowserStack، Sauce Labs، TestMu، ابرهای دستگاه واقعی و مرورگر)

از طریق بسته [`@wdio/mcp`](https://www.npmjs.com/package/@wdio/mcp).

این امکان را به دستیارهای هوش مصنوعی می‌دهد که:

-   **مرورگرها را راه‌اندازی و کنترل کنند** با ابعاد قابل پیکربندی، حالت headless و پیمایش اولیه اختیاری
-   **در وب‌سایت‌ها پیمایش کنند** و با عناصر تعامل داشته باشند (کلیک، تایپ، اسکرول)
-   **محتوای صفحه را تحلیل کنند** از طریق درخت دسترس‌پذیری و تشخیص عناصر قابل مشاهده با پشتیبانی از صفحه‌بندی
-   **اسکرین‌شات بگیرند** که به‌طور خودکار بهینه می‌شوند (تغییر اندازه، فشرده‌سازی تا حداکثر ۱ مگابایت)
-   **کوکی‌ها را مدیریت کنند** برای مدیریت نشست
-   **دستگاه‌های موبایل را کنترل کنند** شامل حرکات لمسی (ضربه، کشیدن، کشیدن و رها کردن)
-   **زمینه را تغییر دهند** در اپلیکیشن‌های هیبریدی بین native و webview
-   **اسکریپت اجرا کنند** - JavaScript در مرورگرها، دستورات موبایل Appium روی دستگاه‌ها
-   **ویژگی‌های دستگاه را مدیریت کنند** مانند چرخش، صفحه‌کلید، موقعیت جغرافیایی
-   و موارد بسیار بیشتر، گزینه‌های [ابزارها](./mcp/tools) و [پیکربندی](./mcp/configuration) را ببینید

:::info

نکته برای اپلیکیشن‌های موبایل
خودکارسازی موبایل نیازمند یک سرور Appium در حال اجرا با درایورهای مناسب نصب‌شده است. برای دستورالعمل‌های راه‌اندازی، [پیش‌نیازها](#prerequisites) را ببینید.

:::

## نصب

ساده‌ترین راه برای استفاده از `@wdio/mcp` از طریق npx و بدون هیچ نصب محلی است:

```sh
npx @wdio/mcp
```

یا آن را به‌صورت سراسری نصب کنید:

```sh
npm install -g @wdio/mcp
```

## استفاده با Claude

برای استفاده از WebdriverIO MCP با Claude، فایل پیکربندی را ویرایش کنید:

```json
{
    "mcpServers": {
        "wdio-mcp": {
            "command": "npx",
            "args": ["-y", "@wdio/mcp"]
        }
    }
}
```

پس از افزودن پیکربندی، محیط اجرای خود را مجدداً راه‌اندازی کنید. ابزارهای WebdriverIO MCP برای وظایف خودکارسازی مرورگر و موبایل در دسترس خواهند بود.

### استفاده با Claude Code

Claude Code به‌طور خودکار سرورهای MCP را تشخیص می‌دهد. می‌توانید آن را در فایل `.claude/settings.json` یا `.mcp.json` پروژه خود پیکربندی کنید.

یا آن را به‌صورت سراسری با اجرای دستور زیر به .claude.json اضافه کنید:
```bash
claude mcp add --transport stdio wdio-mcp -- npx -y @wdio/mcp
```
با اجرای دستور `/mcp` در داخل Claude Code آن را اعتبارسنجی کنید.

## پیش‌نیازها

### خودکارسازی مرورگر

-   **Chrome، Firefox، Edge یا Safari** باید نصب باشد
-   WebdriverIO مدیریت خودکار درایورها را انجام می‌دهد

### خودکارسازی موبایل

#### iOS

1. **Xcode را نصب کنید** از Mac App Store
2. **Xcode Command Line Tools را نصب کنید**:
   ```sh
   xcode-select --install
   ```
3. **Appium را نصب کنید**:
   ```sh
   npm install -g appium
   ```
4. **درایور XCUITest را نصب کنید**:
   ```sh
   appium driver install xcuitest
   ```
5. **سرور Appium را راه‌اندازی کنید**:
   ```sh
   appium
   ```
6. **برای شبیه‌سازها**: برای ایجاد/مدیریت شبیه‌سازها، Xcode → Window → Devices and Simulators را باز کنید
7. **برای دستگاه‌های واقعی**: به UDID دستگاه (شناسه یکتای ۴۰ کاراکتری) نیاز خواهید داشت

#### Android

1. **Android Studio را نصب کنید** و Android SDK را راه‌اندازی کنید
2. **متغیرهای محیطی را تنظیم کنید**:
   ```sh
   export ANDROID_HOME=$HOME/Library/Android/sdk
   export PATH=$PATH:$ANDROID_HOME/emulator
   export PATH=$PATH:$ANDROID_HOME/platform-tools
   ```
3. **Appium را نصب کنید**:
   ```sh
   npm install -g appium
   ```
4. **درایور UiAutomator2 را نصب کنید**:
   ```sh
   appium driver install uiautomator2
   ```
5. **سرور Appium را راه‌اندازی کنید**:
   ```sh
   appium
   ```
6. **یک امولاتور ایجاد کنید** از طریق Android Studio → Virtual Device Manager
7. **امولاتور را راه‌اندازی کنید** پیش از اجرای تست‌ها

## معماری

### نحوه کار

WebdriverIO MCP به‌عنوان پلی بین دستیارهای هوش مصنوعی و خودکارسازی مرورگر/موبایل عمل می‌کند:

```
┌─────────────────┐     MCP Protocol      ┌─────────────────┐
│  Claude Desktop │ ◄──────────────────►  │    @wdio/mcp    │
│  or Claude Code │   (stdio or HTTP)     │     Server      │
└─────────────────┘                       └────────┬────────┘
                                                   │
                                             WebDriverIO API
                                                   │
                    ┌──────────────────────────────┼──────────────────────────────┐
                    │                              │                              │
            ┌───────▼───────┐             ┌───────▼───────┐             ┌───────▼───────┐
            │    Browser    │             │    Appium     │             │   Cloud        │
            │ (local/CDP)   │             │  (iOS/Android)│             │   Providers    │
            └───────────────┘             └───────────────┘             └───────────────┘
```

### مدیریت نشست

-   **مدل تک‌نشستی**: در هر زمان فقط یک نشست مرورگر یا اپلیکیشن می‌تواند فعال باشد
-   **وضعیت نشست** به‌صورت سراسری در میان فراخوانی‌های ابزار حفظ می‌شود
-   **جداسازی خودکار**: نشست‌هایی با وضعیت حفظ‌شده (`noReset: true`) هنگام بستن به‌طور خودکار جدا می‌شوند

### تشخیص عناصر

#### مرورگر (وب)

-   از یک اسکریپت مرورگر بهینه‌شده برای یافتن همه عناصر قابل مشاهده و قابل تعامل استفاده می‌کند
-   عناصر را همراه با انتخابگرهای CSS، شناسه‌ها، کلاس‌ها و اطلاعات ARIA برمی‌گرداند
-   از فیلتر viewport و صفحه‌بندی پشتیبانی می‌کند

#### موبایل (اپلیکیشن‌های بومی)

-   از تجزیه کارآمد سورس صفحه XML استفاده می‌کند (۲ فراخوانی HTTP در مقابل بیش از ۶۰۰ فراخوانی برای کوئری‌های سنتی)
-   دسته‌بندی عناصر مخصوص هر پلتفرم برای Android و iOS
-   چندین استراتژی مکان‌یابی برای هر عنصر تولید می‌کند:
    -   Accessibility ID (چندسکویی، پایدارترین)
    -   Resource ID / ویژگی Name
    -   تطبیق Text / Label
    -   XPath (کامل و ساده‌شده)
    -   UiAutomator (Android) / Predicates (iOS)

## نحو انتخابگرها

سرور MCP از چندین استراتژی انتخابگر پشتیبانی می‌کند. برای مستندات تفصیلی، [انتخابگرها](./mcp/selectors) را ببینید.

### وب (CSS/XPath)

```
# انتخابگرهای CSS
button.my-class
#element-id
[data-testid="login"]

# XPath
//button[@class='submit']
//a[contains(text(), 'Click')]

# انتخابگرهای متنی (مخصوص WebdriverIO)
button=Exact Button Text
a*=Partial Link Text
```

### موبایل (چندسکویی)

```
# Accessibility ID (توصیه‌شده - روی iOS و Android کار می‌کند)
~loginButton

# Android UiAutomator
android=new UiSelector().text("Login")

# iOS Predicate String
-ios predicate string:label == "Login"

# iOS Class Chain
-ios class chain:**/XCUIElementTypeButton[`label == "Login"`]

# XPath (روی هر دو پلتفرم کار می‌کند)
//android.widget.Button[@text="Login"]
//XCUIElementTypeButton[@label="Login"]
```

## ابزارهای موجود

سرور MCP ۲۹ ابزار برای خودکارسازی مرورگر و موبایل فراهم می‌کند. برای مرجع کامل، [ابزارها](./mcp/tools) را ببینید.

| ابزار | پلتفرم | توضیحات |
|------|----------|-------------|
| `start_session` | all | شروع یک نشست مرورگر یا موبایل (محلی یا ارائه‌دهنده ابری) |
| `close_session` | all | بستن یا جدا شدن از نشست فعلی |
| `launch_chrome` | browser | باز کردن Chrome با اشکال‌زدایی از راه دور برای اتصال CDP |
| `navigate` | browser | بارگذاری یک URL در تب فعلی |
| `get_tabs` | browser | فهرست همه تب‌های باز |
| `switch_tab` | browser | تمرکز روی یک تب با handle یا اندیس |
| `switch_frame` | browser | ورود به یک iframe با انتخابگر، یا بازگشت به سطح بالا |
| `click_element` | browser | کلیک روی یک عنصر |
| `set_value` | all | تایپ متن در یک ورودی |
| `scroll` | browser | اسکرول صفحه به بالا یا پایین |
| `get_elements` | all | دریافت عناصر قابل تعامل (با فیلتر + صفحه‌بندی) |
| `get_accessibility_tree` | browser | دریافت درخت دسترس‌پذیری (با فیلتر نقش) |
| `get_screenshot` | all | گرفتن اسکرین‌شات (بهینه‌سازی خودکار) |
| `get_cookies` | browser | دریافت همه کوکی‌ها یا یک کوکی مشخص |
| `set_cookie` | browser | تنظیم یک کوکی مرورگر |
| `delete_cookies` | browser | حذف همه کوکی‌ها یا یک کوکی |
| `emulate_device` | browser | شبیه‌سازی viewport یک دستگاه موبایل/تبلت |
| `execute_script` | all | اجرای JavaScript (مرورگر) یا دستورات Appium (موبایل) |
| `tap_element` | mobile | ضربه روی یک عنصر یا مختصات صفحه |
| `swipe` | mobile | حرکت کشیدن در یک جهت |
| `drag_and_drop` | mobile | کشیدن بین عناصر یا مختصات |
| `get_contexts` | mobile | فهرست زمینه‌های native/webview موجود |
| `switch_context` | mobile | جابه‌جایی بین زمینه‌های native و webview |
| `rotate_device` | mobile | چرخاندن به حالت عمودی یا افقی |
| `hide_keyboard` | mobile | بستن صفحه‌کلید نرم‌افزاری |
| `set_geolocation` | all | جایگزینی مختصات GPS دستگاه |
| `get_app_state` | mobile | دریافت وضعیت چرخه حیات اپلیکیشن |
| `list_apps` | cloud | فهرست اپلیکیشن‌های بارگذاری‌شده (BrowserStack، Sauce Labs، TestMu، TestingBot) |
| `upload_app` | cloud | بارگذاری یک `.apk`/`.ipa` در یک ارائه‌دهنده ابری |

## منابع MCP

علاوه بر ابزارها، سرور وضعیت زنده نشست را به‌صورت منابع MCP در اختیار قرار می‌دهد. برای مرجع کامل، [منابع](./mcp/resources) را ببینید.

| URI منبع | توضیحات |
|-------------|-------------|
| `wdio://sessions` | فهرست همه نشست‌ها |
| `wdio://session/current/elements` | عناصر قابل تعامل (بر اسکرین‌شات ترجیح داده شود) |
| `wdio://session/current/screenshot` | اسکرین‌شات به‌صورت base64 |
| `wdio://session/current/accessibility` | درخت دسترس‌پذیری |
| `wdio://session/current/cookies` | کوکی‌های مرورگر |
| `wdio://session/current/tabs` | تب‌های باز مرورگر |
| `wdio://session/current/contexts` | زمینه‌های موبایل موجود |
| `wdio://session/current/context` | زمینه موبایل فعال |
| `wdio://session/current/app-state/{bundleId}` | وضعیت چرخه حیات اپلیکیشن موبایل |
| `wdio://session/current/geolocation` | جایگزینی فعلی GPS |
| `wdio://session/current/logs` | لاگ‌های نشست (کنسول مرورگر، logcat، crashlog) |
| `wdio://session/current/capabilities` | قابلیت‌های خام WebDriver |
| `wdio://session/current/code` | کد JS تولیدشده WebdriverIO |
| `wdio://session/current/steps` | لاگ مراحل نشست |
| `wdio://session/{sessionId}/code` | کد JS تولیدشده برای نشست قبلی |
| `wdio://session/{sessionId}/steps` | مراحل نشست قبلی |
| `wdio://browserstack/local-binary` | دستورالعمل‌های راه‌اندازی BrowserStack Local |
| `wdio://saucelabs/local-binary` | دستورالعمل‌های راه‌اندازی Sauce Connect Proxy |
| `wdio://testmu/local-binary` | دستورالعمل‌های راه‌اندازی TestMu Tunnel |
| `wdio://testingbot/local-binary` | دستورالعمل‌های راه‌اندازی TestingBot Tunnel |

## مدیریت خودکار

### مجوزها

به‌طور پیش‌فرض، سرور MCP به‌طور خودکار مجوزهای اپلیکیشن را اعطا می‌کند (`autoGrantPermissions: true`)، که نیاز به مدیریت دستی پنجره‌های درخواست مجوز در طول خودکارسازی را از بین می‌برد.

### هشدارهای سیستمی

هشدارهای سیستمی (مانند "Allow notifications?") به‌طور پیش‌فرض به‌صورت خودکار پذیرفته می‌شوند (`autoAcceptAlerts: true`). می‌توان این را طوری پیکربندی کرد که به‌جای آن با `autoDismissAlerts: true` رد شوند.

## انتقال (Transport)

به‌طور پیش‌فرض، سرور روی **stdio** اجرا می‌شود (توسط کلاینت هوش مصنوعی به‌عنوان یک زیرفرایند راه‌اندازی می‌شود). برای کلاینت‌هایی که از MCP مبتنی بر زیرفرایند پشتیبانی نمی‌کنند (llama.cpp، حالت امن Codex)، از **انتقال HTTP** استفاده کنید:

```bash
npx @wdio/mcp --http --port 3000
```

برای گزینه‌های کامل از جمله `--allowedHosts` و `--allowedOrigins`، [انتقال](./mcp/transport) را ببینید.

## بهینه‌سازی عملکرد

سرور MCP برای ارتباط کارآمد با دستیار هوش مصنوعی بهینه شده است:

-   **فرمت TOON**: از Token-Oriented Object Notation برای حداقل مصرف توکن استفاده می‌کند
-   **تجزیه XML**: تشخیص عناصر موبایل از ۲ فراخوانی HTTP استفاده می‌کند (در مقابل بیش از ۶۰۰ فراخوانی به روش سنتی)
-   **فشرده‌سازی اسکرین‌شات**: تصاویر به‌طور خودکار تا حداکثر ۱ مگابایت فشرده می‌شوند
-   **فیلتر viewport**: به‌طور پیش‌فرض فقط عناصر قابل مشاهده برگردانده می‌شوند
-   **صفحه‌بندی**: فهرست‌های بزرگ عناصر را می‌توان برای کاهش حجم پاسخ صفحه‌بندی کرد

## مدیریت خطا

همه ابزارها با مدیریت خطای قدرتمند طراحی شده‌اند:

-   خطاها به‌صورت محتوای متنی برگردانده می‌شوند (هرگز throw نمی‌شوند)، که پایداری پروتکل MCP را حفظ می‌کند
-   پیام‌های خطای توصیفی به تشخیص مشکلات کمک می‌کنند
-   وضعیت نشست حتی زمانی که عملیات‌های جداگانه شکست می‌خورند حفظ می‌شود

## موارد استفاده

### تضمین کیفیت

-   اجرای موارد تست با کمک هوش مصنوعی
-   تست رگرسیون بصری با اسکرین‌شات‌ها
-   ممیزی دسترس‌پذیری از طریق تحلیل درخت دسترس‌پذیری

### استخراج داده از وب

-   پیمایش جریان‌های پیچیده چندصفحه‌ای
-   استخراج داده‌های ساختاریافته از محتوای پویا
-   مدیریت احراز هویت و مدیریت نشست

### تست اپلیکیشن موبایل

-   خودکارسازی تست چندسکویی (iOS + Android)
-   اعتبارسنجی جریان ورود اولیه (onboarding)
-   تست deep linking و پیمایش

### تست یکپارچه‌سازی

-   تست جریان کاری سرتاسری (end-to-end)
-   تأیید یکپارچگی API + UI
-   بررسی‌های سازگاری چندپلتفرمی

## عیب‌یابی

### مرورگر راه‌اندازی نمی‌شود

-   اطمینان حاصل کنید که مرورگر مورد نظر نصب شده است
-   بررسی کنید که هیچ فرایند دیگری از پورت پیش‌فرض اشکال‌زدایی (9222) استفاده نمی‌کند
-   در صورت بروز مشکلات نمایش، حالت headless را امتحان کنید

### اتصال به Appium ناموفق بود

-   تأیید کنید که سرور Appium در حال اجرا است (`appium`)
-   میزبان و پورت Appium را در `appiumConfig` بررسی کنید
-   اطمینان حاصل کنید که درایور مناسب نصب شده است (`appium driver list`)

### مشکلات شبیه‌ساز iOS

-   اطمینان حاصل کنید که Xcode نصب و به‌روز است
-   بررسی کنید که شبیه‌سازها در دسترس هستند (`xcrun simctl list devices`)
-   برای دستگاه‌های واقعی، صحت UDID را تأیید کنید

### مشکلات امولاتور Android

-   اطمینان حاصل کنید که Android SDK به‌درستی پیکربندی شده است
-   تأیید کنید که امولاتور در حال اجرا است (`adb devices`)
-   بررسی کنید که متغیر محیطی `ANDROID_HOME` تنظیم شده باشد
