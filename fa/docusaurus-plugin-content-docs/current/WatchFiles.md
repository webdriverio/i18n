id: watcher
title: نظارت بر فایل‌های تست
description: "اجرای مجدد خودکار تست‌ها هنگام تغییر فایل‌های spec یا فایل‌های برنامه، با اجرای WDIO testrunner همراه با فلگ --watch و filesToWatch."
---

با WDIO testrunner می‌توانید فایل‌ها را در حین کار روی آن‌ها تحت نظارت داشته باشید. اگر چیزی را در برنامه یا در فایل‌های تست خود تغییر دهید، تست‌ها به‌طور خودکار دوباره اجرا می‌شوند. با افزودن فلگ `--watch` هنگام فراخوانی دستور `wdio`، testrunner پس از اجرای همه تست‌ها منتظر تغییرات فایل‌ها می‌ماند، به‌عنوان مثال:

```sh
wdio wdio.conf.js --watch
```

به‌طور پیش‌فرض، فقط تغییرات فایل‌های `specs` شما بررسی می‌شود. با این حال، با تنظیم ویژگی `filesToWatch` در `wdio.conf.js` که شامل فهرستی از مسیرهای فایل است (globbing پشتیبانی می‌شود)، تغییرات این فایل‌ها نیز برای اجرای مجدد کل مجموعه تست بررسی می‌شود. این قابلیت زمانی مفید است که بخواهید پس از تغییر کد برنامه، همه تست‌های خود را به‌طور خودکار دوباره اجرا کنید، به‌عنوان مثال:

```js
// wdio.conf.js
export const config = {
    // ...
    filesToWatch: [
        // نظارت بر تمام فایل‌های JS در برنامه من
        './src/app/**/*.js'
    ],
    // ...
}
```

:::info
سعی کنید تا حد امکان تست‌ها را به‌صورت موازی اجرا کنید. تست‌های E2E ذاتاً کند هستند. اجرای مجدد تست‌ها تنها زمانی مفید است که بتوانید زمان اجرای هر تست را کوتاه نگه دارید. برای صرفه‌جویی در زمان، testrunner نشست‌های WebDriver را در حین انتظار برای تغییرات فایل‌ها فعال نگه می‌دارد. مطمئن شوید که بک‌اند WebDriver شما قابل تنظیم است تا در صورت عدم اجرای هیچ دستوری پس از مدت زمان مشخص، نشست را به‌طور خودکار نبندد.
:::
