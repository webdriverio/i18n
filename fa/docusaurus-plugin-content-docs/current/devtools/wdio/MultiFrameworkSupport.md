---

DevTools به‌طور خودکار با Mocha، Jasmine و Cucumber کار می‌کند و نیازی به هیچ پیکربندی مخصوص فریم‌ورک ندارد. کافی است سرویس را به پیکربندی WebDriverIO خود اضافه کنید تا همه قابلیت‌ها، صرف‌نظر از فریم‌ورک تستی که استفاده می‌کنید، به‌طور یکپارچه کار کنند.

**فریم‌ورک‌های پشتیبانی‌شده:**
- **Mocha** - اجرا در سطح تست و مجموعه (suite) با فیلتر grep
- **Jasmine** - یکپارچگی کامل با فیلتر مبتنی بر grep
- **Cucumber** - اجرا در سطح سناریو و مثال (example) با هدف‌گیری به‌صورت feature:line

همان رابط اشکال‌زدایی، قابلیت اجرای مجدد تست‌ها و امکانات بصری‌سازی به‌طور یکسان در همه فریم‌ورک‌ها کار می‌کنند.

## پیکربندی

```js
// wdio.conf.js
export const config = {
    framework: 'mocha', // یا 'jasmine' یا 'cucumber'
    services: ['devtools'],
    // ...
};
```
