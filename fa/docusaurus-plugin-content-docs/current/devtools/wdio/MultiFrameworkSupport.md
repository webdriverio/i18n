---

DevTools به‌طور خودکار با Mocha، Jasmine و Cucumber کار می‌کند و به هیچ پیکربندی مخصوص فریم‌ورک نیاز ندارد. کافی است این سرویس را به پیکربندی WebDriverIO خود اضافه کنید تا تمام قابلیت‌ها، صرف‌نظر از فریم‌ورک تستی که استفاده می‌کنید، به‌صورت یکپارچه کار کنند.

**فریم‌ورک‌های پشتیبانی‌شده:**
- **Mocha** - اجرا در سطح تست و مجموعه تست (suite) همراه با فیلتر grep
- **Jasmine** - یکپارچگی کامل همراه با فیلتر مبتنی بر grep
- **Cucumber** - اجرا در سطح سناریو و مثال (example) همراه با هدف‌گیری به‌صورت feature:line

همان رابط اشکال‌زدایی، قابلیت اجرای مجدد تست‌ها و ویژگی‌های بصری‌سازی، در تمام فریم‌ورک‌ها به‌طور یکسان کار می‌کنند.

## پیکربندی

```js
// wdio.conf.js
export const config = {
    framework: 'mocha', // یا 'jasmine' یا 'cucumber'
    services: ['devtools'],
    // ...
};
```
