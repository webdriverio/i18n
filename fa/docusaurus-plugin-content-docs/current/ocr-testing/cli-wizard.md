با استفاده از جادوگر CLI سرویس OCR می‌توانید بدون اجرای تست، بررسی کنید که کدام متن‌ها در یک تصویر قابل پیدا شدن هستند. تنها چیزهایی که لازم است عبارتند از:

-   `@wdio/ocr-service` را به‌عنوان یک وابستگی نصب کرده باشید، به [شروع به کار](./getting-started) مراجعه کنید
-   تصویری که می‌خواهید پردازش کنید

سپس دستور زیر را برای شروع جادوگر اجرا کنید

```sh
npx ocr-service
```

این دستور جادوگری را شروع می‌کند که شما را در مراحل انتخاب یک تصویر و استفاده از یک haystack به‌همراه حالت پیشرفته راهنمایی می‌کند. سؤالات زیر پرسیده می‌شوند

## چگونه می‌خواهید فایل را مشخص کنید؟

گزینه‌های زیر قابل انتخاب هستند

-   استفاده از یک «مرورگر فایل»
-   وارد کردن دستی مسیر فایل

### استفاده از یک «مرورگر فایل»

جادوگر CLI گزینه‌ای برای استفاده از یک «مرورگر فایل» جهت جستجوی فایل‌ها در سیستم شما فراهم می‌کند. این مرورگر از پوشه‌ای که دستور را در آن اجرا می‌کنید شروع می‌شود. پس از انتخاب یک تصویر (با استفاده از کلیدهای جهت‌نما و کلید ENTER) به سؤال بعدی خواهید رفت

### وارد کردن دستی مسیر فایل

این یک مسیر مستقیم به فایلی در جایی از دستگاه محلی شماست

### آیا می‌خواهید از یک haystack استفاده کنید؟

در اینجا می‌توانید ناحیه‌ای را که باید پردازش شود انتخاب کنید. این کار می‌تواند فرآیند را سریع‌تر کند یا مقدار متنی را که موتور OCR ممکن است پیدا کند کاهش دهد/محدود کند. باید داده‌های `x`، `y`، `width` و `height` را بر اساس سؤالات زیر وارد کنید:

## آیا می‌خواهید از حالت پیشرفته استفاده کنید؟

حالت پیشرفته شامل ویژگی‌های اضافی مانند موارد زیر خواهد بود:

-   تنظیم کنتراست
-   موارد بیشتر در آینده
