گزارش‌گر بصری (Visual Reporter) یک ویژگی جدید است که در `@wdio/visual-service` و از نسخه [v5.2.0](https://github.com/webdriverio/visual-testing/releases/tag/%40wdio%2Fvisual-service%405.2.0) معرفی شده است. این گزارش‌گر به کاربران امکان می‌دهد گزارش‌های تفاوت JSON تولیدشده توسط سرویس تست بصری را به‌صورت بصری مشاهده کرده و آن‌ها را به قالبی خوانا برای انسان تبدیل کنند. این ابزار با فراهم کردن یک رابط گرافیکی برای بررسی خروجی، به تیم‌ها کمک می‌کند تا نتایج تست بصری را بهتر تحلیل و مدیریت کنند.

برای استفاده از این ویژگی، اطمینان حاصل کنید که پیکربندی لازم برای تولید فایل `output.json` را دارید. این سند شما را در راه‌اندازی، اجرا و درک گزارش‌گر بصری راهنمایی می‌کند.

# پیش‌نیازها

پیش از استفاده از گزارش‌گر بصری، مطمئن شوید که سرویس تست بصری را برای تولید فایل‌های گزارش JSON پیکربندی کرده‌اید:

```ts
export const config = {
    // ...
    services: [
        [
            "visual",
            {
                createJsonReportFiles: true, // فایل output.json را تولید می‌کند
            },
        ],
    ],
};
```

برای دستورالعمل‌های راه‌اندازی دقیق‌تر، به [مستندات تست بصری](./) WebdriverIO یا [`createJsonReportFiles`](./service-options.md#createjsonreportfiles-new) مراجعه کنید.

# نصب

برای نصب گزارش‌گر بصری، آن را با استفاده از npm به‌عنوان وابستگی توسعه به پروژه خود اضافه کنید:

```bash
npm install @wdio/visual-reporter --save-dev
```

این کار تضمین می‌کند که فایل‌های لازم برای تولید گزارش از تست‌های بصری شما در دسترس باشند.

# استفاده

## ساخت گزارش بصری

پس از اجرای تست‌های بصری و تولید فایل `output.json`، می‌توانید گزارش بصری را با استفاده از CLI یا پرسش‌های تعاملی بسازید.

### استفاده از CLI

می‌توانید با اجرای دستور CLI زیر گزارش را تولید کنید:

```bash
npx wdio-visual-reporter --jsonOutput=<path-to-output.json> --reportFolder=<path-to-store-report> --logLevel=debug
```

#### گزینه‌های الزامی:

-   `--jsonOutput`: مسیر نسبی فایل `output.json` که توسط سرویس تست بصری تولید شده است. این مسیر نسبت به دایرکتوری‌ای است که دستور را از آن اجرا می‌کنید.
-   `--reportFolder`: دایرکتوری نسبی که گزارش تولیدشده در آن ذخیره خواهد شد. این مسیر نیز نسبت به دایرکتوری‌ای است که دستور را از آن اجرا می‌کنید.

#### گزینه‌های اختیاری:

-   `--logLevel`: آن را روی `debug` تنظیم کنید تا لاگ‌های دقیق دریافت کنید؛ این گزینه به‌ویژه برای عیب‌یابی مفید است.

#### مثال

```bash
npx wdio-visual-reporter --jsonOutput=/path/to/output.json --reportFolder=/path/to/report --logLevel=debug
```

این دستور گزارش را در پوشه مشخص‌شده تولید کرده و بازخوردی در کنسول ارائه می‌دهد. برای مثال:

```bash
✔ Build output copied successfully to "/path/to/report".
⠋ Prepare report assets...
✔ Successfully generated the report assets.
```

#### مشاهده گزارش

:::warning
باز کردن مستقیم `path/to/report/index.html` در مرورگر **بدون ارائه آن از طریق یک سرور محلی** کار **نخواهد** کرد.
:::

برای مشاهده گزارش، باید از یک سرور ساده مانند [sirv-cli](https://www.npmjs.com/package/sirv-cli) استفاده کنید. می‌توانید سرور را با دستور زیر راه‌اندازی کنید:

```bash
npx sirv-cli /path/to/report --single
```

این دستور لاگ‌هایی مشابه نمونه زیر تولید می‌کند. توجه داشته باشید که شماره پورت ممکن است متفاوت باشد:

```logs
  Your application is ready~! 🚀

  - Local:      http://localhost:8080
  - Network:    Add `--host` to expose

────────────────── LOGS ──────────────────
```

اکنون می‌توانید با باز کردن URL ارائه‌شده در مرورگر خود، گزارش را مشاهده کنید.

### استفاده از پرسش‌های تعاملی

به‌عنوان جایگزین، می‌توانید دستور زیر را اجرا کرده و به پرسش‌ها پاسخ دهید تا گزارش تولید شود:

```bash
npx @wdio/visual-reporter
```

پرسش‌ها شما را در ارائه مسیرها و گزینه‌های لازم راهنمایی می‌کنند. در پایان، پرسش تعاملی از شما می‌پرسد که آیا می‌خواهید سروری برای مشاهده گزارش راه‌اندازی کنید یا خیر. اگر راه‌اندازی سرور را انتخاب کنید، ابزار یک سرور ساده را اجرا کرده و یک URL را در لاگ‌ها نمایش می‌دهد. می‌توانید این URL را در مرورگر خود باز کنید تا گزارش را مشاهده کنید.

# نمونه گزارش

برای دیدن نمونه‌ای از ظاهر گزارش، از [نسخه نمایشی ما در GitHub Pages](https://webdriverio.github.io/visual-testing/) دیدن کنید.

# درک گزارش بصری

گزارش‌گر بصری نمایی سازمان‌یافته از نتایج تست بصری شما ارائه می‌دهد. برای هر اجرای تست، می‌توانید:

-   به‌راحتی بین موارد تست جابه‌جا شوید و نتایج تجمیع‌شده را ببینید.
-   فراداده‌هایی مانند نام تست‌ها، مرورگرهای استفاده‌شده و نتایج مقایسه را بررسی کنید.
-   تصاویر تفاوت را مشاهده کنید که نشان می‌دهند تفاوت‌های بصری در کجا شناسایی شده‌اند.

این نمایش بصری تحلیل نتایج تست را ساده‌تر می‌کند و شناسایی و رفع رگرسیون‌های بصری را آسان‌تر می‌سازد.
