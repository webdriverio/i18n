Se dina tester köras i realtid med live-förhandsvisningar i webbläsaren och automatiska skärmdumpar som tas efter varje WebDriver-kommando. Gränssnittet visar en komplett visuell tidslinje över testkörningen och visar exakt webbläsarens tillstånd vid varje steg.

När din första testkörning är klar kan du klicka på valfritt testfall eller valfri svit i DevTools-gränssnittet för att köra om det direkt. Du behöver då inte starta om hela testkörningen eller ändra din kod, vilket gör felsökningen betydligt snabbare.

**Huvudfunktioner:**
- **Visualisering i realtid** - Automatisk skärmdump efter varje kommando (click, toBeExisting osv.)
- **Live-förhandsvisning i webbläsaren** - Se applikationens aktuella tillstånd under testkörningen
- **Kommandotidslinje** - Visa detaljerade loggar med tidsstämplar för varje åtgärd
- **Interaktiv omkörning** - Klicka på valfritt test eller valfri svit för att köra om det direkt
- **Körning i samma session** - Tester körs om i samma webbläsarsession för snabbare återkoppling
- **Skrollbar historik** - Granska valfri tidpunkt i testkörningen
