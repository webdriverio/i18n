TestLens erbjuder intelligent kodnavigering mellan DevTools-gränssnittet och dina testkällfiler. Klicka på valfritt test i gränssnittet för att hoppa direkt till testets definition i din kodredigerare, komplett med exakta radnummer.

**Så fungerar det:**
- **Visuell testhierarki** - Se din teststruktur (sviter, tester, scenarier) i en trädvy
- **Källmappning** - Varje test länkar till sin exakta plats i dina källfiler
- **Navigering med ett klick** - Klicka på valfritt test för att öppna det i din redigerare
- **Redigerarintegration** - Fungerar med populära kodredigerare via file:line-protokoll

Denna sömlösa koppling mellan gränssnitt och kod snabbar upp felsökningen genom att eliminera manuell kodsökning när du undersöker misslyckade tester.
