Beobachten Sie die Ausführung Ihrer Tests in Echtzeit mit Live-Browservorschauen und automatischen Screenshots, die nach jedem WebDriver-Befehl aufgenommen werden. Die Oberfläche zeigt eine vollständige visuelle Zeitleiste Ihrer Testausführung und stellt den genauen Browserzustand bei jedem Schritt dar.

Nach Abschluss Ihres ersten Testlaufs können Sie in der DevTools-Oberfläche auf einen beliebigen Testfall oder eine beliebige Suite klicken, um diese sofort erneut auszuführen. Dadurch müssen Sie weder Ihren gesamten Testrunner neu starten noch Ihren Code ändern, was Debugging-Zyklen erheblich beschleunigt.

**Hauptfunktionen:**
- **Echtzeit-Visualisierung** - Automatische Screenshot-Aufnahme nach jedem Befehl (click, toBeExisting usw.)
- **Live-Browservorschau** - Sehen Sie den aktuellen Zustand Ihrer Anwendung während der Testausführung
- **Befehls-Zeitleiste** - Zeigen Sie detaillierte Logs mit Zeitstempeln für jede Aktion an
- **Interaktives erneutes Ausführen** - Klicken Sie auf einen beliebigen Test oder eine Suite, um diese sofort erneut auszuführen
- **Gleiches Dashboard-Fenster** - Erneute Ausführungen starten einen neuen Testprozess und werden in das bestehende Dashboard-Fenster übertragen, ohne neue Tabs zu öffnen
- **Scrollbarer Verlauf** - Überprüfen Sie jeden beliebigen Zeitpunkt der Testausführung
