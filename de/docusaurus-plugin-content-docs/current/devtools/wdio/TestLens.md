---

TestLens bietet eine intelligente Code-Navigation zwischen der DevTools-Oberfläche und Ihren Test-Quelldateien. Klicken Sie auf einen beliebigen Test in der Oberfläche, um direkt zur Definition dieses Tests in Ihrem Code-Editor zu springen, inklusive exakter Zeilennummern.

**So funktioniert es:**
- **Visuelle Testhierarchie** - Sehen Sie Ihre Teststruktur (Suites, Tests, Szenarien) in einer Baumansicht
- **Source Mapping** - Jeder Test verweist auf seine exakte Position in Ihren Quelldateien
- **Navigation mit einem Klick** - Klicken Sie auf einen beliebigen Test, um ihn in Ihrem Editor zu öffnen
- **Editor-Integration** - Funktioniert mit gängigen Code-Editoren über file:line-Protokolle

Diese nahtlose Verbindung zwischen Oberfläche und Code beschleunigt das Debugging, da die manuelle Suche im Code bei der Untersuchung von Testfehlern entfällt.
