TestLens bietet eine intelligente Code-Navigation zwischen der DevTools-Oberfläche und Ihren Testquelldateien. Klicken Sie auf einen beliebigen Test oder Befehl in der Oberfläche, um dessen Quellcode an der exakten Zeile im **Source**-Tab des Dashboards zu öffnen, und öffnen Sie die Datei von dort aus in VS Code.

**So funktioniert es:**
- **Visuelle Testhierarchie** - Sehen Sie Ihre Teststruktur (Suites, Tests, Szenarien) in einer Baumansicht
- **Source Mapping** - Jeder Test verweist auf seine exakte Position in Ihren Quelldateien
- **Navigation mit einem Klick** - Klicken Sie auf einen beliebigen Test oder Befehl, um dessen Quellcodezeile im **Source**-Tab anzuzeigen
- **Editor-Link** - Der Link **Open in editor** im Source-Tab öffnet die Datei an dieser Zeile in VS Code (`vscode://file/...`)

Diese nahtlose Verbindung zwischen Oberfläche und Code beschleunigt das Debugging, da die manuelle Suche im Code bei der Untersuchung fehlgeschlagener Tests entfällt.
