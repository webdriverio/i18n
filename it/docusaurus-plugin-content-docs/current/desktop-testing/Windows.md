title: Windows
description: "Scopri lo stato attuale dell'automazione delle applicazioni Windows native con WebdriverIO e perché non è ancora disponibile un driver stabile."
---

Purtroppo al momento non esiste un driver stabile per l'automazione delle applicazioni Windows. Anche se Appium mantiene un [Windows Driver](https://github.com/appium/appium-windows-driver) basato sul [server WinAppDriver](https://github.com/microsoft/WinAppDriver) di Microsoft, non ne consigliamo l'utilizzo, dato che Microsoft ha smesso di mantenere il server e ci sono molti [bug noti](https://github.com/search?q=repo%3Amicrosoft%2FWinAppDriver+webdriverio&type=issues).

Se qualcuno conosce un modo per automatizzare le applicazioni Windows, faccelo sapere su [Discord](https://discord.webdriver.io).
