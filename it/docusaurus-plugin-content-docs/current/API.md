Benvenuto nella documentazione API di WebdriverIO. Queste pagine contengono materiale di riferimento per tutti i binding di protocollo implementati e i comandi di utilità. I comandi di protocollo, inclusi [WebDriver](/docs/api/webdriver), [WebDriver Bidi](/docs/api/webdriverBidi) o comandi mobile come [Appium](http://appium.io), sono comandi che vengono inviati direttamente al backend del driver sottostante. I comandi di utilità forniti dagli oggetti [`browser`](/docs/api/browser), [`element`](/docs/api/element) o [`mock`](/docs/api/mock) offrono un'interattività di livello superiore.

:::info
Questa è la documentazione per WebdriverIO __v10__. Sei ancora alla v9? Usa la [documentazione v9](https://v9.webdriver.io) oppure segui la [guida alla migrazione alla v10](/docs/v10-migration).
:::

Assicurati di aver compreso il modo in cui scriviamo questa documentazione consultando la sezione [Contributing](https://github.com/webdriverio/webdriverio/blob/main/CONTRIBUTING.md).
