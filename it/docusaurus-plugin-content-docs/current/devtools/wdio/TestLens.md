TestLens offre una navigazione intelligente del codice tra l'interfaccia di DevTools e i file sorgente dei tuoi test. Fai clic su qualsiasi test nell'interfaccia per passare direttamente alla definizione di quel test nel tuo editor di codice, con i numeri di riga esatti.

**Come funziona:**
- **Gerarchia visiva dei test** - Visualizza la struttura dei tuoi test (suite, test, scenari) in una vista ad albero
- **Mappatura del codice sorgente** - Ogni test rimanda alla sua posizione esatta nei tuoi file sorgente
- **Navigazione con un clic** - Fai clic su qualsiasi test per aprirlo nel tuo editor
- **Integrazione con l'editor** - Funziona con i più diffusi editor di codice tramite i protocolli file:line

Questa connessione diretta tra interfaccia e codice velocizza il debugging, eliminando la ricerca manuale nel codice quando si analizzano i test falliti.
