---
id: watcher
title: مراقبة ملفات الاختبار
description: "أعد تشغيل الاختبارات تلقائيًا عند تغيير ملفات المواصفات أو ملفات التطبيق، وذلك بتشغيل WDIO testrunner مع العلامة ‎--watch والخاصية filesToWatch."
---

باستخدام WDIO testrunner، يمكنك مراقبة الملفات أثناء العمل عليها. إذ يُعاد تشغيل الاختبارات تلقائيًا عند تغيير أي شيء في تطبيقك أو في ملفات الاختبار. وعند إضافة العلامة `--watch` إلى الأمر `wdio`، ينتظر testrunner حدوث تغييرات في الملفات بعد انتهائه من تشغيل جميع الاختبارات، على سبيل المثال:

```sh
wdio wdio.conf.js --watch
```

افتراضيًا، يراقب testrunner التغييرات في ملفات `specs` فقط. لكن إذا عيّنت الخاصية `filesToWatch` في ملف `wdio.conf.js` بقائمة من مسارات الملفات (مع دعم أنماط globbing)، فسيراقب هذه الملفات أيضًا ويعيد تشغيل مجموعة الاختبارات بالكامل عند تغيّرها. يفيد ذلك إذا أردت إعادة تشغيل جميع اختباراتك تلقائيًا بعد تعديل شيفرة تطبيقك، على سبيل المثال:

```js
// wdio.conf.js
export const config = {
    // ...
    filesToWatch: [
        // مراقبة جميع ملفات JS في تطبيقي
        './src/app/**/*.js'
    ],
    // ...
}
```

:::info
حاول تشغيل الاختبارات بالتوازي قدر الإمكان، فاختبارات E2E بطيئة بطبيعتها. ولا تكون إعادة تشغيل الاختبارات مفيدة إلا إذا أبقيت مدة تشغيل كل اختبار قصيرة. ولتوفير الوقت، يُبقي testrunner جلسات WebDriver نشطة أثناء انتظار تغييرات الملفات. تأكد من إمكانية ضبط واجهة WebDriver الخلفية لديك بحيث لا تُغلق الجلسة تلقائيًا إذا لم يُنفَّذ أي أمر بعد مدة معينة.
:::
