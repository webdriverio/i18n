المُبلِّغ المرئي (Visual Reporter) هو ميزة جديدة تم تقديمها في `@wdio/visual-service`، بدءًا من الإصدار [v5.2.0](https://github.com/webdriverio/visual-testing/releases/tag/%40wdio%2Fvisual-service%405.2.0). يتيح هذا المُبلِّغ للمستخدمين تصوّر تقارير اختلافات JSON التي تُنشئها خدمة الاختبار المرئي وتحويلها إلى صيغة سهلة القراءة. يساعد الفرق على تحليل نتائج الاختبارات المرئية وإدارتها بشكل أفضل من خلال توفير واجهة رسومية لمراجعة المخرجات.

للاستفادة من هذه الميزة، تأكد من وجود الإعدادات المطلوبة لإنشاء ملف `output.json` اللازم. سيرشدك هذا المستند خلال إعداد المُبلِّغ المرئي وتشغيله وفهمه.

# المتطلبات الأساسية

قبل استخدام المُبلِّغ المرئي، تأكد من أنك قمت بتهيئة خدمة الاختبار المرئي لإنشاء ملفات تقارير JSON:

```ts
export const config = {
    // ...
    services: [
        [
            "visual",
            {
                createJsonReportFiles: true, // Generates the output.json file
            },
        ],
    ],
};
```

للحصول على تعليمات إعداد أكثر تفصيلًا، راجع [وثائق الاختبار المرئي](./) الخاصة بـ WebdriverIO أو [`createJsonReportFiles`](./service-options.md#createjsonreportfiles-new)

# التثبيت

لتثبيت المُبلِّغ المرئي، أضفه كاعتمادية تطوير إلى مشروعك باستخدام npm:

```bash
npm install @wdio/visual-reporter --save-dev
```

سيضمن ذلك توفر الملفات اللازمة لإنشاء التقارير من اختباراتك المرئية.

# الاستخدام

## بناء التقرير المرئي

بمجرد تشغيل اختباراتك المرئية وإنشائها لملف `output.json`، يمكنك بناء التقرير المرئي باستخدام واجهة سطر الأوامر (CLI) أو المطالبات التفاعلية.

### استخدام واجهة سطر الأوامر (CLI)

يمكنك استخدام أمر CLI لإنشاء التقرير عن طريق تشغيل:

```bash
npx wdio-visual-reporter --jsonOutput=<path-to-output.json> --reportFolder=<path-to-store-report> --logLevel=debug
```

#### الخيارات المطلوبة:

-   `--jsonOutput`: المسار النسبي لملف `output.json` الذي أنشأته خدمة الاختبار المرئي. هذا المسار نسبي إلى المجلد الذي تنفّذ منه الأمر.
-   `--reportFolder`: المجلد النسبي الذي سيتم تخزين التقرير المُنشأ فيه. هذا المسار أيضًا نسبي إلى المجلد الذي تنفّذ منه الأمر.

#### الخيارات الاختيارية:

-   `--logLevel`: اضبطه على `debug` للحصول على سجلات مفصلة، وهو مفيد بشكل خاص لاستكشاف الأخطاء وإصلاحها.

#### مثال

```bash
npx wdio-visual-reporter --jsonOutput=/path/to/output.json --reportFolder=/path/to/report --logLevel=debug
```

سيؤدي هذا إلى إنشاء التقرير في المجلد المحدد وتقديم ملاحظات في وحدة التحكم. على سبيل المثال:

```bash
✔ Build output copied successfully to "/path/to/report".
⠋ Prepare report assets...
✔ Successfully generated the report assets.
```

#### عرض التقرير

:::warning
فتح `path/to/report/index.html` مباشرةً في المتصفح **دون تقديمه من خادم محلي** **لن** يعمل.
:::

لعرض التقرير، تحتاج إلى استخدام خادم بسيط مثل [sirv-cli](https://www.npmjs.com/package/sirv-cli). يمكنك تشغيل الخادم بالأمر التالي:

```bash
npx sirv-cli /path/to/report --single
```

سينتج عن ذلك سجلات مشابهة للمثال أدناه. لاحظ أن رقم المنفذ قد يختلف:

```logs
  Your application is ready~! 🚀

  - Local:      http://localhost:8080
  - Network:    Add `--host` to expose

────────────────── LOGS ──────────────────
```

يمكنك الآن عرض التقرير عن طريق فتح عنوان URL المقدم في متصفحك.

### استخدام المطالبات التفاعلية

بدلًا من ذلك، يمكنك تشغيل الأمر التالي والإجابة على المطالبات لإنشاء التقرير:

```bash
npx @wdio/visual-reporter
```

سترشدك المطالبات خلال تقديم المسارات والخيارات المطلوبة. وفي النهاية، ستسألك المطالبة التفاعلية أيضًا عمّا إذا كنت تريد تشغيل خادم لعرض التقرير. إذا اخترت تشغيل الخادم، ستقوم الأداة بتشغيل خادم بسيط وعرض عنوان URL في السجلات. يمكنك فتح عنوان URL هذا في متصفحك لعرض التقرير.

![Visual Reporter CLI](/img/visual/cli-screen-recording.gif)

![Visual Reporter](/img/visual/visual-reporter.gif)

#### عرض التقرير

:::warning
فتح `path/to/report/index.html` مباشرةً في المتصفح **دون تقديمه من خادم محلي** **لن** يعمل.
:::

إذا اخترت **عدم** تشغيل الخادم عبر المطالبة التفاعلية، فلا يزال بإمكانك عرض التقرير عن طريق تشغيل الأمر التالي يدويًا:

```bash
npx sirv-cli /path/to/report --single
```

سينتج عن ذلك سجلات مشابهة للمثال أدناه. لاحظ أن رقم المنفذ قد يختلف:

```logs
  Your application is ready~! 🚀

  - Local:      http://localhost:8080
  - Network:    Add `--host` to expose

────────────────── LOGS ──────────────────
```

يمكنك الآن عرض التقرير عن طريق فتح عنوان URL المقدم في متصفحك.

# فهم التقرير المرئي

يوفر المُبلِّغ المرئي عرضًا منظمًا لنتائج اختباراتك المرئية. لكل عملية تشغيل اختبار، ستتمكن من:

-   التنقل بسهولة بين حالات الاختبار ورؤية النتائج المجمّعة.
-   مراجعة البيانات الوصفية مثل أسماء الاختبارات والمتصفحات المستخدمة ونتائج المقارنة.
-   عرض صور الاختلافات التي توضح أماكن اكتشاف الاختلافات المرئية.

يُبسّط هذا التمثيل المرئي تحليل نتائج اختباراتك، مما يسهّل تحديد التراجعات المرئية ومعالجتها.
