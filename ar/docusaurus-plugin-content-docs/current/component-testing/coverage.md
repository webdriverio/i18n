يدعم مشغل المتصفح في WebdriverIO إعداد تقارير تغطية الكود باستخدام [`istanbul`](https://istanbul.js.org/). سيقوم مشغل الاختبارات تلقائيًا بتجهيز الكود الخاص بك للقياس (instrumentation) باستخدام Vite ويلتقط بيانات تغطية الكود نيابةً عنك.

## كيف يعمل

يستخدم `@wdio/browser-runner` أداة Vite لتقديم تطبيقك. عند تفعيل التغطية، يضيف إضافة (plugin) إلى خادم Vite تحاول تجهيز الكود المصدري للقياس فوريًا عند طلبه من قِبل المتصفح.

:::warning مهم
**لا تنتقل بعيدًا عن مشغل الاختبارات!**

تعتمد تغطية الكود على الملفات التي يقدمها ويجهزها للقياس خادم Vite المحلي الذي يشغّله WebdriverIO.
إذا استخدمت `browser.url('http://...')` أو `browser.url('file://...')` للانتقال إلى صفحة مختلفة، فإنك تغادر البيئة المجهّزة للقياس. سيعمل الكود الخاص بك، لكن **لن يتم جمع أي بيانات تغطية**.

**النهج الصحيح (اختبار المكونات):**
اعرض المكون الخاص بك أو استورد الوحدة مباشرةً في ملف الاختبار.

```js
import { myFunction } from '../src/utils.js'

it('should cover my function', () => {
    myFunction() // هذا مشمول بالتغطية
})
```

**النهج الخاطئ (أسلوب E2E):**
```js
it('will not have coverage', async () => {
    // ❌ الانتقال بعيدًا يعطّل التجهيز للقياس
    await browser.url('http://localhost:3000')
})
```
:::

## الإعداد

لتفعيل إعداد تقارير تغطية الكود، قم بتفعيلها من خلال إعدادات مشغل المتصفح في WebdriverIO، على سبيل المثال:

```js title=wdio.conf.js
export const config = {
    // ...
    runner: ['browser', {
        preset: process.env.WDIO_PRESET,
        coverage: {
            enabled: true
        }
    }],
    // ...
}
```

اطّلع على جميع [خيارات التغطية](/docs/runner#coverage-options)، لتتعلم كيفية إعدادها بشكل صحيح.

:::tip نصائح الإعداد
إذا كنت تختبر ملفات غير قياسية (مثل السكربتات المضمّنة في ملفات `.html`) أو إذا لم يتم التقاط ملفاتك، فقد تحتاج إلى التحقق صراحةً من خيارَي `include` و`extension`:

```js
coverage: {
    enabled: true,
    // استهدف ملفاتك المصدرية صراحةً إذا فشل التحديد الافتراضي
    include: ['src/**/*.js', 'src/**/*.vue'],
    // أضف .html إذا كانت لديك سكربتات مضمّنة
    extension: ['.js', '.jsx', '.ts', '.tsx', '.vue', '.html']
}
```
:::

## تجاهل الكود

قد تكون هناك بعض الأجزاء من قاعدة الكود الخاصة بك التي ترغب في استبعادها عمدًا من تتبع التغطية، ولفعل ذلك يمكنك استخدام تلميحات التحليل التالية:

- `/* istanbul ignore if */`: تجاهل جملة if التالية.
- `/* istanbul ignore else */`: تجاهل جزء else من جملة if.
- `/* istanbul ignore next */`: تجاهل العنصر التالي في الكود المصدري (الدوال، جمل if، الأصناف، وغيرها).
- `/* istanbul ignore file */`: تجاهل ملف مصدري بالكامل (يجب وضع هذا في أعلى الملف).

:::info

يُوصى باستبعاد ملفات الاختبار الخاصة بك من تقارير التغطية لأنها قد تسبب أخطاءً، على سبيل المثال عند استدعاء الأمر `execute`. إذا كنت ترغب في الإبقاء عليها في تقريرك، فتأكد من استبعادها من التجهيز للقياس عبر:

```ts
await browser.execute(/* istanbul ignore next */() => {
    // ...
})
```

:::
