يدعم مشغل المتصفح في WebdriverIO إعداد تقارير تغطية الكود باستخدام [`istanbul`](https://istanbul.js.org/). سيقوم مشغل الاختبار تلقائيًا بتجهيز (instrument) الكود الخاص بك باستخدام Vite ويلتقط تغطية الكود نيابةً عنك.

## كيف يعمل

يستخدم `@wdio/browser-runner` أداة Vite لتقديم تطبيقك. عند تفعيل التغطية، يضيف مكونًا إضافيًا (plugin) إلى خادم Vite يحاول تجهيز الكود المصدري الخاص بك فوريًا عند طلبه من قِبل المتصفح.

:::warning مهم
**لا تنتقل بعيدًا عن مشغل الاختبار!**

تعتمد تغطية الكود على الملفات التي يقدمها ويجهزها خادم Vite المحلي الذي يشغله WebdriverIO.
إذا استخدمت `browser.url('http://...')` أو `browser.url('file://...')` للانتقال إلى صفحة مختلفة، فإنك تغادر البيئة المجهزة. سيعمل الكود الخاص بك، لكن **لن يتم جمع أي تغطية**.

**النهج الصحيح (اختبار المكونات):**
قم بعرض المكون الخاص بك أو استورد الوحدة الخاصة بك مباشرةً في ملف الاختبار.

```js
import { myFunction } from '../src/utils.js'

it('should cover my function', () => {
    myFunction() // هذا مُغطى
})
```

**النهج الخاطئ (أسلوب E2E):**
```js
it('will not have coverage', async () => {
    // ❌ الانتقال بعيدًا يكسر التجهيز
    await browser.url('http://localhost:3000')
})
```
:::

## الإعداد

لتفعيل إعداد تقارير تغطية الكود، قم بتفعيله من خلال إعدادات مشغل المتصفح في WebdriverIO، على سبيل المثال:

```js title=wdio.conf.js
export const config = {
    // ...
    runner: ['browser', {
        preset: process.env.WDIO_PRESET,
        coverage: {
            enabled: true
        }
    }],
    // ...
}
```

اطلع على جميع [خيارات التغطية](/docs/runner#coverage-options)، لتتعلم كيفية إعدادها بشكل صحيح.

:::tip نصائح الإعداد
إذا كنت تختبر ملفات غير قياسية (مثل السكربتات المضمنة في `.html`) أو إذا لم يتم التقاط ملفاتك، فقد تحتاج إلى التحقق صراحةً من خيارات `include` و `extension`:

```js
coverage: {
    enabled: true,
    // استهدف ملفاتك المصدرية صراحةً إذا فشل التحليل الافتراضي
    include: ['src/**/*.js', 'src/**/*.vue'],
    // أضف .html إذا كانت لديك سكربتات مضمنة
    extension: ['.js', '.jsx', '.ts', '.tsx', '.vue', '.html']
}
```
:::

## تجاهل الكود

قد تكون هناك بعض الأقسام في قاعدة الكود الخاصة بك التي ترغب في استبعادها عمدًا من تتبع التغطية، وللقيام بذلك يمكنك استخدام تلميحات التحليل التالية:

- `/* istanbul ignore if */`: تجاهل عبارة if التالية.
- `/* istanbul ignore else */`: تجاهل جزء else من عبارة if.
- `/* istanbul ignore next */`: تجاهل الشيء التالي في الكود المصدري (الدوال، عبارات if، الأصناف، وغيرها).
- `/* istanbul ignore file */`: تجاهل ملفًا مصدريًا بالكامل (يجب وضع هذا في أعلى الملف).

:::info

يُوصى باستبعاد ملفات الاختبار الخاصة بك من تقارير التغطية لأنها قد تتسبب في حدوث أخطاء، على سبيل المثال عند استدعاء الأمر `execute`. إذا كنت ترغب في إبقائها في تقريرك، فتأكد من استبعاد تجهيزها عبر:

```ts
await browser.execute(/* istanbul ignore next */() => {
    // ...
})
```

:::
