تعمل DevTools تلقائيًا مع Mocha وJasmine وCucumber دون الحاجة إلى أي إعدادات خاصة بإطار العمل. ما عليك سوى إضافة الخدمة إلى ملف إعدادات WebDriverIO الخاص بك، وستعمل جميع الميزات بسلاسة بغض النظر عن إطار الاختبار الذي تستخدمه.

**أطر العمل المدعومة:**
- **Mocha** - تنفيذ على مستوى الاختبار ومجموعة الاختبارات (suite) مع التصفية باستخدام grep
- **Jasmine** - تكامل كامل مع التصفية المعتمدة على grep
- **Cucumber** - تنفيذ على مستوى السيناريو والمثال مع الاستهداف باستخدام feature:line

تعمل واجهة تصحيح الأخطاء نفسها، وإعادة تشغيل الاختبارات، وميزات العرض المرئي بشكل متسق عبر جميع أطر العمل.

## الإعدادات

```js
// wdio.conf.js
export const config = {
    framework: 'mocha', // أو 'jasmine' أو 'cucumber'
    services: ['devtools'],
    // ...
};
```
