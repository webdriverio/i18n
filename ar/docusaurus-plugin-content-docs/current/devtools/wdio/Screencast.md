يسجّل جلسات المتصفح كمقاطع فيديو بصيغة `.webm`. تُعرض مقاطع الفيديو في واجهة DevTools إلى جانب عروض اللقطات وتغييرات DOM.

متاح عبر المحوّلات الثلاثة جميعها - **WebdriverIO** و **[Selenium WebDriver](/docs/devtools/selenium)** و **[Nightwatch.js](/docs/devtools/nightwatch#screencast)**. يختلف وضع الالتقاط حسب كل إطار عمل (الدفع عبر CDP حيثما أمكن، والاستطلاع الدوري (polling) في غير ذلك - راجع [دعم المتصفحات](#browser-support) أدناه).

## الإعداد

يتطلب ترميز تسجيل الشاشة وجود **ffmpeg** على `PATH` وحزمة `fluent-ffmpeg`:

```sh
# تثبيت ffmpeg - https://ffmpeg.org/download.html
brew install ffmpeg        # macOS
sudo apt install ffmpeg    # Ubuntu/Debian

# تثبيت fluent-ffmpeg
npm install fluent-ffmpeg
```

## التهيئة

```ts
services: [
  [
    'devtools',
    {
      screencast: {
        enabled: true,
        captureFormat: 'jpeg',
        quality: 70,
        maxWidth: 1280,
        maxHeight: 720,
      }
    }
  ]
]
```

## الخيارات

| الخيار | النوع | القيمة الافتراضية | الوصف |
|---|---|---|---|
| `enabled` | `boolean` | `false` | تفعيل تسجيل الجلسة |
| `captureFormat` | `'jpeg' \| 'png'` | `'jpeg'` | صيغة صورة الإطار. **Chrome/Chromium فقط** - يتحكم في الصيغة التي يرسلها Chrome عبر CDP. يُتجاهل في وضع الاستطلاع (Firefox و Safari) حيث تكون لقطات الشاشة دائمًا بصيغة PNG. لا يؤثر على حاوية الفيديو الناتج، والتي تكون دائمًا `.webm` |
| `quality` | `number` | `70` | جودة ضغط JPEG من 0 إلى 100. ينطبق فقط في وضع CDP على Chrome/Chromium مع `captureFormat: 'jpeg'` |
| `maxWidth` | `number` | `1280` | الحد الأقصى لعرض الإطار بالبكسل. **Chrome/Chromium فقط** - يقوم Chrome بتغيير حجم الإطارات قبل إرسالها عبر CDP. يُتجاهل في وضع الاستطلاع |
| `maxHeight` | `number` | `720` | الحد الأقصى لارتفاع الإطار بالبكسل. **Chrome/Chromium فقط** - كما هو مذكور أعلاه |
| `pollIntervalMs` | `number` | `200` | الفاصل الزمني لالتقاط لقطات الشاشة بالمللي ثانية للمتصفحات غير Chrome (وضع الاستطلاع). كلما قلّت القيمة = فيديو أكثر سلاسة ولكن مع عدد أكبر من الطلبات ذهابًا وإيابًا إلى WebDriver أثناء تنفيذ الاختبار |

## دعم المتصفحات

يعمل التسجيل عبر جميع المتصفحات الرئيسية باستخدام الاختيار التلقائي للوضع:

| المتصفح | الوضع | ملاحظات |
|---|---|---|
| Chrome / Chromium / Edge | **الدفع عبر CDP** | يدفع Chrome الإطارات عبر بروتوكول DevTools. فعّال - دون أي تأثير على توقيت أوامر الاختبار |
| Firefox / Safari / وغيرها | **الاستطلاع عبر BiDi** | يلجأ إلى استدعاء `browser.takeScreenshot()` على فترات `pollIntervalMs`. يعمل حيثما تكون لقطات شاشة WebDriver مدعومة؛ ويضيف عبئًا إضافيًا صغيرًا يتناسب مع الفاصل الزمني |

لا حاجة لأي تغيير في التهيئة للتبديل بين الأوضاع - إذ تكتشف الخدمة إمكانيات المتصفح تلقائيًا وتسجّل في السجلات الوضع النشط.

## السلوك

- يبدأ التسجيل عند فتح جلسة المتصفح ويتوقف عند إغلاقها.
- تُقتطع الإطارات الفارغة في البداية (الملتقطة قبل أول انتقال إلى عنوان URL) تلقائيًا بحيث تبدأ مقاطع الفيديو عند أول إجراء ذي معنى على الصفحة.
- إذا تم استدعاء `browser.reloadSession()` أثناء التشغيل، فإن الخدمة تُنهي التسجيل الحالي وتبدأ تسجيلًا جديدًا للجلسة الجديدة. تُنتج كل جلسة ملف `.webm` خاصًا بها.
- عند وجود تسجيلات متعددة، تعرض واجهة DevTools قائمة منسدلة **Recording N** للتبديل بينها.

### أين توضع ملفات الإخراج

يختلف المجلد الذي يختاره كل محوّل اختلافًا طفيفًا - فجميعها تشترك في نفس المُحلِّل في `@wdio/devtools-core` لكنها تزوّده بمدخلات مختلفة:

| المحوّل | موقع الإخراج |
|---|---|
| **WebdriverIO** | `outputDir` إذا تم تعيينه صراحةً في `wdio.conf.ts`، وإلا `rootDir` (المجلد الذي يحتوي على ملف التهيئة). تجنّب تعيين `outputDir` لمجرد التحكم في مسارات الفيديو - إذ يعيد WDIO توجيه سجلات العمّال (workers) إليه أيضًا. |
| **Selenium** | مجلد ملف الاختبار الذي تم تشغيله للتو، مع الرجوع إلى `process.cwd()` كبديل. |
| **Nightwatch** | مجلد ملف الاختبار، مع الرجوع إلى المجلد الذي يحتوي على `nightwatch.conf.*`، ثم `process.cwd()`. |

يتم تخطّي المجلدات الموجودة ضمن `node_modules/` في مسار Selenium/Nightwatch حتى لا تُلقي مساحات العمل المرتبطة رمزيًا (symlinked workspaces) مقاطع الفيديو في مجلد تابع للاعتماديات.

## ملفات الإخراج

يبث الوضع المباشر (Live mode) البيانات الملتقطة إلى لوحة التحكم عبر WebSocket ولا يكتب **أي ملف تتبّع على القرص** — للحصول على ملف قابل للنقل، استخدم [وضع التتبّع](/docs/devtools/wdio/trace-mode) (`trace.zip`). الملف الوحيد الذي يكتبه الوضع المباشر هو فيديو تسجيل الشاشة، وذلك فقط عند تعيين `screencast.enabled: true`. أسماء الملفات خاصة بكل محوّل (يظهر اسم إطار العمل في البادئة):

| المحوّل | فيديو تسجيل الشاشة |
|---|---|
| WebdriverIO | `wdio-video-{sessionId}.webm` |
| Selenium | `selenium-video-{sessionId}.webm` |
| Nightwatch | `nightwatch-video-{sessionId}.webm` |
