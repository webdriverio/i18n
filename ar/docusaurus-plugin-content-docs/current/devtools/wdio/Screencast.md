يسجّل جلسات المتصفح كمقاطع فيديو بصيغة `.webm`. تُعرض مقاطع الفيديو في واجهة DevTools بجانب عرض اللقطات وعرض تغييرات DOM.

متاح عبر المحوّلات الثلاثة جميعها - **WebdriverIO** و**[Selenium WebDriver](/docs/devtools/selenium)** و**[Nightwatch.js](/docs/devtools/nightwatch#screencast)**. يختلف وضع الالتقاط حسب كل إطار عمل (دفع CDP حيثما أمكن، والاستطلاع الدوري في غير ذلك - راجع [دعم المتصفحات](#browser-support) أدناه).

## عرض توضيحي

## الإعداد

يتطلب ترميز الفيديو وجود الملف التنفيذي **ffmpeg** ضمن `PATH`. يُثبَّت المغلّف `fluent-ffmpeg` مع المحوّل، لذا لا حاجة لإضافة أي شيء آخر:

```sh
# تثبيت ffmpeg - https://ffmpeg.org/download.html
brew install ffmpeg        # macOS
sudo apt install ffmpeg    # Ubuntu/Debian
```

بدون ffmpeg يظل المسجّل يعمل، لكن خطوة الترميز تسجّل تحذيرًا ولا تكتب أي ملف.

## الإعدادات

```ts
services: [
  [
    'devtools',
    {
      screencast: {
        enabled: true,
        captureFormat: 'jpeg',
        quality: 70,
        maxWidth: 1280,
        maxHeight: 720,
      }
    }
  ]
]
```

## الخيارات

| الخيار | النوع | القيمة الافتراضية | الوصف |
|---|---|---|---|
| `enabled` | `boolean` | `false` | تفعيل تسجيل الجلسة |
| `captureFormat` | `'jpeg' \| 'png'` | `'jpeg'` | صيغة صورة الإطار. **Chrome/Chromium فقط** - يتحكم في الصيغة التي يرسلها Chrome عبر CDP. يُتجاهل في وضع الاستطلاع (Firefox وSafari) حيث تكون لقطات الشاشة دائمًا بصيغة PNG. لا يؤثر على حاوية الفيديو الناتج، والتي تكون دائمًا `.webm` |
| `quality` | `number` | `70` | جودة ضغط JPEG من 0 إلى 100. ينطبق فقط في وضع CDP على Chrome/Chromium مع `captureFormat: 'jpeg'` |
| `maxWidth` | `number` | `1280` | أقصى عرض للإطار بالبكسل. **Chrome/Chromium فقط** - يغيّر Chrome حجم الإطارات قبل إرسالها عبر CDP. يُتجاهل في وضع الاستطلاع |
| `maxHeight` | `number` | `720` | أقصى ارتفاع للإطار بالبكسل. **Chrome/Chromium فقط** - كما في الخيار السابق |
| `pollIntervalMs` | `number` | `200` | الفاصل الزمني لالتقاط لقطات الشاشة بالمللي ثانية للمتصفحات غير Chrome (وضع الاستطلاع). كلما قلّت القيمة كان الفيديو أكثر سلاسة لكن مع زيادة عدد رحلات WebDriver ذهابًا وإيابًا أثناء تنفيذ الاختبار |
| `maxBufferFrames` | `number` | `2000` | الحد الأقصى لعدد الإطارات المحفوظة في الذاكرة. عند تجاوزه يُخفَّف المخزن المؤقت في مكانه مع الإبقاء على الإطارين الأول والأخير |

## دعم المتصفحات

يعمل التسجيل عبر جميع المتصفحات الرئيسية باستخدام اختيار الوضع التلقائي:

| المتصفح | الوضع | ملاحظات |
|---|---|---|
| Chrome / Chromium / Edge | **دفع CDP** | يدفع Chrome الإطارات عبر بروتوكول DevTools. فعّال - بلا تأثير على توقيت أوامر الاختبار |
| Firefox / Safari / غيرها | **استطلاع BiDi** | يعود إلى استدعاء `browser.takeScreenshot()` على فترات `pollIntervalMs`. يعمل في أي مكان تُدعم فيه لقطات شاشة WebDriver؛ ويضيف حملًا إضافيًا بسيطًا يتناسب مع الفاصل الزمني |

لا حاجة لأي تغيير في الإعدادات للتبديل بين الأوضاع - تكتشف الخدمة قدرات المتصفح تلقائيًا وتسجّل الوضع النشط.

## السلوك

- يبدأ التسجيل عند فتح جلسة المتصفح ويتوقف عند إغلاقها.
- تُقتطع الإطارات الفارغة في البداية (الملتقطة قبل أول انتقال إلى عنوان URL) تلقائيًا بحيث تبدأ مقاطع الفيديو عند أول إجراء ذي معنى على الصفحة.
- إذا استُدعي `browser.reloadSession()` أثناء التشغيل، تُنهي الخدمة التسجيل الحالي وتبدأ تسجيلًا جديدًا للجلسة الجديدة. تُنتج كل جلسة ملف `.webm` خاصًا بها.
- عند وجود عدة تسجيلات، تعرض واجهة DevTools قائمة منسدلة **Recording N** للتبديل بينها.

### أين تُحفظ ملفات الإخراج

يكتب كل محوّل في مجلد `test-results/`؛ ويختلف الدليل الأساسي الذي يقع فيه، لأن المحوّلات تتشارك محلّلًا واحدًا لكنها تزوّده بمدخلات مختلفة:

| المحوّل | موقع الإخراج |
|---|---|
| **WebdriverIO** | `<outputDir>/test-results/` إذا كان `outputDir` محددًا صراحةً في `wdio.conf.ts`، وإلا `<rootDir>/test-results/` (حيث `rootDir` هو الدليل الذي يحتوي على ملف الإعدادات). تجنّب تعيين `outputDir` لمجرد التحكم في مسارات الفيديو - إذ يعيد WDIO توجيه سجلات العمّال إليه أيضًا. |
| **Selenium** | `test-results/` في دليل ملف الاختبار الذي تم تشغيله للتو، مع الرجوع إلى `process.cwd()`. |
| **Nightwatch** | `test-results/` في دليل ملف الاختبار، مع الرجوع إلى الدليل الذي يحتوي على `nightwatch.conf.*`، ثم `process.cwd()`. |

تُتخطّى الأدلة الموجودة تحت `node_modules/` في مسار Selenium/Nightwatch حتى لا تُلقي مساحات العمل المرتبطة رمزيًا مقاطع الفيديو في مجلد تبعية، وإذا كان الدليل غير قابل للكتابة يُنتقل إلى المرشّح التالي.

## ملفات الإخراج

يبث الوضع المباشر البيانات الملتقطة إلى لوحة التحكم عبر WebSocket و**لا يكتب أي ملف تتبع على القرص** — للحصول على ملف قابل للنقل، استخدم [وضع التتبع](/docs/devtools/wdio/trace-mode) (`trace.zip`). الملف الوحيد الذي يكتبه الوضع المباشر هو فيديو التسجيل، وذلك فقط عند ضبط `screencast.enabled: true`. تختلف أسماء الملفات حسب المحوّل (يظهر اسم إطار العمل في البادئة):

| المحوّل | فيديو التسجيل |
|---|---|
| WebdriverIO | `wdio-video-{sessionId}.webm` |
| Selenium | `selenium-video-{sessionId}.webm` |
| Nightwatch | `nightwatch-video-{sessionId}.webm` |
