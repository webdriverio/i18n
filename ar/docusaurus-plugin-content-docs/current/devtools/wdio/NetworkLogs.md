راقب وافحص جميع أنشطة الشبكة أثناء اختباراتك. تلتقط DevTools كل طلب واستجابة HTTP، مما يمنحك رؤية كاملة لاستدعاءات API وتحميل الموارد وتوقيت الشبكة - تمامًا مثل أدوات المطورين في المتصفح.

**ما الذي يتم التقاطه:**
- **تفاصيل الطلب** - عنوان URL، والطريقة (method)، والترويسات (headers)، ومعاملات الاستعلام (query parameters)، ومحتوى الطلب (request body)
- **بيانات الاستجابة** - رمز الحالة (status code)، وترويسات الاستجابة، ومحتوى الاستجابة، والتوقيت
- **أنواع الموارد** - طلبات XHR/Fetch، والسكربتات، وأوراق الأنماط (stylesheets)، والصور، والمزيد
- **مقاييس الأداء** - توقيت الطلب، والمدة، والمخطط الشلالي للشبكة (network waterfall)

يُعد هذا أمرًا لا يقدر بثمن لتصحيح مشكلات API، وتحديد الطلبات البطيئة، والتحقق من صحة البيانات المُرسلة (payloads)، وفهم سلوك الشبكة في تطبيقك أثناء الاختبارات.
