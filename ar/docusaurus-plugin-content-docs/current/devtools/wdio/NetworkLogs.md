راقب وافحص جميع أنشطة الشبكة أثناء اختباراتك. تلتقط DevTools كل طلب واستجابة HTTP، مما يمنحك رؤية كاملة لاستدعاءات API وتحميل الموارد وتوقيتات الشبكة - تمامًا مثل أدوات المطوّر في المتصفح.

**ما الذي يتم التقاطه:**
- **تفاصيل الطلب** - عنوان URL، والطريقة (method)، والترويسات (headers)، ومعاملات الاستعلام، ومحتوى الطلب
- **بيانات الاستجابة** - رمز الحالة، وترويسات الاستجابة، ومحتوى الاستجابة، والتوقيت
- **أنواع الموارد** - طلبات XHR/Fetch، والسكربتات، وأوراق الأنماط، والصور، والمزيد
- **مقاييس الأداء** - توقيت الطلب، ومدته، والمخطط الشلالي للشبكة (network waterfall)

يُعد هذا أمرًا بالغ الأهمية لتصحيح مشكلات API، وتحديد الطلبات البطيئة، والتحقق من صحة البيانات المرسلة، وفهم سلوك تطبيقك على الشبكة أثناء الاختبارات.
