---

تُرفَق عناصر وضع التتبع — ملف zip الخاص بالتتبع ولقطة الشاشة والفيديو الخاصين بكل اختبار — بتقرير Allure تلقائيًا، بحيث يمكنك فتحها مباشرةً من التقرير. راجع [وضع التتبع](/docs/devtools/wdio/trace-mode) لمعرفة كيفية تفعيل وضع التتبع وإنتاج هذه العناصر.

عند وجود مُبلِّغ Allure، تُرفَق عناصر وضع التتبع بتقرير Allure تلقائيًا — دون أي ربط إضافي:

- **`traceGranularity: 'test'`** — يُرفَق ملف `trace.zip` الخاص بكل اختبار (`application/zip`، ملف للتنزيل يُفتح في `show-trace`) و`screenshot` (`image/png`، مضمَّن) و`video` (`video/webm`، مضمَّن) ببطاقة ذلك الاختبار. هذا هو مستوى التفصيل الذي ينبغي استخدامه للحصول على تقرير Allure لكل اختبار على حدة. يتطلب ترميز `video` الخاص بكل اختبار وجود `ffmpeg` في `PATH`.
- **`traceGranularity: 'session'` / `'spec'`** — يُكتب التتبع الممتد عبر الجلسة/المواصفة على القرص ويُدرَج في [بيان العناصر](/docs/devtools/wdio/trace-mode#artifacts-manifest--emitartifactsmanifest)، لكنه **لا** يُرفَق ببطاقات الاختبارات الفردية: إذ لا يُستكمَل تتبع الجلسة/المواصفة إلا بعد تشغيل جميع اختباراته، وحينها تكون بطاقات Allure الخاصة بها قد أُغلقت ولا يوجد اختبار مفتوح لإرفاقه به. لإظهاره رغم ذلك، عالِج البيان لاحقًا في خطاف `onComplete` الخاص بك.

الدعم حسب المحوِّل:

| المحوِّل | آلية الإرفاق |
|---|---|
| **WebdriverIO** | دعم أصيل عبر `addAttachment` الخاص بـ `@wdio/allure-reporter`. |
| **Selenium** | عبر `attachment()` الخاص بـ `allure-js-commons` — مستقل عن بيئة التشغيل، ويُرفِق ضمن أي محوِّل لمشغِّل Allure، بشرط وجود بيئة تشغيل نشطة لـ `allure-js-commons`. |
| **Nightwatch** | **إنتاج فقط** — تُكتب الملفات والبيان لكنها لا تُرفَق بشكل مضمَّن (لا توجد واجهة برمجية حية للإرفاق في Allure). |

**عارض التتبع المضمَّن.** نظرًا لأن الأرشيف يستخدم تنسيقًا قياسيًا ومحمولًا لعارض التتبع على القرص، يمكن لـ **عارض التتبع المضمَّن** الخاص بتقرير Allure (Allure ≥ 2.35) فتح ملف `trace.zip` المُرفَق مباشرةً داخل التقرير.

**الضوضاء في التقرير.** في وضع التتبع، يلتقط النظام `takeScreenshot` لكل إجراء لبناء الخط الزمني؛ ويسجّل Allure كل أمر WebDriver كخطوة ولقطة شاشة لكل `takeScreenshot`. أوقِف هذا الفيض باستخدام خيارات المُبلِّغ نفسه — ولن تتأثر مرفقات التتبع / لقطات الشاشة / الفيديو:

```ts
reporters: [
  ['allure', {
    outputDir: 'allure-results',
    disableWebdriverStepsReporting: true,
    disableWebdriverScreenshotsReporting: true
  }]
]
```
