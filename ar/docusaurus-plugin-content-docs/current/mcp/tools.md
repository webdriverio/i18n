يوفر خادم WebdriverIO MCP عدد 29 أداة مُنظّمة حسب الوظيفة. الأدوات المُعلَّمة بـ **للمتصفح فقط** تتطلب جلسة بـ `platform: "browser"`. الأدوات المُعلَّمة بـ **للجوال فقط** تتطلب `platform: "ios"` أو `platform: "android"`.

## إدارة الجلسات

### `start_session`

تبدأ جلسة أتمتة جديدة للمتصفح أو الجوال. يُسمح بجلسة نشطة واحدة فقط في كل مرة؛ وبدء جلسة جديدة يُغلق الجلسة الحالية.

| المعامل                | النوع                                                                  | مطلوب        | القيمة الافتراضية | الوصف                                                                                                                             |
| ---------------------- | ---------------------------------------------------------------------- | ------------ | ---------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `platform`             | `"browser" \| "ios" \| "android"`                                      | ✓            | —                | منصة الجلسة                                                                                                                       |
| `provider`             | `"local" \| "browserstack" \| "saucelabs" \| "testmu" \| "testingbot"` | —            | `"local"`        | مزوّد الجلسة                                                                                                                      |
| `browser`              | `"chrome" \| "firefox" \| "edge" \| "safari"`                          | للمتصفح فقط  | —                | المتصفح المراد تشغيله                                                                                                             |
| `browserVersion`       | string                                                                 | —            | latest           | إصدار المتصفح (لمزوّدي الخدمات السحابية فقط، الافتراضي: latest)                                                                   |
| `os`                   | string                                                                 | —            | —                | نظام التشغيل (لمزوّدي الخدمات السحابية فقط، مثل `"Windows"`، `"OS X"`)                                                            |
| `osVersion`            | string                                                                 | —            | —                | إصدار نظام التشغيل (لمزوّدي الخدمات السحابية فقط، مثل `"11"`، `"Sequoia"`)                                                        |
| `headless`             | boolean                                                                | —            | `true`           | تشغيل المتصفح بدون واجهة رسومية                                                                                                   |
| `windowWidth`          | number                                                                 | —            | `1920`           | عرض نافذة المتصفح (400–3840)                                                                                                      |
| `windowHeight`         | number                                                                 | —            | `1080`           | ارتفاع نافذة المتصفح (400–2160)                                                                                                   |
| `navigationUrl`        | string                                                                 | —            | —                | عنوان URL للانتقال إليه بعد البدء                                                                                                 |
| `deviceName`           | string                                                                 | للجوال فقط   | —                | اسم الجهاز/المحاكي                                                                                                                |
| `platformVersion`      | string                                                                 | —            | —                | إصدار نظام التشغيل (مثل `"17.0"`، `"14"`)                                                                                         |
| `appPath`              | string                                                                 | —            | —                | المسار إلى ملف `.app` / `.apk` / `.ipa`                                                                                           |
| `app`                  | string                                                                 | —            | —                | عنوان URL للتطبيق (`bs://...` لـ BrowserStack، و`storage:filename=` لـ Sauce Labs، و`lt://...` لـ TestMu، وapp_url لـ TestingBot) أو custom_id |
| `automationName`       | `"XCUITest" \| "UiAutomator2"`                                         | —            | auto             | مشغّل الأتمتة                                                                                                                     |
| `autoGrantPermissions` | boolean                                                                | —            | `true`           | منح أذونات التطبيق تلقائيًا                                                                                                       |
| `autoAcceptAlerts`     | boolean                                                                | —            | `true`           | قبول التنبيهات تلقائيًا                                                                                                           |
| `autoDismissAlerts`    | boolean                                                                | —            | `false`          | رفض التنبيهات تلقائيًا                                                                                                            |
| `appWaitActivity`      | string                                                                 | —            | —                | نشاط Android المراد انتظاره عند التشغيل                                                                                           |
| `udid`                 | string                                                                 | —            | —                | معرّف UDID لجهاز iOS الحقيقي                                                                                                      |
| `noReset`              | boolean                                                                | —            | —                | الحفاظ على بيانات التطبيق بين الجلسات                                                                                             |
| `fullReset`            | boolean                                                                | —            | —                | إلغاء تثبيت التطبيق قبل/بعد الجلسة                                                                                                |
| `newCommandTimeout`    | number                                                                 | —            | `300`            | مهلة أوامر Appium (بالثواني)                                                                                                      |
| `attach`               | boolean                                                                | —            | `false`          | الاتصال بمتصفح Chrome قائم عبر CDP                                                                                                |
| `attachConfig`         | object                                                                 | —            | —                | اتصال CDP: `{ port: 9222, host: "localhost" }`                                                                                    |
| `appiumConfig`         | object                                                                 | —            | —                | خادم Appium: `{ host, port, path }`                                                                                               |
| `tunnel`               | `boolean \| "external"`                                                | —            | `false`          | توجيه النفق المحلي (لمزوّدي الخدمات السحابية). `true` = بدء تلقائي، `"external"` = النفق يعمل بالفعل خارجيًا                       |
| `reporting`            | object                                                                 | —            | —                | تسميات التقارير لدى المزوّد السحابي: `{ project, build, session }`                                                                |
| `trace`                | boolean                                                                | —            | `false`          | تفعيل تسجيل التتبع — يُنتج ملف zip بصيغة `.trace` متوافق مع Playwright                                                            |
| `region`               | `"us-west-1" \| "eu-central-1" \| "apac-southeast-1"`                  | —            | `"eu-central-1"` | منطقة مركز بيانات Sauce Labs                                                                                                      |
| `tunnelName`           | string                                                                 | —            | —                | اسم معرّف النفق (مطلوب عند `tunnel: "external"`)                                                                                  |
| `capabilities`         | object                                                                 | —            | —                | قدرات (capabilities) خام إضافية لدمجها                                                                                            |

```js
// متصفح Chrome محلي
start_session({ platform: "browser", browser: "chrome" })

// محاكي iOS
start_session({ platform: "ios", deviceName: "iPhone 16", platformVersion: "18.0", appPath: "/path/to/app.app" })

// Android على BrowserStack
start_session({ platform: "android", provider: "browserstack", deviceName: "Samsung Galaxy S24", app: "bs://abc123" })

// iOS على Sauce Labs
start_session({ platform: "ios", provider: "saucelabs", deviceName: "iPhone 15", platformVersion: "17.0", app: "storage:filename=MyApp.ipa" })

// متصفح على TestMu
start_session({ platform: "browser", provider: "testmu", browser: "chrome", os: "Windows", osVersion: "11" })

// متصفح على TestingBot
start_session({ platform: "browser", provider: "testingbot", browser: "chrome", os: "Windows", osVersion: "11" })

// مزوّد سحابي مع نفق
start_session({ platform: "browser", provider: "browserstack", browser: "chrome", tunnel: true })

// الاتصال بمتصفح Chrome قائم (بعد launch_chrome)
start_session({ platform: "browser", browser: "chrome", attach: true })
```

---

### `close_session`

تُغلق الجلسة الحالية أو تنفصل عنها.

| المعامل   | النوع   | مطلوب | القيمة الافتراضية | الوصف                                                          |
| --------- | ------- | ----- | ------- | -------------------------------------------------------------- |
| `detach`  | boolean | —     | `false` | قطع الاتصال دون إنهاء الجلسة (يحافظ على حالة التطبيق في Appium) |

الجلسات التي بُدئت بـ `noReset: true` تنفصل تلقائيًا بشكل افتراضي.

---

### `launch_chrome`

تُجهّز نسخة من Chrome مع تفعيل التصحيح عن بُعد حتى يتمكن `start_session({ attach: true })` من الاتصال بها. يوجد وضعان:

- `newInstance` (الافتراضي): يفتح Chrome بجانب نسختك الحالية باستخدام مجلد ملف تعريف منفصل؛ ولا تتأثر جلستك الحالية.
- `freshSession`: يشغّل Chrome بملف تعريف فارغ (بدون ملفات تعريف ارتباط أو تسجيلات دخول). استخدم `copyProfileFiles: true` لنقل ملفات تعريف الارتباط وتسجيلات الدخول.

| المعامل            | النوع                             | مطلوب | القيمة الافتراضية | الوصف                                                            |
| ------------------ | --------------------------------- | ----- | --------------- | ---------------------------------------------------------------- |
| `port`             | number                            | —     | `9222`          | منفذ التصحيح عن بُعد                                             |
| `mode`             | `"newInstance" \| "freshSession"` | —     | `"newInstance"` | وضع التشغيل                                                      |
| `copyProfileFiles` | boolean                           | —     | `false`         | نسخ ملف تعريف Chrome الافتراضي (ملفات تعريف الارتباط، تسجيلات الدخول) إلى جلسة التصحيح |

بعد نجاح هذه الأداة، استدعِ `start_session({ platform: "browser", browser: "chrome", attach: true })`.

## التنقل وعلامات التبويب

### `navigate`

تحمّل عنوان URL في علامة التبويب الحالية وتنتظر حدث تحميل الصفحة. تُعيد تعيين حالة الصفحة (DOM، بيئة تشغيل JS). **للمتصفح فقط.**

| المعامل   | النوع  | مطلوب | الوصف                     |
| --------- | ------ | ----- | ------------------------- |
| `url`     | string | ✓     | عنوان URL للانتقال إليه   |

---

### `get_tabs`

تعرض جميع علامات تبويب المتصفح مع المعرّف (handle) والعنوان وعنوان URL وأيّها النشطة. استخدمها قبل `switch_tab` للعثور على المعرّف المستهدف. **للمتصفح فقط.**

بدون معاملات.

---

### `switch_tab`

تنقل التركيز إلى علامة تبويب في المتصفح عبر معرّف النافذة أو فهرس يبدأ من 0. جميع استدعاءات الأدوات اللاحقة تعمل على علامة التبويب النشطة الجديدة. **للمتصفح فقط.**

| المعامل   | النوع  | مطلوب | الوصف                            |
| --------- | ------ | ----- | -------------------------------- |
| `handle`  | string | —     | معرّف النافذة المراد التبديل إليها |
| `index`   | number | —     | فهرس علامة التبويب يبدأ من 0 (≥ 0) |

قدّم إما `handle` أو `index`. احصل على المعرّفات من `get_tabs` أو `wdio://session/current/tabs`.

---

### `switch_frame`

تبدّل سياق إطار WebDriver إلى داخل iframe عبر محدد CSS/XPath، أو تعود إلى المستوى الأعلى إذا حُذف المحدد. تستمر التغييرات؛ إذ تعمل جميع استدعاءات `click_element` و`set_value` و`get_elements` اللاحقة داخل الإطار المُبدَّل إليه حتى تعود منه. تنتظر حتى 5 ثوانٍ لظهور الـ iframe. **للمتصفح فقط.**

| المعامل    | النوع  | مطلوب | الوصف                                                                                  |
| ---------- | ------ | ----- | -------------------------------------------------------------------------------------- |
| `selector` | string | —     | محدد CSS/XPath لعنصر الـ iframe. احذفه للعودة إلى الإطار ذي المستوى الأعلى.            |

```js
// التبديل إلى داخل iframe
switch_frame({ selector: "#my-iframe" })

// التفاعل مع العناصر داخل الـ iframe
click_element({ selector: "button.submit" })

// العودة إلى المستوى الأعلى
switch_frame()
```

## التفاعل مع العناصر

### `click_element`

تنتظر وجود العنصر، وتمرّر الصفحة لإظهاره، ثم تنقر عليه. تعمل على المتصفح والجوال. على iOS، يُفضَّل استخدام `tap_element`؛ إذ قد تتجاهل الطبقة الأصلية `click_element` أحيانًا.

| المعامل        | النوع   | مطلوب | القيمة الافتراضية | الوصف                                    |
| -------------- | ------- | ----- | ------- | ---------------------------------------- |
| `selector`     | string  | ✓     | —       | محدد CSS أو XPath أو نصي                 |
| `scrollToView` | boolean | —     | `true`  | تمرير العنصر إلى مجال الرؤية قبل النقر   |
| `timeout`      | number  | —     | —       | أقصى وقت انتظار (بالمللي ثانية)          |

---

### `set_value`

تمسح حقل إدخال أو textarea وتكتب النص المحدد. تستبدل المحتوى الموجود دائمًا.

| المعامل        | النوع   | مطلوب | القيمة الافتراضية | الوصف                                  |
| -------------- | ------- | ----- | ------- | -------------------------------------- |
| `selector`     | string  | ✓     | —       | محدد CSS أو XPath أو نصي               |
| `value`        | string  | ✓     | —       | النص المراد كتابته                     |
| `scrollToView` | boolean | —     | `true`  | تمرير العنصر إلى مجال الرؤية قبل الكتابة |
| `timeout`      | number  | —     | —       | أقصى وقت انتظار (بالمللي ثانية)        |

---

### `scroll`

تمرّر الصفحة بعدد محدد من البكسلات. **للمتصفح فقط.** للجوال، استخدم `swipe`.

| المعامل     | النوع            | مطلوب | القيمة الافتراضية | الوصف              |
| ----------- | ---------------- | ----- | ------- | ------------------ |
| `direction` | `"up" \| "down"` | ✓     | —       | اتجاه التمرير      |
| `pixels`    | number           | —     | `500`   | عدد بكسلات التمرير |

## تحليل العناصر

### `get_elements`

تُعيد العناصر القابلة للتفاعل في الصفحة الحالية مع محددات جاهزة للاستخدام. يُفضَّل استخدام المورد `wdio://session/current/elements` للوعي المحيطي؛ واستخدم هذه الأداة عندما تحتاج إلى التصفية أو الترقيم.

| المعامل             | النوع   | مطلوب | القيمة الافتراضية | الوصف                                       |
| ------------------- | ------- | ----- | ------- | ------------------------------------------- |
| `inViewportOnly`    | boolean | —     | `false` | إعادة العناصر المرئية في منفذ العرض فقط     |
| `includeContainers` | boolean | —     | `false` | تضمين عناصر الحاويات (divs، sections)       |
| `includeBounds`     | boolean | —     | `false` | تضمين إحداثيات المربع المحيط                |
| `limit`             | number  | —     | `0`     | الحد الأقصى للعناصر المُعادة (0 = غير محدود) |
| `offset`            | number  | —     | `0`     | عدد العناصر المراد تخطيها (الترقيم)          |

---

### `get_accessibility_tree`

تُعيد شجرة إمكانية الوصول للصفحة مع الأدوار والأسماء والمحددات. تدعم التصفية والترقيم. **للمتصفح فقط.**

| المعامل   | النوع    | مطلوب | القيمة الافتراضية | الوصف                                                      |
| --------- | -------- | ----- | ------- | ---------------------------------------------------------- |
| `limit`   | number   | —     | `0`     | الحد الأقصى للعقد المُعادة (0 = غير محدود)                 |
| `offset`  | number   | —     | `0`     | عدد العقد المراد تخطيها (الترقيم)                          |
| `roles`   | string[] | —     | —       | التصفية حسب أدوار ARIA، مثل `["button", "link", "heading"]` |

## لقطات الشاشة

### `get_screenshot`

تلتقط صورة للصفحة أو الشاشة الحالية. تُعيد صورة مُرمَّزة بـ base64، يُعاد تحجيمها وضغطها تلقائيًا لتبقى ضمن حدود سياق النموذج (بحد أقصى 1 ميغابايت، و2000 بكسل).

بدون معاملات. يُفضَّل استخدام `wdio://session/current/elements` بدلًا من لقطات الشاشة لاكتشاف العناصر؛ فهو أسرع ويستهلك رموزًا (tokens) أقل بكثير. استخدم لقطات الشاشة للتحقق البصري أو لتصحيح التخطيط.

## إدارة ملفات تعريف الارتباط

### `get_cookies`

تُعيد جميع ملفات تعريف الارتباط للجلسة الحالية، أو ملف تعريف ارتباط واحد حسب الاسم. **للمتصفح فقط.**

| المعامل   | النوع  | مطلوب | الوصف                                              |
| --------- | ------ | ----- | -------------------------------------------------- |
| `name`    | string | —     | اسم ملف تعريف الارتباط. احذفه لإعادة جميع الملفات. |

---

### `set_cookie`

تعيّن ملف تعريف ارتباط في المتصفح. يجب أن يكون المتصفح موجودًا بالفعل على النطاق المستهدف — لا يمكن تعيين ملفات تعريف الارتباط عبر النطاقات. استخدمها لحقن رموز الجلسة أو علامات الميزات دون المرور بمراحل تسجيل الدخول. **للمتصفح فقط.**

| المعامل    | النوع                         | مطلوب | الوصف                                          |
| ---------- | ----------------------------- | ----- | ---------------------------------------------- |
| `name`     | string                        | ✓     | اسم ملف تعريف الارتباط                         |
| `value`    | string                        | ✓     | قيمة ملف تعريف الارتباط                        |
| `domain`   | string                        | —     | نطاق ملف تعريف الارتباط (الافتراضي هو النطاق الحالي) |
| `path`     | string                        | —     | مسار ملف تعريف الارتباط (الافتراضي `/`)        |
| `expiry`   | number                        | —     | تاريخ الانتهاء كطابع زمني Unix (بالثواني)      |
| `httpOnly` | boolean                       | —     | علامة HttpOnly                                 |
| `secure`   | boolean                       | —     | علامة Secure                                   |
| `sameSite` | `"strict" \| "lax" \| "none"` | —     | سمة SameSite                                   |

---

### `delete_cookies`

تحذف جميع ملفات تعريف الارتباط أو ملفًا محددًا حسب الاسم. **للمتصفح فقط.**

| المعامل   | النوع  | مطلوب | الوصف                                                         |
| --------- | ------ | ----- | ------------------------------------------------------------- |
| `name`    | string | —     | اسم ملف تعريف الارتباط المراد حذفه. احذفه لحذف جميع الملفات. |

## إيماءات اللمس (الجوال)

### `tap_element`

تستدعي `element.tap()` على عنصر مطابق أو تنقر عند إحداثيات مطلقة على الشاشة. استخدمها على iOS عندما يتم تجاهل `click_element`؛ فالنقر هو الإيماءة الأصلية التي يستجيب لها iOS. **للجوال فقط.**

| المعامل    | النوع  | مطلوب | الوصف                                          |
| ---------- | ------ | ----- | ---------------------------------------------- |
| `selector` | string | —     | محدد العنصر                                    |
| `x`        | number | —     | الإحداثي X للنقر على الشاشة (في حال عدم وجود محدد) |
| `y`        | number | —     | الإحداثي Y للنقر على الشاشة (في حال عدم وجود محدد) |

قدّم إما `selector` أو الإحداثيات `x`/`y`.

---

### `swipe`

تنفّذ إيماءة سحب على كامل الشاشة. الاتجاه هو اتجاه حركة المحتوى (مثلًا `"up"` يمرّر القائمة إلى الأعلى). استخدمها للتمرير إلى ما بعد الحدود المرئية. لتحريك عنصر محدد، استخدم `drag_and_drop`. **للجوال فقط.** للمتصفحات، استخدم `scroll`.

| المعامل     | النوع                                 | مطلوب | القيمة الافتراضية | الوصف                                  |
| ----------- | ------------------------------------- | ----- | -------------- | -------------------------------------- |
| `direction` | `"up" \| "down" \| "left" \| "right"` | ✓     | —              | اتجاه السحب                            |
| `duration`  | number                                | —     | `500`          | مدة السحب (بالمللي ثانية، 100–5000)    |
| `percent`   | number                                | —     | `0.5` / `0.95` | نسبة الشاشة المراد سحبها (0–1)         |

---

### `drag_and_drop`

تسحب عنصرًا إلى عنصر آخر أو إلى إحداثيات معينة. **للجوال فقط.**

| المعامل          | النوع  | مطلوب | القيمة الافتراضية | الوصف                                          |
| ---------------- | ------ | ----- | ------- | ---------------------------------------------- |
| `sourceSelector` | string | ✓     | —       | العنصر المصدر المراد سحبه                      |
| `targetSelector` | string | —     | —       | العنصر الهدف المراد الإفلات عليه               |
| `x`              | number | —     | —       | إزاحة X للهدف (في حال عدم وجود targetSelector) |
| `y`              | number | —     | —       | إزاحة Y للهدف (في حال عدم وجود targetSelector) |
| `duration`       | number | —     | —       | مدة السحب (بالمللي ثانية، 100–5000)            |

## تبديل السياق (الجوال)

### `get_contexts`

تُعيد سياقات الأتمتة المتاحة والسياق النشط حاليًا. استخدمها قبل `switch_context` لاكتشاف أهداف `NATIVE_APP` و`WEBVIEW_*`. **للجوال فقط.**

بدون معاملات.

---

### `switch_context`

تبدّل بين سياقات الأتمتة الأصلية وسياقات webview في تطبيق جوال هجين. مطلوبة قبل استخدام محددات CSS/XPath داخل webview مضمّن. **للجوال فقط.**

| المعامل   | النوع  | مطلوب | الوصف                                                          |
| --------- | ------ | ----- | -------------------------------------------------------------- |
| `context` | string | ✓     | اسم السياق، مثل `"NATIVE_APP"`، `"WEBVIEW_com.example.app"`    |

احصل على أسماء السياقات المتاحة من `get_contexts` أو `wdio://session/current/contexts`.

```js
// 1. التحقق مما هو متاح
get_contexts()
// → { contexts: ["NATIVE_APP", "WEBVIEW_com.example.app"], currentContext: "NATIVE_APP" }

// 2. التبديل إلى الـ webview لاستخدام CSS/XPath
switch_context({ context: "WEBVIEW_com.example.app" })

// 3. التفاعل مع عناصر الـ webview باستخدام محددات CSS
click_element({ selector: "#login-button" })

// 4. العودة إلى السياق الأصلي لواجهة المستخدم الأصلية
switch_context({ context: "NATIVE_APP" })
```

## أدوات المتصفح المساعدة

### `emulate_device`

تحاكي جهاز جوال أو جهازًا لوحيًا في جلسة المتصفح الحالية (تعيّن منفذ العرض وDPR ووكيل المستخدم وأحداث اللمس). تتطلب جلسة مُفعّل فيها BiDi: `start_session({ capabilities: { webSocketUrl: true } })`. **للمتصفح فقط.**

| المعامل   | النوع  | مطلوب | الوصف                                                                                                                   |
| --------- | ------ | ----- | ----------------------------------------------------------------------------------------------------------------------- |
| `device`  | string | —     | اسم الإعداد المسبق للجهاز (مثل `"iPhone 15"`، `"Pixel 7"`). احذفه لعرض الإعدادات المسبقة. مرّر `"reset"` لاستعادة إعدادات سطح المكتب الافتراضية. |

---

### `execute_script`

تنفّذ JavaScript في المتصفح أو أوامر الجوال عبر Appium.

| المعامل   | النوع  | مطلوب | الوصف                                                         |
| --------- | ------ | ----- | ------------------------------------------------------------- |
| `script`  | string | ✓     | كود JS (للمتصفح) أو أمر Appium مثل `"mobile: pressKey"`       |
| `args`    | any[]  | —     | الوسائط المُمرّرة إلى السكربت أو الأمر                        |

**المتصفح:** استخدم `return` لاستعادة القيم.

```javascript
// الحصول على عنوان الصفحة
execute_script({ script: "return document.title" })

// تمرير العنصر إلى مجال الرؤية
execute_script({ script: "arguments[0].scrollIntoView()", args: ["#my-element"] })
```

**الجوال (Appium):** يستخدم صيغة `mobile: <command>`.

```javascript
// الضغط على زر الرجوع في Android
execute_script({ script: "mobile: pressKey", args: [{ keycode: 4 }] })

// تنشيط التطبيق (iOS/Android)
execute_script({ script: "mobile: activateApp", args: [{ bundleId: "com.example.app" }] })

// رابط عميق (iOS)
execute_script({ script: "mobile: deepLink", args: [{ url: "myapp://route", bundleId: "com.example.app" }] })
```

## مزوّدو الخدمات السحابية

### `list_apps`

تعرض التطبيقات المرفوعة إلى مزوّد سحابي (BrowserStack App Automate، أو Sauce Labs App Storage، أو TestMu، أو TestingBot Storage). تقرأ بيانات الاعتماد الخاصة بكل مزوّد من متغيرات البيئة.

| المعامل            | النوع                                                       | مطلوب | القيمة الافتراضية | الوصف                                          |
| ------------------ | ----------------------------------------------------------- | ----- | ---------------- | ---------------------------------------------- |
| `provider`         | `"browserstack" \| "saucelabs" \| "testmu" \| "testingbot"` | ✓     | —                | المزوّد السحابي                                |
| `sortBy`           | `"app_name" \| "uploaded_at"`                               | —     | `"uploaded_at"`  | ترتيب الفرز                                    |
| `organizationWide` | boolean                                                     | —     | `false`          | (لـ BrowserStack فقط) عرض جميع مرفوعات المؤسسة |
| `limit`            | number                                                      | —     | `20`             | الحد الأقصى للنتائج                            |
| `region`           | `"us-west-1" \| "eu-central-1" \| "apac-southeast-1"`       | —     | `"eu-central-1"` | منطقة Sauce Labs                               |

```js
// عرض التطبيقات لدى المزوّدين الأربعة
list_apps({ provider: "browserstack" })
list_apps({ provider: "saucelabs", region: "us-west-1" })
list_apps({ provider: "testmu" })
list_apps({ provider: "testingbot" })
```

---

### `upload_app`

ترفع ملف `.apk` أو `.ipa` محليًا إلى مزوّد سحابي (BrowserStack، أو Sauce Labs، أو TestMu، أو TestingBot). تُعيد عنوان URL للتطبيق لاستخدامه في `start_session`.

| المعامل    | النوع                                                       | مطلوب | القيمة الافتراضية | الوصف                                                 |
| ---------- | ----------------------------------------------------------- | ----- | ---------------- | ----------------------------------------------------- |
| `provider` | `"browserstack" \| "saucelabs" \| "testmu" \| "testingbot"` | ✓     | —                | المزوّد السحابي                                       |
| `path`     | string                                                      | ✓     | —                | المسار المطلق لملف `.apk` أو `.ipa`                   |
| `customId` | string                                                      | —     | —                | معرّف مخصص اختياري للإشارة إلى التطبيق لاحقًا         |
| `region`   | `"us-west-1" \| "eu-central-1" \| "apac-southeast-1"`       | —     | `"eu-central-1"` | منطقة Sauce Labs                                      |

```js
// الرفع إلى كل مزوّد
upload_app({ provider: "browserstack", path: "/path/to/app.apk" })
upload_app({ provider: "saucelabs", path: "/path/to/app.ipa", region: "us-west-1" })
upload_app({ provider: "testmu", path: "/path/to/app.apk" })
upload_app({ provider: "testingbot", path: "/path/to/app.apk" })
```
