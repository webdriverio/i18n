أدوات المطور (DevTools) هي واجهة قوية لتصحيح الأخطاء قائمة على المتصفح، تتيح لك تصوّر عمليات تنفيذ اختباراتك والتحكم بها وفحصها في الوقت الفعلي. تعمل مع **WebdriverIO** و**Nightwatch.js** و**Selenium WebDriver** (مع أي مُشغّل) — بنفس الواجهة الخلفية، ونفس واجهة المستخدم، ونفس البنية التحتية للالتقاط.

## ما الذي توفره

- **إعادة تشغيل الاختبارات بشكل انتقائي** - انقر على أي حالة اختبار أو مجموعة اختبارات لإعادة تنفيذها فوراً ([التفاصيل](/docs/devtools/wdio/interactive-test-rerunning))
- **الحفظ وإعادة التشغيل (المقارنة)** - التقط لقطة لاختبار فاشل، ثم أعد تشغيله، وقارن بين التشغيلين جنباً إلى جنب مع محاذاتهما حسب الأوامر ([التفاصيل](/docs/devtools/wdio/preserve-and-rerun))
- **تصحيح الأخطاء بصرياً** - شاهد معاينات مباشرة للمتصفح مع لقطات شاشة تلقائية بعد كل أمر
- **تتبع التنفيذ** - اعرض سجلات أوامر مفصلة مع الطوابع الزمنية والنتائج
- **مراقبة الشبكة ووحدة التحكم** - افحص استدعاءات API وسجلات JavaScript ([الشبكة](/docs/devtools/wdio/network-logs) · [وحدة التحكم](/docs/devtools/wdio/console-logs))
- **الانتقال إلى الكود** - انتقل مباشرة إلى ملفات مصدر الاختبار باستخدام TestLens ([التفاصيل](/docs/devtools/wdio/testlens))
- **تسجيل الجلسات** - فيديو `.webm` متواصل للمتصفح لكل جلسة ([التفاصيل](/docs/devtools/wdio/screencast))
- **وضع التتبع (Trace mode)** - مسار التقاط بدون واجهة رسومية (headless) يُنتج ملف `trace.zip` قابلاً للنقل لإعادة التشغيل دون اتصال أو للاستخدام من قِبل الوكلاء ([التفاصيل](/docs/devtools/wdio/trace-mode))

## كيف تعمل

1. ابدأ اختباراتك كالمعتاد
2. تفتح أدوات المطور تلقائياً نافذة متصفح على `http://localhost:3000`
3. تعرض الواجهة التسلسل الهرمي للاختبارات، ومعاينة المتصفح، والخط الزمني للأوامر، والسجلات في الوقت الفعلي
4. بعد اكتمال الاختبارات، انقر على أي اختبار لإعادة تشغيله بشكل منفرد في نفس جلسة المتصفح

## اختر إطار العمل الخاص بك

- **[WebDriverIO](/docs/devtools/wdio)** - استخدم `@wdio/devtools-service` مع Mocha أو Jasmine أو Cucumber
- **[Nightwatch](/docs/devtools/nightwatch)** - استخدم `@wdio/nightwatch-devtools` دون أي تغييرات على كود الاختبار
- **[Selenium](/docs/devtools/selenium)** - استخدم `@wdio/selenium-devtools` مع Mocha أو Jest أو Cucumber أو سكربتات Node العادية
