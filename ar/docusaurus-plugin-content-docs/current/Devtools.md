---

أدوات المطورين (DevTools) هي واجهة تصحيح قوية تعمل في المتصفح لتصور تنفيذ الاختبارات والتحكم فيها وفحصها في الوقت الفعلي. تعمل مع كل من **WebdriverIO** و**Nightwatch.js** — نفس الخلفية، نفس واجهة المستخدم، نفس البنية التحتية للتسجيل.

## ما الذي توفره

- **إعادة تشغيل الاختبارات بشكل انتقائي** - انقر على أي حالة اختبار أو مجموعة لإعادة تنفيذها فوراً
- **التصحيح بصرياً** - شاهد معاينات المتصفح المباشرة مع لقطات شاشة تلقائية بعد كل أمر
- **تتبع التنفيذ** - عرض سجلات الأوامر التفصيلية مع الطوابع الزمنية والنتائج
- **مراقبة الشبكة والكونسول** - فحص استدعاءات API وسجلات JavaScript
- **التنقل إلى الكود** - الانتقال مباشرة إلى ملفات مصدر الاختبار باستخدام TestLens

## كيف تعمل

1. ابدأ اختباراتك بشكل طبيعي
2. تفتح DevTools تلقائياً نافذة متصفح على `http://localhost:3000`
3. تعرض الواجهة تسلسل الاختبار، ومعاينة المتصفح، والجدول الزمني للأوامر، والسجلات في الوقت الفعلي
4. بعد اكتمال الاختبارات، انقر على أي اختبار لإعادة تشغيله بشكل فردي في نفس جلسة المتصفح

## اختر إطار العمل

- **[WebDriverIO](/docs/devtools/wdio)** - استخدم `@wdio/devtools-service` مع Mocha أو Jasmine أو Cucumber
- **[Nightwatch](/docs/devtools/nightwatch)** - استخدم `@wdio/nightwatch-devtools` دون أي تغييرات في كود الاختبار
