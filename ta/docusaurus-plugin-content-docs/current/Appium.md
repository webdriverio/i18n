WebdriverIO மூலம் நீங்கள் உலாவியில் உள்ள வலைப் பயன்பாடுகளை மட்டுமல்லாமல், பின்வரும் பிற தளங்களையும் சோதிக்கலாம்:

- 📱 iOS, Android அல்லது Tizen இல் உள்ள மொபைல் பயன்பாடுகள்
- 🖥️ macOS அல்லது Windows இல் உள்ள டெஸ்க்டாப் பயன்பாடுகள்
- 📺 அத்துடன் Roku, tvOS, Android TV மற்றும் Samsung க்கான TV பயன்பாடுகள்

இந்த வகையான சோதனைகளை எளிதாக்க [Appium](https://appium.io/) ஐப் பயன்படுத்த நாங்கள் பரிந்துரைக்கிறோம். Appium பற்றிய ஒரு கண்ணோட்டத்தை அவர்களின் [அதிகாரப்பூர்வ ஆவணப் பக்கத்தில்](https://appium.io/docs/en/latest/intro/) பெறலாம்.

சரியான சூழலை அமைப்பது எளிதானது அல்ல. அதிர்ஷ்டவசமாக, இதற்கு உதவ Appium சூழலமைப்பில் சிறந்த கருவிகள் உள்ளன. மேலே உள்ள சூழல்களில் ஒன்றை அமைக்க, இதை இயக்கவும்:

```sh
$ npx appium-installer
```

இது அமைவு செயல்முறையின் மூலம் உங்களுக்கு வழிகாட்டும் [appium-installer](https://github.com/AppiumTestDistribution/appium-installer) கருவித்தொகுப்பைத் தொடங்கும்.
