WebdriverIO API ஆவணங்களுக்கு வரவேற்கிறோம். இந்தப் பக்கங்களில் செயல்படுத்தப்பட்ட அனைத்து நெறிமுறை இணைப்புகள் (protocol bindings) மற்றும் வசதிக் கட்டளைகளுக்கான (convenience commands) குறிப்புப் பொருட்கள் உள்ளன. [WebDriver](/docs/api/webdriver), [WebDriver Bidi](/docs/api/webdriverBidi) அல்லது [Appium](http://appium.io) போன்ற மொபைல் கட்டளைகள் உள்ளிட்ட நெறிமுறைக் கட்டளைகள், அடிப்படை டிரைவர் பின்தளத்திற்கு (driver backend) நேரடியாக அனுப்பப்படும் கட்டளைகளாகும். [`browser`](/docs/api/browser), [`element`](/docs/api/element) அல்லது [`mock`](/docs/api/mock) பொருளால் வழங்கப்படும் வசதிக் கட்டளைகள் உயர் நிலை ஊடாடலை வழங்குகின்றன.

:::info
இவை WebdriverIO __v10__-க்கான ஆவணங்கள். இன்னும் v9-ஐப் பயன்படுத்துகிறீர்களா? [v9 ஆவணங்களைப்](https://v9.webdriver.io) பயன்படுத்தவும் அல்லது [v10 இடம்பெயர்வு வழிகாட்டியைப்](/docs/v10-migration) பின்பற்றவும்.
:::

## பங்களிக்கவும்

ஒரு கட்டளைக்கு உங்களிடம் நல்ல உதாரணம் இருப்பதாக நீங்கள் கருதினால், தயங்காமல் ஒரு PR-ஐத் திறந்து சமர்ப்பிக்கவும். கீழே இடதுபுறத்தில் _“இந்தப் பக்கத்தைத் திருத்து”_ என்ற லேபிளுடன் உள்ள ஆரஞ்சு இணைப்பைக் கிளிக் செய்யவும். [பங்களிப்பு](https://github.com/webdriverio/webdriverio/blob/main/CONTRIBUTING.md) பகுதியைப் பார்த்து, இந்த ஆவணங்களை நாங்கள் எழுதும் முறையை நீங்கள் புரிந்துகொண்டுள்ளீர்கள் என்பதை உறுதிப்படுத்திக் கொள்ளுங்கள்.
