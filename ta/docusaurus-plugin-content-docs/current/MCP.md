## இது என்ன செய்ய முடியும்?

WebdriverIO MCP என்பது ஒரு **Model Context Protocol (MCP) சர்வர்** ஆகும், இது AI உதவியாளர்கள் வலை உலாவிகள் மற்றும் மொபைல் பயன்பாடுகளுடன் தானியக்கமாகச் செயல்படவும் தொடர்பு கொள்ளவும் உதவுகிறது.

### ஏன் WebdriverIO MCP?

-   **மொபைல்-முதன்மை**: உலாவி-மட்டும் MCP சர்வர்களைப் போலல்லாமல், WebdriverIO MCP ஆனது Appium வழியாக iOS மற்றும் Android நேட்டிவ் ஆப் தானியக்கத்தை ஆதரிக்கிறது
-   **குறுக்கு-தள செலக்டர்கள்**: ஸ்மார்ட் எலிமெண்ட் கண்டறிதல் பல லொகேட்டர் உத்திகளை (accessibility ID, XPath, UiAutomator, iOS predicates) தானாகவே உருவாக்குகிறது
-   **WebdriverIO சூழலமைப்பு**: சேவைகள் மற்றும் ரிப்போர்ட்டர்களின் வளமான சூழலமைப்புடன் கூடிய, நன்கு சோதிக்கப்பட்ட WebdriverIO கட்டமைப்பின் மீது கட்டமைக்கப்பட்டது

இது பின்வருவனவற்றுக்கு ஒரு ஒருங்கிணைந்த இடைமுகத்தை வழங்குகிறது:

-   🖥️ **டெஸ்க்டாப் உலாவிகள்** (Chrome, Firefox, Edge, Safari, headed அல்லது headless)
-   📱 **நேட்டிவ் மொபைல் ஆப்கள்** (Appium வழியாக iOS சிமுலேட்டர்கள் / Android எமுலேட்டர்கள் / உண்மையான சாதனங்கள்)
-   📳 **ஹைப்ரிட் மொபைல் ஆப்கள்** (Appium வழியாக Native + WebView கான்டெக்ஸ்ட் மாற்றம்)
-   ☁️ **கிளவுட் சாதனங்கள்** (BrowserStack, Sauce Labs, TestMu உண்மையான சாதன மற்றும் உலாவி கிளவுட்கள்)

இவை அனைத்தும் [`@wdio/mcp`](https://www.npmjs.com/package/@wdio/mcp) தொகுப்பின் மூலம் வழங்கப்படுகின்றன.

இது AI உதவியாளர்களை பின்வருவனவற்றைச் செய்ய அனுமதிக்கிறது:

-   **உலாவிகளைத் தொடங்கி கட்டுப்படுத்துதல்** - கட்டமைக்கக்கூடிய பரிமாணங்கள், headless பயன்முறை மற்றும் விருப்பமான ஆரம்ப நேவிகேஷனுடன்
-   **இணையதளங்களில் நேவிகேட் செய்தல்** மற்றும் எலிமெண்ட்களுடன் தொடர்பு கொள்ளுதல் (கிளிக், டைப், ஸ்க்ரோல்)
-   **பக்க உள்ளடக்கத்தைப் பகுப்பாய்வு செய்தல்** - accessibility tree மற்றும் தெரியும் எலிமெண்ட்கள் கண்டறிதல் வழியாக, பேஜினேஷன் ஆதரவுடன்
-   **ஸ்கிரீன்ஷாட்கள் எடுத்தல்** - தானாக மேம்படுத்தப்பட்டவை (அளவு மாற்றப்பட்டு, அதிகபட்சம் 1MB க்கு சுருக்கப்பட்டவை)
-   **குக்கீகளை நிர்வகித்தல்** - செஷன் கையாளுதலுக்காக
-   **மொபைல் சாதனங்களைக் கட்டுப்படுத்துதல்** - சைகைகள் உட்பட (tap, swipe, drag and drop)
-   **கான்டெக்ஸ்ட்களை மாற்றுதல்** - ஹைப்ரிட் ஆப்களில் native மற்றும் webview இடையே
-   **ஸ்கிரிப்ட்களை இயக்குதல்** - உலாவிகளில் JavaScript, சாதனங்களில் Appium மொபைல் கட்டளைகள்
-   **சாதன அம்சங்களைக் கையாளுதல்** - சுழற்சி, கீபோர்டு, புவிஇருப்பிடம் போன்றவை
-   மேலும் பல, [Tools](./mcp/tools) மற்றும் [Configuration](./mcp/configuration) விருப்பங்களைப் பார்க்கவும்

:::info

மொபைல் ஆப்களுக்கான குறிப்பு
மொபைல் தானியக்கத்திற்கு, பொருத்தமான டிரைவர்கள் நிறுவப்பட்ட, இயங்கும் Appium சர்வர் தேவை. அமைவு வழிமுறைகளுக்கு [முன்தேவைகள்](#prerequisites) பகுதியைப் பார்க்கவும்.

## நிறுவல்

`@wdio/mcp` ஐப் பயன்படுத்த எளிதான வழி, எந்த உள்ளூர் நிறுவலும் இல்லாமல் npx வழியாகப் பயன்படுத்துவதாகும்:

```sh
npx @wdio/mcp
```

அல்லது அதை உலகளாவிய முறையில் நிறுவவும்:

```sh
npm install -g @wdio/mcp
```

## Claude உடன் பயன்பாடு

Claude உடன் WebdriverIO MCP ஐப் பயன்படுத்த, கட்டமைப்புக் கோப்பை மாற்றவும்:

```json
{
    "mcpServers": {
        "wdio-mcp": {
            "command": "npx",
            "args": ["-y", "@wdio/mcp"]
        }
    }
}
```

கட்டமைப்பைச் சேர்த்த பிறகு, உங்கள் harness ஐ மறுதொடக்கம் செய்யவும். WebdriverIO MCP கருவிகள் உலாவி மற்றும் மொபைல் தானியக்கப் பணிகளுக்குக் கிடைக்கும்.

### Claude Code உடன் பயன்பாடு

Claude Code தானாகவே MCP சர்வர்களைக் கண்டறிகிறது. உங்கள் திட்டத்தின் `.claude/settings.json` அல்லது `.mcp.json` இல் இதைக் கட்டமைக்கலாம்.

அல்லது பின்வரும் கட்டளையை இயக்குவதன் மூலம் உலகளாவிய முறையில் .claude.json இல் சேர்க்கவும்:
```bash
claude mcp add --transport stdio wdio-mcp -- npx -y @wdio/mcp
```
claude code இல் `/mcp` கட்டளையை இயக்குவதன் மூலம் அதைச் சரிபார்க்கவும்.

## முன்தேவைகள்

### உலாவி தானியக்கம்

-   **Chrome, Firefox, Edge அல்லது Safari** நிறுவப்பட்டிருக்க வேண்டும்
-   WebdriverIO தானியங்கி டிரைவர் மேலாண்மையைக் கையாளுகிறது

### மொபைல் தானியக்கம்

#### iOS

1. Mac App Store இலிருந்து **Xcode ஐ நிறுவவும்**
2. **Xcode Command Line Tools ஐ நிறுவவும்**:
   ```sh
   xcode-select --install
   ```
3. **Appium ஐ நிறுவவும்**:
   ```sh
   npm install -g appium
   ```
4. **XCUITest டிரைவரை நிறுவவும்**:
   ```sh
   appium driver install xcuitest
   ```
5. **Appium சர்வரைத் தொடங்கவும்**:
   ```sh
   appium
   ```
6. **சிமுலேட்டர்களுக்கு**: சிமுலேட்டர்களை உருவாக்க/நிர்வகிக்க Xcode → Window → Devices and Simulators ஐத் திறக்கவும்
7. **உண்மையான சாதனங்களுக்கு**: உங்களுக்குச் சாதன UDID (40-எழுத்து தனித்துவ அடையாளங்காட்டி) தேவைப்படும்

#### Android

1. **Android Studio ஐ நிறுவி** Android SDK ஐ அமைக்கவும்
2. **சூழல் மாறிகளை அமைக்கவும்**:
   ```sh
   export ANDROID_HOME=$HOME/Library/Android/sdk
   export PATH=$PATH:$ANDROID_HOME/emulator
   export PATH=$PATH:$ANDROID_HOME/platform-tools
   ```
3. **Appium ஐ நிறுவவும்**:
   ```sh
   npm install -g appium
   ```
4. **UiAutomator2 டிரைவரை நிறுவவும்**:
   ```sh
   appium driver install uiautomator2
   ```
5. **Appium சர்வரைத் தொடங்கவும்**:
   ```sh
   appium
   ```
6. Android Studio → Virtual Device Manager வழியாக **ஒரு எமுலேட்டரை உருவாக்கவும்**
7. சோதனைகளை இயக்குவதற்கு முன் **எமுலேட்டரைத் தொடங்கவும்**

## கட்டமைப்பு

### இது எப்படி செயல்படுகிறது

WebdriverIO MCP ஆனது AI உதவியாளர்களுக்கும் உலாவி/மொபைல் தானியக்கத்திற்கும் இடையே ஒரு பாலமாகச் செயல்படுகிறது:

```
┌─────────────────┐     MCP Protocol      ┌─────────────────┐
│  Claude Desktop │ ◄──────────────────►  │    @wdio/mcp    │
│  or Claude Code │   (stdio or HTTP)     │     Server      │
└─────────────────┘                       └────────┬────────┘
                                                   │
                                             WebDriverIO API
                                                   │
                    ┌──────────────────────────────┼──────────────────────────────┐
                    │                              │                              │
            ┌───────▼───────┐             ┌───────▼───────┐             ┌───────▼───────┐
            │    Browser    │             │    Appium     │             │   Cloud        │
            │ (local/CDP)   │             │  (iOS/Android)│             │   Providers    │
            └───────────────┘             └───────────────┘             └───────────────┘
```

### செஷன் மேலாண்மை

-   **ஒற்றை-செஷன் மாதிரி**: ஒரு நேரத்தில் ஒரு உலாவி அல்லது ஆப் செஷன் மட்டுமே செயலில் இருக்க முடியும்
-   **செஷன் நிலை** கருவி அழைப்புகள் முழுவதும் உலகளாவிய முறையில் பராமரிக்கப்படுகிறது
-   **தானியங்கி பிரிப்பு**: பாதுகாக்கப்பட்ட நிலையுடன் (`noReset: true`) உள்ள செஷன்கள் மூடும்போது தானாகவே பிரிக்கப்படும்

### எலிமெண்ட் கண்டறிதல்

#### உலாவி (வலை)

-   தெரியும், தொடர்பு கொள்ளக்கூடிய அனைத்து எலிமெண்ட்களையும் கண்டறிய மேம்படுத்தப்பட்ட உலாவி ஸ்கிரிப்டைப் பயன்படுத்துகிறது
-   CSS செலக்டர்கள், IDகள், கிளாஸ்கள் மற்றும் ARIA தகவல்களுடன் எலிமெண்ட்களைத் திருப்பி அனுப்புகிறது
-   வியூபோர்ட் வடிகட்டல் மற்றும் பேஜினேஷனை ஆதரிக்கிறது

#### மொபைல் (நேட்டிவ் ஆப்கள்)

-   திறமையான XML page source பாகுபடுத்தலைப் பயன்படுத்துகிறது (பாரம்பரிய வினவல்களுக்கான 600+ க்கு எதிராக 2 HTTP அழைப்புகள்)
-   Android மற்றும் iOS க்கான தள-சார்ந்த எலிமெண்ட் வகைப்பாடு
-   ஒவ்வொரு எலிமெண்டிற்கும் பல லொகேட்டர் உத்திகளை உருவாக்குகிறது:
    -   Accessibility ID (குறுக்கு-தளம், மிகவும் நிலையானது)
    -   Resource ID / Name பண்புக்கூறு
    -   Text / Label பொருத்துதல்
    -   XPath (முழு மற்றும் எளிமைப்படுத்தப்பட்டது)
    -   UiAutomator (Android) / Predicates (iOS)

## செலக்டர் தொடரியல்

MCP சர்வர் பல செலக்டர் உத்திகளை ஆதரிக்கிறது. விரிவான ஆவணங்களுக்கு [Selectors](./mcp/selectors) ஐப் பார்க்கவும்.

### வலை (CSS/XPath)

```
# CSS செலக்டர்கள்
button.my-class
#element-id
[data-testid="login"]

# XPath
//button[@class='submit']
//a[contains(text(), 'Click')]

# உரை செலக்டர்கள் (WebdriverIO-க்கு குறிப்பானது)
button=Exact Button Text
a*=Partial Link Text
```

### மொபைல் (குறுக்கு-தளம்)

```
# Accessibility ID (பரிந்துரைக்கப்படுகிறது - iOS & Android இரண்டிலும் செயல்படும்)
~loginButton

# Android UiAutomator
android=new UiSelector().text("Login")

# iOS Predicate String
-ios predicate string:label == "Login"

# iOS Class Chain
-ios class chain:**/XCUIElementTypeButton[`label == "Login"`]

# XPath (இரண்டு தளங்களிலும் செயல்படும்)
//android.widget.Button[@text="Login"]
//XCUIElementTypeButton[@label="Login"]
```

## தானியங்கி கையாளுதல்

### அனுமதிகள்

இயல்பாக, MCP சர்வர் ஆப் அனுமதிகளைத் தானாகவே வழங்குகிறது (`autoGrantPermissions: true`), இது தானியக்கத்தின் போது அனுமதி உரையாடல்களைக் கைமுறையாகக் கையாள வேண்டிய தேவையை நீக்குகிறது.

### சிஸ்டம் அலர்ட்கள்

சிஸ்டம் அலர்ட்கள் ("Allow notifications?" போன்றவை) இயல்பாகவே தானாக ஏற்றுக்கொள்ளப்படுகின்றன (`autoAcceptAlerts: true`). இதற்குப் பதிலாக நிராகரிக்க `autoDismissAlerts: true` மூலம் இதைக் கட்டமைக்கலாம்.

## டிரான்ஸ்போர்ட்

இயல்பாக, சர்வர் **stdio** மூலம் இயங்குகிறது (AI கிளையண்டால் ஒரு subprocess ஆகத் தொடங்கப்படுகிறது). subprocess-அடிப்படையிலான MCP ஐ ஆதரிக்காத கிளையண்ட்களுக்கு (llama.cpp, Codex secure mode), **HTTP டிரான்ஸ்போர்ட்டைப்** பயன்படுத்தவும்:

```bash
npx @wdio/mcp --http --port 3000
```

`--allowedHosts` மற்றும் `--allowedOrigins` உட்பட முழு விருப்பங்களுக்கு [Transport](./mcp/transport) ஐப் பார்க்கவும்.

## செயல்திறன் மேம்படுத்தல்

MCP சர்வர் திறமையான AI உதவியாளர் தொடர்புக்காக மேம்படுத்தப்பட்டுள்ளது:

-   **TOON வடிவம்**: குறைந்தபட்ச டோக்கன் பயன்பாட்டிற்காக Token-Oriented Object Notation ஐப் பயன்படுத்துகிறது
-   **XML பாகுபடுத்தல்**: மொபைல் எலிமெண்ட் கண்டறிதல் 2 HTTP அழைப்புகளைப் பயன்படுத்துகிறது (பாரம்பரியமாக 600+ க்கு எதிராக)
-   **ஸ்கிரீன்ஷாட் சுருக்கம்**: படங்கள் அதிகபட்சம் 1MB க்கு தானாகச் சுருக்கப்படுகின்றன
-   **வியூபோர்ட் வடிகட்டல்**: இயல்பாக தெரியும் எலிமெண்ட்கள் மட்டுமே திருப்பி அனுப்பப்படுகின்றன
-   **பேஜினேஷன்**: பதில் அளவைக் குறைக்க பெரிய எலிமெண்ட் பட்டியல்களைப் பக்கங்களாகப் பிரிக்கலாம்

## பிழை கையாளுதல்

அனைத்து கருவிகளும் வலுவான பிழை கையாளுதலுடன் வடிவமைக்கப்பட்டுள்ளன:

-   பிழைகள் உரை உள்ளடக்கமாகத் திருப்பி அனுப்பப்படுகின்றன (ஒருபோதும் throw செய்யப்படுவதில்லை), இது MCP புரோட்டோகால் நிலைத்தன்மையைப் பராமரிக்கிறது
-   விளக்கமான பிழைச் செய்திகள் சிக்கல்களைக் கண்டறிய உதவுகின்றன
-   தனிப்பட்ட செயல்பாடுகள் தோல்வியடைந்தாலும் செஷன் நிலை பாதுகாக்கப்படுகிறது

## பயன்பாட்டு நிகழ்வுகள்

### தர உறுதிப்பாடு

-   AI-இயக்கப்படும் சோதனை நிகழ்வு இயக்கம்
-   ஸ்கிரீன்ஷாட்களுடன் காட்சி பின்னடைவு சோதனை
-   accessibility tree பகுப்பாய்வு வழியாக அணுகல்தன்மை தணிக்கை

### வலை ஸ்கிரேப்பிங் & தரவு பிரித்தெடுத்தல்

-   சிக்கலான பல-பக்க ஓட்டங்களில் நேவிகேட் செய்தல்
-   மாறும் உள்ளடக்கத்திலிருந்து கட்டமைக்கப்பட்ட தரவைப் பிரித்தெடுத்தல்
-   அங்கீகாரம் மற்றும் செஷன் மேலாண்மையைக் கையாளுதல்

### மொபைல் ஆப் சோதனை

-   குறுக்கு-தள சோதனை தானியக்கம் (iOS + Android)
-   ஆன்போர்டிங் ஓட்ட சரிபார்ப்பு
-   டீப் லிங்கிங் மற்றும் நேவிகேஷன் சோதனை

### ஒருங்கிணைப்பு சோதனை

-   முழுமையான (End-to-end) பணிப்பாய்வு சோதனை
-   API + UI ஒருங்கிணைப்பு சரிபார்ப்பு
-   பல-தள நிலைத்தன்மை சோதனைகள்

## சிக்கல் தீர்த்தல்

### உலாவி தொடங்கவில்லை

-   இலக்கு உலாவி நிறுவப்பட்டுள்ளதா என்பதை உறுதிசெய்யவும்
-   வேறு எந்த செயல்முறையும் இயல்புநிலை டிபக்கிங் போர்ட்டை (9222) பயன்படுத்தவில்லை என்பதைச் சரிபார்க்கவும்
-   காட்சிச் சிக்கல்கள் ஏற்பட்டால் headless பயன்முறையை முயற்சிக்கவும்

### Appium இணைப்பு தோல்வியடைந்தது

-   Appium சர்வர் இயங்குகிறதா என்பதைச் சரிபார்க்கவும் (`appium`)
-   `appiumConfig` இல் Appium host மற்றும் port ஐச் சரிபார்க்கவும்
-   பொருத்தமான டிரைவர் நிறுவப்பட்டுள்ளதா என்பதை உறுதிசெய்யவும் (`appium driver list`)

### iOS சிமுலேட்டர் சிக்கல்கள்

-   Xcode நிறுவப்பட்டு புதுப்பித்த நிலையில் உள்ளதா என்பதை உறுதிசெய்யவும்
-   சிமுலேட்டர்கள் கிடைக்கின்றனவா என்பதைச் சரிபார்க்கவும் (`xcrun simctl list devices`)
-   உண்மையான சாதனங்களுக்கு, UDID சரியானதா என்பதைச் சரிபார்க்கவும்

### Android எமுலேட்டர் சிக்கல்கள்

-   Android SDK சரியாகக் கட்டமைக்கப்பட்டுள்ளதா என்பதை உறுதிசெய்யவும்
-   எமுலேட்டர் இயங்குகிறதா என்பதைச் சரிபார்க்கவும் (`adb devices`)
-   `ANDROID_HOME` சூழல் மாறி அமைக்கப்பட்டுள்ளதா என்பதைச் சரிபார்க்கவும்
