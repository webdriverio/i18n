Witamy w dokumentacji API WebdriverIO. Strony te zawierają materiały referencyjne dotyczące wszystkich zaimplementowanych powiązań protokołów oraz poleceń ułatwiających pracę. Polecenia protokołów, w tym [WebDriver](/docs/api/webdriver), [WebDriver Bidi](/docs/api/webdriverBidi) czy polecenia mobilne, takie jak [Appium](http://appium.io), to polecenia wysyłane bezpośrednio do bazowego backendu sterownika. Polecenia ułatwiające pracę, udostępniane przez obiekty [`browser`](/docs/api/browser), [`element`](/docs/api/element) lub [`mock`](/docs/api/mock), oferują interakcję na wyższym poziomie.

:::info
To jest dokumentacja dla WebdriverIO __v10__. Nadal korzystasz z v9? Skorzystaj z [dokumentacji v9](https://v9.webdriver.io) lub postępuj zgodnie z [przewodnikiem migracji do v10](/docs/v10-migration).
:::
