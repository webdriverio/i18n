---

Niestety w tej chwili nie istnieje stabilny sterownik do automatyzacji aplikacji Windows. Chociaż Appium utrzymuje [Windows Driver](https://github.com/appium/appium-windows-driver), który bazuje na [serwerze WinAppDriver](https://github.com/microsoft/WinAppDriver) firmy Microsoft, nie zalecamy jego używania, ponieważ Microsoft przestał rozwijać ten serwer i istnieje wiele [znanych błędów](https://github.com/search?q=repo%3Amicrosoft%2FWinAppDriver+webdriverio&type=issues).

Jeśli ktoś zna sposób na automatyzację aplikacji Windows, prosimy o informację na [Discordzie](https://discord.webdriver.io).
