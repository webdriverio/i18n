title: Windows
description: "Consulta el estado actual de la automatización de aplicaciones nativas de Windows con WebdriverIO y por qué todavía no hay un driver estable disponible."
---

Desafortunadamente, en este momento no existe un driver estable para automatizar aplicaciones de Windows. Aunque Appium mantiene un [Windows Driver](https://github.com/appium/appium-windows-driver) basado en el [servidor WinAppDriver](https://github.com/microsoft/WinAppDriver) de Microsoft, no recomendamos usarlo, dado que Microsoft ha dejado de mantener el servidor y existen muchos [errores conocidos](https://github.com/search?q=repo%3Amicrosoft%2FWinAppDriver+webdriverio&type=issues).

Si alguien conoce una forma de automatizar aplicaciones de Windows, por favor háganoslo saber en [Discord](https://discord.webdriver.io).
