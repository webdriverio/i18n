Bienvenido a la documentación de la API de WebdriverIO. Estas páginas contienen materiales de referencia para todos los enlaces de protocolo y comandos de conveniencia implementados. Los comandos de protocolo, incluidos [WebDriver](/docs/api/webdriver), [WebDriver Bidi](/docs/api/webdriverBidi) o comandos móviles como [Appium](http://appium.io), son comandos que se envían directamente al backend del driver subyacente. Los comandos de conveniencia proporcionados por los objetos [`browser`](/docs/api/browser), [`element`](/docs/api/element) o [`mock`](/docs/api/mock) ofrecen una interactividad de más alto nivel.

:::info
Esta es la documentación de WebdriverIO __v10__. ¿Todavía usas la v9? Consulta la [documentación de la v9](https://v9.webdriver.io) o sigue la [guía de migración a la v10](/docs/v10-migration).
:::
