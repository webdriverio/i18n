TestLens proporciona navegación de código inteligente entre la interfaz de DevTools y los archivos fuente de tus pruebas. Haz clic en cualquier prueba en la interfaz para saltar directamente a la definición de esa prueba en tu editor de código, con números de línea exactos.

**Cómo funciona:**
- **Jerarquía visual de pruebas** - Visualiza la estructura de tus pruebas (suites, tests, escenarios) en una vista de árbol
- **Mapeo de código fuente** - Cada prueba enlaza con su ubicación exacta en tus archivos fuente
- **Navegación con un clic** - Haz clic en cualquier prueba para abrirla en tu editor
- **Integración con editores** - Funciona con editores de código populares a través de protocolos file:line

Esta conexión fluida entre la interfaz y el código acelera la depuración al eliminar la búsqueda manual de código cuando se investigan fallos en las pruebas.
