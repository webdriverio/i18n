TestLens proporciona navegación inteligente de código entre la interfaz de DevTools y los archivos fuente de tus pruebas. Haz clic en cualquier prueba en la interfaz para saltar directamente a la definición de esa prueba en tu editor de código, con los números de línea exactos.

**Cómo funciona:**
- **Jerarquía visual de pruebas** - Visualiza la estructura de tus pruebas (suites, pruebas, escenarios) en una vista de árbol
- **Mapeo de código fuente** - Cada prueba enlaza a su ubicación exacta en tus archivos fuente
- **Navegación con un clic** - Haz clic en cualquier prueba para abrirla en tu editor
- **Integración con editores** - Funciona con editores de código populares mediante protocolos file:line

Esta conexión fluida entre la interfaz y el código agiliza la depuración al eliminar la búsqueda manual de código cuando investigas fallos en las pruebas.
