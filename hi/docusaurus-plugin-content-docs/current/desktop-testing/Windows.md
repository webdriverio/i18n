---

दुर्भाग्य से इस समय Windows एप्लिकेशन को ऑटोमेट करने के लिए कोई स्थिर ड्राइवर उपलब्ध नहीं है। हालांकि Appium एक [Windows Driver](https://github.com/appium/appium-windows-driver) का रखरखाव करता है जो Microsoft के [WinAppDriver server](https://github.com/microsoft/WinAppDriver) पर आधारित है, फिर भी हम इसका उपयोग करने की सलाह नहीं देंगे क्योंकि Microsoft ने इस सर्वर का रखरखाव बंद कर दिया है और इसमें कई [ज्ञात बग](https://github.com/search?q=repo%3Amicrosoft%2FWinAppDriver+webdriverio&type=issues) हैं।

यदि किसी को Windows एप्लिकेशन को ऑटोमेट करने का कोई तरीका पता है, तो कृपया हमें [Discord](https://discord.webdriver.io) पर बताएं।
