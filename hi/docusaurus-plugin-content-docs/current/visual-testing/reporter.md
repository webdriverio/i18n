विज़ुअल रिपोर्टर `@wdio/visual-service` में पेश की गई एक नई सुविधा है, जो संस्करण [v5.2.0](https://github.com/webdriverio/visual-testing/releases/tag/%40wdio%2Fvisual-service%405.2.0) से उपलब्ध है। यह रिपोर्टर उपयोगकर्ताओं को विज़ुअल टेस्टिंग सर्विस द्वारा जनरेट की गई JSON डिफ़ रिपोर्ट्स को विज़ुअलाइज़ करने और उन्हें मानव-पठनीय प्रारूप में बदलने की सुविधा देता है। यह आउटपुट की समीक्षा के लिए एक ग्राफ़िकल इंटरफ़ेस प्रदान करके टीमों को विज़ुअल टेस्टिंग परिणामों का बेहतर विश्लेषण और प्रबंधन करने में मदद करता है।

इस सुविधा का उपयोग करने के लिए, सुनिश्चित करें कि आपके पास आवश्यक `output.json` फ़ाइल जनरेट करने के लिए ज़रूरी कॉन्फ़िगरेशन है। यह दस्तावेज़ आपको विज़ुअल रिपोर्टर को सेट अप करने, चलाने और समझने में मार्गदर्शन करेगा।

# पूर्वापेक्षाएँ

विज़ुअल रिपोर्टर का उपयोग करने से पहले, सुनिश्चित करें कि आपने JSON रिपोर्ट फ़ाइलें जनरेट करने के लिए विज़ुअल टेस्टिंग सर्विस को कॉन्फ़िगर किया है:

```ts
export const config = {
    // ...
    services: [
        [
            "visual",
            {
                createJsonReportFiles: true, // output.json फ़ाइल जनरेट करता है
            },
        ],
    ],
};
```

अधिक विस्तृत सेटअप निर्देशों के लिए, WebdriverIO [विज़ुअल टेस्टिंग डॉक्यूमेंटेशन](./) या [`createJsonReportFiles`](./service-options.md#createjsonreportfiles-new) देखें

# इंस्टॉलेशन

विज़ुअल रिपोर्टर को इंस्टॉल करने के लिए, npm का उपयोग करके इसे अपने प्रोजेक्ट में डेवलपमेंट डिपेंडेंसी के रूप में जोड़ें:

```bash
npm install @wdio/visual-reporter --save-dev
```

यह सुनिश्चित करेगा कि आपके विज़ुअल टेस्ट से रिपोर्ट जनरेट करने के लिए आवश्यक फ़ाइलें उपलब्ध हैं।

# उपयोग

## विज़ुअल रिपोर्ट बनाना

एक बार जब आप अपने विज़ुअल टेस्ट चला लेते हैं और वे `output.json` फ़ाइल जनरेट कर देते हैं, तो आप CLI या इंटरैक्टिव प्रॉम्प्ट्स का उपयोग करके विज़ुअल रिपोर्ट बना सकते हैं।

### CLI उपयोग

आप निम्नलिखित चलाकर रिपोर्ट जनरेट करने के लिए CLI कमांड का उपयोग कर सकते हैं:

```bash
npx wdio-visual-reporter --jsonOutput=<path-to-output.json> --reportFolder=<path-to-store-report> --logLevel=debug
```

#### आवश्यक विकल्प:

-   `--jsonOutput`: विज़ुअल टेस्टिंग सर्विस द्वारा जनरेट की गई `output.json` फ़ाइल का रिलेटिव पाथ। यह पाथ उस डायरेक्टरी के सापेक्ष है जिससे आप कमांड चलाते हैं।
-   `--reportFolder`: वह रिलेटिव डायरेक्टरी जहाँ जनरेट की गई रिपोर्ट संग्रहीत की जाएगी। यह पाथ भी उस डायरेक्टरी के सापेक्ष है जिससे आप कमांड चलाते हैं।

#### वैकल्पिक विकल्प:

-   `--logLevel`: विस्तृत लॉगिंग प्राप्त करने के लिए `debug` पर सेट करें, जो विशेष रूप से समस्या निवारण के लिए उपयोगी है।

#### उदाहरण

```bash
npx wdio-visual-reporter --jsonOutput=/path/to/output.json --reportFolder=/path/to/report --logLevel=debug
```

यह निर्दिष्ट फ़ोल्डर में रिपोर्ट जनरेट करेगा और कंसोल में फ़ीडबैक प्रदान करेगा। उदाहरण के लिए:

```bash
✔ Build output copied successfully to "/path/to/report".
⠋ Prepare report assets...
✔ Successfully generated the report assets.
```

#### रिपोर्ट देखना

:::warning
`path/to/report/index.html` को **लोकल सर्वर से सर्व किए बिना** सीधे ब्राउज़र में खोलना काम **नहीं** करेगा।
:::

रिपोर्ट देखने के लिए, आपको [sirv-cli](https://www.npmjs.com/package/sirv-cli) जैसे एक साधारण सर्वर का उपयोग करना होगा। आप निम्नलिखित कमांड से सर्वर शुरू कर सकते हैं:

```bash
npx sirv-cli /path/to/report --single
```

यह नीचे दिए गए उदाहरण के समान लॉग उत्पन्न करेगा। ध्यान दें कि पोर्ट नंबर भिन्न हो सकता है:

```logs
  Your application is ready~! 🚀

  - Local:      http://localhost:8080
  - Network:    Add `--host` to expose

────────────────── LOGS ──────────────────
```

अब आप दिए गए URL को अपने ब्राउज़र में खोलकर रिपोर्ट देख सकते हैं।

### इंटरैक्टिव प्रॉम्प्ट्स का उपयोग

वैकल्पिक रूप से, आप निम्नलिखित कमांड चला सकते हैं और रिपोर्ट जनरेट करने के लिए प्रॉम्प्ट्स का उत्तर दे सकते हैं:

```bash
npx @wdio/visual-reporter
```

प्रॉम्प्ट्स आवश्यक पाथ और विकल्प प्रदान करने में आपका मार्गदर्शन करेंगे। अंत में इंटरैक्टिव प्रॉम्प्ट यह भी पूछेगा कि क्या आप रिपोर्ट देखने के लिए सर्वर शुरू करना चाहते हैं। यदि आप सर्वर शुरू करना चुनते हैं, तो टूल एक साधारण सर्वर लॉन्च करेगा और लॉग में एक URL प्रदर्शित करेगा। रिपोर्ट देखने के लिए आप इस URL को अपने ब्राउज़र में खोल सकते हैं।

# विज़ुअल रिपोर्ट को समझना

विज़ुअल रिपोर्टर आपके विज़ुअल टेस्ट परिणामों का एक व्यवस्थित दृश्य प्रदान करता है। प्रत्येक टेस्ट रन के लिए, आप निम्न कर सकेंगे:

-   टेस्ट केस के बीच आसानी से नेविगेट करें और एकत्रित परिणाम देखें।
-   टेस्ट नाम, उपयोग किए गए ब्राउज़र और तुलना परिणाम जैसे मेटाडेटा की समीक्षा करें।
-   डिफ़ इमेज देखें जो दिखाती हैं कि विज़ुअल अंतर कहाँ पाए गए।

यह विज़ुअल प्रस्तुति आपके टेस्ट परिणामों के विश्लेषण को सरल बनाती है, जिससे विज़ुअल रिग्रेशन की पहचान करना और उन्हें ठीक करना आसान हो जाता है।
