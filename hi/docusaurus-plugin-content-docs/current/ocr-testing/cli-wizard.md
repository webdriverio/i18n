आप OCR CLI विज़ार्ड का उपयोग करके बिना टेस्ट चलाए यह जाँच सकते हैं कि किसी इमेज में कौन-सा टेक्स्ट ढूँढा जा सकता है। इसके लिए केवल निम्नलिखित चीज़ों की आवश्यकता है:

-   आपने `@wdio/ocr-service` को एक dependency के रूप में इंस्टॉल किया हो, देखें [Getting Started](./getting-started)
-   एक इमेज जिसे आप प्रोसेस करना चाहते हैं

फिर विज़ार्ड शुरू करने के लिए निम्नलिखित कमांड चलाएँ

```sh
npx ocr-service
```

यह एक विज़ार्ड शुरू करेगा जो आपको इमेज चुनने और haystack के साथ-साथ advanced mode का उपयोग करने के चरणों में मार्गदर्शन करेगा। निम्नलिखित प्रश्न पूछे जाते हैं

## आप फ़ाइल को कैसे निर्दिष्ट करना चाहेंगे?

निम्नलिखित विकल्प चुने जा सकते हैं

-   "फ़ाइल एक्सप्लोरर" का उपयोग करें
-   फ़ाइल पाथ मैन्युअल रूप से टाइप करें

### "फ़ाइल एक्सप्लोरर" का उपयोग करें

CLI विज़ार्ड आपके सिस्टम पर फ़ाइलें खोजने के लिए "फ़ाइल एक्सप्लोरर" का उपयोग करने का विकल्प प्रदान करता है। यह उस फ़ोल्डर से शुरू होता है जहाँ से आप कमांड चलाते हैं। एक इमेज चुनने के बाद (अपनी arrow keys और ENTER key का उपयोग करें) आप अगले प्रश्न पर आगे बढ़ेंगे

### फ़ाइल पाथ मैन्युअल रूप से टाइप करें

यह आपकी लोकल मशीन पर कहीं मौजूद किसी फ़ाइल का सीधा पाथ है

### क्या आप haystack का उपयोग करना चाहेंगे?

यहाँ आपके पास उस क्षेत्र को चुनने का विकल्प है जिसे प्रोसेस किया जाना है। इससे प्रक्रिया तेज़ हो सकती है या OCR इंजन द्वारा ढूँढे जा सकने वाले टेक्स्ट की मात्रा कम/सीमित हो सकती है। आपको निम्नलिखित प्रश्नों के आधार पर `x`, `y`, `width`, `height` डेटा प्रदान करना होगा:

-   x कोऑर्डिनेट दर्ज करें:
-   y कोऑर्डिनेट दर्ज करें:
-   width दर्ज करें:
-   height दर्ज करें:

## क्या आप advanced mode का उपयोग करना चाहते हैं?

Advanced mode में अतिरिक्त फ़ीचर्स होंगे, जैसे:

-   कंट्रास्ट सेट करना
-   भविष्य में और भी फ़ीचर्स आएँगे
