---

WebdriverIO API डॉक्स में आपका स्वागत है। इन पृष्ठों में सभी लागू किए गए प्रोटोकॉल बाइंडिंग्स और सुविधाजनक कमांड्स के लिए संदर्भ सामग्री शामिल है। प्रोटोकॉल कमांड्स, जिनमें [WebDriver](/docs/api/webdriver), [WebDriver Bidi](/docs/api/webdriverBidi) या [Appium](http://appium.io) जैसी मोबाइल कमांड्स शामिल हैं, वे कमांड्स हैं जो सीधे अंतर्निहित ड्राइवर बैकएंड को भेजी जाती हैं। [`browser`](/docs/api/browser), [`element`](/docs/api/element) या [`mock`](/docs/api/mock) ऑब्जेक्ट द्वारा प्रदान की गई सुविधाजनक कमांड्स उच्च स्तरीय इंटरैक्टिविटी प्रदान करती हैं।

:::info
ये WebdriverIO __v10__ के डॉक्स हैं। अभी भी v9 पर हैं? [v9 दस्तावेज़ीकरण](https://v9.webdriver.io) का उपयोग करें या [v10 माइग्रेशन गाइड](/docs/v10-migration) का पालन करें।
:::
