WebdriverIO [Jenkins](https://jenkins-ci.org) जैसे CI सिस्टम के साथ गहन इंटीग्रेशन प्रदान करता है। `junit` रिपोर्टर के साथ, आप आसानी से अपने टेस्ट को डीबग कर सकते हैं और साथ ही अपने टेस्ट परिणामों को ट्रैक भी कर सकते हैं। यह इंटीग्रेशन काफी आसान है।

1. `junit` टेस्ट रिपोर्टर इंस्टॉल करें: `$ npm install @wdio/junit-reporter --save-dev`)
1. अपने कॉन्फ़िग को अपडेट करें ताकि आपके XUnit परिणाम ऐसी जगह सेव हों जहाँ Jenkins उन्हें ढूंढ सके,
    (और `junit` रिपोर्टर निर्दिष्ट करें):

```js
// wdio.conf.js
module.exports = {
    // ...
    reporters: [
        'dot',
        ['junit', {
            outputDir: './'
        }]
    ],
    // ...
}
```

कौन सा फ्रेमवर्क चुनना है, यह आप पर निर्भर है। रिपोर्ट्स एक जैसी ही होंगी।
इस ट्यूटोरियल के लिए, हम Jasmine का उपयोग करेंगे।

कुछ टेस्ट लिखने के बाद, आप एक नया Jenkins जॉब सेटअप कर सकते हैं। इसे एक नाम और विवरण दें:

![Name And Description](/img/jenkins/jobname.png "Name And Description")

फिर सुनिश्चित करें कि यह हमेशा आपकी रिपॉजिटरी का नवीनतम संस्करण प्राप्त करे:

![Jenkins Git Setup](/img/jenkins/gitsetup.png "Jenkins Git Setup")

**अब महत्वपूर्ण भाग:** शेल कमांड्स निष्पादित करने के लिए एक `build` स्टेप बनाएं। `build` स्टेप को आपका प्रोजेक्ट बिल्ड करना होता है। चूंकि यह डेमो प्रोजेक्ट केवल एक बाहरी ऐप का परीक्षण करता है, इसलिए आपको कुछ भी बिल्ड करने की आवश्यकता नहीं है। बस node डिपेंडेंसीज़ इंस्टॉल करें और कमांड `npm test` चलाएं (जो `node_modules/.bin/wdio test/wdio.conf.js` का एक उपनाम है)।

यदि आपने AnsiColor जैसा कोई प्लगइन इंस्टॉल किया है, लेकिन लॉग्स अभी भी रंगीन नहीं हैं, तो एनवायरनमेंट वेरिएबल `FORCE_COLOR=1` के साथ टेस्ट चलाएं (उदाहरण के लिए, `FORCE_COLOR=1 npm test`)।

![Build Step](/img/jenkins/runjob.png "Build Step")

अपने टेस्ट के बाद, आप चाहेंगे कि Jenkins आपकी XUnit रिपोर्ट को ट्रैक करे। ऐसा करने के लिए, आपको _"Publish JUnit test result report"_ नामक एक पोस्ट-बिल्ड एक्शन जोड़ना होगा।

आप अपनी रिपोर्ट्स को ट्रैक करने के लिए एक बाहरी XUnit प्लगइन भी इंस्टॉल कर सकते हैं। JUnit प्लगइन बुनियादी Jenkins इंस्टॉलेशन के साथ आता है और अभी के लिए पर्याप्त है।

कॉन्फ़िग फ़ाइल के अनुसार, XUnit रिपोर्ट्स प्रोजेक्ट की रूट डायरेक्टरी में सेव की जाएंगी। ये रिपोर्ट्स XML फ़ाइलें हैं। इसलिए, रिपोर्ट्स को ट्रैक करने के लिए आपको बस Jenkins को अपनी रूट डायरेक्टरी में मौजूद सभी XML फ़ाइलों की ओर इंगित करना है:

![Post-build Action](/img/jenkins/postjob.png "Post-build Action")

बस इतना ही! आपने अब अपने WebdriverIO जॉब्स चलाने के लिए Jenkins को सेटअप कर लिया है। आपका जॉब अब इतिहास चार्ट के साथ विस्तृत टेस्ट परिणाम, विफल जॉब्स पर स्टैकट्रेस जानकारी, और प्रत्येक टेस्ट में उपयोग किए गए पेलोड सहित कमांड्स की एक सूची प्रदान करेगा।
