यह ट्यूटोरियल उन लोगों के लिए है जो Protractor का उपयोग कर रहे हैं और अपने फ्रेमवर्क को WebdriverIO में माइग्रेट करना चाहते हैं। इसकी शुरुआत तब हुई जब Angular टीम ने [घोषणा की](https://github.com/angular/protractor/issues/5502) कि Protractor को अब सपोर्ट नहीं किया जाएगा। WebdriverIO, Protractor के कई डिज़ाइन निर्णयों से प्रभावित रहा है, इसलिए माइग्रेट करने के लिए यह संभवतः सबसे करीबी फ्रेमवर्क है। WebdriverIO टीम Protractor के हर एक योगदानकर्ता के काम की सराहना करती है और आशा करती है कि यह ट्यूटोरियल WebdriverIO में बदलाव को आसान और सीधा बना देगा।

हालाँकि हम इसके लिए एक पूरी तरह से स्वचालित प्रक्रिया चाहेंगे, लेकिन वास्तविकता कुछ अलग है। हर किसी का सेटअप अलग होता है और हर कोई Protractor का उपयोग अलग-अलग तरीकों से करता है। हर चरण को चरण-दर-चरण निर्देश की बजाय मार्गदर्शन के रूप में देखा जाना चाहिए। यदि आपको माइग्रेशन में कोई समस्या आती है, तो [हमसे संपर्क करने](https://github.com/webdriverio/codemod/discussions/new) में संकोच न करें।

## सेटअप

Protractor और WebdriverIO API वास्तव में काफी हद तक समान हैं, इतना कि अधिकांश कमांड को एक [codemod](https://github.com/webdriverio/codemod) के माध्यम से स्वचालित तरीके से फिर से लिखा जा सकता है।

codemod इंस्टॉल करने के लिए, यह चलाएँ:

```sh
npm install jscodeshift @wdio/codemod
```

## रणनीति

माइग्रेशन की कई रणनीतियाँ हैं। आपकी टीम के आकार, टेस्ट फ़ाइलों की संख्या और माइग्रेट करने की तात्कालिकता के आधार पर आप सभी टेस्ट को एक साथ या फ़ाइल दर फ़ाइल बदलने का प्रयास कर सकते हैं। चूँकि Protractor का रखरखाव Angular संस्करण 15 (2022 के अंत) तक जारी रहेगा, इसलिए आपके पास अभी भी पर्याप्त समय है। आप Protractor और WebdriverIO टेस्ट को एक ही समय में चला सकते हैं और नए टेस्ट WebdriverIO में लिखना शुरू कर सकते हैं। अपने समय बजट के अनुसार आप पहले महत्वपूर्ण टेस्ट केस माइग्रेट करना शुरू कर सकते हैं और धीरे-धीरे उन टेस्ट तक पहुँच सकते हैं जिन्हें शायद आप हटा भी सकें।

## पहले कॉन्फ़िग फ़ाइल

codemod इंस्टॉल करने के बाद हम पहली फ़ाइल को बदलना शुरू कर सकते हैं। पहले [WebdriverIO के कॉन्फ़िगरेशन विकल्पों](configuration) पर एक नज़र डालें। कॉन्फ़िग फ़ाइलें बहुत जटिल हो सकती हैं और केवल आवश्यक हिस्सों को पोर्ट करना और यह देखना समझदारी हो सकती है कि बाकी को तब कैसे जोड़ा जा सकता है जब उन विशेष विकल्पों की आवश्यकता वाले संबंधित टेस्ट माइग्रेट किए जा रहे हों।

पहले माइग्रेशन के लिए हम केवल कॉन्फ़िग फ़ाइल को बदलते हैं और यह चलाते हैं:

```sh
npx jscodeshift -t ./node_modules/@wdio/codemod/protractor ./conf.ts
```

:::info

 आपकी कॉन्फ़िग का नाम अलग हो सकता है, लेकिन सिद्धांत वही होना चाहिए: माइग्रेशन की शुरुआत पहले कॉन्फ़िग से करें।

:::

## WebdriverIO डिपेंडेंसी इंस्टॉल करें

अगला चरण एक न्यूनतम WebdriverIO सेटअप को कॉन्फ़िगर करना है, जिसे हम एक फ्रेमवर्क से दूसरे में माइग्रेट करते समय धीरे-धीरे बढ़ाते जाएँगे। पहले हम WebdriverIO CLI इंस्टॉल करते हैं:

```sh
npm install --save-dev @wdio/cli
```

इसके बाद हम कॉन्फ़िगरेशन विज़ार्ड चलाते हैं:

```sh
npx wdio config
```

यह आपसे कुछ प्रश्न पूछेगा। इस माइग्रेशन परिदृश्य के लिए आप:
- डिफ़ॉल्ट विकल्प चुनें
- हम उदाहरण फ़ाइलें स्वतः जनरेट न करने की सलाह देते हैं
- WebdriverIO फ़ाइलों के लिए एक अलग फ़ोल्डर चुनें
- और Jasmine की बजाय Mocha चुनें।

:::info Mocha क्यों?
भले ही आप पहले Protractor के साथ Jasmine का उपयोग कर रहे हों, Mocha बेहतर रीट्राई मैकेनिज़्म प्रदान करता है। चुनाव आपका है!
:::

इस छोटी प्रश्नावली के बाद विज़ार्ड सभी आवश्यक पैकेज इंस्टॉल करेगा और उन्हें आपकी `package.json` में सहेज देगा।

## कॉन्फ़िगरेशन फ़ाइल माइग्रेट करें

जब हमारे पास एक बदली हुई `conf.ts` और एक नई `wdio.conf.ts` हो जाए, तो अब कॉन्फ़िगरेशन को एक कॉन्फ़िग से दूसरी में माइग्रेट करने का समय है। सुनिश्चित करें कि केवल वही कोड पोर्ट करें जो सभी टेस्ट को चलाने के लिए आवश्यक है। हमारे उदाहरण में हम हुक फ़ंक्शन और फ्रेमवर्क टाइमआउट को पोर्ट करते हैं।

अब हम केवल अपनी `wdio.conf.ts` फ़ाइल के साथ आगे बढ़ेंगे और इसलिए मूल Protractor कॉन्फ़िग में अब किसी बदलाव की आवश्यकता नहीं होगी। हम उन बदलावों को वापस ले सकते हैं ताकि दोनों फ्रेमवर्क साथ-साथ चल सकें और हम एक बार में एक फ़ाइल पोर्ट कर सकें।

## टेस्ट फ़ाइल माइग्रेट करें

अब हम पहली टेस्ट फ़ाइल पोर्ट करने के लिए तैयार हैं। सरल शुरुआत के लिए, आइए ऐसी फ़ाइल से शुरू करें जिसकी 3rd party पैकेज या PageObjects जैसी अन्य फ़ाइलों पर ज़्यादा निर्भरता न हो। हमारे उदाहरण में माइग्रेट करने वाली पहली फ़ाइल `first-test.spec.ts` है। पहले वह डायरेक्टरी बनाएँ जहाँ नया WebdriverIO कॉन्फ़िगरेशन अपनी फ़ाइलों की अपेक्षा करता है और फिर फ़ाइल को वहाँ ले जाएँ:

```sh
mv mkdir -p ./test/specs/
mv test-suites/first-test.spec.ts ./test/specs
```

अब आइए इस फ़ाइल को बदलें:

```sh
npx jscodeshift -t ./node_modules/@wdio/codemod/protractor ./test/specs/first-test.spec.ts
```

बस इतना ही! यह फ़ाइल इतनी सरल है कि हमें अब किसी अतिरिक्त बदलाव की आवश्यकता नहीं है और हम सीधे WebdriverIO को चलाने का प्रयास कर सकते हैं:

```sh
npx wdio run wdio.conf.ts
```

बधाई हो 🥳 आपने अभी-अभी पहली फ़ाइल माइग्रेट कर ली!

## अगले कदम

इस बिंदु से आप एक-एक करके टेस्ट और पेज ऑब्जेक्ट बदलना जारी रखें। संभावना है कि codemod कुछ फ़ाइलों के लिए इस तरह की त्रुटि के साथ विफल हो जाए:

```
ERR /path/to/project/test/testdata/failing_submit.js Transformation error (Error transforming /test/testdata/failing_submit.js:2)
Error transforming /test/testdata/failing_submit.js:2

> login_form.submit()
  ^

The command "submit" is not supported in WebdriverIO. We advise to use the click command to click on the submit button instead. For more information on this configuration, see https://webdriver.io/docs/api/element/click.
  at /path/to/project/test/testdata/failing_submit.js:132:0
```

कुछ Protractor कमांड के लिए WebdriverIO में कोई विकल्प मौजूद ही नहीं है। ऐसे मामले में codemod आपको सलाह देगा कि इसे कैसे रीफैक्टर करें। यदि आपको ऐसे त्रुटि संदेश बार-बार मिलते हैं, तो बेझिझक [एक issue उठाएँ](https://github.com/webdriverio/codemod/issues/new) और किसी विशेष ट्रांसफ़ॉर्मेशन को जोड़ने का अनुरोध करें। हालाँकि codemod पहले से ही Protractor API के अधिकांश हिस्से को बदल देता है, फिर भी सुधार की काफी गुंजाइश है।

## निष्कर्ष

हमें आशा है कि यह ट्यूटोरियल WebdriverIO में माइग्रेशन प्रक्रिया में आपका थोड़ा मार्गदर्शन करेगा। समुदाय विभिन्न संगठनों की विभिन्न टीमों के साथ इसका परीक्षण करते हुए codemod को लगातार बेहतर बना रहा है। यदि आपके पास कोई फ़ीडबैक है तो [एक issue उठाने](https://github.com/webdriverio/codemod/issues/new) में या माइग्रेशन प्रक्रिया के दौरान कठिनाई होने पर [चर्चा शुरू करने](https://github.com/webdriverio/codemod/discussions/new) में संकोच न करें।
