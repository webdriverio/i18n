---

WDIO टेस्टरनर के साथ आप फ़ाइलों पर काम करते समय उन्हें वॉच कर सकते हैं। यदि आप अपने ऐप में या अपनी टेस्ट फ़ाइलों में कुछ भी बदलते हैं, तो टेस्ट अपने आप फिर से चलते हैं। `wdio` कमांड को कॉल करते समय `--watch` फ़्लैग जोड़ने पर, टेस्टरनर सभी टेस्ट चलाने के बाद फ़ाइल परिवर्तनों की प्रतीक्षा करेगा, उदाहरण के लिए:

```sh
wdio wdio.conf.js --watch
```

डिफ़ॉल्ट रूप से यह केवल आपकी `specs` फ़ाइलों में होने वाले परिवर्तनों को वॉच करता है। हालाँकि, अपनी `wdio.conf.js` में एक `filesToWatch` प्रॉपर्टी सेट करके, जिसमें फ़ाइल पाथ की एक सूची हो (ग्लोबिंग समर्थित है), यह इन फ़ाइलों में होने वाले परिवर्तनों को भी वॉच करेगा ताकि पूरा सूट फिर से चलाया जा सके। यह तब उपयोगी है जब आप अपने एप्लिकेशन कोड में बदलाव करने पर अपने सभी टेस्ट अपने आप फिर से चलाना चाहते हैं, उदाहरण के लिए:

```js
// wdio.conf.js
export const config = {
    // ...
    filesToWatch: [
        // मेरे ऐप की सभी JS फ़ाइलों को वॉच करें
        './src/app/**/*.js'
    ],
    // ...
}
```

:::info
जितना संभव हो सके टेस्ट को पैरेलल में चलाने का प्रयास करें। E2E टेस्ट स्वभाव से ही धीमे होते हैं। टेस्ट को फिर से चलाना केवल तभी उपयोगी है जब आप प्रत्येक टेस्ट रन का समय कम रख सकें। समय बचाने के लिए, टेस्टरनर फ़ाइल परिवर्तनों की प्रतीक्षा करते समय WebDriver सेशन को सक्रिय रखता है। सुनिश्चित करें कि आपके WebDriver बैकएंड को इस तरह से संशोधित किया जा सके कि यदि कुछ समय तक कोई कमांड निष्पादित न हो, तो वह सेशन को अपने आप बंद न करे।
:::
