WebdriverIO MCP के बारे में अक्सर पूछे जाने वाले प्रश्न।

## सामान्य

### MCP क्या है?

MCP (Model Context Protocol) एक ओपन प्रोटोकॉल है जो Claude जैसे AI असिस्टेंट को बाहरी टूल्स और सेवाओं के साथ इंटरैक्ट करने में सक्षम बनाता है। WebdriverIO MCP इस प्रोटोकॉल को लागू करता है ताकि Claude Desktop और Claude Code को ब्राउज़र और मोबाइल ऑटोमेशन क्षमताएं प्रदान की जा सकें।

### मैं WebdriverIO MCP के साथ क्या ऑटोमेट कर सकता हूं?

आप ऑटोमेट कर सकते हैं:
-   **डेस्कटॉप ब्राउज़र** (Chrome, Firefox, Edge, Safari) - नेविगेशन, क्लिक करना, टाइप करना, स्क्रीनशॉट
-   **iOS ऐप्स** - सिम्युलेटर या असली डिवाइस पर
-   **Android ऐप्स** - एमुलेटर या असली डिवाइस पर
-   **हाइब्रिड ऐप्स** - नेटिव और वेब कॉन्टेक्स्ट के बीच स्विच करना
-   **क्लाउड डिवाइस** - BrowserStack, Sauce Labs, TestMu और TestingBot डिवाइस क्लाउड के माध्यम से

### क्या मुझे कोड लिखने की आवश्यकता है?

नहीं! यही MCP का मुख्य लाभ है। आप जो करना चाहते हैं उसे प्राकृतिक भाषा में बता सकते हैं, और Claude कार्य को पूरा करने के लिए उपयुक्त टूल्स का उपयोग करेगा।

**उदाहरण प्रॉम्प्ट:**
-   "Open Chrome and navigate to webdriver.io"
-   "Click the Get Started button"
-   "Take a screenshot of the current page"
-   "Start my iOS app and log in as test user"

## इंस्टॉलेशन और सेटअप

### मैं WebdriverIO MCP को कैसे इंस्टॉल करूं?

आपको इसे अलग से इंस्टॉल करने की आवश्यकता नहीं है। जब आप इसे अपने हार्नेस में कॉन्फ़िगर करते हैं तो MCP सर्वर npx के माध्यम से स्वचालित रूप से चलता है। इसे अपनी कॉन्फ़िग में जोड़ें:

```json
{
    "mcpServers": {
        "wdio-mcp": {
            "command": "npx",
            "args": ["-y", "@wdio/mcp"]
        }
    }
}
```

### Claude Desktop कॉन्फ़िग फ़ाइल कहां है?

-   **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
-   **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`

### क्या ब्राउज़र ऑटोमेशन के लिए मुझे Appium की आवश्यकता है?

नहीं। ब्राउज़र ऑटोमेशन के लिए केवल लक्षित ब्राउज़र का इंस्टॉल होना आवश्यक है। WebdriverIO ड्राइवर प्रबंधन को स्वचालित रूप से संभालता है।

### क्या मोबाइल ऑटोमेशन के लिए मुझे Appium की आवश्यकता है?

हां। मोबाइल ऑटोमेशन के लिए आवश्यक है:
1. Appium सर्वर चल रहा हो (`npm install -g appium && appium`)
2. प्लेटफ़ॉर्म ड्राइवर इंस्टॉल हों (iOS के लिए `appium driver install xcuitest`, Android के लिए `appium driver install uiautomator2`)
3. उपयुक्त डेवलपमेंट टूल्स (iOS के लिए Xcode, Android के लिए Android SDK)

## ब्राउज़र ऑटोमेशन

### कौन से ब्राउज़र समर्थित हैं?

Chrome, Firefox, Edge और Safari सभी समर्थित हैं। `start_session` में `browser` पैरामीटर का उपयोग करें:

```text
"Start a Firefox session"
"Start Chrome in headless mode"
```

### क्या मैं ब्राउज़र को हेडलेस मोड में चला सकता हूं?

हां। हेडलेस डिफ़ॉल्ट है (`headless: true`)। यदि आप ब्राउज़र देखना चाहते हैं तो Claude से हेडेड मोड में चलाने के लिए कहें:

"Start Chrome in headed mode (not headless)"

### क्या मैं ब्राउज़र विंडो का आकार सेट कर सकता हूं?

हां। ब्राउज़र शुरू करते समय आप आयाम निर्दिष्ट कर सकते हैं:

"Start Chrome with a window size of 1920x1080"

समर्थित आयाम: 400–3840 पिक्सेल चौड़ाई, 400–2160 पिक्सेल ऊंचाई। डिफ़ॉल्ट 1920×1080 है।

### क्या मैं एक ही चरण में ब्राउज़र शुरू करके नेविगेट कर सकता हूं?

हां! `navigationUrl` पैरामीटर का उपयोग करें:

"Start Chrome and navigate to https://webdriver.io"

यह ब्राउज़र शुरू करने और फिर अलग से नेविगेट करने की तुलना में अधिक कुशल है।

### मैं स्क्रीनशॉट कैसे लूं?

बस पूछें:

"Take a screenshot of the current page"

स्क्रीनशॉट स्वचालित रूप से ऑप्टिमाइज़ किए जाते हैं:
- अधिकतम 2000px आयाम तक स्केल किए जाते हैं
- अधिकतम 1MB फ़ाइल आकार तक कंप्रेस किए जाते हैं
- फ़ॉर्मेट: PNG या JPEG (इष्टतम गुणवत्ता के लिए स्वचालित रूप से चुना जाता है)

### क्या मैं iframes के साथ इंटरैक्ट कर सकता हूं?

हां। CSS या XPath सेलेक्टर द्वारा किसी iframe में स्विच करने के लिए `switch_frame` टूल का उपयोग करें। इसके बाद के सभी `click_element`, `set_value` और `get_elements` कॉल स्विच किए गए फ़्रेम के भीतर काम करते हैं। टॉप-लेवल फ़्रेम पर वापस जाने के लिए सेलेक्टर को छोड़ दें। iframes मुख्य पेज के समान ओरिजिन से होने चाहिए।

### क्या मैं कस्टम JavaScript एक्ज़ीक्यूट कर सकता हूं?

हां! `execute_script` टूल का उपयोग करें:

"Execute script to get the page title"
"Execute script: return document.querySelectorAll('button').length"

### क्या मैं किसी मौजूदा Chrome सेशन से अटैच कर सकता हूं?

हां। पहले `launch_chrome` का उपयोग करें (रिमोट डिबगिंग के साथ Chrome खोलता है), फिर `attach: true` के साथ `start_session` का उपयोग करें।

"Launch Chrome with remote debugging, then attach to it"

### क्या मैं कई टैब के साथ काम कर सकता हूं?

हां। खुले टैब की सूची देखने के लिए `get_tabs` और किसी विशिष्ट टैब पर फ़ोकस करने के लिए `switch_tab` का उपयोग करें:

"Get all open tabs"
"Switch to the tab at index 1"

## मोबाइल ऑटोमेशन

### मैं iOS या Android सेशन कैसे शुरू करूं?

उपयुक्त प्लेटफ़ॉर्म के साथ `start_session` का उपयोग करें:

"Start my iOS app located at /path/to/MyApp.app on the iPhone 15 simulator"

"Start my Android app at /path/to/app.apk on the Pixel 7 emulator"

या पहले से इंस्टॉल ऐप के लिए:

"Start the app with noReset enabled on the iPhone 15 simulator"

### क्या मैं असली डिवाइस पर टेस्ट कर सकता हूं?

हां! असली डिवाइस के लिए, आपको डिवाइस UDID की आवश्यकता होगी:

-   **iOS:** डिवाइस कनेक्ट करें, Finder खोलें, डिवाइस पर क्लिक करें, UDID दिखाने के लिए सीरियल नंबर पर क्लिक करें
-   **Android:** टर्मिनल में `adb devices` चलाएं

फिर पूछें:

"Start my iOS app on the real device with UDID abc123..."

### मैं परमिशन डायलॉग को कैसे संभालूं?

डिफ़ॉल्ट रूप से, परमिशन स्वचालित रूप से प्रदान की जाती हैं (`autoGrantPermissions: true`)। यदि आपको परमिशन फ़्लो का परीक्षण करना है, तो आप इसे अक्षम कर सकते हैं:

"Start my app without automatically granting permissions"

### कौन से जेस्चर समर्थित हैं?

-   **टैप:** एलिमेंट्स या कोऑर्डिनेट्स पर टैप करें (`tap_element`)
-   **स्वाइप:** ऊपर, नीचे, बाएं या दाएं स्वाइप करें (`swipe`)
-   **ड्रैग एंड ड्रॉप:** एक एलिमेंट से दूसरे एलिमेंट या कोऑर्डिनेट्स तक ड्रैग करें (`drag_and_drop`)

नोट: `long_press` Appium मोबाइल कमांड के साथ `execute_script` के माध्यम से उपलब्ध है।

### मोबाइल ऐप्स में मैं स्क्रॉल कैसे करूं?

स्वाइप जेस्चर का उपयोग करें:

"Swipe up to scroll down"
"Swipe down to scroll up"

### क्या मैं डिवाइस को रोटेट कर सकता हूं?

हां:

"Rotate the device to landscape"
"Rotate the device to portrait"

### मैं हाइब्रिड ऐप्स को कैसे संभालूं?

वेबव्यू वाले ऐप्स के लिए, आप कॉन्टेक्स्ट स्विच कर सकते हैं:

"Get available contexts"
"Switch to the webview context"
"Switch back to native context"

### क्या मैं Appium मोबाइल कमांड एक्ज़ीक्यूट कर सकता हूं?

हां! `execute_script` टूल का उपयोग करें:

```text
Execute script "mobile: pressKey" with args [{ keycode: 4 }]  // Android पर BACK दबाएं
Execute script "mobile: activateApp" with args [{ bundleId: "com.example.app" }]
Execute script "mobile: terminateApp" with args [{ bundleId: "com.example.app" }]
```

## एलिमेंट चयन

### AI असिस्टेंट को कैसे पता चलता है कि किस एलिमेंट के साथ इंटरैक्ट करना है?

यह पेज/स्क्रीन पर इंटरैक्टिव एलिमेंट्स की पहचान करने के लिए `wdio://session/current/elements` रिसोर्स या `get_elements` टूल का उपयोग करता है। प्रत्येक एलिमेंट उपयोग के लिए तैयार सेलेक्टर्स के साथ आता है।

### यदि पेज पर बहुत अधिक एलिमेंट्स हों तो क्या करें?

बड़ी एलिमेंट सूचियों को प्रबंधित करने के लिए पेजिनेशन का उपयोग करें:

"Get the first 20 elements"
"Get elements with offset 20 and limit 20"

रिस्पॉन्स में एलिमेंट्स के माध्यम से नेविगेट करने में मदद के लिए `total`, `showing` और `hasMore` शामिल होते हैं।

### यदि Claude गलत एलिमेंट पर क्लिक कर दे तो क्या करें?

आप अधिक विशिष्ट हो सकते हैं:

-   सटीक टेक्स्ट प्रदान करें: "Click the button that says 'Submit Order'"
-   सेलेक्टर प्रदान करें: "Click the element with selector #submit-btn"
-   एक्सेसिबिलिटी ID प्रदान करें: "Click the element with accessibility ID loginButton"

### मोबाइल के लिए सबसे अच्छी सेलेक्टर रणनीति क्या है?

1. **Accessibility ID** (सर्वोत्तम) - `~loginButton`
2. **Resource ID** (Android) - `id=login_button`
3. **Predicate String** (iOS) - `-ios predicate string:label == "Login"`
4. **XPath** (अंतिम उपाय) - धीमा लेकिन हर जगह काम करता है

### एक्सेसिबिलिटी ट्री क्या है और मुझे इसका उपयोग कब करना चाहिए?

एक्सेसिबिलिटी ट्री पेज एलिमेंट्स के बारे में सिमेंटिक जानकारी (roles, names, states) प्रदान करता है। `get_accessibility_tree` का उपयोग तब करें जब:
- `get_elements` अपेक्षित एलिमेंट्स नहीं लौटाता
- आपको एक्सेसिबिलिटी role (button, link, textbox, आदि) द्वारा एलिमेंट्स ढूंढने की आवश्यकता हो
- आपको एलिमेंट्स के बारे में विस्तृत सिमेंटिक जानकारी की आवश्यकता हो

"Get accessibility tree filtered to button and link roles"

## सेशन प्रबंधन

### क्या मेरे पास एक साथ कई सेशन हो सकते हैं?

नहीं। MCP सर्वर सिंगल-सेशन मॉडल का उपयोग करता है। एक समय में केवल एक ब्राउज़र या ऐप सेशन सक्रिय हो सकता है।

### जब मैं सेशन बंद करता हूं तो क्या होता है?

यह सेशन के प्रकार और सेटिंग्स पर निर्भर करता है:

-   **ब्राउज़र:** ब्राउज़र पूरी तरह से बंद हो जाता है
-   **`noReset: false` के साथ मोबाइल:** ऐप टर्मिनेट हो जाता है
-   **`noReset: true` या बिना `appPath` के मोबाइल:** ऐप खुला रहता है (सेशन स्वचालित रूप से डिटैच हो जाता है)

### क्या मैं सेशन के बीच ऐप स्टेट को सुरक्षित रख सकता हूं?

हां! `noReset` विकल्प का उपयोग करें:

"Start my app with noReset enabled"

यह लॉगिन स्टेट, प्राथमिकताएं और अन्य ऐप डेटा सुरक्षित रखता है।

### close और detach में क्या अंतर है?

-   **Close:** ब्राउज़र/ऐप को पूरी तरह से टर्मिनेट कर देता है
-   **Detach:** ऑटोमेशन को डिस्कनेक्ट करता है लेकिन ब्राउज़र/ऐप को चालू रखता है

Detach तब उपयोगी है जब आप ऑटोमेशन के बाद स्टेट का मैन्युअल रूप से निरीक्षण करना चाहते हैं।

### डिबगिंग के दौरान मेरा सेशन बार-बार टाइम आउट हो जाता है

कमांड टाइमआउट बढ़ाएं:

"Start my app with newCommandTimeout of 300 seconds"

डिफ़ॉल्ट 300 सेकंड है। बहुत लंबे डिबगिंग सेशन के लिए, 600 सेकंड आज़माएं।

## समस्या निवारण

### "Session not found" त्रुटि

इसका अर्थ है कि कोई सक्रिय सेशन मौजूद नहीं है। पहले ब्राउज़र या ऐप सेशन शुरू करें:

"Start Chrome and navigate to google.com"

### "Element not found" त्रुटि

हो सकता है कि एलिमेंट दिखाई न दे रहा हो या उसका सेलेक्टर अलग हो। आज़माएं:

1. पहले Claude से सभी दिखाई देने वाले एलिमेंट्स प्राप्त करने के लिए कहें
2. अधिक विशिष्ट सेलेक्टर प्रदान करें
3. पेज/ऐप के पूरी तरह से लोड होने की प्रतीक्षा करें
4. ऑफ़-स्क्रीन एलिमेंट्स ढूंढने के लिए `inViewportOnly: false` का उपयोग करें

### ब्राउज़र शुरू नहीं हो रहा

1. सुनिश्चित करें कि लक्षित ब्राउज़र इंस्टॉल है
2. जांचें कि कोई अन्य प्रोसेस डिबगिंग पोर्ट (9222) का उपयोग तो नहीं कर रही
3. हेडलेस मोड आज़माएं

### Appium कनेक्शन विफल

मोबाइल ऑटोमेशन शुरू करते समय यह सबसे आम समस्या है।

1. **सत्यापित करें कि Appium चल रहा है**: `curl http://localhost:4723/status`
2. आवश्यकता हो तो Appium शुरू करें: `appium`
3. जांचें कि आपका Appium कनेक्शन सर्वर से मेल खाता है (`start_session` में `appiumConfig` का उपयोग करें)
4. सुनिश्चित करें कि ड्राइवर इंस्टॉल हैं: `appium driver list --installed`

:::tip
मोबाइल सेशन शुरू करने से पहले MCP सर्वर को Appium का चलना आवश्यक है। पहले Appium शुरू करना सुनिश्चित करें:
```sh
appium
```
भविष्य के संस्करणों में स्वचालित Appium सर्विस प्रबंधन शामिल हो सकता है।
:::

### iOS Simulator शुरू नहीं हो रहा

1. सुनिश्चित करें कि Xcode इंस्टॉल है: `xcode-select --install`
2. उपलब्ध सिम्युलेटर की सूची देखें: `xcrun simctl list devices`
3. Console.app में विशिष्ट सिम्युलेटर त्रुटियों की जांच करें

### Android Emulator शुरू नहीं हो रहा

1. `ANDROID_HOME` सेट करें: `export ANDROID_HOME=$HOME/Library/Android/sdk`
2. एमुलेटर जांचें: `emulator -list-avds`
3. एमुलेटर मैन्युअल रूप से शुरू करें: `emulator -avd <avd-name>`
4. सत्यापित करें कि डिवाइस कनेक्टेड है: `adb devices`

### स्क्रीनशॉट काम नहीं कर रहे

1. मोबाइल के लिए, सुनिश्चित करें कि सेशन सक्रिय है
2. ब्राउज़र के लिए, कोई अलग पेज आज़माएं (कुछ पेज स्क्रीनशॉट ब्लॉक करते हैं)
3. त्रुटियों के लिए Claude Desktop लॉग जांचें

स्क्रीनशॉट स्वचालित रूप से अधिकतम 1MB तक कंप्रेस किए जाते हैं, इसलिए बड़े स्क्रीनशॉट काम करेंगे लेकिन उनकी गुणवत्ता कम हो सकती है।

## प्रदर्शन

### मोबाइल ऑटोमेशन धीमा क्यों है?

मोबाइल ऑटोमेशन में शामिल है:
1. Appium सर्वर के साथ नेटवर्क संचार
2. Appium का डिवाइस/सिम्युलेटर के साथ संचार
3. डिवाइस रेंडरिंग और रिस्पॉन्स

तेज़ ऑटोमेशन के लिए सुझाव:
-   डेवलपमेंट के लिए असली डिवाइस के बजाय एमुलेटर/सिम्युलेटर का उपयोग करें
-   XPath के बजाय एक्सेसिबिलिटी ID का उपयोग करें
-   एलिमेंट डिटेक्शन के लिए `inViewportOnly: true` सक्षम करें
-   टोकन उपयोग कम करने के लिए पेजिनेशन (`limit`) का उपयोग करें

### मैं एलिमेंट डिटेक्शन को कैसे तेज़ कर सकता हूं?

MCP सर्वर पहले से ही XML पेज सोर्स पार्सिंग का उपयोग करके एलिमेंट डिटेक्शन को ऑप्टिमाइज़ करता है (पारंपरिक एलिमेंट क्वेरी के लिए 600+ की तुलना में 2 HTTP कॉल)। अतिरिक्त सुझाव:

-   ऑफ़-स्क्रीन एलिमेंट्स को फ़िल्टर करने के लिए `inViewportOnly: true` सेट करें
-   `includeContainers: false` सेट करें (डिफ़ॉल्ट)
-   बड़ी स्क्रीन पर पेजिनेशन के लिए `limit` और `offset` का उपयोग करें
-   सभी एलिमेंट्स ढूंढने के बजाय विशिष्ट सेलेक्टर्स का उपयोग करें

### स्क्रीनशॉट धीमे हैं या विफल हो रहे हैं

स्क्रीनशॉट स्वचालित रूप से ऑप्टिमाइज़ किए जाते हैं:
- 2000px से बड़े होने पर आकार बदला जाता है
- 1MB से कम रखने के लिए कंप्रेस किया जाता है
- PNG बहुत बड़ा होने पर JPEG में कन्वर्ट किया जाता है

यह ऑप्टिमाइज़ेशन प्रोसेसिंग समय कम करता है और सुनिश्चित करता है कि Claude इमेज को संभाल सके।

## सीमाएं

### वर्तमान सीमाएं क्या हैं?

-   **सिंगल सेशन:** एक समय में केवल एक ब्राउज़र/ऐप
-   **iframe समर्थन:** समान-ओरिजिन iframes `switch_frame` के माध्यम से समर्थित हैं; ब्राउज़र सुरक्षा प्रतिबंधों के कारण क्रॉस-ओरिजिन iframes तक पहुंच नहीं है
-   **फ़ाइल अपलोड:** टूल्स के माध्यम से सीधे समर्थित नहीं
-   **ऑडियो/वीडियो:** मीडिया प्लेबैक के साथ इंटरैक्ट नहीं कर सकते
-   **ब्राउज़र एक्सटेंशन:** समर्थित नहीं

### क्या मैं इसका उपयोग प्रोडक्शन टेस्टिंग के लिए कर सकता हूं?

WebdriverIO MCP इंटरैक्टिव AI-सहायता प्राप्त ऑटोमेशन के लिए डिज़ाइन किया गया है। प्रोडक्शन CI/CD टेस्टिंग के लिए, पूर्ण प्रोग्रामेटिक नियंत्रण के साथ WebdriverIO के पारंपरिक टेस्ट रनर का उपयोग करने पर विचार करें।

## सुरक्षा

### क्या मेरा डेटा सुरक्षित है?

MCP सर्वर आपकी मशीन पर स्थानीय रूप से चलता है। सभी ऑटोमेशन स्थानीय ब्राउज़र/Appium कनेक्शन के माध्यम से होता है। आप जिन साइटों पर स्पष्ट रूप से नेविगेट करते हैं, उनके अलावा कोई डेटा बाहरी सर्वर पर नहीं भेजा जाता।

HTTP ट्रांसपोर्ट मोड (`--http`) का उपयोग करते समय, सर्वर डिफ़ॉल्ट रूप से केवल `localhost` से कनेक्शन स्वीकार करता है; एक्सेस नियंत्रित करने के लिए `--allowedHosts` और `--allowedOrigins` का उपयोग करें। विवरण के लिए [Transport](./transport) देखें।

### क्या Claude मेरे पासवर्ड तक पहुंच सकता है?

Claude पेज की सामग्री देख सकता है और एलिमेंट्स के साथ इंटरैक्ट कर सकता है, लेकिन:
-   `<input type="password">` फ़ील्ड में पासवर्ड मास्क किए जाते हैं
-   आपको संवेदनशील क्रेडेंशियल्स को ऑटोमेट करने से बचना चाहिए
-   ऑटोमेशन के लिए टेस्ट अकाउंट का उपयोग करें
