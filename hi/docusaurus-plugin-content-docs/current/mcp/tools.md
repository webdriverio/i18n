WebdriverIO MCP सर्वर 29 टूल्स उपलब्ध कराता है, जिन्हें उनके कार्य के अनुसार व्यवस्थित किया गया है। **browser-only** के रूप में चिह्नित टूल्स के लिए `platform: "browser"` सेशन आवश्यक है। **mobile-only** के रूप में चिह्नित टूल्स के लिए `platform: "ios"` या `platform: "android"` आवश्यक है।

## सेशन प्रबंधन

### `start_session`

एक नया ब्राउज़र या मोबाइल ऑटोमेशन सेशन शुरू करता है। एक समय में केवल एक सक्रिय सेशन हो सकता है; नया सेशन शुरू करने पर मौजूदा सेशन बंद हो जाता है।

| पैरामीटर              | प्रकार                                                                   | आवश्यक     | डिफ़ॉल्ट          | विवरण                                                                                                                       |
| ---------------------- | ---------------------------------------------------------------------- | ------------ | ---------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `platform`             | `"browser" \| "ios" \| "android"`                                      | ✓            | —                | सेशन प्लेटफ़ॉर्म                                                                                                                  |
| `provider`             | `"local" \| "browserstack" \| "saucelabs" \| "testmu" \| "testingbot"` | —            | `"local"`        | सेशन प्रोवाइडर                                                                                                                  |
| `browser`              | `"chrome" \| "firefox" \| "edge" \| "safari"`                          | केवल ब्राउज़र | —                | लॉन्च करने के लिए ब्राउज़र                                                                                                                 |
| `browserVersion`       | string                                                                 | —            | latest           | ब्राउज़र संस्करण (केवल क्लाउड प्रोवाइडर, डिफ़ॉल्ट: latest)                                                                           |
| `os`                   | string                                                                 | —            | —                | ऑपरेटिंग सिस्टम (केवल क्लाउड प्रोवाइडर, उदा. `"Windows"`, `"OS X"`)                                                               |
| `osVersion`            | string                                                                 | —            | —                | OS संस्करण (केवल क्लाउड प्रोवाइडर, उदा. `"11"`, `"Sequoia"`)                                                                       |
| `headless`             | boolean                                                                | —            | `true`           | ब्राउज़र को headless मोड में चलाएँ                                                                                                            |
| `windowWidth`          | number                                                                 | —            | `1920`           | ब्राउज़र विंडो की चौड़ाई (400–3840)                                                                                                   |
| `windowHeight`         | number                                                                 | —            | `1080`           | ब्राउज़र विंडो की ऊँचाई (400–2160)                                                                                                  |
| `navigationUrl`        | string                                                                 | —            | —                | शुरू होने के बाद जिस URL पर नेविगेट करना है                                                                                                 |
| `deviceName`           | string                                                                 | केवल मोबाइल  | —                | डिवाइस/एमुलेटर/सिम्युलेटर का नाम                                                                                                    |
| `platformVersion`      | string                                                                 | —            | —                | OS संस्करण (उदा. `"17.0"`, `"14"`)                                                                                                |
| `appPath`              | string                                                                 | —            | —                | `.app` / `.apk` / `.ipa` का पाथ                                                                                                  |
| `app`                  | string                                                                 | —            | —                | ऐप URL (BrowserStack के लिए `bs://...`, Sauce Labs के लिए `storage:filename=`, TestMu के लिए `lt://...`, TestingBot app_url) या custom_id |
| `automationName`       | `"XCUITest" \| "UiAutomator2"`                                         | —            | auto             | ऑटोमेशन ड्राइवर                                                                                                                 |
| `autoGrantPermissions` | boolean                                                                | —            | `true`           | ऐप अनुमतियाँ स्वचालित रूप से प्रदान करें                                                                                                        |
| `autoAcceptAlerts`     | boolean                                                                | —            | `true`           | अलर्ट स्वचालित रूप से स्वीकार करें                                                                                                                |
| `autoDismissAlerts`    | boolean                                                                | —            | `false`          | अलर्ट स्वचालित रूप से खारिज करें                                                                                                               |
| `appWaitActivity`      | string                                                                 | —            | —                | लॉन्च पर जिस Android activity की प्रतीक्षा करनी है                                                                                            |
| `udid`                 | string                                                                 | —            | —                | iOS रियल डिवाइस UDID                                                                                                              |
| `noReset`              | boolean                                                                | —            | —                | सेशनों के बीच ऐप डेटा सुरक्षित रखें                                                                                                |
| `fullReset`            | boolean                                                                | —            | —                | सेशन से पहले/बाद ऐप अनइंस्टॉल करें                                                                                                |
| `newCommandTimeout`    | number                                                                 | —            | `300`            | Appium कमांड टाइमआउट (सेकंड)                                                                                                  |
| `attach`               | boolean                                                                | —            | `false`          | CDP के माध्यम से मौजूदा Chrome से जुड़ें                                                                                                 |
| `attachConfig`         | object                                                                 | —            | —                | CDP कनेक्शन: `{ port: 9222, host: "localhost" }`                                                                               |
| `appiumConfig`         | object                                                                 | —            | —                | Appium सर्वर: `{ host, port, path }`                                                                                             |
| `tunnel`               | `boolean \| "external"`                                                | —            | `false`          | लोकल टनल रूटिंग (क्लाउड प्रोवाइडर)। `true` = स्वतः शुरू, `"external"` = टनल पहले से बाहरी रूप से चल रहा है                     |
| `reporting`            | object                                                                 | —            | —                | क्लाउड प्रोवाइडर रिपोर्टिंग लेबल: `{ project, build, session }`                                                                    |
| `trace`                | boolean                                                                | —            | `false`          | ट्रेस रिकॉर्डिंग सक्षम करें — Playwright-संगत `.trace` zip बनाता है                                                            |
| `region`               | `"us-west-1" \| "eu-central-1" \| "apac-southeast-1"`                  | —            | `"eu-central-1"` | Sauce Labs डेटा सेंटर क्षेत्र                                                                                                     |
| `tunnelName`           | string                                                                 | —            | —                | टनल पहचानकर्ता नाम (`tunnel: "external"` के लिए आवश्यक)                                                                        |
| `capabilities`         | object                                                                 | —            | —                | मर्ज करने के लिए अतिरिक्त raw capabilities                                                                                              |

```js
// लोकल Chrome ब्राउज़र
start_session({ platform: "browser", browser: "chrome" })

// iOS सिम्युलेटर
start_session({ platform: "ios", deviceName: "iPhone 16", platformVersion: "18.0", appPath: "/path/to/app.app" })

// BrowserStack Android
start_session({ platform: "android", provider: "browserstack", deviceName: "Samsung Galaxy S24", app: "bs://abc123" })

// Sauce Labs iOS
start_session({ platform: "ios", provider: "saucelabs", deviceName: "iPhone 15", platformVersion: "17.0", app: "storage:filename=MyApp.ipa" })

// TestMu ब्राउज़र
start_session({ platform: "browser", provider: "testmu", browser: "chrome", os: "Windows", osVersion: "11" })

// TestingBot ब्राउज़र
start_session({ platform: "browser", provider: "testingbot", browser: "chrome", os: "Windows", osVersion: "11" })

// टनल के साथ क्लाउड प्रोवाइडर
start_session({ platform: "browser", provider: "browserstack", browser: "chrome", tunnel: true })

// मौजूदा Chrome से जुड़ें (launch_chrome के बाद)
start_session({ platform: "browser", browser: "chrome", attach: true })
```

### `close_session`

वर्तमान सेशन को बंद करता है या उससे डिटैच करता है।

| पैरामीटर | प्रकार    | आवश्यक | डिफ़ॉल्ट | विवरण                                                    |
| --------- | ------- | -------- | ------- | -------------------------------------------------------------- |
| `detach`  | boolean | —        | `false` | समाप्त किए बिना डिस्कनेक्ट करें (Appium पर ऐप की स्थिति सुरक्षित रखता है) |

`noReset: true` के साथ शुरू किए गए सेशन डिफ़ॉल्ट रूप से स्वतः डिटैच हो जाते हैं।

---

### `launch_chrome`

रिमोट डिबगिंग सक्षम के साथ एक Chrome इंस्टेंस तैयार करता है ताकि `start_session({ attach: true })` कनेक्ट हो सके। दो मोड:

- `newInstance` (डिफ़ॉल्ट): एक अलग प्रोफ़ाइल डायरेक्टरी का उपयोग करके आपके मौजूदा Chrome के साथ-साथ Chrome खोलता है; आपका वर्तमान सेशन अप्रभावित रहता है।
- `freshSession`: खाली प्रोफ़ाइल (कोई कुकीज़ नहीं, कोई लॉगिन नहीं) के साथ Chrome लॉन्च करता है। कुकीज़ और लॉगिन साथ लाने के लिए `copyProfileFiles: true` का उपयोग करें।

| पैरामीटर          | प्रकार                              | आवश्यक | डिफ़ॉल्ट         | विवरण                                                      |
| ------------------ | --------------------------------- | -------- | --------------- | ---------------------------------------------------------------- |
| `port`             | number                            | —        | `9222`          | रिमोट डिबगिंग पोर्ट                                            |
| `mode`             | `"newInstance" \| "freshSession"` | —        | `"newInstance"` | लॉन्च मोड                                                      |
| `copyProfileFiles` | boolean                           | —        | `false`         | Chrome Default प्रोफ़ाइल (कुकीज़, लॉगिन) को डिबग सेशन में कॉपी करें |

यह टूल सफल होने के बाद, `start_session({ platform: "browser", browser: "chrome", attach: true })` कॉल करें।

## नेविगेशन और टैब

### `navigate`

वर्तमान टैब में एक URL लोड करता है और पेज लोड इवेंट की प्रतीक्षा करता है। पेज की स्थिति (DOM, JS runtime) रीसेट करता है। **Browser-only.**

| पैरामीटर | प्रकार   | आवश्यक | विवरण        |
| --------- | ------ | -------- | ------------------ |
| `url`     | string | ✓        | जिस URL पर नेविगेट करना है |

---

### `get_tabs`

सभी ब्राउज़र टैब को handle, शीर्षक, URL और कौन-सा सक्रिय है, के साथ सूचीबद्ध करता है। लक्ष्य handle खोजने के लिए `switch_tab` से पहले इसका उपयोग करें। **Browser-only.**

कोई पैरामीटर नहीं।

---

### `switch_tab`

विंडो handle या 0-आधारित इंडेक्स द्वारा किसी ब्राउज़र टैब पर फ़ोकस करता है। इसके बाद के सभी टूल कॉल नए सक्रिय टैब पर काम करते हैं। **Browser-only.**

| पैरामीटर | प्रकार   | आवश्यक | विवरण                |
| --------- | ------ | -------- | -------------------------- |
| `handle`  | string | —        | जिस विंडो handle पर स्विच करना है |
| `index`   | number | —        | 0-आधारित टैब इंडेक्स (≥ 0)    |

`handle` या `index` में से कोई एक प्रदान करें। handles `get_tabs` या `wdio://session/current/tabs` से प्राप्त करें।

---

### `switch_frame`

CSS/XPath सेलेक्टर द्वारा WebDriver फ़्रेम कॉन्टेक्स्ट को किसी iframe में स्विच करता है, या सेलेक्टर छोड़ दिए जाने पर वापस टॉप-लेवल पर ले जाता है। परिवर्तन बने रहते हैं; जब तक आप वापस स्विच नहीं करते, तब तक सभी बाद के `click_element`, `set_value`, `get_elements` कॉल स्विच किए गए फ़्रेम के भीतर काम करते हैं। iframe के लिए 5s तक प्रतीक्षा करता है। **Browser-only.**

| पैरामीटर  | प्रकार   | आवश्यक | विवरण                                                                            |
| ---------- | ------ | -------- | -------------------------------------------------------------------------------------- |
| `selector` | string | —        | iframe एलिमेंट के लिए CSS/XPath सेलेक्टर। टॉप-लेवल फ़्रेम पर वापस जाने के लिए इसे छोड़ दें। |

```js
// iframe में स्विच करें
switch_frame({ selector: "#my-iframe" })

// iframe के अंदर के एलिमेंट्स के साथ इंटरैक्ट करें
click_element({ selector: "button.submit" })

// वापस टॉप-लेवल पर स्विच करें
switch_frame()
```

## एलिमेंट इंटरैक्शन

### `click_element`

किसी एलिमेंट के मौजूद होने की प्रतीक्षा करता है, उसे स्क्रॉल करके दृश्य में लाता है, और उस पर क्लिक करता है। ब्राउज़र और मोबाइल दोनों पर काम करता है। iOS पर `tap_element` को प्राथमिकता दें; `click_element` को कभी-कभी नेटिव लेयर द्वारा अनदेखा कर दिया जाता है।

| पैरामीटर      | प्रकार    | आवश्यक | डिफ़ॉल्ट | विवरण                              |
| -------------- | ------- | -------- | ------- | ---------------------------------------- |
| `selector`     | string  | ✓        | —       | CSS, XPath, या टेक्स्ट सेलेक्टर             |
| `scrollToView` | boolean | —        | `true`  | क्लिक करने से पहले एलिमेंट को स्क्रॉल करके दृश्य में लाएँ |
| `timeout`      | number  | —        | —       | अधिकतम प्रतीक्षा समय (ms)                       |

---

### `set_value`

किसी input या textarea को साफ़ करता है और दिया गया टेक्स्ट टाइप करता है। हमेशा मौजूदा सामग्री को बदल देता है।

| पैरामीटर      | प्रकार    | आवश्यक | डिफ़ॉल्ट | विवरण                            |
| -------------- | ------- | -------- | ------- | -------------------------------------- |
| `selector`     | string  | ✓        | —       | CSS, XPath, या टेक्स्ट सेलेक्टर           |
| `value`        | string  | ✓        | —       | टाइप करने के लिए टेक्स्ट                           |
| `scrollToView` | boolean | —        | `true`  | टाइप करने से पहले एलिमेंट को स्क्रॉल करके दृश्य में लाएँ |
| `timeout`      | number  | —        | —       | अधिकतम प्रतीक्षा समय (ms)                     |

---

### `scroll`

पेज को कुछ पिक्सेल तक स्क्रॉल करता है। **Browser-only.** मोबाइल के लिए `swipe` का उपयोग करें।

| पैरामीटर   | प्रकार             | आवश्यक | डिफ़ॉल्ट | विवरण      |
| ----------- | ---------------- | -------- | ------- | ---------------- |
| `direction` | `"up" \| "down"` | ✓        | —       | स्क्रॉल दिशा |
| `pixels`    | number           | —        | `500`   | स्क्रॉल करने के लिए पिक्सेल |

## एलिमेंट विश्लेषण

### `get_elements`

वर्तमान पेज पर इंटरैक्ट करने योग्य एलिमेंट्स को उपयोग के लिए तैयार सेलेक्टर्स के साथ लौटाता है। सामान्य जानकारी के लिए `wdio://session/current/elements` रिसोर्स को प्राथमिकता दें; जब आपको फ़िल्टरिंग या पेजिनेशन की आवश्यकता हो तो इस टूल का उपयोग करें।

| पैरामीटर           | प्रकार    | आवश्यक | डिफ़ॉल्ट | विवरण                                 |
| ------------------- | ------- | -------- | ------- | ------------------------------------------- |
| `inViewportOnly`    | boolean | —        | `false` | केवल viewport में दिखाई देने वाले एलिमेंट्स लौटाएँ       |
| `includeContainers` | boolean | —        | `false` | कंटेनर एलिमेंट्स (divs, sections) शामिल करें |
| `includeBounds`     | boolean | —        | `false` | बाउंडिंग बॉक्स निर्देशांक शामिल करें            |
| `limit`             | number  | —        | `0`     | लौटाए जाने वाले अधिकतम एलिमेंट्स (0 = असीमित)      |
| `offset`            | number  | —        | `0`     | छोड़े जाने वाले एलिमेंट्स (पेजिनेशन)               |

---

### `get_accessibility_tree`

पेज का accessibility tree roles, names और सेलेक्टर्स के साथ लौटाता है। फ़िल्टरिंग और पेजिनेशन का समर्थन करता है। **Browser-only.**

| पैरामीटर | प्रकार     | आवश्यक | डिफ़ॉल्ट | विवरण                                                |
| --------- | -------- | -------- | ------- | ---------------------------------------------------------- |
| `limit`   | number   | —        | `0`     | लौटाए जाने वाले अधिकतम नोड्स (0 = असीमित)                        |
| `offset`  | number   | —        | `0`     | छोड़े जाने वाले नोड्स (पेजिनेशन)                                 |
| `roles`   | string[] | —        | —       | ARIA roles द्वारा फ़िल्टर करें, उदा. `["button", "link", "heading"]` |

## स्क्रीनशॉट

### `get_screenshot`

वर्तमान पेज या स्क्रीन का स्क्रीनशॉट लेता है। एक base64-एन्कोडेड इमेज लौटाता है, जिसे मॉडल कॉन्टेक्स्ट सीमाओं (अधिकतम 1 MB, अधिकतम 2000px) के भीतर रखने के लिए स्वचालित रूप से रीसाइज़ और कंप्रेस किया जाता है।

कोई पैरामीटर नहीं। एलिमेंट खोजने के लिए स्क्रीनशॉट के बजाय `wdio://session/current/elements` को प्राथमिकता दें; यह तेज़ है और बहुत कम टोकन का उपयोग करता है। विज़ुअल सत्यापन या लेआउट डिबगिंग के लिए स्क्रीनशॉट का उपयोग करें।

## कुकी प्रबंधन

### `get_cookies`

वर्तमान सेशन की सभी कुकीज़, या नाम द्वारा एक कुकी लौटाता है। **Browser-only.**

| पैरामीटर | प्रकार   | आवश्यक | विवरण                              |
| --------- | ------ | -------- | ---------------------------------------- |

## टच जेस्चर (मोबाइल)

### `tap_element`

मेल खाने वाले एलिमेंट पर `element.tap()` कॉल करता है या निरपेक्ष स्क्रीन निर्देशांकों पर टैप करता है। iOS पर जब `click_element` को अनदेखा किया जाए तब इसका उपयोग करें; tap वह नेटिव जेस्चर है जिस पर iOS प्रतिक्रिया देता है। **Mobile-only.**

| पैरामीटर  | प्रकार   | आवश्यक | विवरण                                  |
| ---------- | ------ | -------- | -------------------------------------------- |
| `selector` | string | —        | एलिमेंट सेलेक्टर                             |
| `x`        | number | —        | स्क्रीन टैप के लिए X निर्देशांक (यदि कोई सेलेक्टर नहीं) |
| `y`        | number | —        | स्क्रीन टैप के लिए Y निर्देशांक (यदि कोई सेलेक्टर नहीं) |

`selector` या `x`/`y` निर्देशांकों में से कोई एक प्रदान करें।

### `swipe`

पूर्ण-स्क्रीन swipe जेस्चर करता है। दिशा सामग्री के खिसकने की दिशा है (उदा. `"up"` किसी सूची को ऊपर की ओर स्क्रॉल करता है)। दृश्य सीमाओं से आगे स्क्रॉल करने के लिए इसका उपयोग करें। किसी विशिष्ट एलिमेंट को हिलाने के लिए `drag_and_drop` का उपयोग करें। **Mobile-only.** ब्राउज़रों के लिए `scroll` का उपयोग करें।

| पैरामीटर   | प्रकार                                  | आवश्यक | डिफ़ॉल्ट        | विवरण                       |
| ----------- | ------------------------------------- | -------- | -------------- | --------------------------------- |
| `direction` | `"up" \| "down" \| "left" \| "right"` | ✓        | —              | Swipe दिशा                   |
| `duration`  | number                                | —        | `500`          | Swipe अवधि (ms, 100–5000)     |
| `percent`   | number                                | —        | `0.5` / `0.95` | स्क्रीन का वह अंश जिसे swipe करना है (0–1) |

---

### `drag_and_drop`

किसी एलिमेंट को दूसरे एलिमेंट या निर्देशांकों तक खींचता है। **Mobile-only.**

| पैरामीटर        | प्रकार   | आवश्यक | डिफ़ॉल्ट | विवरण                            |
| ---------------- | ------ | -------- | ------- | -------------------------------------- |
| `sourceSelector` | string | ✓        | —       | खींचा जाने वाला स्रोत एलिमेंट                 |
| `targetSelector` | string | —        | —       | लक्ष्य एलिमेंट जिस पर छोड़ना है            |
| `x`              | number | —        | —       | लक्ष्य X ऑफ़सेट (यदि कोई targetSelector नहीं) |
| `y`              | number | —        | —       | लक्ष्य Y ऑफ़सेट (यदि कोई targetSelector नहीं) |

## कॉन्टेक्स्ट स्विचिंग (मोबाइल)

### `get_contexts`

उपलब्ध ऑटोमेशन कॉन्टेक्स्ट और वर्तमान में सक्रिय कॉन्टेक्स्ट लौटाता है। `NATIVE_APP` और `WEBVIEW_*` लक्ष्यों को खोजने के लिए `switch_context` से पहले इसका उपयोग करें। **Mobile-only.**

कोई पैरामीटर नहीं।

---

### `switch_context`

हाइब्रिड मोबाइल ऐप में नेटिव और webview ऑटोमेशन कॉन्टेक्स्ट के बीच स्विच करता है। एम्बेडेड webview के अंदर CSS/XPath सेलेक्टर्स का उपयोग करने से पहले यह आवश्यक है। **Mobile-only.**

| पैरामीटर | प्रकार   | आवश्यक | विवरण                                                    |
| --------- | ------ | -------- | -------------------------------------------------------------- |
| `context` | string | ✓        | कॉन्टेक्स्ट का नाम, उदा. `"NATIVE_APP"`, `"WEBVIEW_com.example.app"` |

उपलब्ध कॉन्टेक्स्ट नाम `get_contexts` या `wdio://session/current/contexts` से प्राप्त करें।

```js
// 1. जाँचें कि क्या उपलब्ध है
get_contexts()
// → { contexts: ["NATIVE_APP", "WEBVIEW_com.example.app"], currentContext: "NATIVE_APP" }

// 2. CSS/XPath के लिए webview में स्विच करें
switch_context({ context: "WEBVIEW_com.example.app" })

// 3. CSS सेलेक्टर्स का उपयोग करके webview एलिमेंट्स के साथ इंटरैक्ट करें
click_element({ selector: "#login-button" })

// 4. नेटिव UI के लिए वापस नेटिव पर स्विच करें
switch_context({ context: "NATIVE_APP" })
```

## ब्राउज़र यूटिलिटीज़

### `emulate_device`

वर्तमान ब्राउज़र सेशन में मोबाइल या टैबलेट डिवाइस का अनुकरण करता है (viewport, DPR, user-agent, touch events सेट करता है)। BiDi-सक्षम सेशन आवश्यक है: `start_session({ capabilities: { webSocketUrl: true } })`। **Browser-only.**

| पैरामीटर | प्रकार   | आवश्यक | विवरण                                                                                                             |
| --------- | ------ | -------- | ----------------------------------------------------------------------------------------------------------------------- |
| `device`  | string | —        | डिवाइस प्रीसेट नाम (उदा. `"iPhone 15"`, `"Pixel 7"`)। प्रीसेट सूचीबद्ध करने के लिए इसे छोड़ दें। डेस्कटॉप डिफ़ॉल्ट पुनर्स्थापित करने के लिए `"reset"` पास करें। |

---

### `execute_script`

ब्राउज़र में JavaScript या Appium के माध्यम से मोबाइल कमांड निष्पादित करता है।

| पैरामीटर | प्रकार   | आवश्यक | विवरण                                                   |
| --------- | ------ | -------- | ------------------------------------------------------------- |
| `script`  | string | ✓        | JS कोड (ब्राउज़र) या Appium कमांड जैसे `"mobile: pressKey"` |
| `args`    | any[]  | —        | स्क्रिप्ट या कमांड को पास किए जाने वाले आर्ग्युमेंट्स                     |

**ब्राउज़र:** मान वापस पाने के लिए `return` का उपयोग करें।

```javascript
// पेज का शीर्षक प्राप्त करें
execute_script({ script: "return document.title" })

// एलिमेंट को स्क्रॉल करके दृश्य में लाएँ
execute_script({ script: "arguments[0].scrollIntoView()", args: ["#my-element"] })
```

**मोबाइल (Appium):** `mobile: <command>` सिंटैक्स का उपयोग करता है।

```javascript
// Android back key दबाएँ
execute_script({ script: "mobile: pressKey", args: [{ keycode: 4 }] })

// ऐप सक्रिय करें (iOS/Android)
execute_script({ script: "mobile: activateApp", args: [{ bundleId: "com.example.app" }] })

// डीप लिंक (iOS)
execute_script({ script: "mobile: deepLink", args: [{ url: "myapp://route", bundleId: "com.example.app" }] })
```

## क्लाउड प्रोवाइडर

### `list_apps`

किसी क्लाउड प्रोवाइडर (BrowserStack App Automate, Sauce Labs App Storage, TestMu, या TestingBot Storage) पर अपलोड किए गए ऐप्स को सूचीबद्ध करता है। प्रोवाइडर-विशिष्ट क्रेडेंशियल्स environment से पढ़ता है।

| पैरामीटर          | प्रकार                                                        | आवश्यक | डिफ़ॉल्ट          | विवरण                              |
| ------------------ | ----------------------------------------------------------- | -------- | ---------------- | ---------------------------------------- |
| `provider`         | `"browserstack" \| "saucelabs" \| "testmu" \| "testingbot"` | ✓        | —                | क्लाउड प्रोवाइडर                           |
| `sortBy`           | `"app_name" \| "uploaded_at"`                               | —        | `"uploaded_at"`  | क्रमबद्धता का क्रम                               |
| `organizationWide` | boolean                                                     | —        | `false`          | (केवल BrowserStack) संगठन के सभी अपलोड सूचीबद्ध करें |
| `limit`            | number                                                      | —        | `20`             | अधिकतम परिणाम                              |
| `region`           | `"us-west-1" \| "eu-central-1" \| "apac-southeast-1"`       | —        | `"eu-central-1"` | Sauce Labs क्षेत्र                        |

```js
// सभी चार प्रोवाइडर्स को सूचीबद्ध करें
list_apps({ provider: "browserstack" })
list_apps({ provider: "saucelabs", region: "us-west-1" })
list_apps({ provider: "testmu" })
list_apps({ provider: "testingbot" })
```

---

### `upload_app`

एक लोकल `.apk` या `.ipa` को किसी क्लाउड प्रोवाइडर (BrowserStack, Sauce Labs, TestMu, या TestingBot) पर अपलोड करता है। `start_session` में उपयोग के लिए ऐप URL लौटाता है।

| पैरामीटर  | प्रकार                                                        | आवश्यक | डिफ़ॉल्ट          | विवरण                                      |
| ---------- | ----------------------------------------------------------- | -------- | ---------------- | ------------------------------------------------ |
| `provider` | `"browserstack" \| "saucelabs" \| "testmu" \| "testingbot"` | ✓        | —                | क्लाउड प्रोवाइडर                                   |
| `path`     | string                                                      | ✓        | —                | `.apk` या `.ipa` फ़ाइल का निरपेक्ष पाथ       |
| `customId` | string                                                      | —        | —                | बाद में ऐप को संदर्भित करने के लिए वैकल्पिक कस्टम ID |
| `region`   | `"us-west-1" \| "eu-central-1" \| "apac-southeast-1"`       | —        | `"eu-central-1"` | Sauce Labs क्षेत्र                                |

```js
// प्रत्येक प्रोवाइडर पर अपलोड करें
upload_app({ provider: "browserstack", path: "/path/to/app.apk" })
upload_app({ provider: "saucelabs", path: "/path/to/app.ipa", region: "us-west-1" })
upload_app({ provider: "testmu", path: "/path/to/app.apk" })
upload_app({ provider: "testingbot", path: "/path/to/app.apk" })
```
