DevTools किसी भी फ्रेमवर्क-विशिष्ट कॉन्फ़िगरेशन की आवश्यकता के बिना Mocha, Jasmine और Cucumber के साथ स्वचालित रूप से काम करता है। बस अपने WebDriverIO कॉन्फ़िग में सर्विस जोड़ें और सभी सुविधाएँ बिना किसी रुकावट के काम करेंगी, चाहे आप कोई भी टेस्ट फ्रेमवर्क उपयोग कर रहे हों।

**समर्थित फ्रेमवर्क:**
- **Mocha** - grep फ़िल्टरिंग के साथ टेस्ट और सुइट-स्तरीय एक्ज़ीक्यूशन
- **Jasmine** - grep-आधारित फ़िल्टरिंग के साथ पूर्ण इंटीग्रेशन
- **Cucumber** - feature:line टार्गेटिंग के साथ सीनेरियो और उदाहरण-स्तरीय एक्ज़ीक्यूशन

वही डीबगिंग इंटरफ़ेस, टेस्ट को दोबारा चलाने और विज़ुअलाइज़ेशन की सुविधाएँ सभी फ्रेमवर्क में एक समान रूप से काम करती हैं।

## कॉन्फ़िगरेशन

```js
// wdio.conf.js
export const config = {
    framework: 'mocha', // या 'jasmine' या 'cucumber'
    services: ['devtools'],
    // ...
};
```
