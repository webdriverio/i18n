TestLens, DevTools UI और आपकी टेस्ट सोर्स फ़ाइलों के बीच इंटेलिजेंट कोड नेविगेशन प्रदान करता है। UI में किसी भी टेस्ट या कमांड पर क्लिक करें ताकि डैशबोर्ड के **Source** टैब में उसका सोर्स सटीक लाइन पर खुल जाए, और वहाँ से फ़ाइल को VS Code में खोलें।

**यह कैसे काम करता है:**
- **विज़ुअल टेस्ट पदानुक्रम** - अपनी टेस्ट संरचना (suites, tests, scenarios) को ट्री व्यू में देखें
- **सोर्स मैपिंग** - प्रत्येक टेस्ट आपकी सोर्स फ़ाइलों में उसके सटीक स्थान से लिंक होता है
- **वन-क्लिक नेविगेशन** - किसी भी टेस्ट या कमांड पर क्लिक करके **Source** टैब में उसकी सोर्स लाइन देखें
- **एडिटर लिंक** - Source टैब का **Open in editor** लिंक फ़ाइल को VS Code में उसी लाइन पर खोलता है (`vscode://file/...`)

UI और कोड के बीच यह सहज कनेक्शन टेस्ट विफलताओं की जाँच करते समय मैन्युअल कोड खोज को समाप्त करके डीबगिंग को तेज़ बनाता है।
