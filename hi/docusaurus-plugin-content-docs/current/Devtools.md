DevTools एक शक्तिशाली ब्राउज़र-आधारित डीबगिंग इंटरफ़ेस है, जो आपके टेस्ट निष्पादन को रीयल-टाइम में विज़ुअलाइज़ करने, नियंत्रित करने और उनका निरीक्षण करने के लिए है। यह **WebdriverIO**, **Nightwatch.js**, **Selenium WebDriver** (कोई भी रनर) और **Python Selenium** के साथ काम करता है — सभी के लिए एक ही बैकएंड, एक ही UI और एक ही कैप्चर इन्फ्रास्ट्रक्चर।

## यह क्या प्रदान करता है

- **टेस्ट को चुनिंदा रूप से दोबारा चलाएँ** - किसी भी टेस्ट केस या सूट पर क्लिक करके उसे तुरंत फिर से निष्पादित करें ([विवरण](/docs/devtools/wdio/interactive-test-rerunning))
- **Preserve & Rerun (Compare)** - किसी विफल टेस्ट का स्नैपशॉट लें, उसे दोबारा चलाएँ, और दोनों रन को कमांड के अनुसार संरेखित करके साथ-साथ तुलना (diff) करें ([विवरण](/docs/devtools/wdio/preserve-and-rerun))
- **विज़ुअल रूप से डीबग करें** - प्रत्येक कमांड के बाद स्वचालित स्क्रीनशॉट के साथ लाइव ब्राउज़र प्रीव्यू देखें
- **निष्पादन ट्रैक करें** - टाइमस्टैम्प और परिणामों के साथ विस्तृत कमांड लॉग देखें
- **नेटवर्क और कंसोल की निगरानी करें** - API कॉल और JavaScript लॉग का निरीक्षण करें ([नेटवर्क](/docs/devtools/wdio/network-logs) · [कंसोल](/docs/devtools/wdio/console-logs))
- **कोड पर नेविगेट करें** - TestLens के साथ सीधे टेस्ट सोर्स फ़ाइलों पर जाएँ ([विवरण](/docs/devtools/wdio/testlens))
- **सेशन रिकॉर्ड करें** - प्रत्येक सेशन के लिए ब्राउज़र का निरंतर `.webm` वीडियो ([विवरण](/docs/devtools/wdio/screencast))
- **मोबाइल** - लाइव और ट्रेस मोड में Appium सेशन (मोबाइल ब्राउज़र, नेटिव और हाइब्रिड ऐप्स) ([विवरण](/docs/devtools/mobile))
- **ट्रेस मोड** - हेडलेस कैप्चर पाथ, जो ऑफ़लाइन रीप्ले या एजेंटिक उपयोग के लिए एक पोर्टेबल `trace.zip` आर्टिफ़ैक्ट तैयार करता है ([विवरण](/docs/devtools/wdio/trace-mode))

## यह कैसे काम करता है

1. अपने टेस्ट सामान्य रूप से शुरू करें
2. DevTools स्वचालित रूप से `http://localhost:3000` पर एक ब्राउज़र विंडो खोलता है
3. UI रीयल-टाइम में टेस्ट पदानुक्रम, ब्राउज़र प्रीव्यू, कमांड टाइमलाइन और लॉग दिखाता है
4. टेस्ट पूरे होने के बाद, किसी भी टेस्ट को दोबारा चलाने के लिए उस पर क्लिक करें; रीरन एक नई टेस्ट प्रोसेस में चलता है और उसी डैशबोर्ड विंडो में स्ट्रीम होता है

## अपना फ़्रेमवर्क चुनें

- **[WebDriverIO](/docs/devtools/wdio)** - Mocha, Jasmine, या Cucumber के साथ `@wdio/devtools-service` का उपयोग करें
- **[Nightwatch](/docs/devtools/nightwatch)** - टेस्ट कोड में बिना किसी बदलाव के `@wdio/nightwatch-devtools` का उपयोग करें
- **[Selenium](/docs/devtools/selenium)** - Mocha, Jest, Cucumber, या सामान्य Node स्क्रिप्ट के साथ `@wdio/selenium-devtools` का उपयोग करें
- **[Python Selenium](/docs/devtools/selenium)** - pytest या सामान्य स्क्रिप्ट के अंतर्गत `selenium-devtools-py` का उपयोग करें (Python टैब देखें)
