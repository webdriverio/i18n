DevTools एक शक्तिशाली ब्राउज़र-आधारित डिबगिंग इंटरफ़ेस है जो आपके टेस्ट एक्ज़ीक्यूशन को रीयल-टाइम में विज़ुअलाइज़ करने, नियंत्रित करने और निरीक्षण करने के लिए है। यह **WebdriverIO**, **Nightwatch.js**, और **Selenium WebDriver** (किसी भी रनर) के साथ काम करता है — वही बैकएंड, वही UI, वही कैप्चर इंफ्रास्ट्रक्चर।

## यह क्या प्रदान करता है

- **टेस्ट को चुनिंदा रूप से फिर से चलाएँ** - किसी भी टेस्ट केस या सूट को तुरंत फिर से चलाने के लिए उस पर क्लिक करें ([विवरण](/docs/devtools/wdio/interactive-test-rerunning))
- **Preserve & Rerun (Compare)** - किसी विफल टेस्ट का स्नैपशॉट लें, उसे फिर से चलाएँ, और दोनों रन को कमांड के अनुसार संरेखित करके साथ-साथ तुलना करें ([विवरण](/docs/devtools/wdio/preserve-and-rerun))
- **विज़ुअली डिबग करें** - प्रत्येक कमांड के बाद स्वचालित स्क्रीनशॉट के साथ लाइव ब्राउज़र प्रीव्यू देखें
- **एक्ज़ीक्यूशन ट्रैक करें** - टाइमस्टैम्प और परिणामों के साथ विस्तृत कमांड लॉग देखें
- **नेटवर्क और कंसोल की निगरानी करें** - API कॉल और JavaScript लॉग का निरीक्षण करें ([नेटवर्क](/docs/devtools/wdio/network-logs) · [कंसोल](/docs/devtools/wdio/console-logs))
- **कोड पर नेविगेट करें** - TestLens के साथ सीधे टेस्ट सोर्स फ़ाइलों पर जाएँ ([विवरण](/docs/devtools/wdio/testlens))
- **सेशन रिकॉर्ड करें** - प्रति सेशन ब्राउज़र का निरंतर `.webm` वीडियो ([विवरण](/docs/devtools/wdio/screencast))
- **Trace mode** - हेडलेस कैप्चर पाथ जो ऑफ़लाइन रीप्ले या एजेंटिक उपयोग के लिए एक पोर्टेबल `trace.zip` आर्टिफ़ैक्ट बनाता है ([विवरण](/docs/devtools/wdio/trace-mode))

## यह कैसे काम करता है

1. अपने टेस्ट सामान्य रूप से शुरू करें
2. DevTools स्वचालित रूप से `http://localhost:3000` पर एक ब्राउज़र विंडो खोलता है
3. UI रीयल-टाइम में टेस्ट पदानुक्रम, ब्राउज़र प्रीव्यू, कमांड टाइमलाइन और लॉग दिखाता है
4. टेस्ट पूरे होने के बाद, किसी भी टेस्ट को उसी ब्राउज़र सेशन में अलग से फिर से चलाने के लिए उस पर क्लिक करें

## अपना फ़्रेमवर्क चुनें

- **[WebDriverIO](/docs/devtools/wdio)** - Mocha, Jasmine, या Cucumber के साथ `@wdio/devtools-service` का उपयोग करें
- **[Nightwatch](/docs/devtools/nightwatch)** - बिना किसी टेस्ट कोड बदलाव के `@wdio/nightwatch-devtools` का उपयोग करें
- **[Selenium](/docs/devtools/selenium)** - Mocha, Jest, Cucumber, या सामान्य Node स्क्रिप्ट के साथ `@wdio/selenium-devtools` का उपयोग करें
