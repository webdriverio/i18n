TestLens offre une navigation intelligente dans le code entre l'interface DevTools et les fichiers sources de vos tests. Cliquez sur n'importe quel test dans l'interface pour accéder directement à sa définition dans votre éditeur de code, avec les numéros de ligne exacts.

**Fonctionnement :**
- **Hiérarchie visuelle des tests** - Visualisez la structure de vos tests (suites, tests, scénarios) sous forme d'arborescence
- **Correspondance avec les sources** - Chaque test est lié à son emplacement exact dans vos fichiers sources
- **Navigation en un clic** - Cliquez sur n'importe quel test pour l'ouvrir dans votre éditeur
- **Intégration avec les éditeurs** - Fonctionne avec les éditeurs de code populaires grâce aux protocoles file:line

Cette connexion fluide entre l'interface et le code accélère le débogage en vous évitant de rechercher manuellement dans le code lorsque vous analysez des échecs de tests.
