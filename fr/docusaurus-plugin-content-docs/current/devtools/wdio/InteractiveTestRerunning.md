Regardez vos tests s'exécuter en temps réel avec des aperçus du navigateur en direct et des captures d'écran automatiques prises après chaque commande WebDriver. L'interface affiche une chronologie visuelle complète de l'exécution de vos tests, montrant l'état exact du navigateur à chaque étape.

Une fois votre première exécution de tests terminée, cliquez sur n'importe quel cas de test ou suite dans l'interface DevTools pour le réexécuter instantanément. Cela vous évite de redémarrer l'ensemble de votre test runner ou de modifier votre code, ce qui accélère considérablement les cycles de débogage.

**Fonctionnalités clés :**
- **Visualisation en temps réel** - Capture d'écran automatique après chaque commande (click, toBeExisting, etc.)
- **Aperçu du navigateur en direct** - Visualisez l'état actuel de votre application pendant l'exécution des tests
- **Chronologie des commandes** - Consultez des logs détaillés avec horodatage pour chaque action
- **Réexécution interactive** - Cliquez sur n'importe quel test ou suite pour le réexécuter instantanément
- **Exécution dans la même session** - Les tests sont réexécutés dans la même session de navigateur pour un retour plus rapide
- **Historique défilant** - Revenez sur n'importe quel moment de l'exécution des tests
