title: Windows
description: "Découvrez l'état actuel de l'automatisation des applications Windows natives avec WebdriverIO et pourquoi aucun pilote stable n'est encore disponible."
---

Malheureusement, il n'existe pour le moment aucun pilote stable pour automatiser les applications Windows. Bien qu'Appium maintienne un [Windows Driver](https://github.com/appium/appium-windows-driver) basé sur le [serveur WinAppDriver](https://github.com/microsoft/WinAppDriver) de Microsoft, nous ne recommandons pas de l'utiliser, étant donné que Microsoft a cessé de maintenir ce serveur et qu'il existe de nombreux [bugs connus](https://github.com/search?q=repo%3Amicrosoft%2FWinAppDriver+webdriverio&type=issues).

Si quelqu'un connaît un moyen d'automatiser les applications Windows, n'hésitez pas à nous en faire part sur [Discord](https://discord.webdriver.io).
