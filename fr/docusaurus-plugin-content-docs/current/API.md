Bienvenue dans la documentation de l'API WebdriverIO. Ces pages contiennent des documents de référence pour toutes les liaisons de protocole implémentées et les commandes utilitaires. Les commandes de protocole, y compris [WebDriver](/docs/api/webdriver), [WebDriver Bidi](/docs/api/webdriverBidi) ou les commandes mobiles comme [Appium](http://appium.io), sont des commandes envoyées directement au backend du driver sous-jacent. Les commandes utilitaires fournies par les objets [`browser`](/docs/api/browser), [`element`](/docs/api/element) ou [`mock`](/docs/api/mock) offrent une interactivité de plus haut niveau.

:::info
Ceci est la documentation de WebdriverIO __v10__. Vous utilisez encore la v9 ? Consultez la [documentation v9](https://v9.webdriver.io) ou suivez le [guide de migration v10](/docs/v10-migration).
:::

## Contribuer

Si vous pensez avoir un bon exemple pour une commande, n'hésitez pas à ouvrir une PR pour le soumettre. Cliquez simplement sur le lien orange en bas à gauche portant le libellé _« Edit this page »_. Assurez-vous de bien comprendre la manière dont nous rédigeons cette documentation en consultant la section [Contributing](https://github.com/webdriverio/webdriverio/blob/main/CONTRIBUTING.md).
