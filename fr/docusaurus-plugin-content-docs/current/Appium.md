Avec WebdriverIO, vous pouvez tester non seulement des applications web dans le navigateur, mais aussi d'autres plateformes telles que :

- 📱 les applications mobiles sur iOS, Android ou Tizen
- 🖥️ les applications de bureau sur macOS ou Windows
- 📺 ainsi que les applications TV pour Roku, tvOS, Android TV et Samsung

Nous recommandons d'utiliser [Appium](https://appium.io/) pour vous aider à réaliser ce type de tests. Vous pouvez obtenir un aperçu d'Appium sur leur [page de documentation officielle](https://appium.io/docs/en/latest/intro/).

Mettre en place le bon environnement n'est pas simple. Heureusement, l'écosystème Appium dispose d'excellents outils pour vous aider. Pour configurer l'un des environnements ci-dessus, exécutez simplement :

```sh
$ npx appium-installer
```

Cela lancera la boîte à outils [appium-installer](https://github.com/AppiumTestDistribution/appium-installer) qui vous guidera tout au long du processus de configuration.
