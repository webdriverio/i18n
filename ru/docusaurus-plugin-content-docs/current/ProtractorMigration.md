Это руководство предназначено для тех, кто использует Protractor и хочет перевести свой фреймворк на WebdriverIO. Оно было создано после того, как команда Angular [объявила](https://github.com/angular/protractor/issues/5502), что Protractor больше не будет поддерживаться. На WebdriverIO повлияли многие проектные решения Protractor, поэтому он, вероятно, является наиболее близким фреймворком для миграции. Команда WebdriverIO ценит работу каждого участника проекта Protractor и надеется, что это руководство сделает переход на WebdriverIO простым и понятным.

Хотя мы бы хотели иметь полностью автоматизированный процесс, реальность выглядит иначе. У всех разная конфигурация, и все используют Protractor по-разному. Каждый шаг следует рассматривать скорее как рекомендацию, чем как пошаговую инструкцию. Если у вас возникнут проблемы с миграцией, не стесняйтесь [связаться с нами](https://github.com/webdriverio/codemod/discussions/new).

## Настройка

API Protractor и WebdriverIO на самом деле очень похожи, настолько, что большинство команд можно переписать автоматически с помощью [codemod](https://github.com/webdriverio/codemod).

Чтобы установить codemod, выполните:

```sh
npm install jscodeshift @wdio/codemod
```

## Стратегия

Существует множество стратегий миграции. В зависимости от размера вашей команды, количества тестовых файлов и срочности миграции вы можете попробовать преобразовать все тесты сразу или файл за файлом. Учитывая, что Protractor будет поддерживаться до версии Angular 15 (конец 2022 года), у вас еще достаточно времени. Вы можете одновременно запускать тесты Protractor и WebdriverIO и начать писать новые тесты на WebdriverIO. В зависимости от имеющегося у вас времени вы можете сначала перенести важные тестовые сценарии, а затем постепенно переходить к тестам, которые, возможно, даже можно удалить.

## Сначала файл конфигурации

После установки codemod мы можем начать преобразование первого файла. Сначала ознакомьтесь с [параметрами конфигурации WebdriverIO](configuration). Файлы конфигурации могут быть очень сложными, и имеет смысл перенести только основные части, а затем посмотреть, как можно добавить остальное, когда будут переноситься соответствующие тесты, которым нужны определенные параметры.

Для первой миграции мы преобразуем только файл конфигурации и выполняем:

```sh
npx jscodeshift -t ./node_modules/@wdio/codemod/protractor ./conf.ts
```

:::info

 Ваш файл конфигурации может называться иначе, однако принцип должен быть тем же: начинайте миграцию с конфигурации.

:::

## Установка зависимостей WebdriverIO

Следующий шаг — настроить минимальную конфигурацию WebdriverIO, которую мы будем расширять по мере перехода с одного фреймворка на другой. Сначала установим WebdriverIO CLI:

```sh
npm install --save-dev @wdio/cli
```

Затем запустим мастер настройки:

```sh
npx wdio config
```

Мастер задаст вам несколько вопросов. Для этого сценария миграции:
- выбирайте варианты по умолчанию
- мы рекомендуем не генерировать файлы примеров автоматически
- выберите другую папку для файлов WebdriverIO
- и выберите Mocha вместо Jasmine.

:::info Почему Mocha?
Даже если раньше вы использовали Protractor с Jasmine, Mocha предоставляет более удобные механизмы повторных попыток. Выбор за вами!
:::

После небольшого опроса мастер установит все необходимые пакеты и сохранит их в вашем `package.json`.

## Миграция файла конфигурации

Теперь, когда у нас есть преобразованный `conf.ts` и новый `wdio.conf.ts`, пришло время перенести конфигурацию из одного файла в другой. Убедитесь, что переносите только тот код, который необходим для запуска всех тестов. В нашем случае мы переносим функцию хука и тайм-аут фреймворка.

Далее мы будем работать только с файлом `wdio.conf.ts`, поэтому никакие изменения в исходной конфигурации Protractor больше не понадобятся. Мы можем отменить их, чтобы оба фреймворка могли работать параллельно, а мы могли переносить по одному файлу за раз.

## Миграция тестового файла

Теперь мы готовы перенести первый тестовый файл. Для начала выберем файл, у которого немного зависимостей от сторонних пакетов или других файлов, таких как PageObjects. В нашем примере первым мигрируемым файлом является `first-test.spec.ts`. Сначала создайте каталог, в котором новая конфигурация WebdriverIO ожидает найти файлы, а затем переместите файл туда:

```sh
mv mkdir -p ./test/specs/
mv test-suites/first-test.spec.ts ./test/specs
```

Теперь преобразуем этот файл:

```sh
npx jscodeshift -t ./node_modules/@wdio/codemod/protractor ./test/specs/first-test.spec.ts
```

Вот и всё! Этот файл настолько прост, что никаких дополнительных изменений не требуется, и мы можем сразу попробовать запустить WebdriverIO:

```sh
npx wdio run wdio.conf.ts
```

Поздравляем 🥳 вы только что перенесли первый файл!

## Следующие шаги

Дальше вы продолжаете преобразовывать тест за тестом и page object за page object. Есть вероятность, что для некоторых файлов codemod завершится с ошибкой, например:

```
ERR /path/to/project/test/testdata/failing_submit.js Transformation error (Error transforming /test/testdata/failing_submit.js:2)
Error transforming /test/testdata/failing_submit.js:2

> login_form.submit()
  ^

The command "submit" is not supported in WebdriverIO. We advise to use the click command to click on the submit button instead. For more information on this configuration, see https://webdriver.io/docs/api/element/click.
  at /path/to/project/test/testdata/failing_submit.js:132:0
```

Для некоторых команд Protractor в WebdriverIO просто нет замены. В этом случае codemod подскажет, как выполнить рефакторинг. Если вы слишком часто сталкиваетесь с такими сообщениями об ошибках, не стесняйтесь [создать issue](https://github.com/webdriverio/codemod/issues/new) и попросить добавить определенное преобразование. Хотя codemod уже преобразует большую часть API Protractor, возможностей для улучшения по-прежнему много.

## Заключение

Мы надеемся, что это руководство немного поможет вам в процессе миграции на WebdriverIO. Сообщество продолжает улучшать codemod, тестируя его с различными командами в разных организациях. Не стесняйтесь [создать issue](https://github.com/webdriverio/codemod/issues/new), если у вас есть отзывы, или [начать обсуждение](https://github.com/webdriverio/codemod/discussions/new), если у вас возникли трудности в процессе миграции.
