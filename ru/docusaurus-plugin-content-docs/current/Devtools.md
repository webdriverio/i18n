DevTools — это мощный браузерный интерфейс отладки для визуализации, управления и анализа выполнения ваших тестов в реальном времени. Он работает с **WebdriverIO**, **Nightwatch.js** и **Selenium WebDriver** (с любым раннером) — один и тот же бэкенд, один и тот же интерфейс, одна и та же инфраструктура захвата.

## Возможности

- **Выборочный перезапуск тестов** — нажмите на любой тест-кейс или набор тестов, чтобы мгновенно запустить его повторно ([подробнее](/docs/devtools/wdio/interactive-test-rerunning))
- **Сохранение и перезапуск (сравнение)** — сделайте снимок упавшего теста, перезапустите его и сравните два запуска бок о бок с выравниванием по командам ([подробнее](/docs/devtools/wdio/preserve-and-rerun))
- **Визуальная отладка** — просматривайте живое превью браузера с автоматическими скриншотами после каждой команды
- **Отслеживание выполнения** — просматривайте подробные журналы команд с временными метками и результатами
- **Мониторинг сети и консоли** — анализируйте API-запросы и логи JavaScript ([сеть](/docs/devtools/wdio/network-logs) · [консоль](/docs/devtools/wdio/console-logs))
- **Переход к коду** — переходите напрямую к исходным файлам тестов с помощью TestLens ([подробнее](/docs/devtools/wdio/testlens))
- **Запись сессий** — непрерывное видео браузера в формате `.webm` для каждой сессии ([подробнее](/docs/devtools/wdio/screencast))
- **Режим трассировки** — headless-режим захвата, создающий переносимый артефакт `trace.zip` для офлайн-воспроизведения или использования агентами ([подробнее](/docs/devtools/wdio/trace-mode))

## Как это работает

1. Запустите тесты как обычно
2. DevTools автоматически откроет окно браузера по адресу `http://localhost:3000`
3. Интерфейс в реальном времени отображает иерархию тестов, превью браузера, временную шкалу команд и логи
4. После завершения тестов нажмите на любой тест, чтобы перезапустить его отдельно в той же сессии браузера

## Выберите свой фреймворк

- **[WebDriverIO](/docs/devtools/wdio)** — используйте `@wdio/devtools-service` с Mocha, Jasmine или Cucumber
- **[Nightwatch](/docs/devtools/nightwatch)** — используйте `@wdio/nightwatch-devtools` без каких-либо изменений в коде тестов
- **[Selenium](/docs/devtools/selenium)** — используйте `@wdio/selenium-devtools` с Mocha, Jest, Cucumber или обычными Node-скриптами
