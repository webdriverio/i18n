`export` создаёт спецификацию из записанных шагов. Ссылки (refs) заменяются стабильными селекторами. Для веб-страницы используется первый из следующих вариантов, который соответствует ровно одному элементу: тестовый идентификатор (`data-testid`, `data-test`, `data-qa`), [селектор роли](/docs/selectors#role-selector), например `role/button[name="Add to cart"]`, доступное имя (`aria/Add to cart`), id, текст кнопки или ссылки, имя поля формы и, наконец, CSS-путь.

```sh
npx wdio session export --out test/specs/cart.e2e.ts
npx wdio run wdio.conf.ts --spec test/specs/cart.e2e.ts
```

`history` выводит шаги перед экспортом. `history clear` удаляет их.

## Объекты страниц

`--page-objects` создаёт объект страницы рядом со спецификацией. Селекторы группируются по пути, на котором они выполнялись. Литерал `$('…')` в записанном шаге становится геттером. `$$`, строки, которые случайно содержат `$('…')`, и динамический `$(selector)` остаются без изменений.

```sh
npx wdio session export --page-objects --out test/specs/cart.e2e.ts
```

Команда не перезаписывает объект страницы, который уже находится в выходном каталоге. Сначала измените `--out` или удалите этот файл. Сам файл спецификации перезаписывается.

`import` в начале шага `exec` поднимается в начало спецификации, за пределы тестовой функции.

## Хелперы

Добавьте файл в `.wdio/helpers/`, если шаг слишком длинный для `exec`. Каждый файл экспортирует по умолчанию функцию, которая получает браузер и регистрирует команды с помощью `addCommand`. Относительные импорты остаются относительными к этому файлу. Импорты пакетов по имени разрешаются из проекта.

```js title=".wdio/helpers/login.js"
import { mark } from './util.js'

export default function login (browser) {
    browser.addCommand('fillLogin', async (email) => {
        await browser.$('#email').setValue(email + mark)
    })
}
```

Хелперы загружаются при открытии сессии, а также повторно с помощью `npx wdio session helpers --reload`. Если `.wdio/helpers` ещё не существует, сессия отслеживает его появление. В экспортированном тесте хелперы становятся пользовательскими командами.
