---
id: globals
title: Глобальные объекты
---

В ваших тестовых файлах WebdriverIO помещает каждый из этих методов и объектов в глобальное окружение. Вам не нужно ничего импортировать, чтобы использовать их. Однако, если вы предпочитаете явный импорт, вы можете написать `import { browser, $, $$, expect } from '@wdio/globals'` и установить `injectGlobals: false` в конфигурации WDIO.

Следующие глобальные объекты устанавливаются, если не настроено иное:

- `browser`: [объект Browser](https://webdriver.io/docs/api/browser) WebdriverIO
- `driver`: псевдоним для `browser` (используется при запуске мобильных тестов)
- `multiRemoteBrowser`: псевдоним для `browser` или `driver`, но устанавливается только для сессий [multi-remote](/docs/multiremote)
- `$`: команда для получения элемента (подробнее в [документации API](/docs/api/browser/$))
- `$$`: команда для получения элементов (подробнее в [документации API](/docs/api/browser/$$))
- `expect`: фреймворк утверждений для WebdriverIO (см. [документацию API](/docs/api/expect-webdriverio))

__Примечание:__ WebdriverIO не контролирует то, как используемые фреймворки (например, Mocha или Jasmine) устанавливают глобальные переменные при инициализации своего окружения.
