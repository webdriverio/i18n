Изучайте полный контекст каждой браузерной сессии, которую открывает ваш тест. Вкладка Metadata отображает возможности, окружение и тайминги каждого запуска, позволяя точно убедиться, что именно тестировалось, без необходимости копаться в логах.

**Что фиксируется:**
- **Возможности сессии** - название и версия браузера, платформа и согласованные возможности WebDriver
- **Сведения о сессии** - идентификатор сессии, базовый URL и размер области просмотра
- **Тайминги выполнения** - длительность теста, статус и временные метки начала и окончания
- **Просмотр по сессиям** - каждая браузерная сессия (включая сессии, созданные с помощью `browser.reloadSession()`) сохраняется независимо и может быть выбрана из выпадающего списка

Это незаменимо для диагностики сбоев, связанных с конкретным окружением, проверки того, что были применены нужные возможности, и понимания поведения тестов с несколькими сессиями.
