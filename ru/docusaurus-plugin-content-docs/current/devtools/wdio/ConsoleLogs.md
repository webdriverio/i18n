Перехватывайте и просматривайте весь вывод консоли браузера во время выполнения тестов. DevTools записывает сообщения консоли вашего приложения (`console.log()`, `console.warn()`, `console.error()`, `console.info()`, `console.debug()`), а также логи фреймворка WebDriverIO в соответствии с уровнем `logLevel`, настроенным в вашем `wdio.conf.ts`.

**Возможности:**
- Перехват сообщений консоли в реальном времени во время выполнения тестов
- Логи консоли браузера (log, warn, error, info, debug)
- Логи фреймворка WebDriverIO, отфильтрованные по настроенному `logLevel` (trace, debug, info, warn, error, silent)
- Временные метки, показывающие, когда именно было записано каждое сообщение
- Логи консоли отображаются рядом с шагами теста и скриншотами браузера для понимания контекста

**Конфигурация:**
```js
// wdio.conf.ts
export const config = {
    // Уровень детализации логирования: trace | debug | info | warn | error | silent
    logLevel: 'info', // Определяет, какие логи фреймворка будут перехвачены
    // ...
};
```

Это упрощает отладку ошибок JavaScript, отслеживание поведения приложения и просмотр внутренних операций WebDriverIO во время выполнения тестов.
