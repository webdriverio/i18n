TestLens обеспечивает интеллектуальную навигацию по коду между интерфейсом DevTools и исходными файлами ваших тестов. Нажмите на любой тест в интерфейсе, чтобы сразу перейти к его определению в редакторе кода с точным номером строки.

**Как это работает:**
- **Визуальная иерархия тестов** — просматривайте структуру тестов (наборы, тесты, сценарии) в виде дерева
- **Сопоставление с исходным кодом** — каждый тест связан с его точным расположением в исходных файлах
- **Навигация в один клик** — нажмите на любой тест, чтобы открыть его в редакторе
- **Интеграция с редакторами** — работает с популярными редакторами кода через протоколы file:line

Такая бесшовная связь между интерфейсом и кодом ускоряет отладку, избавляя от необходимости вручную искать код при расследовании падений тестов.
