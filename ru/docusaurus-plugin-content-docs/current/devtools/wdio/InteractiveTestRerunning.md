Наблюдайте за выполнением тестов в реальном времени с живым предпросмотром браузера и автоматическими скриншотами, которые делаются после каждой команды WebDriver. Интерфейс отображает полную визуальную временную шкалу выполнения теста, показывая точное состояние браузера на каждом шаге.

После завершения первоначального запуска тестов нажмите на любой тест или набор тестов в интерфейсе DevTools, чтобы мгновенно выполнить его повторно. Это избавляет от необходимости перезапускать весь тест-раннер или изменять код и значительно ускоряет циклы отладки.

**Ключевые возможности:**
- **Визуализация в реальном времени** — автоматическое создание скриншота после каждой команды (click, toBeExisting и т. д.)
- **Живой предпросмотр браузера** — просмотр текущего состояния вашего приложения во время выполнения теста
- **Временная шкала команд** — подробные логи с временными метками для каждого действия
- **Интерактивный перезапуск** — нажмите на любой тест или набор, чтобы мгновенно выполнить его повторно
- **Выполнение в той же сессии** — тесты перезапускаются в той же сессии браузера для более быстрой обратной связи
- **Прокручиваемая история** — просмотр любого момента выполнения теста
