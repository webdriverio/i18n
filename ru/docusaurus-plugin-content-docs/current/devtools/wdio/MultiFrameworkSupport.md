DevTools автоматически работает с Mocha, Jasmine и Cucumber без необходимости в какой-либо специфичной для фреймворка конфигурации. Просто добавьте сервис в конфигурацию WebDriverIO, и все функции будут работать без проблем, независимо от того, какой тестовый фреймворк вы используете.

**Поддерживаемые фреймворки:**
- **Mocha** — выполнение на уровне тестов и наборов (suite) с фильтрацией через grep
- **Jasmine** — полная интеграция с фильтрацией на основе grep
- **Cucumber** — выполнение на уровне сценариев и примеров с указанием цели в формате feature:line

Один и тот же интерфейс отладки, повторный запуск тестов и функции визуализации работают одинаково во всех фреймворках.

## Конфигурация

```js
// wdio.conf.js
export const config = {
    framework: 'mocha', // или 'jasmine', или 'cucumber'
    services: ['devtools'],
    // ...
};
```
