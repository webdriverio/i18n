Проигрыватель `show-trace` открывает любую трассировку, созданную в [режиме трассировки](/docs/devtools/wdio/trace-mode), прямо в интерфейсе WebdriverIO DevTools — в специальном режиме **проигрывателя** только для чтения, предназначенном для офлайн-воспроизведения, анализа и сравнения результатов AI-агентами.

## `show-trace` — собственный проигрыватель

Откройте трассировку в интерфейсе DevTools:

```sh
show-trace trace-<sessionId>.zip          # bin on PATH after install
npx show-trace trace-<sessionId>.zip      # or via npx
pnpm show-trace trace-<sessionId>.zip     # from the devtools monorepo
```

Исполняемый файл `show-trace` поставляется вместе с каждым адаптером (`@wdio/devtools-service`, `@wdio/nightwatch-devtools`, `@wdio/selenium-devtools`), поэтому он доступен в любом проекте, где установлен один из них, — без дополнительных зависимостей. Он запускает тот же интерфейс DevTools в специальном режиме **проигрывателя** и открывает его в вашем браузере:

- **Список действий** (слева) — записанные команды, а рядом вкладка **Metadata**.
- **Панель браузера** (в центре) — восстановленная страница для выбранного действия (см. [путешествие во времени по DOM](#trace-player-features) ниже). Если трассировка содержит кадры диафильма или видео, переключатель **Snapshot / Screencast** позволяет перейти к записанному видео.
- **Полоса временной шкалы** (сверху) — диафильм из миниатюр, расположенных в соответствии с реальным временем, а также полоса прокрутки с перетаскиваемым указателем воспроизведения. Нажмите на миниатюру или перетащите указатель в любое место, чтобы перейти к нужному моменту.
- **Панель управления** — воспроизведение/пауза, пошаговый переход и скорость.
- **Вкладки панели** (снизу) — **Source**, **Log**, **Console**, **Network**, **Errors** (у каждой есть значок с количеством записей), а также доступные только в проигрывателе вкладки **A11y** и **Transcript**. Нажмите на строку во вкладке **Network**, чтобы увидеть подробности запроса (заголовки, тайминги, статус).
- **Сочетания клавиш** — `Space` воспроизведение/пауза, `←`/`→` переход между действиями, `Home`/`End` переход к первому/последнему, `,`/`.` изменение скорости, `/` фокус на фильтре, `?` показать все сочетания клавиш.

> Принимаются только файлы `.zip`. Те же сочетания клавиш работают и в живой панели мониторинга (`←`/`→` перемещаются по списку команд, `?` показывает справку).

### Возможности проигрывателя трассировок

Помимо простого пошагового просмотра статичных кадров, проигрыватель восстанавливает ход выполнения и связывает данные между собой:

- **Путешествие во времени по DOM** — панель браузера воспроизводит записанный поток мутаций DOM (и состояние полей форм — `value` у input, `checked` у checkbox, включая поля, очищенные до пустого значения), чтобы восстановить *реальный* DOM на момент выбранного действия, а не просто скриншот. Точки, для которых не было записано кадра (проверки, статические ожидания), всё равно показывают истинное состояние страницы.
- **Вкладка A11y и наложение элементов («выбор локатора»)** — вкладка **A11y** показывает дерево доступности (роли и доступные имена), записанное для выбранной команды. Включите наложение элементов в панели браузера, чтобы обвести каждый элемент, с которым взаимодействовал тест; **наведите курсор** на рамку, чтобы подсветить соответствующую строку в дереве A11y, **нажмите**, чтобы скопировать устойчивый локатор. Связь двусторонняя — при наведении на строку дерева соответствующий элемент подсвечивается на снимке.
- **Вкладка Transcript и Copy-for-LLM** — вкладка **Transcript** отображает файл `transcript.md` прогона (сводку в порядке выполнения, удобную для чтения человеком и LLM). Кнопка **Copy** одним нажатием объединяет транскрипт с ошибками упавших команд в готовый для вставки контекст для LLM.
- **Маркеры ввода на временной шкале** — каждое действие отмечено на полосе прокрутки в зависимости от типа: действия с клавиатурой — зелёной полосой, действия указателем (у которых есть точка попадания) — синей точкой, остальные — обычной засечкой, так что ритм взаимодействий можно понять с одного взгляда.
- **Вложенность Cucumber** — прогоны Cucumber отображаются в дереве действий с вложенностью Feature → Scenario → Step, поэтому шаги располагаются под своими сценариями и фичами.
- **Плотная прокрутка диафильма** — при включённой опции [`filmstrip`](/docs/devtools/wdio/trace-mode#dense-filmstrip--filmstrip) временная шкала содержит плотную последовательность кадров для плавной прокрутки вместо скачков по одному кадру на действие.

## Другие просмотрщики трассировок

Поскольку артефакт использует переносимый стандартный формат хранения на диске для просмотрщиков трассировок, тот же `.zip` (или каталог) также открывается в совместимых **автономных просмотрщиках трассировок**, а благодаря общему формату — и во **встроенном просмотрщике трассировок отчёта Allure** (Allure ≥ 2.35). Они отображают:
- Временную шкалу действий с таймингами
- Скриншоты для каждого действия
- Снимки элементов
- Каскадную диаграмму сетевых запросов
- События консоли

Для использования LLM или агентами читайте `transcript.md` напрямую — это компактное представление действий в формате Markdown с селекторами и значениями.

Конвейер трассировки (сопоставление действий, сериализаторы снимков, запись NDJSON, запись в zip или каталог) общий для всех адаптеров благодаря [`@wdio/devtools-core`](https://github.com/webdriverio/devtools/tree/main/packages/core), поэтому структура артефакта одинакова независимо от того, какой адаптер его создал, — см. [Кроссфреймворковая поддержка](/docs/devtools/cross-framework).
