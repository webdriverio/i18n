В этом руководстве рассматривается настройка, структурирование и запуск сквозных (End-to-End, E2E) тестов для приложений **Flutter** с использованием **WebdriverIO** и **Appium**.

WebdriverIO предоставляет тестовый фреймворк на базе Node.js с нативной поддержкой протоколов WebDriver и Appium, что позволяет автоматизировать Flutter-приложения как на Android, так и на iOS.

---

### Архитектурная проблема: чем отличается Flutter

При автоматизации стандартных нативных мобильных приложений (Kotlin/Java на Android или Swift/Objective-C на iOS) драйверы Appium (`UiAutomator2` для Android, `XCUITest` для iOS) служат точкой доступа для инспектирования приложения и взаимодействия с ним, запрашивая нативное дерево доступности (accessibility tree) операционной системы. Эти драйверы считывают UI-компоненты уровня ОС (кнопки, поля ввода, метки) и предоставляют их инструментам инспектирования и тестовым скриптам с помощью стандартных стратегий поиска локаторов, таких как ID, Accessibility ID или XPath.

Flutter работает иначе:

Flutter не использует нативные UI-компоненты операционной системы. Вместо этого он отрисовывает свой интерфейс непосредственно на холсте (canvas) с помощью встроенного графического движка. Фреймворк рисует собственные виджеты пиксель за пикселем.

#### Влияние на традиционную автоматизацию
Для стандартных нативных драйверов и инспекторов Flutter-приложение часто выглядит как единая графическая поверхность. Внутренние виджеты (например, кнопки или текстовые поля) по умолчанию отсутствуют в дереве доступности ОС. В результате стандартные нативные стратегии поиска локаторов не могут напрямую взаимодействовать с внутренними виджетами Flutter.

### Как WebdriverIO и Appium работают с Flutter

WebdriverIO и Appium предоставляют инструменты, необходимые для взаимодействия с внутренним деревом виджетов Flutter, однако вам нужно установить и настроить соответствующий драйвер и расширения локаторов для вашего проекта.

С помощью [Appium Flutter Driver](https://github.com/appium/appium-flutter-driver) Appium подключается к тестовому расширению Flutter (`flutter_driver`). Это дает доступ к специфичным для Flutter стратегиям поиска локаторов (Finders), включая:

* `byValueKey`: находит виджеты по их явно заданному `Key` в коде Flutter.
* `byText`: находит виджеты по видимому текстовому содержимому.
* `byTooltip`: находит виджеты по тексту их всплывающей подсказки.
