Visual Reporter — это новая функция, появившаяся в `@wdio/visual-service` начиная с версии [v5.2.0](https://github.com/webdriverio/visual-testing/releases/tag/%40wdio%2Fvisual-service%405.2.0). Этот репортер позволяет визуализировать JSON-отчёты о различиях, создаваемые сервисом Visual Testing, и преобразовывать их в удобочитаемый формат. Он помогает командам эффективнее анализировать результаты визуального тестирования и управлять ими, предоставляя графический интерфейс для их просмотра.

Чтобы воспользоваться этой функцией, убедитесь, что у вас настроена конфигурация, необходимая для создания файла `output.json`. Этот документ поможет вам настроить, запустить Visual Reporter и разобраться в его работе.

# Предварительные требования

Перед использованием Visual Reporter убедитесь, что сервис Visual Testing настроен на создание файлов JSON-отчётов:

```ts
export const config = {
    // ...
    services: [
        [
            "visual",
            {
                createJsonReportFiles: true, // Генерирует файл output.json
            },
        ],
    ],
};
```

Более подробные инструкции по настройке смотрите в [документации по визуальному тестированию](./) WebdriverIO или в описании опции [`createJsonReportFiles`](./service-options.md#createjsonreportfiles-new)

# Установка

Чтобы установить Visual Reporter, добавьте его в проект как зависимость для разработки с помощью npm:

```bash
npm install @wdio/visual-reporter --save-dev
```

Это обеспечит наличие всех файлов, необходимых для создания отчётов по вашим визуальным тестам.

# Использование

## Создание визуального отчёта

После того как вы запустили визуальные тесты и они сгенерировали файл `output.json`, вы можете создать визуальный отчёт с помощью CLI или интерактивных подсказок.

### Использование CLI

Вы можете создать отчёт с помощью команды CLI:

```bash
npx wdio-visual-reporter --jsonOutput=<path-to-output.json> --reportFolder=<path-to-store-report> --logLevel=debug
```

#### Обязательные опции:

-   `--jsonOutput`: Относительный путь к файлу `output.json`, созданному сервисом Visual Testing. Путь указывается относительно директории, из которой выполняется команда.
-   `--reportFolder`: Относительный путь к директории, в которой будет сохранён созданный отчёт. Этот путь также указывается относительно директории, из которой выполняется команда.

#### Необязательные опции:

-   `--logLevel`: Установите значение `debug`, чтобы получить подробное логирование, что особенно полезно при устранении неполадок.

#### Пример

```bash
npx wdio-visual-reporter --jsonOutput=/path/to/output.json --reportFolder=/path/to/report --logLevel=debug
```

Эта команда создаст отчёт в указанной папке и выведет информацию в консоль. Например:

```bash
✔ Build output copied successfully to "/path/to/report".
⠋ Prepare report assets...
✔ Successfully generated the report assets.
```

#### Просмотр отчёта

:::warning
Открытие `path/to/report/index.html` напрямую в браузере **без запуска локального сервера** **НЕ** будет работать.
:::

Для просмотра отчёта необходимо использовать простой сервер, например [sirv-cli](https://www.npmjs.com/package/sirv-cli). Запустить сервер можно следующей командой:

```bash
npx sirv-cli /path/to/report --single
```

В результате будут выведены логи, похожие на пример ниже. Обратите внимание, что номер порта может отличаться:

```logs
  Your application is ready~! 🚀

  - Local:      http://localhost:8080
  - Network:    Add `--host` to expose

────────────────── LOGS ──────────────────
```

Теперь вы можете просмотреть отчёт, открыв указанный URL в браузере.

### Использование интерактивных подсказок

В качестве альтернативы вы можете выполнить следующую команду и ответить на вопросы, чтобы создать отчёт:

```bash
npx @wdio/visual-reporter
```

Подсказки помогут вам указать необходимые пути и опции. В конце интерактивная подсказка также спросит, хотите ли вы запустить сервер для просмотра отчёта. Если вы решите запустить сервер, инструмент запустит простой сервер и выведет URL в логах. Вы можете открыть этот URL в браузере, чтобы просмотреть отчёт.

# Разбор визуального отчёта

Visual Reporter предоставляет упорядоченное представление результатов ваших визуальных тестов. Для каждого запуска тестов вы сможете:

-   Легко переключаться между тест-кейсами и просматривать сводные результаты.
-   Просматривать метаданные, такие как названия тестов, используемые браузеры и результаты сравнения.
-   Просматривать изображения с различиями, показывающие, где были обнаружены визуальные расхождения.

Такое визуальное представление упрощает анализ результатов тестов, облегчая выявление и устранение визуальных регрессий.
