---
id: watcher
title: Отслеживание тестовых файлов
description: "Автоматически перезапускайте тесты при изменении spec-файлов или файлов приложения, запуская WDIO testrunner с флагом --watch и параметром filesToWatch."
---

С помощью WDIO testrunner вы можете отслеживать файлы, пока работаете над ними. Тесты автоматически перезапускаются, если вы что-то изменили в своём приложении или в тестовых файлах. Если добавить флаг `--watch` при вызове команды `wdio`, testrunner после выполнения всех тестов будет ожидать изменений в файлах, например:

```sh
wdio wdio.conf.js --watch
```

По умолчанию отслеживаются только изменения в ваших файлах `specs`. Однако если задать в `wdio.conf.js` свойство `filesToWatch`, содержащее список путей к файлам (поддерживаются glob-шаблоны), то testrunner будет также отслеживать изменения в этих файлах, чтобы перезапустить весь набор тестов. Это полезно, если вы хотите автоматически перезапускать все тесты после изменения кода приложения, например:

```js
// wdio.conf.js
export const config = {
    // ...
    filesToWatch: [
        // отслеживать все JS-файлы в моём приложении
        './src/app/**/*.js'
    ],
    // ...
}
```

:::info
Старайтесь по возможности запускать тесты параллельно. E2E-тесты по своей природе медленные. Перезапуск тестов полезен только в том случае, если время выполнения отдельного теста остаётся коротким. Для экономии времени testrunner сохраняет сессии WebDriver активными во время ожидания изменений в файлах. Убедитесь, что ваш бэкенд WebDriver можно настроить так, чтобы он не закрывал сессию автоматически, если в течение некоторого времени не было выполнено ни одной команды.
:::
