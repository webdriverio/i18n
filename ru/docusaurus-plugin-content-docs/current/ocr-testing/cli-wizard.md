Вы можете проверить, какой текст может быть найден на изображении, без запуска теста с помощью мастера OCR CLI. Для этого нужно только следующее:

-   у вас установлен `@wdio/ocr-service` в качестве зависимости, см. [Начало работы](./getting-started)
-   изображение, которое вы хотите обработать

Затем выполните следующую команду, чтобы запустить мастер

```sh
npx ocr-service
```

Это запустит мастер, который проведёт вас через шаги по выбору изображения и использованию области поиска (haystack), а также расширенного режима. Задаются следующие вопросы

## Как вы хотите указать файл?

Можно выбрать следующие варианты

-   Использовать «проводник файлов»
-   Ввести путь к файлу вручную

### Использовать «проводник файлов»

Мастер CLI предоставляет возможность использовать «проводник файлов» для поиска файлов в вашей системе. Он начинает работу с папки, из которой вы вызываете команду. После выбора изображения (используйте клавиши со стрелками и клавишу ENTER) вы перейдёте к следующему вопросу

### Ввести путь к файлу вручную

Это прямой путь к файлу где-либо на вашем локальном компьютере

### Хотите ли вы использовать область поиска (haystack)?

Здесь у вас есть возможность выбрать область, которую нужно обработать. Это может ускорить процесс или уменьшить/сузить объём текста, который может найти движок OCR. Вам нужно указать данные `x`, `y`, `width`, `height`, отвечая на следующие вопросы:

-   Введите координату x:
-   Введите координату y:
-   Введите ширину:
-   Введите высоту:

## Хотите ли вы использовать расширенный режим?

Расширенный режим будет содержать дополнительные функции, такие как:

-   настройка контрастности
-   в будущем появятся и другие
