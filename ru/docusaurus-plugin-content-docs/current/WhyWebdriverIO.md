WebdriverIO — это фреймворк автоматизации тестирования с открытым исходным кодом для Node.js. С помощью одного тест-раннера и одного API вы можете автоматизировать веб-браузеры, нативные и гибридные мобильные приложения, десктопные приложения и расширения редакторов, а также дополнительно проводить визуальное тестирование, тестирование доступности и компонентное тестирование. Проект развивается сообществом под эгидой [OpenJS Foundation](https://openjsf.org/).

## Один фреймворк для всех платформ

Большинство команд выпускают не только веб-сайт. WebdriverIO позволяет тестировать всё это с помощью одних и тех же селекторов, утверждений, репортеров и настроек CI:

| Платформа | Как WebdriverIO её автоматизирует | С чего начать |
| --- | --- | --- |
| Веб-браузеры | WebDriver и WebDriver BiDi в Chrome, Firefox, Safari и Edge | [Web Browsers](/docs/platforms/web) |
| Веб-компоненты | Компонентные тесты в реальном браузере для React, Vue, Svelte, Solid, Preact, Lit и Stencil | [Component Testing](/docs/component-testing) |
| Мобильные приложения | Нативные, гибридные и мобильные веб-приложения на iOS и Android через Appium, включая Flutter | [Mobile Apps](/docs/platforms/mobile) |
| Десктопные приложения | Приложения на Electron, Tauri и Dioxus на macOS, Windows и Linux, нативные приложения macOS через Appium | [Desktop Apps](/docs/platforms/desktop) |
| Редакторы и расширения | Расширения VS Code и расширения браузеров | [Extensions & Editors](/docs/platforms/apps-and-extensions) |
| Визуальные регрессии | Сравнение экранов, элементов и целых страниц для веба и мобильных устройств | [Visual Testing](/docs/visual-testing) |

Один и тот же тест может даже управлять несколькими из них одновременно, например мобильным приложением и веб-панелью в одном сценарии, с помощью [multi-remote](/docs/multiremote).

## Основан на веб-стандартах

WebdriverIO автоматизирует браузеры через [WebDriver](https://w3c.github.io/webdriver/) и [WebDriver BiDi](https://w3c.github.io/webdriver-bidi/) — стандарты W3C, которые реализует и [тестирует](https://wpt.fyi/results/webdriver/tests) каждый производитель браузеров. Ваши тесты запускаются на тех же сборках браузеров, что и у ваших пользователей, а такие взаимодействия, как клики и нажатия клавиш, выполняются самим браузером, а не эмулируются с помощью JavaScript. WebDriver BiDi добавляет мокирование сети, события консоли и логов и многое другое во всех браузерах, а не только в Chromium.

Если вам нужны возможности конкретного браузера, WebdriverIO предоставляет доступ к Chrome DevTools Protocol через [Puppeteer](/docs/api/browser/getPuppeteer). Подробнее читайте в разделе [Automation Protocols](/docs/automationProtocols).

## Развивается сообществом и управляется открыто

WebdriverIO — не продукт компании-поставщика инструментов тестирования. Проект:

- принадлежит [OpenJS Foundation](https://openjsf.org/) — независимой некоммерческой организации, что юридически обязывает его служить интересам всех пользователей
- следует публичной [модели управления](https://github.com/webdriverio/webdriverio/blob/main/GOVERNANCE.md): любой может внести вклад, а коммиттеры и Технический руководящий комитет формируются из сообщества
- не имеет платных тарифов и ограничений функциональности; все функции бесплатны, и вы можете запускать тесты где угодно — локально или у любого облачного провайдера
- направляет спонсорские средства людям, которые его создают, через [программу стипендий для контрибьюторов](/blog/2024/02/15/new-contributor-stipend-program)
- предлагает бесплатную поддержку сообщества в [Discord](https://discord.webdriver.io) и [GitHub Discussions](https://github.com/webdriverio/webdriverio/discussions)

## Готов к работе с ИИ-агентами

Документация, инструменты и артефакты тестов спроектированы так, чтобы ИИ-агенты для программирования могли самостоятельно работать с WebdriverIO:

- **Документация, готовая для агентов**: каждая страница доступна в формате Markdown, есть тщательно подготовленный [`llms.txt`](https://webdriver.io/llms.txt) и MCP-сервер документации по адресу `https://webdriver.io/mcp`.
- **WebdriverIO MCP**: сервер [`@wdio/mcp`](/docs/mcp) позволяет агенту управлять браузерами и мобильными приложениями, чтобы исследовать ваш UI и проверять селекторы.
- **Трассировки**: [режим трассировки DevTools](/docs/devtools/wdio/trace-mode) создаёт расшифровку в формате Markdown, скриншоты и снимки дерева доступности для каждого упавшего теста.

Инструкции по настройке смотрите в разделе [WebdriverIO for Coding Agents](/docs/ai-agents).

## Когда стоит выбрать что-то другое

WebdriverIO хорошо подходит, если вы тестируете более одной платформы, хотите запускать тесты на реальных браузерах и устройствах или цените независимый инструмент, принадлежащий сообществу. Если вы тестируете только одно веб-приложение в одном браузере и вам не нужны мобильные, десктопные или облачные устройства, инструмент только для браузеров может показаться более лёгким для старта. Если вы не уверены, [создайте проект](/docs/gettingstarted) с помощью `npm init wdio@latest` и попробуйте: настройка занимает около минуты.
