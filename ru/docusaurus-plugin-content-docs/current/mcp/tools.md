MCP-сервер WebdriverIO предоставляет 29 инструментов, сгруппированных по назначению. Инструменты с пометкой **только для браузера** требуют сессии с `platform: "browser"`. Инструменты с пометкой **только для мобильных устройств** требуют `platform: "ios"` или `platform: "android"`.

## Управление сессиями

### `start_session`

Запускает новую сессию автоматизации браузера или мобильного устройства. Одновременно может быть активна только одна сессия; запуск новой сессии закрывает существующую.

| Параметр               | Тип                                                                    | Обязательный         | По умолчанию     | Описание                                                                                                                          |
| ---------------------- | ---------------------------------------------------------------------- | -------------------- | ---------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `platform`             | `"browser" \| "ios" \| "android"`                                      | ✓                    | —                | Платформа сессии                                                                                                                  |
| `provider`             | `"local" \| "browserstack" \| "saucelabs" \| "testmu" \| "testingbot"` | —                    | `"local"`        | Провайдер сессии                                                                                                                  |
| `browser`              | `"chrome" \| "firefox" \| "edge" \| "safari"`                          | только для браузера  | —                | Запускаемый браузер                                                                                                               |
| `browserVersion`       | string                                                                 | —                    | latest           | Версия браузера (только для облачных провайдеров, по умолчанию: latest)                                                           |
| `os`                   | string                                                                 | —                    | —                | Операционная система (только для облачных провайдеров, например `"Windows"`, `"OS X"`)                                            |
| `osVersion`            | string                                                                 | —                    | —                | Версия ОС (только для облачных провайдеров, например `"11"`, `"Sequoia"`)                                                         |
| `headless`             | boolean                                                                | —                    | `true`           | Запуск браузера в headless-режиме                                                                                                 |
| `windowWidth`          | number                                                                 | —                    | `1920`           | Ширина окна браузера (400–3840)                                                                                                   |
| `windowHeight`         | number                                                                 | —                    | `1080`           | Высота окна браузера (400–2160)                                                                                                   |
| `navigationUrl`        | string                                                                 | —                    | —                | URL для перехода после запуска                                                                                                    |
| `deviceName`           | string                                                                 | только для мобильных | —                | Имя устройства/эмулятора/симулятора                                                                                               |
| `platformVersion`      | string                                                                 | —                    | —                | Версия ОС (например `"17.0"`, `"14"`)                                                                                             |
| `appPath`              | string                                                                 | —                    | —                | Путь к `.app` / `.apk` / `.ipa`                                                                                                   |
| `app`                  | string                                                                 | —                    | —                | URL приложения (`bs://...` для BrowserStack, `storage:filename=` для Sauce Labs, `lt://...` для TestMu, app_url для TestingBot) или custom_id |
| `automationName`       | `"XCUITest" \| "UiAutomator2"`                                         | —                    | auto             | Драйвер автоматизации                                                                                                             |
| `autoGrantPermissions` | boolean                                                                | —                    | `true`           | Автоматически предоставлять разрешения приложению                                                                                 |
| `autoAcceptAlerts`     | boolean                                                                | —                    | `true`           | Автоматически принимать алерты                                                                                                    |
| `autoDismissAlerts`    | boolean                                                                | —                    | `false`          | Автоматически отклонять алерты                                                                                                    |
| `appWaitActivity`      | string                                                                 | —                    | —                | Android activity, ожидаемая при запуске                                                                                           |
| `udid`                 | string                                                                 | —                    | —                | UDID реального iOS-устройства                                                                                                     |
| `noReset`              | boolean                                                                | —                    | —                | Сохранять данные приложения между сессиями                                                                                        |
| `fullReset`            | boolean                                                                | —                    | —                | Удалять приложение до/после сессии                                                                                                |
| `newCommandTimeout`    | number                                                                 | —                    | `300`            | Тайм-аут команд Appium (в секундах)                                                                                               |
| `attach`               | boolean                                                                | —                    | `false`          | Подключиться к существующему Chrome через CDP                                                                                     |
| `attachConfig`         | object                                                                 | —                    | —                | Подключение CDP: `{ port: 9222, host: "localhost" }`                                                                              |
| `appiumConfig`         | object                                                                 | —                    | —                | Сервер Appium: `{ host, port, path }`                                                                                             |
| `tunnel`               | `boolean \| "external"`                                                | —                    | `false`          | Маршрутизация через локальный туннель (облачные провайдеры). `true` = автозапуск, `"external"` = туннель уже запущен извне        |
| `reporting`            | object                                                                 | —                    | —                | Метки отчётов облачного провайдера: `{ project, build, session }`                                                                 |
| `trace`                | boolean                                                                | —                    | `false`          | Включить запись трассировки — создаёт совместимый с Playwright zip-архив `.trace`                                                 |
| `region`               | `"us-west-1" \| "eu-central-1" \| "apac-southeast-1"`                  | —                    | `"eu-central-1"` | Регион дата-центра Sauce Labs                                                                                                     |
| `tunnelName`           | string                                                                 | —                    | —                | Имя-идентификатор туннеля (обязательно для `tunnel: "external"`)                                                                  |
| `capabilities`         | object                                                                 | —                    | —                | Дополнительные необработанные capabilities для объединения                                                                        |

```js
// Локальный браузер Chrome
start_session({ platform: "browser", browser: "chrome" })

// Симулятор iOS
start_session({ platform: "ios", deviceName: "iPhone 16", platformVersion: "18.0", appPath: "/path/to/app.app" })

// BrowserStack Android
start_session({ platform: "android", provider: "browserstack", deviceName: "Samsung Galaxy S24", app: "bs://abc123" })

// Sauce Labs iOS
start_session({ platform: "ios", provider: "saucelabs", deviceName: "iPhone 15", platformVersion: "17.0", app: "storage:filename=MyApp.ipa" })

// Браузер TestMu
start_session({ platform: "browser", provider: "testmu", browser: "chrome", os: "Windows", osVersion: "11" })

// Браузер TestingBot
start_session({ platform: "browser", provider: "testingbot", browser: "chrome", os: "Windows", osVersion: "11" })

// Облачный провайдер с туннелем
start_session({ platform: "browser", provider: "browserstack", browser: "chrome", tunnel: true })

// Подключение к существующему Chrome (после launch_chrome)
start_session({ platform: "browser", browser: "chrome", attach: true })
```

---

### `close_session`

Закрывает текущую сессию или отключается от неё.

| Параметр | Тип     | Обязательный | По умолчанию | Описание                                                                |
| -------- | ------- | ------------ | ------------ | ----------------------------------------------------------------------- |
| `detach` | boolean | —            | `false`      | Отключиться без завершения (сохраняет состояние приложения в Appium)    |

Сессии, запущенные с `noReset: true`, по умолчанию отключаются автоматически.

---

### `launch_chrome`

Подготавливает экземпляр Chrome с включённой удалённой отладкой, чтобы к нему мог подключиться `start_session({ attach: true })`. Два режима:

- `newInstance` (по умолчанию): открывает Chrome параллельно с уже запущенным, используя отдельный каталог профиля; ваша текущая сессия остаётся нетронутой.
- `freshSession`: запускает Chrome с пустым профилем (без cookie и без входа в аккаунты). Используйте `copyProfileFiles: true`, чтобы перенести cookie и данные входа.

| Параметр           | Тип                               | Обязательный | По умолчанию    | Описание                                                                     |
| ------------------ | --------------------------------- | ------------ | --------------- | ---------------------------------------------------------------------------- |
| `port`             | number                            | —            | `9222`          | Порт удалённой отладки                                                       |
| `mode`             | `"newInstance" \| "freshSession"` | —            | `"newInstance"` | Режим запуска                                                                |
| `copyProfileFiles` | boolean                           | —            | `false`         | Скопировать профиль Chrome Default (cookie, данные входа) в отладочную сессию |

После успешного выполнения этого инструмента вызовите `start_session({ platform: "browser", browser: "chrome", attach: true })`.

## Навигация и вкладки

### `navigate`

Загружает URL в текущей вкладке и ожидает события загрузки страницы. Сбрасывает состояние страницы (DOM, среду выполнения JS). **Только для браузера.**

| Параметр | Тип    | Обязательный | Описание             |
| -------- | ------ | ------------ | -------------------- |
| `url`    | string | ✓            | URL для перехода     |

---

### `get_tabs`

Выводит список всех вкладок браузера с дескриптором, заголовком, URL и указанием активной вкладки. Используйте перед `switch_tab`, чтобы найти нужный дескриптор. **Только для браузера.**

Без параметров.

---

### `switch_tab`

Переводит фокус на вкладку браузера по дескриптору окна или индексу (с отсчётом от 0). Все последующие вызовы инструментов работают с новой активной вкладкой. **Только для браузера.**

| Параметр | Тип    | Обязательный | Описание                                   |
| -------- | ------ | ------------ | ------------------------------------------ |
| `handle` | string | —            | Дескриптор окна для переключения           |
| `index`  | number | —            | Индекс вкладки с отсчётом от 0 (≥ 0)       |

Укажите либо `handle`, либо `index`. Дескрипторы можно получить из `get_tabs` или `wdio://session/current/tabs`.

---

### `switch_frame`

Переключает контекст фрейма WebDriver в iframe по CSS/XPath-селектору или обратно на верхний уровень, если селектор не указан. Изменения сохраняются: все последующие вызовы `click_element`, `set_value`, `get_elements` работают внутри выбранного фрейма, пока вы не переключитесь обратно. Ожидает iframe до 5 секунд. **Только для браузера.**

| Параметр   | Тип    | Обязательный | Описание                                                                                      |
| ---------- | ------ | ------------ | --------------------------------------------------------------------------------------------- |
| `selector` | string | —            | CSS/XPath-селектор элемента iframe. Не указывайте, чтобы вернуться к фрейму верхнего уровня. |

```js
// Переключиться в iframe
switch_frame({ selector: "#my-iframe" })

// Взаимодействовать с элементами внутри iframe
click_element({ selector: "button.submit" })

// Вернуться на верхний уровень
switch_frame()
```

## Взаимодействие с элементами

### `click_element`

Ожидает появления элемента, прокручивает его в область видимости и кликает по нему. Работает в браузере и на мобильных устройствах. На iOS лучше использовать `tap_element`: нативный слой иногда игнорирует `click_element`.

| Параметр       | Тип     | Обязательный | По умолчанию | Описание                                          |
| -------------- | ------- | ------------ | ------------ | ------------------------------------------------- |
| `selector`     | string  | ✓            | —            | CSS-, XPath- или текстовый селектор               |
| `scrollToView` | boolean | —            | `true`       | Прокрутить элемент в область видимости перед кликом |
| `timeout`      | number  | —            | —            | Максимальное время ожидания (мс)                  |

---

### `set_value`

Очищает поле input или textarea и вводит заданный текст. Всегда заменяет существующее содержимое.

| Параметр       | Тип     | Обязательный | По умолчанию | Описание                                           |
| -------------- | ------- | ------------ | ------------ | -------------------------------------------------- |
| `selector`     | string  | ✓            | —            | CSS-, XPath- или текстовый селектор                |
| `value`        | string  | ✓            | —            | Вводимый текст                                     |
| `scrollToView` | boolean | —            | `true`       | Прокрутить элемент в область видимости перед вводом |
| `timeout`      | number  | —            | —            | Максимальное время ожидания (мс)                   |

---

### `scroll`

Прокручивает страницу на заданное количество пикселей. **Только для браузера.** Для мобильных устройств используйте `swipe`.

| Параметр    | Тип              | Обязательный | По умолчанию | Описание                     |
| ----------- | ---------------- | ------------ | ------------ | ---------------------------- |
| `direction` | `"up" \| "down"` | ✓            | —            | Направление прокрутки        |
| `pixels`    | number           | —            | `500`        | Количество пикселей прокрутки |

## Анализ элементов

### `get_elements`

Возвращает интерактивные элементы текущей страницы с готовыми к использованию селекторами. Для общего понимания контекста предпочтительнее ресурс `wdio://session/current/elements`; используйте этот инструмент, когда нужна фильтрация или пагинация.

| Параметр            | Тип     | Обязательный | По умолчанию | Описание                                              |
| ------------------- | ------- | ------------ | ------------ | ----------------------------------------------------- |
| `inViewportOnly`    | boolean | —            | `false`      | Возвращать только элементы, видимые в области просмотра |
| `includeContainers` | boolean | —            | `false`      | Включать элементы-контейнеры (div, section)           |
| `includeBounds`     | boolean | —            | `false`      | Включать координаты ограничивающей рамки              |
| `limit`             | number  | —            | `0`          | Максимальное число элементов (0 = без ограничений)    |
| `offset`            | number  | —            | `0`          | Количество пропускаемых элементов (пагинация)         |

---

### `get_accessibility_tree`

Возвращает дерево доступности страницы с ролями, именами и селекторами. Поддерживает фильтрацию и пагинацию. **Только для браузера.**

| Параметр | Тип      | Обязательный | По умолчанию | Описание                                                          |
| -------- | -------- | ------------ | ------------ | ----------------------------------------------------------------- |
| `limit`  | number   | —            | `0`          | Максимальное число узлов (0 = без ограничений)                    |
| `offset` | number   | —            | `0`          | Количество пропускаемых узлов (пагинация)                         |
| `roles`  | string[] | —            | —            | Фильтр по ролям ARIA, например `["button", "link", "heading"]`    |

## Скриншоты

### `get_screenshot`

Делает скриншот текущей страницы или экрана. Возвращает изображение в кодировке base64, автоматически уменьшенное и сжатое, чтобы уложиться в ограничения контекста модели (максимум 1 МБ, максимум 2000 пикселей).

Без параметров. Для поиска элементов предпочтительнее использовать `wdio://session/current/elements`, а не скриншоты: это быстрее и расходует гораздо меньше токенов. Используйте скриншоты для визуальной проверки или отладки вёрстки.

## Управление cookie

### `get_cookies`

Возвращает все cookie текущей сессии или один cookie по имени. **Только для браузера.**

| Параметр | Тип    | Обязательный | Описание                                         |
| -------- | ------ | ------------ | ------------------------------------------------ |
| `name`   | string | —            | Имя cookie. Не указывайте, чтобы получить все cookie. |

---

### `set_cookie`

Устанавливает cookie в браузере. Браузер уже должен находиться на целевом домене — cookie нельзя установить для другого домена. Используйте для внедрения токенов сессии или флагов функций без прохождения процесса входа. **Только для браузера.**

| Параметр   | Тип                           | Обязательный | Описание                                          |
| ---------- | ----------------------------- | ------------ | ------------------------------------------------- |
| `name`     | string                        | ✓            | Имя cookie                                        |
| `value`    | string                        | ✓            | Значение cookie                                   |
| `domain`   | string                        | —            | Домен cookie (по умолчанию — текущий домен)       |
| `path`     | string                        | —            | Путь cookie (по умолчанию `/`)                    |
| `expiry`   | number                        | —            | Срок действия в виде Unix-времени (в секундах)    |
| `httpOnly` | boolean                       | —            | Флаг HttpOnly                                     |
| `secure`   | boolean                       | —            | Флаг Secure                                       |
| `sameSite` | `"strict" \| "lax" \| "none"` | —            | Атрибут SameSite                                  |

---

### `delete_cookies`

Удаляет все cookie или конкретный cookie по имени. **Только для браузера.**

| Параметр | Тип    | Обязательный | Описание                                                      |
| -------- | ------ | ------------ | ------------------------------------------------------------- |
| `name`   | string | —            | Имя удаляемого cookie. Не указывайте, чтобы удалить все cookie. |

## Сенсорные жесты (мобильные устройства)

### `tap_element`

Вызывает `element.tap()` для найденного элемента или выполняет касание по абсолютным координатам экрана. Используйте на iOS, когда `click_element` игнорируется: касание — это нативный жест, на который реагирует iOS. **Только для мобильных устройств.**

| Параметр   | Тип    | Обязательный | Описание                                             |
| ---------- | ------ | ------------ | ---------------------------------------------------- |
| `selector` | string | —            | Селектор элемента                                    |
| `x`        | number | —            | Координата X для касания экрана (если нет селектора) |
| `y`        | number | —            | Координата Y для касания экрана (если нет селектора) |

Укажите либо `selector`, либо координаты `x`/`y`.

---

### `swipe`

Выполняет жест свайпа по всему экрану. Направление соответствует направлению движения содержимого (например, `"up"` прокручивает список вверх). Используйте для прокрутки за пределы видимой области. Для перемещения конкретного элемента используйте `drag_and_drop`. **Только для мобильных устройств.** Для браузеров используйте `scroll`.

| Параметр    | Тип                                   | Обязательный | По умолчанию   | Описание                                |
| ----------- | ------------------------------------- | ------------ | -------------- | --------------------------------------- |
| `direction` | `"up" \| "down" \| "left" \| "right"` | ✓            | —              | Направление свайпа                      |
| `duration`  | number                                | —            | `500`          | Длительность свайпа (мс, 100–5000)      |
| `percent`   | number                                | —            | `0.5` / `0.95` | Доля экрана для свайпа (0–1)            |

---

### `drag_and_drop`

Перетаскивает элемент на другой элемент или по координатам. **Только для мобильных устройств.**

| Параметр         | Тип    | Обязательный | По умолчанию | Описание                                       |
| ---------------- | ------ | ------------ | ------------ | ---------------------------------------------- |
| `sourceSelector` | string | ✓            | —            | Перетаскиваемый исходный элемент               |
| `targetSelector` | string | —            | —            | Целевой элемент, на который нужно сбросить     |
| `x`              | number | —            | —            | Целевое смещение по X (если нет targetSelector) |
| `y`              | number | —            | —            | Целевое смещение по Y (если нет targetSelector) |
| `duration`       | number | —            | —            | Длительность перетаскивания (мс, 100–5000)     |

## Переключение контекста (мобильные устройства)

### `get_contexts`

Возвращает доступные контексты автоматизации и текущий активный контекст. Используйте перед `switch_context`, чтобы найти цели `NATIVE_APP` и `WEBVIEW_*`. **Только для мобильных устройств.**

Без параметров.

---

### `switch_context`

Переключает между нативным контекстом и контекстом webview в гибридном мобильном приложении. Необходимо перед использованием CSS/XPath-селекторов внутри встроенного webview. **Только для мобильных устройств.**

| Параметр  | Тип    | Обязательный | Описание                                                            |
| --------- | ------ | ------------ | ------------------------------------------------------------------- |
| `context` | string | ✓            | Имя контекста, например `"NATIVE_APP"`, `"WEBVIEW_com.example.app"` |

Имена доступных контекстов можно получить из `get_contexts` или `wdio://session/current/contexts`.

```js
// 1. Проверить, что доступно
get_contexts()
// → { contexts: ["NATIVE_APP", "WEBVIEW_com.example.app"], currentContext: "NATIVE_APP" }

// 2. Переключиться в webview для CSS/XPath
switch_context({ context: "WEBVIEW_com.example.app" })

// 3. Взаимодействовать с элементами webview с помощью CSS-селекторов
click_element({ selector: "#login-button" })

// 4. Вернуться в нативный контекст для нативного UI
switch_context({ context: "NATIVE_APP" })
```

## Управление устройством (мобильные устройства)

### `rotate_device`

Поворачивает устройство в портретную или альбомную ориентацию и ожидает завершения поворота в ОС. Используйте для тестирования макетов, зависящих от ориентации. **Только для мобильных устройств.**

| Параметр      | Тип                         | Обязательный | Описание           |
| ------------- | --------------------------- | ------------ | ------------------ |
| `orientation` | `"PORTRAIT" \| "LANDSCAPE"` | ✓            | Целевая ориентация |

---

### `hide_keyboard`

Скрывает экранную клавиатуру. Вызывайте после ввода текста, когда клавиатура перекрывает нужные далее элементы. Ничего не делает, если клавиатура уже скрыта. **Только для мобильных устройств.**

Без параметров.

---

### `set_geolocation`

Переопределяет GPS-координаты устройства для сессии. Влияет на `navigator.geolocation` в вебе и на службы геолокации на мобильных устройствах. Приложению заранее должны быть предоставлены разрешения на доступ к геолокации.

| Параметр    | Тип    | Обязательный | Описание                  |
| ----------- | ------ | ------------ | ------------------------- |
| `latitude`  | number | ✓            | Широта (от −90 до 90)     |
| `longitude` | number | ✓            | Долгота (от −180 до 180)  |
| `altitude`  | number | —            | Высота в метрах           |

## Жизненный цикл приложения (мобильные устройства)

### `get_app_state`

Возвращает текущее состояние жизненного цикла мобильного приложения. **Только для мобильных устройств.**

| Параметр   | Тип    | Обязательный | Описание                                                                   |
| ---------- | ------ | ------------ | -------------------------------------------------------------------------- |
| `bundleId` | string | ✓            | Bundle ID для iOS или имя пакета Android, например `"com.example.app"`     |

Возвращает одно из значений: `not installed`, `not running`, `background (suspended)`, `background`, `foreground`.

## Утилиты браузера

### `emulate_device`

Эмулирует мобильное устройство или планшет в текущей сессии браузера (задаёт область просмотра, DPR, user-agent, сенсорные события). Требуется сессия с поддержкой BiDi: `start_session({ capabilities: { webSocketUrl: true } })`. **Только для браузера.**

| Параметр | Тип    | Обязательный | Описание                                                                                                                                                  |
| -------- | ------ | ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `device` | string | —            | Имя пресета устройства (например `"iPhone 15"`, `"Pixel 7"`). Не указывайте, чтобы получить список пресетов. Передайте `"reset"` для восстановления настроек десктопа по умолчанию. |

---

### `execute_script`

Выполняет JavaScript в браузере или мобильные команды через Appium.

| Параметр | Тип    | Обязательный | Описание                                                            |
| -------- | ------ | ------------ | ------------------------------------------------------------------- |
| `script` | string | ✓            | JS-код (браузер) или команда Appium, например `"mobile: pressKey"`  |
| `args`   | any[]  | —            | Аргументы, передаваемые скрипту или команде                         |

**Браузер:** используйте `return`, чтобы получить значения.

```javascript
// Получить заголовок страницы
execute_script({ script: "return document.title" })

// Прокрутить элемент в область видимости
execute_script({ script: "arguments[0].scrollIntoView()", args: ["#my-element"] })
```

**Мобильные устройства (Appium):** используется синтаксис `mobile: <command>`.

```javascript
// Нажать клавишу «Назад» на Android
execute_script({ script: "mobile: pressKey", args: [{ keycode: 4 }] })

// Активировать приложение (iOS/Android)
execute_script({ script: "mobile: activateApp", args: [{ bundleId: "com.example.app" }] })

// Глубокая ссылка (iOS)
execute_script({ script: "mobile: deepLink", args: [{ url: "myapp://route", bundleId: "com.example.app" }] })
```

## Облачные провайдеры

### `list_apps`

Выводит список приложений, загруженных к облачному провайдеру (BrowserStack App Automate, Sauce Labs App Storage, TestMu или TestingBot Storage). Считывает учётные данные конкретного провайдера из переменных окружения.

| Параметр           | Тип                                                         | Обязательный | По умолчанию     | Описание                                                   |
| ------------------ | ----------------------------------------------------------- | ------------ | ---------------- | ---------------------------------------------------------- |
| `provider`         | `"browserstack" \| "saucelabs" \| "testmu" \| "testingbot"` | ✓            | —                | Облачный провайдер                                         |
| `sortBy`           | `"app_name" \| "uploaded_at"`                               | —            | `"uploaded_at"`  | Порядок сортировки                                         |
| `organizationWide` | boolean                                                     | —            | `false`          | (Только BrowserStack) Показать все загрузки организации    |
| `limit`            | number                                                      | —            | `20`             | Максимальное число результатов                             |
| `region`           | `"us-west-1" \| "eu-central-1" \| "apac-southeast-1"`       | —            | `"eu-central-1"` | Регион Sauce Labs                                          |

```js
// Список для всех четырёх провайдеров
list_apps({ provider: "browserstack" })
list_apps({ provider: "saucelabs", region: "us-west-1" })
list_apps({ provider: "testmu" })
list_apps({ provider: "testingbot" })
```

---

### `upload_app`

Загружает локальный файл `.apk` или `.ipa` к облачному провайдеру (BrowserStack, Sauce Labs, TestMu или TestingBot). Возвращает URL приложения для использования в `start_session`.

| Параметр   | Тип                                                         | Обязательный | По умолчанию     | Описание                                                          |
| ---------- | ----------------------------------------------------------- | ------------ | ---------------- | ----------------------------------------------------------------- |
| `provider` | `"browserstack" \| "saucelabs" \| "testmu" \| "testingbot"` | ✓            | —                | Облачный провайдер                                                |
| `path`     | string                                                      | ✓            | —                | Абсолютный путь к файлу `.apk` или `.ipa`                         |
| `customId` | string                                                      | —            | —                | Необязательный пользовательский ID для последующего обращения к приложению |
| `region`   | `"us-west-1" \| "eu-central-1" \| "apac-southeast-1"`       | —            | `"eu-central-1"` | Регион Sauce Labs                                                 |

```js
// Загрузка к каждому провайдеру
upload_app({ provider: "browserstack", path: "/path/to/app.apk" })
upload_app({ provider: "saucelabs", path: "/path/to/app.ipa", region: "us-west-1" })
upload_app({ provider: "testmu", path: "/path/to/app.apk" })
upload_app({ provider: "testingbot", path: "/path/to/app.apk" })
```
