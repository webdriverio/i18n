Το DevTools είναι μια ισχυρή διεπαφή αποσφαλμάτωσης βασισμένη σε πρόγραμμα περιήγησης για την οπτικοποίηση, τον έλεγχο και την επιθεώρηση των εκτελέσεων των δοκιμών σας σε πραγματικό χρόνο. Λειτουργεί με **WebdriverIO**, **Nightwatch.js** και **Selenium WebDriver** (οποιοδήποτε runner) — ίδιο backend, ίδιο UI, ίδια υποδομή καταγραφής.

## Τι Παρέχει

- **Επανεκτέλεση δοκιμών επιλεκτικά** - Κάντε κλικ σε οποιαδήποτε περίπτωση δοκιμής ή suite για να την επανεκτελέσετε άμεσα ([λεπτομέρειες](/docs/devtools/wdio/interactive-test-rerunning))
- **Διατήρηση & Επανεκτέλεση (Σύγκριση)** - Αποθηκεύστε ένα στιγμιότυπο μιας αποτυχημένης δοκιμής, επανεκτελέστε την και συγκρίνετε τις δύο εκτελέσεις δίπλα-δίπλα, ευθυγραμμισμένες ανά εντολή ([λεπτομέρειες](/docs/devtools/wdio/preserve-and-rerun))
- **Οπτική αποσφαλμάτωση** - Δείτε ζωντανές προεπισκοπήσεις του προγράμματος περιήγησης με αυτόματα στιγμιότυπα οθόνης μετά από κάθε εντολή
- **Παρακολούθηση εκτέλεσης** - Δείτε λεπτομερή αρχεία καταγραφής εντολών με χρονοσημάνσεις και αποτελέσματα
- **Παρακολούθηση δικτύου & κονσόλας** - Επιθεωρήστε κλήσεις API και αρχεία καταγραφής JavaScript ([δίκτυο](/docs/devtools/wdio/network-logs) · [κονσόλα](/docs/devtools/wdio/console-logs))
- **Πλοήγηση στον κώδικα** - Μεταβείτε απευθείας στα αρχεία πηγαίου κώδικα των δοκιμών με το TestLens ([λεπτομέρειες](/docs/devtools/wdio/testlens))
- **Εγγραφή συνεδριών** - Συνεχές βίντεο `.webm` του προγράμματος περιήγησης, ανά συνεδρία ([λεπτομέρειες](/docs/devtools/wdio/screencast))
- **Λειτουργία Trace** - Headless διαδρομή καταγραφής που παράγει ένα φορητό αρχείο `trace.zip` για αναπαραγωγή εκτός σύνδεσης ή χρήση από agents ([λεπτομέρειες](/docs/devtools/wdio/trace-mode))

## Πώς Λειτουργεί

1. Ξεκινήστε τις δοκιμές σας κανονικά
2. Το DevTools ανοίγει αυτόματα ένα παράθυρο προγράμματος περιήγησης στη διεύθυνση `http://localhost:3000`
3. Το UI εμφανίζει την ιεραρχία των δοκιμών, την προεπισκόπηση του προγράμματος περιήγησης, το χρονολόγιο εντολών και τα αρχεία καταγραφής σε πραγματικό χρόνο
4. Μετά την ολοκλήρωση των δοκιμών, κάντε κλικ σε οποιαδήποτε δοκιμή για να την επανεκτελέσετε μεμονωμένα στην ίδια συνεδρία του προγράμματος περιήγησης

## Επιλέξτε το Framework σας

- **[WebDriverIO](/docs/devtools/wdio)** - Χρησιμοποιήστε το `@wdio/devtools-service` με Mocha, Jasmine ή Cucumber
- **[Nightwatch](/docs/devtools/nightwatch)** - Χρησιμοποιήστε το `@wdio/nightwatch-devtools` χωρίς καμία αλλαγή στον κώδικα των δοκιμών
- **[Selenium](/docs/devtools/selenium)** - Χρησιμοποιήστε το `@wdio/selenium-devtools` με Mocha, Jest, Cucumber ή απλά scripts Node
