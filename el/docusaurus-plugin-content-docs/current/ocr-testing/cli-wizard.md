Μπορείτε να επαληθεύσετε ποιο κείμενο μπορεί να βρεθεί σε μια εικόνα χωρίς να εκτελέσετε κάποιο test, χρησιμοποιώντας τον OCR CLI Wizard. Το μόνο που χρειάζεται είναι:

-   να έχετε εγκαταστήσει το `@wdio/ocr-service` ως εξάρτηση, δείτε το [Ξεκινώντας](./getting-started)
-   μια εικόνα που θέλετε να επεξεργαστείτε

Στη συνέχεια, εκτελέστε την ακόλουθη εντολή για να ξεκινήσετε τον οδηγό

```sh
npx ocr-service
```

Αυτό θα ξεκινήσει έναν οδηγό που θα σας καθοδηγήσει στα βήματα για να επιλέξετε μια εικόνα και να χρησιμοποιήσετε ένα haystack καθώς και τη λειτουργία για προχωρημένους. Υποβάλλονται οι ακόλουθες ερωτήσεις

## Πώς θα θέλατε να καθορίσετε το αρχείο;

Μπορούν να επιλεγούν οι ακόλουθες επιλογές

-   Χρήση ενός "εξερευνητή αρχείων"
-   Μη αυτόματη πληκτρολόγηση της διαδρομής του αρχείου

### Χρήση ενός "εξερευνητή αρχείων"

Ο οδηγός CLI παρέχει την επιλογή χρήσης ενός "εξερευνητή αρχείων" για την αναζήτηση αρχείων στο σύστημά σας. Ξεκινά από τον φάκελο από τον οποίο καλείτε την εντολή. Αφού επιλέξετε μια εικόνα (χρησιμοποιήστε τα πλήκτρα βέλους και το πλήκτρο ENTER), θα προχωρήσετε στην επόμενη ερώτηση

### Μη αυτόματη πληκτρολόγηση της διαδρομής του αρχείου

Πρόκειται για μια άμεση διαδρομή προς ένα αρχείο κάπου στον τοπικό σας υπολογιστή

## Θέλετε να χρησιμοποιήσετε τη λειτουργία για προχωρημένους;

Η λειτουργία για προχωρημένους θα περιλαμβάνει επιπλέον δυνατότητες, όπως:
