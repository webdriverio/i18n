Ο αυτοματοποιημένος έλεγχος σε εγγενείς (native) εφαρμογές κινητών και σε ιστότοπους για υπολογιστές μπορεί να είναι ιδιαίτερα απαιτητικός όταν πρόκειται για στοιχεία που δεν διαθέτουν μοναδικά αναγνωριστικά. Οι τυπικοί [επιλογείς του WebdriverIO](https://webdriver.io/docs/selectors) δεν μπορούν πάντα να σας βοηθήσουν. Καλώς ήρθατε στον κόσμο του `@wdio/ocr-service`, μιας ισχυρής υπηρεσίας που αξιοποιεί το OCR ([Οπτική Αναγνώριση Χαρακτήρων](https://en.wikipedia.org/wiki/Optical_character_recognition)) για να αναζητά, να περιμένει και να αλληλεπιδρά με στοιχεία της οθόνης βάσει του **ορατού κειμένου** τους.

Οι παρακάτω προσαρμοσμένες εντολές θα παρέχονται και θα προστίθενται στο αντικείμενο `browser/driver`, ώστε να έχετε τα κατάλληλα εργαλεία για να κάνετε τη δουλειά σας.

-   [`await browser.ocrGetText`](./ocr-get-text.md)
-   [`await browser.ocrGetElementPositionByText`](./ocr-get-element-position-by-text.md)
-   [`await browser.ocrWaitForTextDisplayed`](./ocr-wait-for-text-displayed.md)
-   [`await browser.ocrClickOnText`](./ocr-click-on-text.md)
-   [`await browser.ocrSetValue`](./ocr-set-value.md)

### Πώς λειτουργεί

Αυτή η υπηρεσία θα

1. δημιουργήσει ένα στιγμιότυπο της οθόνης/συσκευής σας. (Εάν χρειάζεται, μπορείτε να παρέχετε ένα haystack, το οποίο μπορεί να είναι ένα στοιχείο ή ένα αντικείμενο ορθογωνίου, για να εστιάσετε σε μια συγκεκριμένη περιοχή. Δείτε την τεκμηρίωση κάθε εντολής.)
1. βελτιστοποιήσει το αποτέλεσμα για OCR μετατρέποντας το στιγμιότυπο σε ασπρόμαυρο με υψηλή αντίθεση (η υψηλή αντίθεση χρειάζεται για να αποφευχθεί ο πολύς θόρυβος στο φόντο της εικόνας. Αυτό μπορεί να προσαρμοστεί ανά εντολή.)
1. χρησιμοποιεί [Οπτική Αναγνώριση Χαρακτήρων](https://en.wikipedia.org/wiki/Optical_character_recognition) από το [Tesseract.js](https://github.com/naptha/tesseract.js)/[Tesseract](https://github.com/tesseract-ocr/tesseract) για να λάβει όλο το κείμενο από την οθόνη και να επισημάνει όλο το κείμενο που βρέθηκε σε μια εικόνα. Υποστηρίζει διάφορες γλώσσες, τις οποίες μπορείτε να βρείτε [εδώ.](https://tesseract-ocr.github.io/tessdoc/Data-Files-in-different-versions.html)
1. χρησιμοποιεί Ασαφή Λογική (Fuzzy Logic) από το [Fuse.js](https://fusejs.io/) για να βρει συμβολοσειρές που είναι _κατά προσέγγιση ίσες_ με ένα δεδομένο μοτίβο (αντί για ακριβώς ίσες). Αυτό σημαίνει, για παράδειγμα, ότι η τιμή αναζήτησης `Username` μπορεί επίσης να βρει το κείμενο `Usename` ή αντίστροφα.
1. Παρέχει έναν οδηγό cli (`npx ocr-service`) για να επικυρώνετε τις εικόνες σας και να ανακτάτε κείμενο μέσω του τερματικού σας

Ένα παράδειγμα των βημάτων 1, 2 και 3 μπορείτε να δείτε σε αυτή την εικόνα

![Process steps](/img/ocr/processing-steps.jpg)

Λειτουργεί με **ΜΗΔΕΝΙΚΕΣ** εξαρτήσεις συστήματος (πέρα από όσες χρησιμοποιεί το WebdriverIO), αλλά εάν χρειάζεται μπορεί επίσης να λειτουργήσει με μια τοπική εγκατάσταση του [Tesseract](https://tesseract-ocr.github.io/tessdoc/), η οποία θα μειώσει δραστικά τον χρόνο εκτέλεσης! (Δείτε επίσης τη [Βελτιστοποίηση Εκτέλεσης Ελέγχων](#test-execution-optimization) για το πώς να επιταχύνετε τους ελέγχους σας.)

Ενθουσιαστήκατε; Ξεκινήστε να το χρησιμοποιείτε σήμερα ακολουθώντας τον οδηγό [Ξεκινώντας](./getting-started).

:::caution Σημαντικό
Υπάρχουν διάφοροι λόγοι για τους οποίους μπορεί να μην λαμβάνετε αποτελέσματα καλής ποιότητας από το Tesseract. Ένας από τους σημαντικότερους λόγους που θα μπορούσε να σχετίζεται με την εφαρμογή σας και αυτή τη μονάδα είναι το γεγονός ότι δεν υπάρχει σωστή χρωματική διάκριση μεταξύ του κειμένου που πρέπει να βρεθεί και του φόντου. Για παράδειγμα, λευκό κείμενο σε σκούρο φόντο μπορεί να βρεθεί _εύκολα_, αλλά ανοιχτόχρωμο κείμενο σε λευκό φόντο ή σκούρο κείμενο σε σκούρο φόντο δύσκολα μπορεί να βρεθεί.

Δείτε επίσης [αυτή τη σελίδα](https://tesseract-ocr.github.io/tessdoc/ImproveQuality) για περισσότερες πληροφορίες από το Tesseract.

Επίσης, μην ξεχάσετε να διαβάσετε τις [Συχνές Ερωτήσεις](./ocr-faq).
:::
