---

Με το WebdriverIO μπορείτε να δοκιμάσετε όχι μόνο εφαρμογές web στον browser αλλά και άλλες πλατφόρμες, όπως:

- 📱 εφαρμογές κινητών σε iOS, Android ή Tizen
- 🖥️ εφαρμογές επιφάνειας εργασίας σε macOS ή Windows
- 📺 καθώς και εφαρμογές TV για Roku, tvOS, Android TV και Samsung

Προτείνουμε να χρησιμοποιήσετε το [Appium](https://appium.io/) για να διευκολύνετε αυτούς τους τύπους δοκιμών. Μπορείτε να βρείτε μια επισκόπηση του Appium στην [επίσημη σελίδα τεκμηρίωσής του](https://appium.io/docs/en/latest/intro/).

Η ρύθμιση του κατάλληλου περιβάλλοντος δεν είναι απλή υπόθεση. Ευτυχώς, το οικοσύστημα του Appium διαθέτει εξαιρετικά εργαλεία που σας βοηθούν σε αυτό. Για να ρυθμίσετε ένα από τα παραπάνω περιβάλλοντα, απλώς εκτελέστε:

```sh
$ npx appium-installer
```

Αυτό θα εκκινήσει το εργαλείο [appium-installer](https://github.com/AppiumTestDistribution/appium-installer), το οποίο σας καθοδηγεί στη διαδικασία ρύθμισης.
