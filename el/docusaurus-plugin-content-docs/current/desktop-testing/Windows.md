---

Δυστυχώς, προς το παρόν δεν υπάρχει σταθερός driver για την αυτοματοποίηση εφαρμογών Windows. Παρόλο που το Appium συντηρεί έναν [Windows Driver](https://github.com/appium/appium-windows-driver) που βασίζεται στον [WinAppDriver server](https://github.com/microsoft/WinAppDriver) της Microsoft, δεν θα συνιστούσαμε τη χρήση του, δεδομένου ότι η Microsoft έχει σταματήσει τη συντήρηση του server και υπάρχουν πολλά [γνωστά σφάλματα](https://github.com/search?q=repo%3Amicrosoft%2FWinAppDriver+webdriverio&type=issues).

Αν κάποιος γνωρίζει έναν τρόπο αυτοματοποίησης εφαρμογών Windows, παρακαλούμε ενημερώστε μας στο [Discord](https://discord.webdriver.io).
