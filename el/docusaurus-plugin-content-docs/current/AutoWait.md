Όταν χρησιμοποιείτε μια εντολή που αλληλεπιδρά απευθείας με ένα στοιχείο, το WebdriverIO θα περιμένει αυτόματα το στοιχείο να γίνει ορατό και διαδραστικό, επομένως δεν χρειάζονται χειροκίνητες αναμονές όταν χρησιμοποιείτε τις εντολές (για παράδειγμα click, setValue κ.λπ.).
Ένα στοιχείο θεωρείται διαδραστικό όταν πληρούνται οι προϋποθέσεις του [isClickable](https://webdriver.io/docs/api/element/isClickable).

Παρόλο που το WebdriverIO περιμένει αυτόματα τα στοιχεία να γίνουν διαδραστικά, υπάρχουν σπάνιες περιπτώσεις στις οποίες μπορεί να χρειαστεί να περιμένετε χειροκίνητα. Για αυτές τις σπάνιες περιπτώσεις προσφέρουμε εντολές όπως η [`waitForDisplayed`](/docs/api/element/waitForDisplayed).


## Implicit timeouts (δεν συνιστάται)

Παρόλο που δεν συνιστούμε τη χρήση τους, το πρωτόκολλο WebDriver προσφέρει [implicit timeouts](https://w3c.github.io/webdriver/#timeouts) που επιτρέπουν να καθορίσετε πόσο χρόνο πρέπει να περιμένει ο driver μέχρι να εμφανιστεί ένα στοιχείο. Από προεπιλογή, αυτό το timeout έχει οριστεί σε `0` και επομένως ο driver επιστρέφει αμέσως ένα σφάλμα `no such element` εάν ένα στοιχείο δεν βρεθεί στη σελίδα. Η αύξηση αυτού του timeout με τη χρήση της [`setTimeout`](/docs/api/browser/setTimeout) θα έκανε τον driver να περιμένει και θα αύξανε τις πιθανότητες να εμφανιστεί τελικά το στοιχείο.

:::note

Διαβάστε περισσότερα για τα timeouts που σχετίζονται με το WebDriver και το framework στον [οδηγό για τα timeouts](/docs/timeouts)

:::
