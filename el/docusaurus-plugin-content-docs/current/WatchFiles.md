description: "Επανεκτελέστε αυτόματα τις δοκιμές όταν αλλάζουν τα αρχεία spec ή τα αρχεία της εφαρμογής, εκτελώντας το WDIO testrunner με τη σημαία --watch και την ιδιότητα filesToWatch."
---

Με το WDIO testrunner μπορείτε να παρακολουθείτε αρχεία ενώ εργάζεστε σε αυτά. Οι δοκιμές επανεκτελούνται αυτόματα αν αλλάξετε κάτι είτε στην εφαρμογή σας είτε στα αρχεία δοκιμών σας. Προσθέτοντας τη σημαία `--watch` κατά την κλήση της εντολής `wdio`, το testrunner θα περιμένει για αλλαγές αρχείων αφού εκτελέσει όλες τις δοκιμές, π.χ.

```sh
wdio wdio.conf.js --watch
```

Από προεπιλογή παρακολουθεί μόνο για αλλαγές στα αρχεία `specs`. Ωστόσο, ορίζοντας μια ιδιότητα `filesToWatch` στο `wdio.conf.js` σας, η οποία περιέχει μια λίστα με διαδρομές αρχείων (υποστηρίζεται globbing), θα παρακολουθεί επίσης αυτά τα αρχεία για αλλαγές, ώστε να επανεκτελέσει ολόκληρη τη σουίτα. Αυτό είναι χρήσιμο αν θέλετε να επανεκτελούνται αυτόματα όλες οι δοκιμές σας όταν έχετε αλλάξει τον κώδικα της εφαρμογής σας, π.χ.

```js
// wdio.conf.js
export const config = {
    // ...
    filesToWatch: [
        // παρακολούθηση όλων των αρχείων JS στην εφαρμογή μου
        './src/app/**/*.js'
    ],
    // ...
}
```

:::info
Προσπαθήστε να εκτελείτε τις δοκιμές παράλληλα όσο το δυνατόν περισσότερο. Οι δοκιμές E2E είναι, από τη φύση τους, αργές. Η επανεκτέλεση των δοκιμών είναι χρήσιμη μόνο αν μπορείτε να διατηρείτε σύντομο τον χρόνο εκτέλεσης κάθε μεμονωμένης δοκιμής. Για εξοικονόμηση χρόνου, το testrunner διατηρεί ενεργές τις συνεδρίες WebDriver ενώ περιμένει για αλλαγές αρχείων. Βεβαιωθείτε ότι το backend του WebDriver σας μπορεί να τροποποιηθεί ώστε να μην κλείνει αυτόματα τη συνεδρία αν δεν έχει εκτελεστεί καμία εντολή μετά από κάποιο χρονικό διάστημα.
:::
