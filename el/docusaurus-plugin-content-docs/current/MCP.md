## Τι μπορεί να κάνει;

Το WebdriverIO MCP είναι ένας **διακομιστής Model Context Protocol (MCP)** που επιτρέπει στους βοηθούς AI να αυτοματοποιούν και να αλληλεπιδρούν με προγράμματα περιήγησης ιστού και εφαρμογές κινητών.

### Γιατί WebdriverIO MCP;

-   **Mobile-First**: Σε αντίθεση με τους διακομιστές MCP που υποστηρίζουν μόνο προγράμματα περιήγησης, το WebdriverIO MCP υποστηρίζει αυτοματοποίηση εγγενών εφαρμογών iOS και Android μέσω του Appium
-   **Επιλογείς Πολλαπλών Πλατφορμών**: Η έξυπνη ανίχνευση στοιχείων δημιουργεί αυτόματα πολλαπλές στρατηγικές εντοπισμού (accessibility ID, XPath, UiAutomator, iOS predicates)
-   **Οικοσύστημα WebdriverIO**: Βασίζεται στο δοκιμασμένο framework WebdriverIO με το πλούσιο οικοσύστημα υπηρεσιών και reporters

Παρέχει μια ενιαία διεπαφή για:

-   🖥️ **Προγράμματα Περιήγησης Desktop** (Chrome, Firefox, Edge, Safari, με ή χωρίς γραφική διεπαφή)
-   📱 **Εγγενείς Εφαρμογές Κινητών** (Προσομοιωτές iOS / Εξομοιωτές Android / Πραγματικές Συσκευές μέσω Appium)
-   📳 **Υβριδικές Εφαρμογές Κινητών** (Εναλλαγή περιβάλλοντος Native + WebView μέσω Appium)
-   ☁️ **Συσκευές Cloud** (BrowserStack, Sauce Labs, TestMu clouds πραγματικών συσκευών και προγραμμάτων περιήγησης)

μέσω του πακέτου [`@wdio/mcp`](https://www.npmjs.com/package/@wdio/mcp).

Αυτό επιτρέπει στους βοηθούς AI να:

-   **Εκκινούν και ελέγχουν προγράμματα περιήγησης** με διαμορφώσιμες διαστάσεις, λειτουργία headless και προαιρετική αρχική πλοήγηση
-   **Πλοηγούνται σε ιστοτόπους** και αλληλεπιδρούν με στοιχεία (κλικ, πληκτρολόγηση, κύλιση)
-   **Αναλύουν το περιεχόμενο της σελίδας** μέσω του δέντρου προσβασιμότητας και της ανίχνευσης ορατών στοιχείων με υποστήριξη σελιδοποίησης
-   **Λαμβάνουν στιγμιότυπα οθόνης** αυτόματα βελτιστοποιημένα (με αλλαγή μεγέθους, συμπιεσμένα έως 1MB το μέγιστο)
-   **Διαχειρίζονται cookies** για τον χειρισμό συνεδριών
-   **Ελέγχουν κινητές συσκευές** συμπεριλαμβανομένων χειρονομιών (πάτημα, σάρωση, μεταφορά και απόθεση)
-   **Εναλλάσσουν περιβάλλοντα** σε υβριδικές εφαρμογές μεταξύ native και webview
-   **Εκτελούν scripts** - JavaScript σε προγράμματα περιήγησης, εντολές Appium για κινητά σε συσκευές
-   **Χειρίζονται λειτουργίες της συσκευής** όπως περιστροφή, πληκτρολόγιο, γεωεντοπισμό
-   και πολλά άλλα, δείτε τις επιλογές [Εργαλεία](./mcp/tools) και [Διαμόρφωση](./mcp/configuration)

:::info

ΣΗΜΕΙΩΣΗ Για Εφαρμογές Κινητών
Η αυτοματοποίηση κινητών απαιτεί έναν διακομιστή Appium σε λειτουργία με εγκατεστημένους τους κατάλληλους drivers. Δείτε τις [Προαπαιτούμενα](#prerequisites) για οδηγίες ρύθμισης.

:::

## Εγκατάσταση

Ο ευκολότερος τρόπος χρήσης του `@wdio/mcp` είναι μέσω npx χωρίς καμία τοπική εγκατάσταση:

```sh
npx @wdio/mcp
```

Ή εγκαταστήστε το καθολικά:

```sh
npm install -g @wdio/mcp
```

## Χρήση με το Claude

Για να χρησιμοποιήσετε το WebdriverIO MCP με το Claude, τροποποιήστε το αρχείο διαμόρφωσης:

```json
{
    "mcpServers": {
        "wdio-mcp": {
            "command": "npx",
            "args": ["-y", "@wdio/mcp"]
        }
    }
}
```

Αφού προσθέσετε τη διαμόρφωση, επανεκκινήστε το harness σας. Τα εργαλεία WebdriverIO MCP θα είναι διαθέσιμα για εργασίες αυτοματοποίησης προγραμμάτων περιήγησης και κινητών.

### Χρήση με το Claude Code

Το Claude Code ανιχνεύει αυτόματα τους διακομιστές MCP. Μπορείτε να το διαμορφώσετε στο `.claude/settings.json` ή στο `.mcp.json` του έργου σας.

Ή προσθέστε το καθολικά στο .claude.json εκτελώντας:
```bash
claude mcp add --transport stdio wdio-mcp -- npx -y @wdio/mcp
```
Επαληθεύστε το εκτελώντας την εντολή `/mcp` μέσα στο claude code.

## Προαπαιτούμενα

### Αυτοματοποίηση Προγράμματος Περιήγησης

-   Πρέπει να είναι εγκατεστημένο το **Chrome, Firefox, Edge ή Safari**
-   Το WebdriverIO χειρίζεται την αυτοματοποιημένη διαχείριση drivers

### Αυτοματοποίηση Κινητών

#### iOS

1. **Εγκαταστήστε το Xcode** από το Mac App Store
2. **Εγκαταστήστε τα Xcode Command Line Tools**:
   ```sh
   xcode-select --install
   ```
3. **Εγκαταστήστε το Appium**:
   ```sh
   npm install -g appium
   ```
4. **Εγκαταστήστε τον driver XCUITest**:
   ```sh
   appium driver install xcuitest
   ```
5. **Εκκινήστε τον διακομιστή Appium**:
   ```sh
   appium
   ```
6. **Για Προσομοιωτές**: Ανοίξτε Xcode → Window → Devices and Simulators για να δημιουργήσετε/διαχειριστείτε προσομοιωτές
7. **Για Πραγματικές Συσκευές**: Θα χρειαστείτε το UDID της συσκευής (μοναδικό αναγνωριστικό 40 χαρακτήρων)

#### Android

1. **Εγκαταστήστε το Android Studio** και ρυθμίστε το Android SDK
2. **Ορίστε τις μεταβλητές περιβάλλοντος**:
   ```sh
   export ANDROID_HOME=$HOME/Library/Android/sdk
   export PATH=$PATH:$ANDROID_HOME/emulator
   export PATH=$PATH:$ANDROID_HOME/platform-tools
   ```
3. **Εγκαταστήστε το Appium**:
   ```sh
   npm install -g appium
   ```
4. **Εγκαταστήστε τον driver UiAutomator2**:
   ```sh
   appium driver install uiautomator2
   ```
5. **Εκκινήστε τον διακομιστή Appium**:
   ```sh
   appium
   ```
6. **Δημιουργήστε έναν εξομοιωτή** μέσω Android Studio → Virtual Device Manager
7. **Εκκινήστε τον εξομοιωτή** πριν εκτελέσετε τα tests

## Αρχιτεκτονική

### Πώς Λειτουργεί

Το WebdriverIO MCP λειτουργεί ως γέφυρα μεταξύ των βοηθών AI και της αυτοματοποίησης προγραμμάτων περιήγησης/κινητών:

```
┌─────────────────┐     MCP Protocol      ┌─────────────────┐
│  Claude Desktop │ ◄──────────────────►  │    @wdio/mcp    │
│  or Claude Code │   (stdio or HTTP)     │     Server      │
└─────────────────┘                       └────────┬────────┘
                                                   │
                                             WebDriverIO API
                                                   │
                    ┌──────────────────────────────┼──────────────────────────────┐
                    │                              │                              │
            ┌───────▼───────┐             ┌───────▼───────┐             ┌───────▼───────┐
            │    Browser    │             │    Appium     │             │   Cloud        │
            │ (local/CDP)   │             │  (iOS/Android)│             │   Providers    │
            └───────────────┘             └───────────────┘             └───────────────┘
```

### Διαχείριση Συνεδριών

-   **Μοντέλο μίας συνεδρίας**: Μόνο μία συνεδρία προγράμματος περιήγησης Ή εφαρμογής μπορεί να είναι ενεργή κάθε φορά
-   **Η κατάσταση της συνεδρίας** διατηρείται καθολικά μεταξύ των κλήσεων εργαλείων
-   **Αυτόματη αποσύνδεση**: Οι συνεδρίες με διατηρημένη κατάσταση (`noReset: true`) αποσυνδέονται αυτόματα κατά το κλείσιμο

### Ανίχνευση Στοιχείων

#### Πρόγραμμα Περιήγησης (Web)

-   Χρησιμοποιεί ένα βελτιστοποιημένο script προγράμματος περιήγησης για την εύρεση όλων των ορατών, διαδραστικών στοιχείων
-   Επιστρέφει στοιχεία με επιλογείς CSS, IDs, κλάσεις και πληροφορίες ARIA
-   Υποστηρίζει φιλτράρισμα viewport και σελιδοποίηση

#### Κινητά (Εγγενείς Εφαρμογές)

-   Χρησιμοποιεί αποδοτική ανάλυση του XML page source (2 κλήσεις HTTP έναντι 600+ για παραδοσιακά ερωτήματα)
-   Κατηγοριοποίηση στοιχείων ειδική για κάθε πλατφόρμα για Android και iOS
-   Δημιουργεί πολλαπλές στρατηγικές εντοπισμού ανά στοιχείο:
    -   Accessibility ID (πολλαπλών πλατφορμών, το πιο σταθερό)
    -   Χαρακτηριστικό Resource ID / Name
    -   Αντιστοίχιση Text / Label
    -   XPath (πλήρες και απλοποιημένο)
    -   UiAutomator (Android) / Predicates (iOS)

## Σύνταξη Επιλογέων

Ο διακομιστής MCP υποστηρίζει πολλαπλές στρατηγικές επιλογέων. Δείτε τους [Επιλογείς](./mcp/selectors) για λεπτομερή τεκμηρίωση.

### Web (CSS/XPath)

```
# Επιλογείς CSS
button.my-class
#element-id
[data-testid="login"]

# XPath
//button[@class='submit']
//a[contains(text(), 'Click')]

# Επιλογείς Κειμένου (ειδικοί για το WebdriverIO)
button=Exact Button Text
a*=Partial Link Text
```

### Κινητά (Πολλαπλών Πλατφορμών)

```
# Accessibility ID (συνιστάται - λειτουργεί σε iOS & Android)
~loginButton

# Android UiAutomator
android=new UiSelector().text("Login")

# iOS Predicate String
-ios predicate string:label == "Login"

# iOS Class Chain
-ios class chain:**/XCUIElementTypeButton[`label == "Login"`]

# XPath (λειτουργεί και στις δύο πλατφόρμες)
//android.widget.Button[@text="Login"]
//XCUIElementTypeButton[@label="Login"]
```

| `get_tabs` | browser | Λίστα όλων των ανοιχτών καρτελών |
| `switch_tab` | browser | Εστίαση σε καρτέλα βάσει handle ή δείκτη |
| `switch_frame` | browser | Εναλλαγή σε iframe βάσει επιλογέα ή επιστροφή στο ανώτατο επίπεδο |
| `click_element` | browser | Κλικ σε ένα στοιχείο |
| `set_value` | all | Πληκτρολόγηση κειμένου σε πεδίο εισαγωγής |
| `scroll` | browser | Κύλιση της σελίδας πάνω ή κάτω |
| `get_elements` | all | Λήψη διαδραστικών στοιχείων (με φιλτράρισμα + σελιδοποίηση) |
| `get_accessibility_tree` | browser | Λήψη δέντρου προσβασιμότητας (με φιλτράρισμα ρόλων) |
| `get_screenshot` | all | Λήψη στιγμιότυπου οθόνης (αυτόματα βελτιστοποιημένο) |
| `get_cookies` | browser | Λήψη όλων των cookies ή ενός συγκεκριμένου cookie |
| `set_cookie` | browser | Ορισμός cookie του προγράμματος περιήγησης |
| `delete_cookies` | browser | Διαγραφή όλων ή ενός cookie |
| `emulate_device` | browser | Εξομοίωση viewport συσκευής κινητού/tablet |
| `execute_script` | all | Εκτέλεση JavaScript (browser) ή εντολών Appium (mobile) |
| `tap_element` | mobile | Πάτημα σε στοιχείο ή συντεταγμένες οθόνης |
| `swipe` | mobile | Χειρονομία σάρωσης προς μια κατεύθυνση |
| `drag_and_drop` | mobile | Μεταφορά μεταξύ στοιχείων ή συντεταγμένων |
| `get_contexts` | mobile | Λίστα διαθέσιμων περιβαλλόντων native/webview |
| `switch_context` | mobile | Εναλλαγή μεταξύ περιβαλλόντων native και webview |
| `rotate_device` | mobile | Περιστροφή σε κατακόρυφο ή οριζόντιο προσανατολισμό |
| `hide_keyboard` | mobile | Απόκρυψη του εικονικού πληκτρολογίου |
| `set_geolocation` | all | Παράκαμψη των συντεταγμένων GPS της συσκευής |
| `get_app_state` | mobile | Λήψη κατάστασης κύκλου ζωής εφαρμογής |
| `list_apps` | cloud | Λίστα μεταφορτωμένων εφαρμογών (BrowserStack, Sauce Labs, TestMu, TestingBot) |
| `upload_app` | cloud | Μεταφόρτωση ενός `.apk`/`.ipa` σε πάροχο cloud |

## Αυτόματος Χειρισμός

### Δικαιώματα

Από προεπιλογή, ο διακομιστής MCP παραχωρεί αυτόματα δικαιώματα εφαρμογών (`autoGrantPermissions: true`), εξαλείφοντας την ανάγκη χειροκίνητου χειρισμού των διαλόγων δικαιωμάτων κατά την αυτοματοποίηση.

### Ειδοποιήσεις Συστήματος

Οι ειδοποιήσεις συστήματος (όπως "Allow notifications?") γίνονται αυτόματα αποδεκτές από προεπιλογή (`autoAcceptAlerts: true`). Αυτό μπορεί να διαμορφωθεί ώστε να απορρίπτονται με `autoDismissAlerts: true`.

## Μεταφορά

Από προεπιλογή, ο διακομιστής εκτελείται μέσω **stdio** (εκκινείται ως υποδιεργασία από τον πελάτη AI). Για πελάτες που δεν υποστηρίζουν MCP βασισμένο σε υποδιεργασίες (llama.cpp, Codex secure mode), χρησιμοποιήστε **μεταφορά HTTP**:

```bash
npx @wdio/mcp --http --port 3000
```

Δείτε τη [Μεταφορά](./mcp/transport) για όλες τις επιλογές, συμπεριλαμβανομένων των `--allowedHosts` και `--allowedOrigins`.

## Βελτιστοποίηση Απόδοσης

Ο διακομιστής MCP είναι βελτιστοποιημένος για αποδοτική επικοινωνία με βοηθούς AI:

-   **Μορφή TOON**: Χρησιμοποιεί Token-Oriented Object Notation για ελάχιστη χρήση tokens
-   **Ανάλυση XML**: Η ανίχνευση στοιχείων σε κινητά χρησιμοποιεί 2 κλήσεις HTTP (έναντι 600+ παραδοσιακά)
-   **Συμπίεση Στιγμιότυπων Οθόνης**: Οι εικόνες συμπιέζονται αυτόματα έως 1MB το μέγιστο
-   **Φιλτράρισμα Viewport**: Από προεπιλογή επιστρέφονται μόνο τα ορατά στοιχεία
-   **Σελιδοποίηση**: Οι μεγάλες λίστες στοιχείων μπορούν να σελιδοποιηθούν για μείωση του μεγέθους της απόκρισης

## Χειρισμός Σφαλμάτων

Όλα τα εργαλεία έχουν σχεδιαστεί με ισχυρό χειρισμό σφαλμάτων:

-   Τα σφάλματα επιστρέφονται ως περιεχόμενο κειμένου (δεν προκαλούνται ποτέ εξαιρέσεις), διατηρώντας τη σταθερότητα του πρωτοκόλλου MCP
-   Περιγραφικά μηνύματα σφαλμάτων βοηθούν στη διάγνωση προβλημάτων
-   Η κατάσταση της συνεδρίας διατηρείται ακόμη και όταν μεμονωμένες λειτουργίες αποτυγχάνουν

## Αντιμετώπιση Προβλημάτων

### Το πρόγραμμα περιήγησης δεν ξεκινά

-   Βεβαιωθείτε ότι το πρόγραμμα περιήγησης-στόχος είναι εγκατεστημένο
-   Ελέγξτε ότι καμία άλλη διεργασία δεν χρησιμοποιεί την προεπιλεγμένη θύρα αποσφαλμάτωσης (9222)
-   Δοκιμάστε τη λειτουργία headless εάν παρουσιαστούν προβλήματα οθόνης

### Η σύνδεση με το Appium απέτυχε

-   Επαληθεύστε ότι ο διακομιστής Appium εκτελείται (`appium`)
-   Ελέγξτε τον host και τη θύρα του Appium στο `appiumConfig`
-   Βεβαιωθείτε ότι ο κατάλληλος driver είναι εγκατεστημένος (`appium driver list`)

### Προβλήματα με τον iOS Simulator

-   Βεβαιωθείτε ότι το Xcode είναι εγκατεστημένο και ενημερωμένο
-   Ελέγξτε ότι οι προσομοιωτές είναι διαθέσιμοι (`xcrun simctl list devices`)
-   Για πραγματικές συσκευές, επαληθεύστε ότι το UDID είναι σωστό

### Προβλήματα με τον Android Emulator

-   Βεβαιωθείτε ότι το Android SDK είναι σωστά διαμορφωμένο
-   Επαληθεύστε ότι ο εξομοιωτής εκτελείται (`adb devices`)
-   Ελέγξτε ότι η μεταβλητή περιβάλλοντος `ANDROID_HOME` έχει οριστεί
