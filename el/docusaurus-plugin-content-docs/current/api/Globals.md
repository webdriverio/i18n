---
id: globals
title: Καθολικές Μεταβλητές
---

Στα αρχεία δοκιμών σας, το WebdriverIO τοποθετεί καθεμία από αυτές τις μεθόδους και τα αντικείμενα στο καθολικό περιβάλλον. Δεν χρειάζεται να εισαγάγετε τίποτα για να τα χρησιμοποιήσετε. Ωστόσο, αν προτιμάτε ρητές εισαγωγές, μπορείτε να χρησιμοποιήσετε `import { browser, $, $$, expect } from '@wdio/globals'` και να ορίσετε `injectGlobals: false` στη διαμόρφωση του WDIO.

Τα ακόλουθα καθολικά αντικείμενα ορίζονται, εφόσον δεν έχει διαμορφωθεί διαφορετικά:

- `browser`: [Αντικείμενο Browser](https://webdriver.io/docs/api/browser) του WebdriverIO
- `driver`: ψευδώνυμο του `browser` (χρησιμοποιείται κατά την εκτέλεση δοκιμών για κινητές συσκευές)
- `multiRemoteBrowser`: ψευδώνυμο του `browser` ή του `driver`, αλλά ορίζεται μόνο για συνεδρίες [multi-remote](/docs/multiremote)
- `$`: εντολή για την ανάκτηση ενός στοιχείου (δείτε περισσότερα στην [τεκμηρίωση API](/docs/api/browser/$))
- `$$`: εντολή για την ανάκτηση στοιχείων (δείτε περισσότερα στην [τεκμηρίωση API](/docs/api/browser/$$))
- `expect`: πλαίσιο επιβεβαιώσεων (assertion framework) για το WebdriverIO (δείτε την [τεκμηρίωση API](/docs/api/expect-webdriverio))

__Σημείωση:__ Το WebdriverIO δεν έχει κανέναν έλεγχο στα χρησιμοποιούμενα frameworks (π.χ. Mocha ή Jasmine) που ορίζουν καθολικές μεταβλητές κατά την εκκίνηση του περιβάλλοντός τους.
