Συχνές ερωτήσεις σχετικά με το WebdriverIO MCP.

## Γενικά

### Τι είναι το MCP;

Το MCP (Model Context Protocol) είναι ένα ανοιχτό πρωτόκολλο που επιτρέπει σε βοηθούς τεχνητής νοημοσύνης όπως το Claude να αλληλεπιδρούν με εξωτερικά εργαλεία και υπηρεσίες. Το WebdriverIO MCP υλοποιεί αυτό το πρωτόκολλο για να παρέχει δυνατότητες αυτοματοποίησης προγραμμάτων περιήγησης και κινητών συσκευών στο Claude Desktop και στο Claude Code.

### Τι μπορώ να αυτοματοποιήσω με το WebdriverIO MCP;

Μπορείτε να αυτοματοποιήσετε:
-   **Προγράμματα περιήγησης υπολογιστή** (Chrome, Firefox, Edge, Safari) - πλοήγηση, κλικ, πληκτρολόγηση, στιγμιότυπα οθόνης
-   **Εφαρμογές iOS** - σε προσομοιωτές ή πραγματικές συσκευές
-   **Εφαρμογές Android** - σε εξομοιωτές ή πραγματικές συσκευές
-   **Υβριδικές εφαρμογές** - εναλλαγή μεταξύ native και web contexts
-   **Συσκευές στο cloud** - μέσω των device clouds BrowserStack, Sauce Labs, TestMu και TestingBot

### Χρειάζεται να γράψω κώδικα;

Όχι! Αυτό είναι το κύριο πλεονέκτημα του MCP. Μπορείτε να περιγράψετε τι θέλετε να κάνετε σε φυσική γλώσσα και το Claude θα χρησιμοποιήσει τα κατάλληλα εργαλεία για να ολοκληρώσει την εργασία.

**Παραδείγματα prompts:**
-   "Άνοιξε το Chrome και πλοηγήσου στο webdriver.io"
-   "Κάνε κλικ στο κουμπί Get Started"
-   "Τράβηξε ένα στιγμιότυπο οθόνης της τρέχουσας σελίδας"
-   "Ξεκίνα την εφαρμογή μου iOS και συνδέσου ως δοκιμαστικός χρήστης"

## Εγκατάσταση & Ρύθμιση

### Πώς εγκαθιστώ το WebdriverIO MCP;

Δεν χρειάζεται να το εγκαταστήσετε ξεχωριστά. Ο διακομιστής MCP εκτελείται αυτόματα μέσω npx όταν τον ρυθμίσετε στο harness σας. Προσθέστε αυτό στη διαμόρφωσή σας:

```json
{
    "mcpServers": {
        "wdio-mcp": {
            "command": "npx",
            "args": ["-y", "@wdio/mcp"]
        }
    }
}
```

### Πού βρίσκεται το αρχείο διαμόρφωσης του Claude Desktop;

-   **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`
-   **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`

### Χρειάζομαι το Appium για αυτοματοποίηση προγραμμάτων περιήγησης;

Όχι. Η αυτοματοποίηση προγραμμάτων περιήγησης απαιτεί μόνο να είναι εγκατεστημένο το επιθυμητό πρόγραμμα περιήγησης. Το WebdriverIO διαχειρίζεται αυτόματα τους drivers.

### Χρειάζομαι το Appium για αυτοματοποίηση κινητών συσκευών;

Ναι. Η αυτοματοποίηση κινητών συσκευών απαιτεί:
1. Να εκτελείται ο διακομιστής Appium (`npm install -g appium && appium`)
2. Να είναι εγκατεστημένοι οι drivers πλατφόρμας (`appium driver install xcuitest` για iOS, `appium driver install uiautomator2` για Android)
3. Τα κατάλληλα εργαλεία ανάπτυξης (Xcode για iOS, Android SDK για Android)

## Αυτοματοποίηση Προγραμμάτων Περιήγησης

### Ποια προγράμματα περιήγησης υποστηρίζονται;

Υποστηρίζονται τα Chrome, Firefox, Edge και Safari. Χρησιμοποιήστε την παράμετρο `browser` στο `start_session`:

```text
"Start a Firefox session"
"Start Chrome in headless mode"
```

### Μπορώ να εκτελέσω το πρόγραμμα περιήγησης σε headless λειτουργία;

Ναι. Η headless λειτουργία είναι η προεπιλογή (`headless: true`). Ζητήστε από το Claude να το εκτελέσει σε headed λειτουργία αν θέλετε να βλέπετε το πρόγραμμα περιήγησης:

"Ξεκίνα το Chrome σε headed λειτουργία (όχι headless)"

### Μπορώ να ορίσω το μέγεθος του παραθύρου του προγράμματος περιήγησης;

Ναι. Μπορείτε να καθορίσετε διαστάσεις κατά την εκκίνηση του προγράμματος περιήγησης:

"Ξεκίνα το Chrome με μέγεθος παραθύρου 1920x1080"

Υποστηριζόμενες διαστάσεις: πλάτος 400–3840 pixels, ύψος 400–2160 pixels. Η προεπιλογή είναι 1920×1080.

### Μπορώ να ξεκινήσω το πρόγραμμα περιήγησης και να πλοηγηθώ σε ένα βήμα;

Ναι! Χρησιμοποιήστε την παράμετρο `navigationUrl`:

"Ξεκίνα το Chrome και πλοηγήσου στο https://webdriver.io"

Αυτό είναι πιο αποδοτικό από την εκκίνηση του προγράμματος περιήγησης και την ξεχωριστή πλοήγηση στη συνέχεια.

### Πώς τραβάω στιγμιότυπα οθόνης;

Απλώς ζητήστε:

"Τράβηξε ένα στιγμιότυπο οθόνης της τρέχουσας σελίδας"

Τα στιγμιότυπα οθόνης βελτιστοποιούνται αυτόματα:
- Κλιμάκωση σε μέγιστη διάσταση 2000px
- Συμπίεση σε μέγιστο μέγεθος αρχείου 1MB
- Μορφή: PNG ή JPEG (επιλέγεται αυτόματα για βέλτιστη ποιότητα)

### Μπορώ να αλληλεπιδράσω με iframes;

Ναι. Χρησιμοποιήστε το εργαλείο `switch_frame` για να μεταβείτε σε ένα iframe μέσω επιλογέα CSS ή XPath. Όλες οι επόμενες κλήσεις `click_element`, `set_value` και `get_elements` λειτουργούν εντός του επιλεγμένου frame. Παραλείψτε τον επιλογέα για να επιστρέψετε στο frame ανώτατου επιπέδου. Τα iframes πρέπει να προέρχονται από την ίδια προέλευση (same origin) με την κύρια σελίδα.

### Μπορώ να εκτελέσω προσαρμοσμένη JavaScript;

Ναι! Χρησιμοποιήστε το εργαλείο `execute_script`:

"Εκτέλεσε script για να πάρεις τον τίτλο της σελίδας"
"Εκτέλεσε script: return document.querySelectorAll('button').length"

### Μπορώ να συνδεθώ σε μια υπάρχουσα συνεδρία Chrome;

Ναι. Χρησιμοποιήστε πρώτα το `launch_chrome` (ανοίγει το Chrome με απομακρυσμένη αποσφαλμάτωση) και στη συνέχεια το `start_session` με `attach: true`.

"Εκκίνησε το Chrome με απομακρυσμένη αποσφαλμάτωση και μετά συνδέσου σε αυτό"

### Μπορώ να δουλέψω με πολλές καρτέλες;

Ναι. Χρησιμοποιήστε το `get_tabs` για να εμφανίσετε τις ανοιχτές καρτέλες και το `switch_tab` για να εστιάσετε σε μια συγκεκριμένη:

"Πάρε όλες τις ανοιχτές καρτέλες"
"Μετάβαση στην καρτέλα με δείκτη 1"

## Αυτοματοποίηση Κινητών Συσκευών

### Πώς ξεκινάω μια συνεδρία iOS ή Android;

Χρησιμοποιήστε το `start_session` με την κατάλληλη πλατφόρμα:

"Ξεκίνα την εφαρμογή μου iOS που βρίσκεται στο /path/to/MyApp.app στον προσομοιωτή iPhone 15"

"Ξεκίνα την εφαρμογή μου Android στο /path/to/app.apk στον εξομοιωτή Pixel 7"

Ή για μια ήδη εγκατεστημένη εφαρμογή:

"Ξεκίνα την εφαρμογή με ενεργοποιημένο το noReset στον προσομοιωτή iPhone 15"

### Μπορώ να κάνω δοκιμές σε πραγματικές συσκευές;

Ναι! Για πραγματικές συσκευές, θα χρειαστείτε το UDID της συσκευής:

-   **iOS:** Συνδέστε τη συσκευή, ανοίξτε το Finder, κάντε κλικ στη συσκευή και στον σειριακό αριθμό για να εμφανιστεί το UDID
-   **Android:** Εκτελέστε `adb devices` στο τερματικό

Στη συνέχεια ζητήστε:

"Ξεκίνα την εφαρμογή μου iOS στην πραγματική συσκευή με UDID abc123..."

### Πώς χειρίζομαι τους διαλόγους δικαιωμάτων;

Από προεπιλογή, τα δικαιώματα παραχωρούνται αυτόματα (`autoGrantPermissions: true`). Αν χρειάζεται να δοκιμάσετε ροές δικαιωμάτων, μπορείτε να το απενεργοποιήσετε:

"Ξεκίνα την εφαρμογή μου χωρίς αυτόματη παραχώρηση δικαιωμάτων"

### Ποιες χειρονομίες υποστηρίζονται;

-   **Πάτημα (Tap):** Πάτημα σε στοιχεία ή συντεταγμένες (`tap_element`)
-   **Σάρωση (Swipe):** Σάρωση προς τα πάνω, κάτω, αριστερά ή δεξιά (`swipe`)
-   **Μεταφορά και Απόθεση (Drag and Drop):** Μεταφορά από ένα στοιχείο σε άλλο ή σε συντεταγμένες (`drag_and_drop`)

Σημείωση: Το `long_press` είναι διαθέσιμο μέσω του `execute_script` με εντολές κινητών του Appium.

### Πώς κάνω κύλιση σε εφαρμογές κινητών;

Χρησιμοποιήστε χειρονομίες σάρωσης:

"Σάρωσε προς τα πάνω για κύλιση προς τα κάτω"
"Σάρωσε προς τα κάτω για κύλιση προς τα πάνω"

### Μπορώ να περιστρέψω τη συσκευή;

Ναι:

"Περίστρεψε τη συσκευή σε οριζόντιο προσανατολισμό"
"Περίστρεψε τη συσκευή σε κατακόρυφο προσανατολισμό"

### Πώς χειρίζομαι υβριδικές εφαρμογές;

Για εφαρμογές με webviews, μπορείτε να αλλάξετε contexts:

"Πάρε τα διαθέσιμα contexts"
"Μετάβαση στο webview context"
"Επιστροφή στο native context"

### Μπορώ να εκτελέσω εντολές κινητών του Appium;

Ναι! Χρησιμοποιήστε το εργαλείο `execute_script`:

```text
Execute script "mobile: pressKey" with args [{ keycode: 4 }]  // Πάτημα BACK στο Android
Execute script "mobile: activateApp" with args [{ bundleId: "com.example.app" }]
Execute script "mobile: terminateApp" with args [{ bundleId: "com.example.app" }]
```

## Επιλογή Στοιχείων

### Πώς γνωρίζει ο βοηθός τεχνητής νοημοσύνης με ποιο στοιχείο να αλληλεπιδράσει;

Χρησιμοποιεί τον πόρο `wdio://session/current/elements` ή το εργαλείο `get_elements` για να εντοπίσει διαδραστικά στοιχεία στη σελίδα/οθόνη. Κάθε στοιχείο συνοδεύεται από έτοιμους προς χρήση επιλογείς.

### Τι γίνεται αν υπάρχουν πάρα πολλά στοιχεία στη σελίδα;

Χρησιμοποιήστε σελιδοποίηση για τη διαχείριση μεγάλων λιστών στοιχείων:

"Πάρε τα πρώτα 20 στοιχεία"
"Πάρε στοιχεία με offset 20 και limit 20"

Η απόκριση περιλαμβάνει τα `total`, `showing` και `hasMore` για να σας βοηθήσει να περιηγηθείτε στα στοιχεία.

### Τι γίνεται αν το Claude κάνει κλικ σε λάθος στοιχείο;

Μπορείτε να είστε πιο συγκεκριμένοι:

-   Δώστε το ακριβές κείμενο: "Κάνε κλικ στο κουμπί που λέει 'Submit Order'"
-   Δώστε επιλογέα: "Κάνε κλικ στο στοιχείο με επιλογέα #submit-btn"
-   Δώστε accessibility ID: "Κάνε κλικ στο στοιχείο με accessibility ID loginButton"

### Ποια είναι η καλύτερη στρατηγική επιλογέων για κινητά;

1. **Accessibility ID** (καλύτερη) - `~loginButton`
2. **Resource ID** (Android) - `id=login_button`
3. **Predicate String** (iOS) - `-ios predicate string:label == "Login"`
4. **XPath** (έσχατη λύση) - πιο αργό αλλά λειτουργεί παντού

### Τι είναι το δέντρο προσβασιμότητας και πότε πρέπει να το χρησιμοποιώ;

Το δέντρο προσβασιμότητας παρέχει σημασιολογικές πληροφορίες για τα στοιχεία της σελίδας (ρόλοι, ονόματα, καταστάσεις). Χρησιμοποιήστε το `get_accessibility_tree` όταν:
- Το `get_elements` δεν επιστρέφει τα αναμενόμενα στοιχεία
- Χρειάζεται να βρείτε στοιχεία με βάση τον ρόλο προσβασιμότητας (button, link, textbox κ.λπ.)
- Χρειάζεστε λεπτομερείς σημασιολογικές πληροφορίες για τα στοιχεία

"Πάρε το δέντρο προσβασιμότητας φιλτραρισμένο στους ρόλους button και link"

## Διαχείριση Συνεδριών

### Μπορώ να έχω πολλές συνεδρίες ταυτόχρονα;

Όχι. Ο διακομιστής MCP χρησιμοποιεί μοντέλο μίας συνεδρίας. Μόνο μία συνεδρία προγράμματος περιήγησης ή εφαρμογής μπορεί να είναι ενεργή κάθε φορά.

### Τι συμβαίνει όταν κλείνω μια συνεδρία;

Εξαρτάται από τον τύπο της συνεδρίας και τις ρυθμίσεις:

-   **Πρόγραμμα περιήγησης:** Το πρόγραμμα περιήγησης κλείνει εντελώς
-   **Κινητό με `noReset: false`:** Η εφαρμογή τερματίζεται
-   **Κινητό με `noReset: true` ή χωρίς `appPath`:** Η εφαρμογή παραμένει ανοιχτή (η συνεδρία αποσυνδέεται αυτόματα)

### Μπορώ να διατηρήσω την κατάσταση της εφαρμογής μεταξύ συνεδριών;

Ναι! Χρησιμοποιήστε την επιλογή `noReset`:

"Ξεκίνα την εφαρμογή μου με ενεργοποιημένο το noReset"

Αυτό διατηρεί την κατάσταση σύνδεσης, τις προτιμήσεις και άλλα δεδομένα της εφαρμογής.

### Ποια είναι η διαφορά μεταξύ close και detach;

-   **Close:** Τερματίζει εντελώς το πρόγραμμα περιήγησης/την εφαρμογή
-   **Detach:** Αποσυνδέει την αυτοματοποίηση αλλά διατηρεί το πρόγραμμα περιήγησης/την εφαρμογή σε λειτουργία

Το detach είναι χρήσιμο όταν θέλετε να επιθεωρήσετε χειροκίνητα την κατάσταση μετά την αυτοματοποίηση.

### Η συνεδρία μου λήγει συνεχώς κατά την αποσφαλμάτωση

Αυξήστε το χρονικό όριο εντολών:

"Ξεκίνα την εφαρμογή μου με newCommandTimeout 300 δευτερολέπτων"

Η προεπιλογή είναι 300 δευτερόλεπτα. Για πολύ μεγάλες συνεδρίες αποσφαλμάτωσης, δοκιμάστε 600 δευτερόλεπτα.

## Αντιμετώπιση Προβλημάτων

### Σφάλμα "Session not found"

Αυτό σημαίνει ότι δεν υπάρχει ενεργή συνεδρία. Ξεκινήστε πρώτα μια συνεδρία προγράμματος περιήγησης ή εφαρμογής:

"Ξεκίνα το Chrome και πλοηγήσου στο google.com"

### Σφάλμα "Element not found"

Το στοιχείο μπορεί να μην είναι ορατό ή να έχει διαφορετικό επιλογέα. Δοκιμάστε:

1. Να ζητήσετε πρώτα από το Claude να πάρει όλα τα ορατά στοιχεία
2. Να δώσετε έναν πιο συγκεκριμένο επιλογέα
3. Να περιμένετε να φορτώσει πλήρως η σελίδα/εφαρμογή
4. Να χρησιμοποιήσετε `inViewportOnly: false` για να βρείτε στοιχεία εκτός οθόνης

### Το πρόγραμμα περιήγησης δεν ξεκινά

1. Βεβαιωθείτε ότι το επιθυμητό πρόγραμμα περιήγησης είναι εγκατεστημένο
2. Ελέγξτε αν κάποια άλλη διεργασία χρησιμοποιεί τη θύρα αποσφαλμάτωσης (9222)
3. Δοκιμάστε τη headless λειτουργία

### Αποτυχία σύνδεσης με το Appium

Αυτό είναι το πιο συνηθισμένο πρόβλημα κατά την έναρξη της αυτοματοποίησης κινητών συσκευών.

1. **Επαληθεύστε ότι το Appium εκτελείται**: `curl http://localhost:4723/status`
2. Ξεκινήστε το Appium αν χρειάζεται: `appium`
3. Ελέγξτε ότι η σύνδεσή σας με το Appium ταιριάζει με τον διακομιστή (χρησιμοποιήστε το `appiumConfig` στο `start_session`)
4. Βεβαιωθείτε ότι οι drivers είναι εγκατεστημένοι: `appium driver list --installed`

:::tip
Ο διακομιστής MCP απαιτεί να εκτελείται το Appium πριν από την έναρξη συνεδριών κινητών συσκευών. Φροντίστε να ξεκινήσετε πρώτα το Appium:
```sh
appium
```
Μελλοντικές εκδόσεις ενδέχεται να περιλαμβάνουν αυτόματη διαχείριση της υπηρεσίας Appium.
:::

### Ο προσομοιωτής iOS δεν ξεκινά

1. Βεβαιωθείτε ότι το Xcode είναι εγκατεστημένο: `xcode-select --install`
2. Εμφανίστε τους διαθέσιμους προσομοιωτές: `xcrun simctl list devices`
3. Ελέγξτε για συγκεκριμένα σφάλματα του προσομοιωτή στο Console.app

### Ο εξομοιωτής Android δεν ξεκινά

1. Ορίστε το `ANDROID_HOME`: `export ANDROID_HOME=$HOME/Library/Android/sdk`
2. Ελέγξτε τους εξομοιωτές: `emulator -list-avds`
3. Ξεκινήστε τον εξομοιωτή χειροκίνητα: `emulator -avd <avd-name>`
4. Επαληθεύστε ότι η συσκευή είναι συνδεδεμένη: `adb devices`

### Τα στιγμιότυπα οθόνης δεν λειτουργούν

1. Για κινητά, βεβαιωθείτε ότι η συνεδρία είναι ενεργή
2. Για προγράμματα περιήγησης, δοκιμάστε μια διαφορετική σελίδα (ορισμένες σελίδες μπλοκάρουν τα στιγμιότυπα οθόνης)
3. Ελέγξτε τα αρχεία καταγραφής του Claude Desktop για σφάλματα

Τα στιγμιότυπα οθόνης συμπιέζονται αυτόματα σε μέγιστο 1MB, επομένως τα μεγάλα στιγμιότυπα θα λειτουργήσουν αλλά ενδέχεται να έχουν χαμηλότερη ποιότητα.

## Απόδοση

### Γιατί η αυτοματοποίηση κινητών συσκευών είναι αργή;

Η αυτοματοποίηση κινητών συσκευών περιλαμβάνει:
1. Επικοινωνία δικτύου με τον διακομιστή Appium
2. Επικοινωνία του Appium με τη συσκευή/τον προσομοιωτή
3. Απόδοση γραφικών και απόκριση της συσκευής

Συμβουλές για ταχύτερη αυτοματοποίηση:
-   Χρησιμοποιήστε εξομοιωτές/προσομοιωτές αντί για πραγματικές συσκευές κατά την ανάπτυξη
-   Χρησιμοποιήστε accessibility IDs αντί για XPath
-   Ενεργοποιήστε το `inViewportOnly: true` για τον εντοπισμό στοιχείων
-   Χρησιμοποιήστε σελιδοποίηση (`limit`) για να μειώσετε τη χρήση tokens

### Πώς μπορώ να επιταχύνω τον εντοπισμό στοιχείων;

Ο διακομιστής MCP ήδη βελτιστοποιεί τον εντοπισμό στοιχείων χρησιμοποιώντας ανάλυση του XML page source (2 κλήσεις HTTP έναντι 600+ για παραδοσιακά ερωτήματα στοιχείων). Επιπλέον συμβουλές:

-   Ορίστε `inViewportOnly: true` για να φιλτράρετε στοιχεία εκτός οθόνης
-   Ορίστε `includeContainers: false` (προεπιλογή)
-   Χρησιμοποιήστε `limit` και `offset` για σελιδοποίηση σε μεγάλες οθόνες
-   Χρησιμοποιήστε συγκεκριμένους επιλογείς αντί να αναζητάτε όλα τα στοιχεία

### Τα στιγμιότυπα οθόνης είναι αργά ή αποτυγχάνουν

Τα στιγμιότυπα οθόνης βελτιστοποιούνται αυτόματα:
- Αλλαγή μεγέθους αν είναι μεγαλύτερα από 2000px
- Συμπίεση ώστε να παραμένουν κάτω από 1MB
- Μετατροπή σε JPEG αν το PNG είναι πολύ μεγάλο

Αυτή η βελτιστοποίηση μειώνει τον χρόνο επεξεργασίας και διασφαλίζει ότι το Claude μπορεί να χειριστεί την εικόνα.

## Περιορισμοί

### Ποιοι είναι οι τρέχοντες περιορισμοί;

-   **Μία συνεδρία:** Μόνο ένα πρόγραμμα περιήγησης/μία εφαρμογή κάθε φορά
-   **Υποστήριξη iframe:** Τα iframes ίδιας προέλευσης υποστηρίζονται μέσω του `switch_frame`· τα iframes διαφορετικής προέλευσης δεν είναι προσβάσιμα λόγω περιορισμών ασφαλείας του προγράμματος περιήγησης
-   **Μεταφόρτωση αρχείων:** Δεν υποστηρίζεται άμεσα μέσω εργαλείων
-   **Ήχος/Βίντεο:** Δεν είναι δυνατή η αλληλεπίδραση με την αναπαραγωγή πολυμέσων
-   **Επεκτάσεις προγράμματος περιήγησης:** Δεν υποστηρίζονται

### Μπορώ να το χρησιμοποιήσω για δοκιμές παραγωγής;

Το WebdriverIO MCP έχει σχεδιαστεί για διαδραστική αυτοματοποίηση με τη βοήθεια τεχνητής νοημοσύνης. Για δοκιμές παραγωγής σε CI/CD, εξετάστε τη χρήση του παραδοσιακού test runner του WebdriverIO με πλήρη προγραμματιστικό έλεγχο.

## Ασφάλεια

### Είναι ασφαλή τα δεδομένα μου;

Ο διακομιστής MCP εκτελείται τοπικά στον υπολογιστή σας. Όλη η αυτοματοποίηση γίνεται μέσω τοπικών συνδέσεων προγράμματος περιήγησης/Appium. Δεν αποστέλλονται δεδομένα σε εξωτερικούς διακομιστές πέρα από όσους πλοηγείστε ρητά.

Όταν χρησιμοποιείτε τη λειτουργία μεταφοράς HTTP (`--http`), ο διακομιστής από προεπιλογή δέχεται συνδέσεις μόνο από το `localhost`· χρησιμοποιήστε τα `--allowedHosts` και `--allowedOrigins` για να ελέγξετε την πρόσβαση. Δείτε το [Transport](./transport) για λεπτομέρειες.

### Μπορεί το Claude να έχει πρόσβαση στους κωδικούς πρόσβασής μου;

Το Claude μπορεί να δει το περιεχόμενο της σελίδας και να αλληλεπιδράσει με στοιχεία, αλλά:
-   Οι κωδικοί πρόσβασης σε πεδία `<input type="password">` είναι κρυμμένοι
-   Θα πρέπει να αποφεύγετε την αυτοματοποίηση ευαίσθητων διαπιστευτηρίων
-   Χρησιμοποιήστε δοκιμαστικούς λογαριασμούς για την αυτοματοποίηση
