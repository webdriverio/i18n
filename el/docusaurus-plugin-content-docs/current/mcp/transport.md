Ο διακομιστής MCP του WebdriverIO υποστηρίζει δύο λειτουργίες μεταφοράς: **stdio** (προεπιλογή) και **HTTP**.

## stdio (προεπιλογή)

Το stdio είναι η τυπική μεταφορά MCP. Ο πελάτης AI εκκινεί τον διακομιστή ως θυγατρική διεργασία και επικοινωνεί μέσω stdin/stdout.

```json
{
  "mcpServers": {
    "webdriverio": {
      "command": "npx",
      "args": ["-y", "@wdio/mcp"]
    }
  }
}
```

Χρησιμοποιήστε το stdio για τοπικές ρυθμίσεις με το Claude Desktop, το Claude Code, το Cursor και παρόμοιους πελάτες που διαχειρίζονται οι ίδιοι τον κύκλο ζωής του διακομιστή.

## HTTP (Streamable HTTP)

Η λειτουργία HTTP εκτελεί τον διακομιστή ως αυτόνομη διεργασία που ακούει σε μια θύρα. Οι πελάτες συνδέονται σε αυτόν μέσω HTTP αντί να τον εκκινούν ως υποδιεργασία. Χρησιμοποιήστε τη όταν:

- Ο πελάτης σας δεν υποστηρίζει MCP βασισμένο σε υποδιεργασίες (π.χ. το web UI του llama.cpp)
- Θέλετε να μοιράζεστε ένα στιγμιότυπο διακομιστή μεταξύ πολλών πελατών
- Εκτελείτε σε ασφαλή λειτουργία (secure mode) του Codex, όπου η εκτέλεση υποδιεργασιών είναι περιορισμένη
- Θέλετε ο διακομιστής να παραμένει σε λειτουργία μεταξύ πολλαπλών συνεδριών πελατών

### Εκκίνηση σε λειτουργία HTTP

```bash
npx @wdio/mcp --http --port 3000
```

Ο διακομιστής εκθέτει ένα μοναδικό endpoint: `http://localhost:<port>/mcp`

### Πλήρεις επιλογές

```bash
npx @wdio/mcp --http \
  --port 3000 \
  --allowedHosts "localhost,127.0.0.1,::1" \
  --allowedOrigins "http://localhost:5173,https://myapp.example.com"
```

| Σημαία             | Προεπιλογή                  | Περιγραφή                                                                       |
| ------------------ | --------------------------- | ------------------------------------------------------------------------------- |
| `--http`           | —                           | Ενεργοποίηση λειτουργίας μεταφοράς HTTP                                         |
| `--port`           | `3000`                      | Θύρα ακρόασης                                                                   |
| `--allowedHosts`   | `localhost,127.0.0.1,::1`   | Επιτρεπόμενες τιμές κεφαλίδας `Host`, διαχωρισμένες με κόμμα (προστασία από DNS rebinding) |
| `--allowedOrigins` | _(καμία — οι browsers αποκλείονται)_ | Επιτρεπόμενες τιμές `Origin` για CORS, διαχωρισμένες με κόμμα. Χρησιμοποιήστε `*` για να επιτρέψετε όλες τις προελεύσεις. |

### Ασφάλεια

**`--allowedHosts`** — Προστατεύει από επιθέσεις DNS rebinding. Γίνονται δεκτά μόνο αιτήματα με κεφαλίδα `Host` που ταιριάζει με αυτή τη λίστα. Η προεπιλογή (`localhost,127.0.0.1,::1`) είναι ασφαλής για τοπική χρήση. Αν εκθέσετε τον διακομιστή σε δημόσια διεπαφή, προσθέστε εδώ το όνομα του host σας.

**`--allowedOrigins`** — Ελέγχει ποιες προελεύσεις browser μπορούν να κάνουν αιτήματα διασταυρούμενης προέλευσης (CORS). Από προεπιλογή, δεν επιτρέπεται καμία προέλευση browser. Αυτό αποκλείει την πρόσβαση από αυθαίρετους ιστότοπους, ενώ εξακολουθεί να επιτρέπει πελάτες εκτός browser (εργαλεία CLI, πελάτες API). Ορίστε σε `*` για να επιτρέψετε όλες τις προελεύσεις ή απαριθμήστε συγκεκριμένες προελεύσεις.

Τα αιτήματα από πελάτες εκτός browser (χωρίς κεφαλίδα `Origin`) δεν υπόκεινται στον έλεγχο CORS· ισχύει μόνο το `--allowedHosts`.

## Περιπτώσεις χρήσης

### Web UI του llama.cpp

Το web UI του llama.cpp εκτελείται στον browser και στέλνει κεφαλίδα `Origin` σε κάθε αίτημα. Εκκινήστε τον διακομιστή με `--allowedOrigins` που να ταιριάζει με την προέλευση του UI:

```bash
# llama.cpp web UI runs at http://localhost:8080
npx @wdio/mcp --http --port 3000 --allowedOrigins "http://localhost:8080"

# Or allow all local origins
npx @wdio/mcp --http --port 3000 --allowedOrigins "*"
```

Στις ρυθμίσεις του llama.cpp, προσθέστε έναν διακομιστή MCP που να δείχνει στο `http://localhost:3000/mcp`.

---

### Ασφαλής λειτουργία του Codex

Το OpenAI Codex εκτελείται σε απομονωμένο περιβάλλον (sandbox) χωρίς υποστήριξη υποδιεργασιών. Χρησιμοποιήστε τη μεταφορά HTTP ώστε το Codex να μπορεί να προσεγγίσει τον διακομιστή MCP που εκτελείται στο μηχάνημα host σας:

```bash
# Start on your host
npx @wdio/mcp --http --port 3000
```

Στη ρύθμιση MCP του Codex, ορίστε το URL του διακομιστή σε `http://localhost:3000/mcp` (ή στη διεύθυνση IP του host σας, αν το Codex εκτελείται σε VM).

---

### Αρχιτεκτονική ανά αίτημα

Κάθε αίτημα HTTP δημιουργεί ένα νέο στιγμιότυπο διακομιστή MCP. Αυτό σημαίνει ότι:

- Οι πελάτες μπορούν να επανασυνδεθούν μετά από απώλεια σύνδεσης χωρίς σφάλματα.
- Πολλοί πελάτες μπορούν να συνδεθούν ταυτόχρονα (ο καθένας λαμβάνει ανεξάρτητη συνεδρία MCP).
- Η κατάσταση της συνεδρίας (ο ενεργός browser/εφαρμογή) μοιράζεται μέσω καθολικής κατάστασης, όχι μέσω της κατάστασης της μεταφοράς.

Δεν υπάρχει mutex· τα αιτήματα εξυπηρετούνται ταυτόχρονα. Η διατήρηση κατάστασης του πρωτοκόλλου MCP (initialize → κλήσεις εργαλείων) διαχειρίζεται ανά αίτημα.
