Αυτό το σεμινάριο απευθύνεται σε όσους χρησιμοποιούν το Protractor και θέλουν να μεταφέρουν το framework τους στο WebdriverIO. Ξεκίνησε αφότου η ομάδα του Angular [ανακοίνωσε](https://github.com/angular/protractor/issues/5502) ότι το Protractor δεν θα υποστηρίζεται πλέον. Το WebdriverIO έχει επηρεαστεί από πολλές σχεδιαστικές αποφάσεις του Protractor, γι' αυτό είναι πιθανώς το πιο κοντινό framework για να μεταβεί κανείς. Η ομάδα του WebdriverIO εκτιμά τη δουλειά κάθε συνεισφέροντα του Protractor και ελπίζει ότι αυτό το σεμινάριο θα κάνει τη μετάβαση στο WebdriverIO εύκολη και απλή.

Παρόλο που θα θέλαμε πολύ να έχουμε μια πλήρως αυτοματοποιημένη διαδικασία για αυτό, η πραγματικότητα είναι διαφορετική. Ο καθένας έχει διαφορετική ρύθμιση και χρησιμοποιεί το Protractor με διαφορετικούς τρόπους. Κάθε βήμα θα πρέπει να θεωρείται περισσότερο ως καθοδήγηση και λιγότερο ως οδηγία βήμα προς βήμα. Αν αντιμετωπίσετε προβλήματα με τη μετάβαση, μη διστάσετε να [επικοινωνήσετε μαζί μας](https://github.com/webdriverio/codemod/discussions/new).

## Ρύθμιση

Τα API του Protractor και του WebdriverIO είναι στην πραγματικότητα πολύ παρόμοια, σε σημείο που η πλειονότητα των εντολών μπορεί να ξαναγραφτεί με αυτοματοποιημένο τρόπο μέσω ενός [codemod](https://github.com/webdriverio/codemod).

Για να εγκαταστήσετε το codemod, εκτελέστε:

```sh
npm install jscodeshift @wdio/codemod
```

## Στρατηγική

Υπάρχουν πολλές στρατηγικές μετάβασης. Ανάλογα με το μέγεθος της ομάδας σας, τον αριθμό των αρχείων δοκιμών και τον βαθμό επείγοντος της μετάβασης, μπορείτε να δοκιμάσετε να μετατρέψετε όλες τις δοκιμές ταυτόχρονα ή αρχείο προς αρχείο. Δεδομένου ότι το Protractor θα συνεχίσει να συντηρείται μέχρι την έκδοση 15 του Angular (τέλος του 2022), έχετε ακόμα αρκετό χρόνο. Μπορείτε να εκτελείτε δοκιμές Protractor και WebdriverIO ταυτόχρονα και να αρχίσετε να γράφετε νέες δοκιμές στο WebdriverIO. Ανάλογα με τον διαθέσιμο χρόνο σας, μπορείτε στη συνέχεια να ξεκινήσετε μεταφέροντας πρώτα τις σημαντικές περιπτώσεις δοκιμών και να προχωρήσετε σταδιακά προς δοκιμές που ίσως μπορείτε ακόμα και να διαγράψετε.

## Πρώτα το Αρχείο Διαμόρφωσης

Αφού εγκαταστήσουμε το codemod, μπορούμε να ξεκινήσουμε τη μετατροπή του πρώτου αρχείου. Ρίξτε πρώτα μια ματιά στις [επιλογές διαμόρφωσης του WebdriverIO](configuration). Τα αρχεία διαμόρφωσης μπορεί να γίνουν πολύ σύνθετα και ίσως είναι λογικό να μεταφέρετε μόνο τα βασικά μέρη και να δείτε πώς μπορούν να προστεθούν τα υπόλοιπα μόλις μεταφερθούν οι αντίστοιχες δοκιμές που χρειάζονται συγκεκριμένες επιλογές.

Για την πρώτη μετάβαση μετατρέπουμε μόνο το αρχείο διαμόρφωσης και εκτελούμε:

```sh
npx jscodeshift -t ./node_modules/@wdio/codemod/protractor ./conf.ts
```

:::info

 Το αρχείο διαμόρφωσής σας μπορεί να έχει διαφορετικό όνομα, ωστόσο η αρχή θα πρέπει να είναι η ίδια: ξεκινήστε τη μετάβαση πρώτα από τη διαμόρφωση.

:::

## Εγκατάσταση Εξαρτήσεων του WebdriverIO

Το επόμενο βήμα είναι να διαμορφώσουμε μια ελάχιστη ρύθμιση του WebdriverIO, την οποία θα επεκτείνουμε καθώς μεταβαίνουμε από το ένα framework στο άλλο. Πρώτα εγκαθιστούμε το WebdriverIO CLI μέσω:

```sh
npm install --save-dev @wdio/cli
```

Στη συνέχεια εκτελούμε τον οδηγό διαμόρφωσης:

```sh
npx wdio config
```

Αυτός θα σας καθοδηγήσει μέσα από μερικές ερωτήσεις. Για αυτό το σενάριο μετάβασης:
- επιλέξτε τις προεπιλεγμένες επιλογές
- συνιστούμε να μην δημιουργηθούν αυτόματα αρχεία παραδειγμάτων
- επιλέξτε διαφορετικό φάκελο για τα αρχεία του WebdriverIO
- και επιλέξτε το Mocha αντί του Jasmine.

:::info Γιατί Mocha;
Παρόλο που μπορεί να χρησιμοποιούσατε το Protractor με το Jasmine στο παρελθόν, το Mocha παρέχει καλύτερους μηχανισμούς επανάληψης. Η επιλογή είναι δική σας!
:::

Μετά το σύντομο ερωτηματολόγιο, ο οδηγός θα εγκαταστήσει όλα τα απαραίτητα πακέτα και θα τα αποθηκεύσει στο `package.json` σας.

## Μετάβαση του Αρχείου Διαμόρφωσης

Αφού έχουμε ένα μετατρεπμένο `conf.ts` και ένα νέο `wdio.conf.ts`, είναι πλέον ώρα να μεταφέρουμε τη διαμόρφωση από το ένα αρχείο στο άλλο. Βεβαιωθείτε ότι μεταφέρετε μόνο κώδικα που είναι απαραίτητος για να μπορούν να εκτελεστούν όλες οι δοκιμές. Στη δική μας περίπτωση μεταφέρουμε τη συνάρτηση hook και το timeout του framework.

Από εδώ και πέρα θα συνεχίσουμε μόνο με το αρχείο `wdio.conf.ts` και επομένως δεν θα χρειαστούμε πλέον αλλαγές στην αρχική διαμόρφωση του Protractor. Μπορούμε να τις αναιρέσουμε ώστε και τα δύο frameworks να μπορούν να εκτελούνται παράλληλα και να μεταφέρουμε ένα αρχείο τη φορά.

## Μετάβαση Αρχείου Δοκιμών

Είμαστε πλέον έτοιμοι να μεταφέρουμε το πρώτο αρχείο δοκιμών. Για να ξεκινήσουμε απλά, ας ξεκινήσουμε με ένα που δεν έχει πολλές εξαρτήσεις από πακέτα τρίτων ή άλλα αρχεία όπως PageObjects. Στο παράδειγμά μας, το πρώτο αρχείο προς μετάβαση είναι το `first-test.spec.ts`. Πρώτα δημιουργήστε τον κατάλογο όπου η νέα διαμόρφωση του WebdriverIO αναμένει τα αρχεία της και στη συνέχεια μετακινήστε το εκεί:

```sh
mv mkdir -p ./test/specs/
mv test-suites/first-test.spec.ts ./test/specs
```

Τώρα ας μετατρέψουμε αυτό το αρχείο:

```sh
npx jscodeshift -t ./node_modules/@wdio/codemod/protractor ./test/specs/first-test.spec.ts
```

Αυτό ήταν! Αυτό το αρχείο είναι τόσο απλό που δεν χρειαζόμαστε πλέον καμία επιπλέον αλλαγή και μπορούμε να δοκιμάσουμε απευθείας να εκτελέσουμε το WebdriverIO μέσω:

```sh
npx wdio run wdio.conf.ts
```

Συγχαρητήρια 🥳 μόλις μεταφέρατε το πρώτο αρχείο!

## Επόμενα Βήματα

Από αυτό το σημείο συνεχίζετε να μετατρέπετε δοκιμή προς δοκιμή και page object προς page object. Υπάρχει πιθανότητα το codemod να αποτύχει για ορισμένα αρχεία με ένα σφάλμα όπως:

```
ERR /path/to/project/test/testdata/failing_submit.js Transformation error (Error transforming /test/testdata/failing_submit.js:2)
Error transforming /test/testdata/failing_submit.js:2

> login_form.submit()
  ^

The command "submit" is not supported in WebdriverIO. We advise to use the click command to click on the submit button instead. For more information on this configuration, see https://webdriver.io/docs/api/element/click.
  at /path/to/project/test/testdata/failing_submit.js:132:0
```

Για ορισμένες εντολές του Protractor απλώς δεν υπάρχει αντικατάσταση στο WebdriverIO. Σε αυτή την περίπτωση το codemod θα σας δώσει κάποιες συμβουλές για το πώς να τις αναδιαμορφώσετε. Αν συναντάτε τέτοια μηνύματα σφάλματος πολύ συχνά, μη διστάσετε να [ανοίξετε ένα issue](https://github.com/webdriverio/codemod/issues/new) και να ζητήσετε την προσθήκη μιας συγκεκριμένης μετατροπής. Παρόλο που το codemod ήδη μετατρέπει την πλειονότητα του API του Protractor, υπάρχει ακόμα πολύ περιθώριο για βελτιώσεις.

## Συμπέρασμα

Ελπίζουμε ότι αυτό το σεμινάριο σας καθοδηγεί λίγο στη διαδικασία μετάβασης στο WebdriverIO. Η κοινότητα συνεχίζει να βελτιώνει το codemod, δοκιμάζοντάς το με διάφορες ομάδες σε διάφορους οργανισμούς. Μη διστάσετε να [ανοίξετε ένα issue](https://github.com/webdriverio/codemod/issues/new) αν έχετε σχόλια ή να [ξεκινήσετε μια συζήτηση](https://github.com/webdriverio/codemod/discussions/new) αν δυσκολεύεστε κατά τη διαδικασία μετάβασης.
