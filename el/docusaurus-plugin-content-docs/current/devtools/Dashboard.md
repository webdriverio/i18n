Η λειτουργία Live ανοίγει το DevTools UI σε ένα εξωτερικό παράθυρο προγράμματος περιήγησης και μεταδίδει την εκτέλεση των δοκιμών σας σε πραγματικό χρόνο. Αποτελεί τη διαδραστική αντίστοιχη λειτουργία του [Trace Mode](/docs/devtools/wdio/trace-mode), το οποίο παραλείπει το UI και αντ' αυτού γράφει ένα φορητό αρχείο για χρήση εκτός σύνδεσης. Η λειτουργία Live είναι ενεργοποιημένη από προεπιλογή (`mode: 'live'`), επομένως η απλή εκτέλεση των δοκιμών σας WebdriverIO εκκινεί τον πίνακα ελέγχου.

Όταν εκτελείτε τις δοκιμές σας, το DevTools UI ανοίγει αυτόματα σε ένα εξωτερικό παράθυρο προγράμματος περιήγησης και οι δοκιμές αρχίζουν να εκτελούνται αμέσως με οπτικοποίηση σε πραγματικό χρόνο. Μετά την ολοκλήρωση της αρχικής εκτέλεσης, χρησιμοποιήστε τα κουμπιά αναπαραγωγής για να επανεκτελέσετε μεμονωμένες δοκιμές ή σουίτες και το κουμπί διακοπής για να τερματίσετε τις δοκιμές που εκτελούνται οποιαδήποτε στιγμή.

## Τι εμφανίζει ο πίνακας ελέγχου

- **Ζωντανή προεπισκόπηση προγράμματος περιήγησης** — παρακολουθήστε το πρόγραμμα περιήγησης υπό δοκιμή καθώς εκτελούνται οι εντολές.
- **Πρόοδος δοκιμών** — οι σουίτες και οι δοκιμές ενημερώνονται καθώς εκτελούνται.
- **Εκτέλεση εντολών** — κάθε ενέργεια εμφανίζεται τη στιγμή που συμβαίνει.
- **Καρτέλες Workbench** — εξερευνήστε τις καρτέλες Actions, Console, Network, Metadata και Source για την επιλεγμένη δοκιμή.

## Δυνατότητες της λειτουργίας Live

- **[Διαδραστική επανεκτέλεση & οπτικοποίηση δοκιμών](/docs/devtools/wdio/interactive-test-rerunning)** — Προεπισκοπήσεις προγράμματος περιήγησης σε πραγματικό χρόνο με επανεκτέλεση δοκιμών
- **[Διατήρηση & επανεκτέλεση (Σύγκριση)](/docs/devtools/wdio/preserve-and-rerun)** — Αποθηκεύστε ένα στιγμιότυπο μιας αποτυχημένης δοκιμής, επανεκτελέστε την και συγκρίνετε τις δύο εκτελέσεις δίπλα-δίπλα
- **[Αρχεία καταγραφής κονσόλας](/docs/devtools/wdio/console-logs)** — Καταγράψτε και επιθεωρήστε την έξοδο της κονσόλας του προγράμματος περιήγησης
- **[Αρχεία καταγραφής δικτύου](/docs/devtools/wdio/network-logs)** — Παρακολουθήστε κλήσεις API και τη δραστηριότητα δικτύου
- **[Μεταδεδομένα](/docs/devtools/wdio/metadata)** — Δυνατότητες συνεδρίας, περιβάλλον και χρονισμοί ανά συνεδρία προγράμματος περιήγησης
- **[TestLens](/docs/devtools/wdio/testlens)** — Μεταβείτε στον πηγαίο κώδικα με έξυπνη πλοήγηση κώδικα
- **[Υποστήριξη πολλαπλών frameworks](/docs/devtools/wdio/multi-framework-support)** — Λειτουργεί με Mocha, Jasmine και Cucumber
- **[Εγγραφή οθόνης συνεδρίας](/docs/devtools/wdio/screencast)** — Αυτόματη εγγραφή βίντεο των συνεδριών του προγράμματος περιήγησης

## Διαμόρφωση του παραθύρου του πίνακα ελέγχου

Οι επιλογές `port`, `hostname` και `devtoolsCapabilities` ελέγχουν τον διακομιστή του DevTools UI και το παράθυρο στο οποίο ανοίγει. Δείτε την [Αναφορά διαμόρφωσης](/docs/devtools/reference) για λεπτομέρειες.

## Εκτέλεση του backend αυτόνομα

Οι adapters εκκινούν τον διακομιστή του πίνακα ελέγχου εντός της ίδιας διεργασίας, οπότε κανονικά δεν χρειάζεται ποτέ να ασχοληθείτε μαζί του. Διατίθεται επίσης ως αυτόνομο εκτελέσιμο, κάτι που χρειάζεστε όταν ο πίνακας ελέγχου πρέπει να παραμείνει ενεργός πέρα από μία μόνο εκτέλεση - ή όταν οι δοκιμές δεν είναι γραμμένες σε JavaScript, όπως με τον adapter για Python (δείτε τη σελίδα [Selenium](/docs/devtools/selenium)).

```bash
npx @wdio/devtools-backend
```

```
Usage: devtools-backend [options]

Options:
  --port <number>     Preferred port; a free one is chosen if it is taken
  --hostname <host>   Host to bind (default: localhost)
  -h, --help          Show this message
```

Το `--port` είναι μια *προτίμηση*, όχι μια εγγύηση: αν η θύρα είναι κατειλημμένη, ο διακομιστής δεσμεύει μια ελεύθερη αντί να αποτύχει. Εκτυπώνει τη θύρα που πραγματικά δέσμευσε, και αυτή είναι η γραμμή που πρέπει να διαβάσετε αντί για τη θύρα που ζητήσατε:

```
devtools-backend listening at http://localhost:3000
```

Κατευθύνετε μια εκτέλεση σε έναν διακομιστή που ήδη ακούει με τη μεταβλητή `DEVTOOLS_PORT` (την υποστηρίζουν όλοι οι adapters), και η εκτέλεση θα συνδεθεί σε αυτόν αντί να εκκινήσει δεύτερο.

Ένα δεύτερο εκτελέσιμο, το `show-trace`, ανοίγει ένα αρχείο trace στον player εκτός σύνδεσης - δείτε το [Trace Player](/docs/devtools/trace-player).
