Παρακολουθήστε τα τεστ σας να εκτελούνται σε πραγματικό χρόνο με ζωντανή προεπισκόπηση του browser και αυτόματα στιγμιότυπα οθόνης που καταγράφονται μετά από κάθε εντολή WebDriver. Το UI εμφανίζει ένα πλήρες οπτικό χρονολόγιο της εκτέλεσης των τεστ σας, δείχνοντας την ακριβή κατάσταση του browser σε κάθε βήμα.

Μόλις ολοκληρωθεί η αρχική εκτέλεση των τεστ, κάντε κλικ σε οποιοδήποτε test case ή suite στο UI των DevTools για να το επανεκτελέσετε αμέσως. Έτσι δεν χρειάζεται να επανεκκινήσετε ολόκληρο τον test runner ή να τροποποιήσετε τον κώδικά σας, επιταχύνοντας σημαντικά τους κύκλους αποσφαλμάτωσης.

**Βασικά Χαρακτηριστικά:**
- **Οπτικοποίηση σε πραγματικό χρόνο** - Αυτόματη λήψη στιγμιότυπου οθόνης μετά από κάθε εντολή (click, toBeExisting κ.λπ.)
- **Ζωντανή προεπισκόπηση browser** - Δείτε την τρέχουσα κατάσταση της εφαρμογής σας κατά την εκτέλεση των τεστ
- **Χρονολόγιο εντολών** - Δείτε λεπτομερή logs με χρονοσημάνσεις για κάθε ενέργεια
- **Διαδραστική επανεκτέλεση** - Κάντε κλικ σε οποιοδήποτε τεστ ή suite για να το επανεκτελέσετε αμέσως
- **Εκτέλεση στην ίδια συνεδρία** - Τα τεστ επανεκτελούνται στην ίδια συνεδρία του browser για ταχύτερη ανατροφοδότηση
- **Ιστορικό με δυνατότητα κύλισης** - Επανεξετάστε οποιοδήποτε σημείο της εκτέλεσης των τεστ
