Καταγράψτε και επιθεωρήστε όλη την έξοδο της κονσόλας του προγράμματος περιήγησης κατά την εκτέλεση των δοκιμών. Το DevTools καταγράφει μηνύματα κονσόλας από την εφαρμογή σας (`console.log()`, `console.warn()`, `console.error()`, `console.info()`, `console.debug()`) καθώς και καταγραφές του framework WebDriverIO με βάση το `logLevel` που έχει ρυθμιστεί στο `wdio.conf.ts` σας.

**Χαρακτηριστικά:**
- Καταγραφή μηνυμάτων κονσόλας σε πραγματικό χρόνο κατά την εκτέλεση των δοκιμών
- Καταγραφές κονσόλας του προγράμματος περιήγησης (log, warn, error, info, debug)
- Καταγραφές του framework WebDriverIO φιλτραρισμένες βάσει του ρυθμισμένου `logLevel` (trace, debug, info, warn, error, silent)
- Χρονοσφραγίδες που δείχνουν ακριβώς πότε καταγράφηκε κάθε μήνυμα
- Οι καταγραφές κονσόλας εμφανίζονται δίπλα στα βήματα των δοκιμών και στα στιγμιότυπα οθόνης του προγράμματος περιήγησης για καλύτερη κατανόηση του πλαισίου

**Διαμόρφωση:**
```js
// wdio.conf.ts
export const config = {
    // Επίπεδο λεπτομέρειας καταγραφής: trace | debug | info | warn | error | silent
    logLevel: 'info', // Ελέγχει ποιες καταγραφές του framework καταγράφονται
    // ...
};
```

Αυτό διευκολύνει την αποσφαλμάτωση σφαλμάτων JavaScript, την παρακολούθηση της συμπεριφοράς της εφαρμογής και την προβολή των εσωτερικών λειτουργιών του WebDriverIO κατά την εκτέλεση των δοκιμών.
