Παρακολουθήστε και επιθεωρήστε όλη τη δραστηριότητα δικτύου κατά τη διάρκεια των tests σας. Τα DevTools καταγράφουν κάθε αίτημα και απόκριση HTTP, προσφέροντάς σας πλήρη ορατότητα στις κλήσεις API, στη φόρτωση πόρων και στους χρόνους δικτύου - ακριβώς όπως τα DevTools του browser.

**Τι καταγράφεται:**
- **Λεπτομέρειες αιτήματος** - URL, μέθοδος, headers, παράμετροι query, σώμα αιτήματος
- **Δεδομένα απόκρισης** - Κωδικός κατάστασης, headers απόκρισης, σώμα απόκρισης, χρονισμός
- **Τύποι πόρων** - Αιτήματα XHR/Fetch, scripts, stylesheets, εικόνες και άλλα
- **Μετρικές απόδοσης** - Χρονισμός αιτημάτων, διάρκεια και network waterfall

Αυτό είναι ανεκτίμητο για το debugging προβλημάτων API, τον εντοπισμό αργών αιτημάτων, την επικύρωση των data payloads και την κατανόηση της συμπεριφοράς δικτύου της εφαρμογής σας κατά τη διάρκεια των tests.
