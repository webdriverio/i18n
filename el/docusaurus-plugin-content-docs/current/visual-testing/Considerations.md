# Βασικά σημεία προσοχής για βέλτιστη χρήση

Πριν εμβαθύνετε στις ισχυρές δυνατότητες του `@wdio/visual-service`, είναι σημαντικό να κατανοήσετε ορισμένα βασικά σημεία που διασφαλίζουν ότι θα αξιοποιήσετε στο έπακρο αυτό το εργαλείο. Τα παρακάτω σημεία έχουν σχεδιαστεί για να σας καθοδηγήσουν στις βέλτιστες πρακτικές και στις συνήθεις παγίδες, βοηθώντας σας να επιτύχετε ακριβή και αποδοτικά αποτελέσματα οπτικών τεστ. Αυτά τα σημεία δεν είναι απλώς συστάσεις, αλλά ουσιώδεις πτυχές που πρέπει να έχετε υπόψη για την αποτελεσματική χρήση της υπηρεσίας σε πραγματικά σενάρια.

## Φύση της σύγκρισης

-   **Αντιληπτική σύγκριση:** Η μονάδα εκτελεί μια αντιληπτική σύγκριση εικόνων σε επίπεδο pixel χρησιμοποιώντας τον χρωματικό χώρο YIQ, ο οποίος ανταποκρίνεται περισσότερο στον τρόπο με τον οποίο οι άνθρωποι αντιλαμβάνονται τις διαφορές χρωμάτων. Ορισμένες πτυχές μπορούν να προσαρμοστούν μέσω των [Επιλογών σύγκρισης](./compare-options).
-   **Επίδραση των ενημερώσεων του browser:** Λάβετε υπόψη ότι οι ενημερώσεις των browsers, όπως του Chrome, μπορεί να επηρεάσουν την απόδοση των γραμματοσειρών, κάτι που ενδεχομένως να απαιτήσει ενημέρωση των baseline εικόνων σας.

## Συνέπεια στις πλατφόρμες

-   **Σύγκριση ίδιων πλατφορμών:** Βεβαιωθείτε ότι τα στιγμιότυπα οθόνης συγκρίνονται στην ίδια πλατφόρμα. Για παράδειγμα, ένα στιγμιότυπο από το Chrome σε Mac δεν πρέπει να συγκρίνεται με ένα από το Chrome σε Ubuntu ή Windows.
-   **Αναλογία:** Με απλά λόγια, συγκρίνετε _'Μήλα με Μήλα, όχι Μήλα με Androids'_.

## Προσοχή με το ποσοστό απόκλισης

-   **Κίνδυνος αποδοχής αποκλίσεων:** Να είστε προσεκτικοί όταν αποδέχεστε ένα ποσοστό απόκλισης. Αυτό ισχύει ιδιαίτερα για μεγάλα στιγμιότυπα οθόνης, όπου η αποδοχή μιας απόκλισης μπορεί ακούσια να παραβλέψει σημαντικές διαφορές, όπως κουμπιά ή στοιχεία που λείπουν.

## Προσομοίωση οθόνης κινητού

-   **Αποφύγετε την αλλαγή μεγέθους του browser για προσομοίωση κινητού:** Μην επιχειρείτε να προσομοιώσετε μεγέθη οθόνης κινητών αλλάζοντας το μέγεθος των desktop browsers και αντιμετωπίζοντάς τους ως mobile browsers. Οι desktop browsers, ακόμη και όταν αλλάζει το μέγεθός τους, δεν αναπαράγουν με ακρίβεια την απόδοση των πραγματικών mobile browsers.
-   **Αυθεντικότητα στη σύγκριση:** Αυτό το εργαλείο στοχεύει στη σύγκριση των οπτικών στοιχείων όπως θα εμφανίζονταν σε έναν τελικό χρήστη. Ένας desktop browser με αλλαγμένο μέγεθος δεν αντικατοπτρίζει την πραγματική εμπειρία σε μια κινητή συσκευή.

## Θέση σχετικά με τους headless browsers

-   **Δεν συνιστάται για headless browsers:** Η χρήση αυτής της μονάδας με headless browsers δεν συνιστάται. Ο λόγος είναι ότι οι τελικοί χρήστες δεν αλληλεπιδρούν με headless browsers, και επομένως ζητήματα που προκύπτουν από μια τέτοια χρήση δεν θα υποστηρίζονται.
