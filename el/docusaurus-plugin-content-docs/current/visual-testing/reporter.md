Το Visual Reporter είναι ένα νέο χαρακτηριστικό που εισήχθη στο `@wdio/visual-service`, ξεκινώντας από την έκδοση [v5.2.0](https://github.com/webdriverio/visual-testing/releases/tag/%40wdio%2Fvisual-service%405.2.0). Αυτός ο reporter επιτρέπει στους χρήστες να οπτικοποιούν τις αναφορές διαφορών JSON που δημιουργούνται από την υπηρεσία Visual Testing και να τις μετατρέπουν σε μια μορφή αναγνώσιμη από τον άνθρωπο. Βοηθά τις ομάδες να αναλύουν και να διαχειρίζονται καλύτερα τα αποτελέσματα των οπτικών δοκιμών, παρέχοντας ένα γραφικό περιβάλλον για την εξέταση της εξόδου.

Για να χρησιμοποιήσετε αυτό το χαρακτηριστικό, βεβαιωθείτε ότι έχετε την απαιτούμενη διαμόρφωση για τη δημιουργία του απαραίτητου αρχείου `output.json`. Αυτό το έγγραφο θα σας καθοδηγήσει στη ρύθμιση, την εκτέλεση και την κατανόηση του Visual Reporter.

# Προαπαιτούμενα

Πριν χρησιμοποιήσετε το Visual Reporter, βεβαιωθείτε ότι έχετε διαμορφώσει την υπηρεσία Visual Testing ώστε να δημιουργεί αρχεία αναφοράς JSON:

```ts
export const config = {
    // ...
    services: [
        [
            "visual",
            {
                createJsonReportFiles: true, // Δημιουργεί το αρχείο output.json
            },
        ],
    ],
};
```

Για πιο λεπτομερείς οδηγίες ρύθμισης, ανατρέξτε στην [Τεκμηρίωση Visual Testing](./) του WebdriverIO ή στο [`createJsonReportFiles`](./service-options.md#createjsonreportfiles-new)

# Εγκατάσταση

Για να εγκαταστήσετε το Visual Reporter, προσθέστε το ως εξάρτηση ανάπτυξης (development dependency) στο έργο σας χρησιμοποιώντας το npm:

```bash
npm install @wdio/visual-reporter --save-dev
```

Αυτό θα διασφαλίσει ότι τα απαραίτητα αρχεία είναι διαθέσιμα για τη δημιουργία αναφορών από τις οπτικές δοκιμές σας.

# Χρήση

## Δημιουργία της Οπτικής Αναφοράς

Αφού εκτελέσετε τις οπτικές δοκιμές σας και αυτές δημιουργήσουν το αρχείο `output.json`, μπορείτε να δημιουργήσετε την οπτική αναφορά χρησιμοποιώντας είτε το CLI είτε τις διαδραστικές ερωτήσεις (interactive prompts).

### Χρήση μέσω CLI

Μπορείτε να χρησιμοποιήσετε την εντολή CLI για να δημιουργήσετε την αναφορά εκτελώντας:

```bash
npx wdio-visual-reporter --jsonOutput=<path-to-output.json> --reportFolder=<path-to-store-report> --logLevel=debug
```

#### Υποχρεωτικές επιλογές:

-   `--jsonOutput`: Η σχετική διαδρομή προς το αρχείο `output.json` που δημιουργήθηκε από την υπηρεσία Visual Testing. Αυτή η διαδρομή είναι σχετική με τον κατάλογο από τον οποίο εκτελείτε την εντολή.
-   `--reportFolder`: Ο σχετικός κατάλογος όπου θα αποθηκευτεί η παραγόμενη αναφορά. Αυτή η διαδρομή είναι επίσης σχετική με τον κατάλογο από τον οποίο εκτελείτε την εντολή.

#### Προαιρετικές επιλογές:

-   `--logLevel`: Ορίστε το σε `debug` για να λάβετε λεπτομερή καταγραφή, ιδιαίτερα χρήσιμη για την αντιμετώπιση προβλημάτων.

#### Παράδειγμα

```bash
npx wdio-visual-reporter --jsonOutput=/path/to/output.json --reportFolder=/path/to/report --logLevel=debug
```

Αυτό θα δημιουργήσει την αναφορά στον καθορισμένο φάκελο και θα εμφανίσει μηνύματα στην κονσόλα. Για παράδειγμα:

```bash
✔ Build output copied successfully to "/path/to/report".
⠋ Prepare report assets...
✔ Successfully generated the report assets.
```

#### Προβολή της Αναφοράς

:::warning
Το άνοιγμα του `path/to/report/index.html` απευθείας σε έναν browser **χωρίς να εξυπηρετείται από έναν τοπικό server** **ΔΕΝ** θα λειτουργήσει.
:::

Για να δείτε την αναφορά, πρέπει να χρησιμοποιήσετε έναν απλό server όπως το [sirv-cli](https://www.npmjs.com/package/sirv-cli). Μπορείτε να εκκινήσετε τον server με την ακόλουθη εντολή:

```bash
npx sirv-cli /path/to/report --single
```

Αυτό θα παράγει logs παρόμοια με το παρακάτω παράδειγμα. Σημειώστε ότι ο αριθμός της θύρας μπορεί να διαφέρει:

```logs
  Your application is ready~! 🚀

  - Local:      http://localhost:8080
  - Network:    Add `--host` to expose

────────────────── LOGS ──────────────────
```

Μπορείτε τώρα να δείτε την αναφορά ανοίγοντας το παρεχόμενο URL στον browser σας.

### Χρήση Διαδραστικών Ερωτήσεων

Εναλλακτικά, μπορείτε να εκτελέσετε την ακόλουθη εντολή και να απαντήσετε στις ερωτήσεις για να δημιουργήσετε την αναφορά:

```bash
npx @wdio/visual-reporter
```

Οι ερωτήσεις θα σας καθοδηγήσουν στην παροχή των απαιτούμενων διαδρομών και επιλογών. Στο τέλος, η διαδραστική διαδικασία θα σας ρωτήσει επίσης αν θέλετε να εκκινήσετε έναν server για να δείτε την αναφορά. Αν επιλέξετε να εκκινήσετε τον server, το εργαλείο θα εκκινήσει έναν απλό server και θα εμφανίσει ένα URL στα logs. Μπορείτε να ανοίξετε αυτό το URL στον browser σας για να δείτε την αναφορά.

# Επίδειξη Αναφοράς

Για να δείτε ένα παράδειγμα του πώς φαίνεται η αναφορά, επισκεφθείτε την [επίδειξη στο GitHub Pages](https://webdriverio.github.io/visual-testing/).

# Κατανόηση της Οπτικής Αναφοράς

Το Visual Reporter παρέχει μια οργανωμένη προβολή των αποτελεσμάτων των οπτικών δοκιμών σας. Για κάθε εκτέλεση δοκιμών, θα μπορείτε να:

-   Πλοηγείστε εύκολα μεταξύ των περιπτώσεων δοκιμών και να βλέπετε συγκεντρωτικά αποτελέσματα.
-   Εξετάζετε μεταδεδομένα όπως ονόματα δοκιμών, browsers που χρησιμοποιήθηκαν και αποτελέσματα συγκρίσεων.
-   Βλέπετε εικόνες διαφορών που δείχνουν πού εντοπίστηκαν οπτικές διαφορές.

Αυτή η οπτική αναπαράσταση απλοποιεί την ανάλυση των αποτελεσμάτων των δοκιμών σας, καθιστώντας ευκολότερο τον εντοπισμό και την αντιμετώπιση οπτικών παλινδρομήσεων (visual regressions).
