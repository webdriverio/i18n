O TestLens oferece navegação inteligente de código entre a interface do DevTools e os arquivos-fonte dos seus testes. Clique em qualquer teste na interface para ir diretamente à definição desse teste no seu editor de código, com os números de linha exatos.

**Como funciona:**
- **Hierarquia visual de testes** - Veja a estrutura dos seus testes (suítes, testes, cenários) em uma visualização em árvore
- **Mapeamento de código-fonte** - Cada teste está vinculado à sua localização exata nos seus arquivos-fonte
- **Navegação com um clique** - Clique em qualquer teste para abri-lo no seu editor
- **Integração com editores** - Funciona com editores de código populares por meio de protocolos file:line

Essa conexão perfeita entre a interface e o código acelera a depuração, eliminando a busca manual no código ao investigar falhas de testes.
