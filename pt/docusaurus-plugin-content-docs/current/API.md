Bem-vindo à documentação da API do WebdriverIO. Estas páginas contêm materiais de referência para todos os bindings de protocolo e comandos de conveniência implementados. Comandos de protocolo, incluindo [WebDriver](/docs/api/webdriver), [WebDriver Bidi](/docs/api/webdriverBidi) ou comandos mobile como [Appium](http://appium.io), são comandos enviados diretamente ao backend do driver subjacente. Os comandos de conveniência fornecidos pelos objetos [`browser`](/docs/api/browser), [`element`](/docs/api/element) ou [`mock`](/docs/api/mock) oferecem interatividade de nível mais alto.

:::info
Esta é a documentação do WebdriverIO __v10__. Ainda está na v9? Use a [documentação da v9](https://v9.webdriver.io) ou siga o [guia de migração para a v10](/docs/v10-migration).
:::
